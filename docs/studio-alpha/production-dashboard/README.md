---

## Mission

Studio Alpha™ requires a centralized **Production Dashboard™** that tracks every creative asset, scene, department, package, Blueprint™, generation, cost, and production metric involved in building **Studio World™**.

This dashboard exists **exclusively for internal production**.

Customers should **never** see it.

---

## One Sentence

**Production Dashboard™** answers how much Studio World™ costs to build, what is generating now, what should generate next, and which assets and Blueprints deliver the highest ROI — with full internal provider visibility.

## Boundary Rules

| GPU cost · token usage | Abstract production dollars only |
