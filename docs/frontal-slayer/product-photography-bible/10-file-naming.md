# 10 — File Naming

## Pattern

```
fs-{collection}-{unit-slug}-{asset-type}-v{version}.{ext}
```

## Examples

- `fs-signature-noir-hero-portrait-v1.0.png`
- `fs-signature-blanco-email-crop-v1.0.png`
- `fs-signature-soft-wave-transparent-png-v1.0.png`

## Rules

- Lowercase slugs, hyphen-separated.
- Version matches Photography Bible version (e.g. `1.0`, `1.1`).
- No spaces or special characters in filenames.
- `reference` suffix for unapproved reference captures: `-reference-v1.0.jpg`

## Folder root

`studio-os/product-photography/media-kits/signature-collection/{unit-slug}/{asset-type}/`
