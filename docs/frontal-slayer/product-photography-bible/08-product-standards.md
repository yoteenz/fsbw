## Per-unit requirements

Each unit must have:

- Approved hero portrait (4096×4096 master)
- Reference image on file
- Complete media kit folder structure (empty slots OK until shoot)
- Photography status + media kit status in studio os admin

## Inheritance

Future collections inherit V1.0 camera, lighting, bust, exports, and folder structure. Collection-specific art direction is layered via **templates**, not by bypassing the bible.
