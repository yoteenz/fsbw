# Purpose

Asset Factory is the **production pipeline** for Product Photography Bible assets. The Photography Bible remains the source of truth; Asset Factory transforms approved master hero portraits into production-ready derivatives.

## This milestone

- Brand Assets → **Asset Factory** admin module
- SOFT WAVE proof-of-concept only
- Ideogram background removal (existing Fal integration)
- Sharp-based derivative crops from reusable templates
- Supabase upload + asset registry
- **No** customer-facing website changes
- **No** AI product generation, OpenArt, or Build-A-Wig variant manufacturing

## Not in scope

- Additional Signature units beyond SOFT WAVE
- Automatic storefront wiring (future milestone)
