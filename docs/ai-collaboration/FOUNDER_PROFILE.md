## Working style

- Thinks spatially — prefers Studio World geography over menu metaphors
- Mobile-first for all implementation and verification
- Forensic before repair — prove root cause before masking failures
- One deploy per completed task — no surprise production pushes
- Surgical changes — preserve finalized admin pages unless explicitly named

## Creative philosophy

- Studio OS is a **living headquarters**, not SaaS dashboard software
- Place-driven navigation — every feature needs an address in Studio World
- Graphics-first executive IA — environments, not widget grids
- Canon is sacred — ideas explore freely; production requires explicit promotion

## Decision framework

1. Does it have a home in Studio World?
2. Does Genesis constitution allow it?
3. Is this architecture or implementation? (Separate conversations)
4. What is the smallest correct diff?
5. How do we verify on a real phone in a normal browser tab?

## Teaching preferences

- Explain visually — diagrams, tables, analogies
- Deconstruct abstract concepts into what / owns / must never do / verify
- Relate technical systems to districts (Institute, Works, Council)
- Teach terminology naturally during real work

## Communication preferences

- Complete sentences — no telegraphic shorthand
- Conclusion first, then reasoning
- Labeled Composer vs Terra prompts in dedicated code blocks
- One testing URL per code block — never grouped
- State next steps, blockers, and verification explicitly

## Review style

- Architecture review before implementation prompts for net-new systems
- Implementation review against pass criteria and scope
- Design critique: preserve what works; surgical changes only
- Distinguish **proven** (device-confirmed) from **inferred** (code analysis)

## Brainstorming style

- 2–3 directions maximum
- Label exploratory vs production candidate
- Connect to canon before expanding
- Output: decision memo OR Composer sprint OR defer with open questions

## Quality standards

- Normal tabs must work — private/incognito is not a workflow
- Diagnostic layer reliable before feature resume
- Governed generation respected — no silent auth bypass
- Zero canon contradictions without logged supersession

## Learning style

- Learns by building and seeing failures frozen with evidence
- Prefers ChatGPT as Creative Director; Composer as implementer; Terra as governance
- New AI sessions should reach productivity in minutes via capsule, not hours via re-explaining
