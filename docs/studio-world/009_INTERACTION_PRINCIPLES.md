# 009 — Interaction Principles™

**Status:** Canonical — Part 1 of Studio World Bible  
**Scope:** How founders and visitors interact with Studio World™

---

## Interaction Thesis

Users don't click menus. They **experience a company**.

Interaction in Studio World™ is **spatial, social, and executive** — not procedural, transactional, or generative.

---

## What Founders Do

| Action | Expression | Never |
|--------|------------|-------|
| **Walk** | Corridor · skybridge · elevator · approach zone | Scroll page · click nav |
| **Enter rooms** | Doorway transition · arrival compression | Route change · tab open |
| **Join meetings** | Walk into prepared room · take seat · participate | Open chat · start call |
| **Review work** | Approach board · orbit table · pan wall | Open grid · view list |
| **Approve work** | Gesture · verbal · ceremony · vault | Click approve button |
| **Request revision** | Point at object · speak direction · pin spec | Type regenerate prompt |
| **Observe production** | Walk warehouse floor · watch monitors | Check status dashboard |
| **Follow specialists** | Orb routes to specialist office | Select from dropdown |
| **Watch live discussions** | Enter mid-debate · listen · then direct | Read thread |
| **Book meetings** | Calendar already populated · confirm attendance | Create calendar event in software |
| **Sign authorization** | Production Readiness ceremony | Toggle production flag |

## Interaction Primitives

### Primitive 1 — Locomotion

Movement is the primary navigation input.

| Type | Use |
|------|-----|
| **Walk** | Corridor transitions |
| **Approach** | Move toward workstation to interact |
| **Orbit** | Survey room zones |
| **Elevate** | Executive overlook · Mission Control |
| **Pan** | Scan wall of concepts |

**Forbidden:** Vertical page scroll as primary room navigation.

### Primitive 2 — Attention

Founder directs attention — system responds with context.

| Gesture | Result |
|---------|--------|
| Approach zone | Zone activates · specialist may speak |
| Point at object | Object inspect · revision targeting |
| Pause at board | Comparison mode · metadata overlay |
| Sit at table | Meeting participation mode |

### Primitive 3 — Speech

Natural language to Orb is **executive speech** — not prompting.

| Executive speech | Prompt (forbidden as primary) |
|------------------|-------------------------------|
| *"Go with Concept B"* | *"Generate three more concepts"* |
| *"Take me to Packaging"* | *"Open packaging tool"* |
| *"What happened overnight?"* | *"Summarize my activity"* |
| *"Schedule arbitration"* | *"Help me decide"* |

### Primitive 4 — Decision

Decisions are ceremonial — not transactional.

| Decision | Physical outcome |
|----------|------------------|
| Approve | Vault · canon wall · production signal |
| Reject | Red-tag shelf |
| Branch | Sandbox spawn |
| Revise | Spec pin · queue |
| Defer | Calendar reschedule |

### Primitive 5 — Observation

Founder may observe without acting — organization continues.

- Walk production floor without approving
- Stand in corridor hearing debate
- Watch Mission Control ticker
- Browse rejection archive

Observation is **legitimate executive activity**.

---

## What Founders Never Do (Primary Flow)

- Click hamburger menus
- Type into prompt boxes as first action
- Scroll card grids
- Toggle feature flags
- Manage plugins
- Configure settings screens
- Export PDFs as primary deliverable
- Refresh to see updates

---

## Specialist Interaction

| Interaction | Model |
|-------------|-------|
| **Specialist presents** | In meeting · at their station |
| **Specialist annotates** | On boards · sticky notes |
| **Specialist disagrees** | Visible debate · not DM |
| **Specialist recommends** | With evidence · not "I made this" |
| **Orb routes to specialist** | *"Brand Strategist has a divergence alert"* |

Founders don't "select AI model." They visit coworkers.

---

## Object Interaction

Objects follow consistent grammar:

| Interaction | Object response |
|-------------|-----------------|
| Approach | Inspect · metadata · lineage |
| Pin | Add to wall · library |
| Compare | Side-by-side layout |
| Layer | Version stack reveal |
| Red-tag | Rejection pipeline |
| Seal | Canon approval |

---

## Meeting Interaction Flow

```
APPROACH ROOM → THRESHOLD → ENTER ACTIVE SPACE → FRAME →
WATCH → DEBATE → DIRECT → DECIDE → OUTCOME PHYSICALIZES → EXIT
```

Founder never "starts meeting." Founder **joins** meeting.

---

## Visitor Interaction (Future)

Visitors have reduced primitives:

- Guided walk (Orb-led)
- Seated observation
- Scoped annotate
- Pointer approve (client sign-off)
- No archive · no genome · no rejection shelves

Before any interaction design:
