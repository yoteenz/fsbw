# Resident Workspace

The **Resident Workspace** is the founder’s primary window into one resident — cinematic dossier + live state + psychological map + work command center + social graph + career record + documentary layer.

Sections: see `RESIDENT_WORKSPACE_SECTIONS` in `life-os/workspace-contract.ts`.
