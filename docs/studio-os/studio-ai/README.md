## What Studio AI is — and is not

| Studio AI **is** | Studio AI **is not** |
|------------------|----------------------|
| The persistent intelligence layer of Studio OS | A foundation model (GPT, Claude, Gemini, etc.) |
| A consistent identity across model upgrades | An LLM product name |
| Roles, memory, persona, and collaboration | Prompts and chat logs |
| The enduring collaborator the founder recognizes | A disposable session |

> **North star:** People should ask *"What version of Studio AI are you running?"* — not *"What model are you?"*

## The stack (canonical)

```
Foundation Model              ← replaceable reasoning engine
        ↓
Reasoning Engine Adapter      ← vendor-neutral interface
        ↓
Studio AI Intelligence Layer  ← persistent identity + roles
        ↓
Institutional Memory Engine   ← memory asset (not prompts)
        ↓
Founder DNA · Project DNA     ← collaboration + civilization traits
        ↓
Knowledge Graph               ← living relationships
        ↓
AI Context Protocol           ← portable memory transfer
        ↓
Studio OS                     ← platform surface
```

**Rule:** Everything above the foundation model belongs to Studio AI.
