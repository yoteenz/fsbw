# Mode System™ — Master Specification

**"How would you like to build today?"**

---

## Core Law

**One platform. Many journeys.**

Modes™ personalize **onboarding · recommendations · AI · layout priorities · workflows** — never the underlying Company Engine™.

---

## The Defining Moment

```
Headquarters appears (slow · cinematic)
        ↓
Orb welcomes founder
        ↓
"How would you like to build today?"
        ↓
Founder selects Mode™
        ↓
Mode DNA™ applied
        ↓
Orb confirms · reassures · begins journey
        ↓
Business Discovery Blueprint™ (when ready)
```

**No forms first.** No template grid. No dashboard picker.

---

## Mode Selection UX Principles

| Principle | Meaning |
|-----------|---------|
| **Conversational** | Orb explains — not a pricing table |
| **Reversible** | "You can always change Modes later" |
| **Non-permanent** | "Your Headquarters will evolve with you" |
| **Way of working** | Not purchasing different software |
| **One tap + confirm** | Low friction · high clarity |

---

## Forbidden Onboarding Language

| Forbidden | Required |
|-----------|----------|
| "Choose a template" | "How would you like to build today?" |
| "Select your plan tier" | "Choose your Mode™" |
| "Pick a dashboard layout" | "We'll shape your Headquarters" |
| "What industry?" (first) | Mode first · industry within Blueprint™ |
| "Sign up for Creator product" | "Creator Mode™ — same Studio OS" |

---

## Mode vs Industry vs Genome

| Layer | Question answered | When |
|-------|-------------------|------|
| **Mode™** | How do I want to build? | First entry |
| **Industry** | What kind of business? | Blueprint™ |
| **Company Genome™** | Who is this company? | Blueprint™ + ongoing |
| **Founder Journey™** | How mature am I? | Continuous |

Modes and industries **compose** — Entrepreneur Mode + Beauty industry is valid.

---

## Mode DNA™ Application

On Mode selection, Studio OS automatically configures:

- Headquarters defaults
- Department priorities
- AI Concierge roster emphasis
- Studio World™ layout weights
- Orb personality register
- Company Engine™ recommendations
- Starter Packs
- Marketplace suggestions
- Production workflow emphasis
- KPI surfaces

**Detail:** [mode-dna.md](./mode-dna.md)

---

## Orb Role

The Orb is the **onboarding facilitator** — not a form wizard.

- Explains each Mode conversationally
- Never pressures
- Confirms choice with tailored response
- Bridges to Blueprint™ when founder is ready

**Detail:** [orb-onboarding.md](./orb-onboarding.md)

---

## Mode Evolution™

Founders are never trapped:

- Entrepreneur → Enterprise (growth)
- Creator → Agency (client work)
- Agency → Enterprise (acquisition)
- Enterprise → Entrepreneur (incubation)

**Detail:** [mode-evolution.md](./mode-evolution.md)

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Separate codebase per mode | Violates one Company Engine™ |
| Mode locked forever | Violates evolution |
| Mode = billing SKU only | Must change experience |
| Skipping Mode on first entry | Misses defining moment |
| Mode replaces Blueprint™ | Mode shapes Blueprint — doesn't replace it |
