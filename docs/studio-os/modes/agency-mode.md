## Client Model

Each client maps to a **Company™** object under agency portfolio:

```
Agency (Operator Company)
    ├── Client Company A → HQ alias / wing
    ├── Client Company B → HQ alias / wing
    └── Internal Agency Ops → central Sets™
```

Same Company Engine™ — multiple company objects.
