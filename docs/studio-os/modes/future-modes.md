# Future Modes™

**Specialized experiences — same Company Engine™**

---

## Principle

Future Modes are **specialized journeys** powered by the identical [Company Engine™](../philosophy/company-engine.md).

They do not fork the platform. They extend **Mode DNA™** with domain-specific priorities.

## Relationship to Industry Architecture™

| Layer | Scope |
|-------|-------|
| **Mode™** | How you build (journey) |
| **Industry pack** | What business type (content) |

**Innovation Mode™ + Healthcare industry** = valid composition.

Modes and industries are **orthogonal** — both apply Mode DNA + industry pack merges.

---

## Future Mode DNA Pattern

Each future mode adds:

```typescript
{
  modeId: 'healthcare',
  extends: 'enterprise',           // optional base mode
  departmentPriority: [...],
  complianceOverlays: [...],
  terminology: { patientLabel: 'Patient', ... },
  regulatedWorkflows: true,
  marketplacePacks: ['hipaa-conscious', ...]
}
```

## Release Criteria

A future Mode ships when:

| Gate | Requirement |
|------|-------------|
| Mode DNA complete | Full config manifest |
| Industry packs exist | At least 2 aligned industries |
| HQ topology spec | Map template in Studio World™ |
| Orb copy certified | Onboarding + confirmation scripts |
| No engine fork | Proven on existing stack |
| Founder pilot | One real company through full journey |

---

## Innovation Mode™ Preview

For founders building **experimental companies**:

- Innovation Tunnel™ transitions default
- Discovery Lab™ as HQ heart
- Higher tolerance for Golden Build™ iteration
- Braintrust weighted toward experience architects

---

## Studio Mode™ Preview

For **Hollywood-scale** production companies:

- Full lot topology · many Sets™
- Production Builder · Director Mode emphasized
- Campaign Orchestrator™ as launch hub
- Gallery Walk™ to Archive™ heavily used

---

## Long-Term Marketplace

Future Modes may ship as **Mode Packs™** in Marketplace — still one engine:

> Install Healthcare Mode DNA™ → HQ reweights · departments suggest · compliance overlays apply
