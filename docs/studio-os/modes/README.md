# Mode System™

**How Would You Like To Build Today?**

**Version:** 1.0.0  
**Status:** Canonical onboarding philosophy  
**Phase:** Philosophy & onboarding (post-platform freeze)  
**Scope:** Every founder's first defining moment in Studio OS

---

> **Studio OS adapts to the founder. The founder never adapts to the software.**

---

## Mission

Instead of choosing templates, dashboards, or layouts — every founder begins by choosing **how they want to build**.

This becomes one of the **first defining moments** inside Studio OS.

---

## The Experience

When entering Studio OS for the first time:

1. The **Headquarters** slowly appears
2. The **Orb** welcomes the founder
3. Instead of company information forms immediately — the Orb asks:

> **"How would you like to build today?"**

The founder chooses a **Mode™**.

---

## What Modes™ Are

| Modes™ **are** | Modes™ **are not** |
|----------------|-------------------|
| A way of working | Separate products |
| Onboarding personalization | Platform forks |
| Journey shaping | Template pickers |
| Recommendation profiles | Different engines |
| Founder-first entry | SaaS plan tiers |

**Studio OS remains one [Company Engine™](../philosophy/company-engine.md).**

---

## What Modes™ Change

Modes configure — they do **not** fragment:

| Configured by Mode™ | Shared across all modes |
|---------------------|-------------------------|
| Onboarding path | Company Engine™ |
| Recommendations | Studio World™ |
| AI behavior tone | Production Lifecycle™ |
| Headquarters layout priorities | Department Runtime™ |
| Department priorities | Marketplace engine |
| Workflows emphasis | Creative Approval Pipeline™ |
| Terminology emphasis | Validation Loop™ |
| Default automations | Asset Registry™ |
| Learning path | Single codebase |

## Success Criteria

Studio OS onboarding should **no longer** ask:

> "What template do you want?"

It asks:

> **"How would you like to build today?"**

That single question should immediately make founders feel **understood**.

Modes™ personalize the experience **without fragmenting the platform**.

## Final Philosophy

Studio OS remains **one platform**.

One Headquarters.  
One Studio World™.  
One Company Engine™.

**Modes™** simply shape the founder's journey through that world.

Every founder begins differently.  
Every company evolves differently.  
Studio OS should evolve with them.
