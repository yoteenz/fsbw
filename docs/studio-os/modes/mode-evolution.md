# Mode Evolution™

**Founders should never become trapped in a Mode™**

---

## Purpose

Companies change. Founders change. Studio OS **adapts naturally** as the company evolves — without platform forks or data loss.

---

## Canonical Evolution Paths

```
Entrepreneur Mode™ ──────────► Enterprise Mode™
        │                            ▲
        ▼                            │
Creator Mode™ ──► Agency Mode™ ──────┤
        │                            │
        ▼                            │
Franchise Mode™ ────────────────────┘

Enterprise Mode™ ──► Entrepreneur Mode™ (incubation spinouts)
Agency Mode™ ──────► Enterprise Mode™ (scale)
Any Mode ──────────► Any Mode (founder choice)
```

---

## What Preserves Across Evolution

| Preserves | May re-weight |
|-----------|---------------|
| Company Genome™ | Department priorities |
| Blueprint™ / Charter | HQ layout emphasis |
| Legacy™ · Archive™ | Orb personality register |
| Certified™ Sets™ | KPI surfaces |
| Profession Brain™ | Workflow ceremony style |
| World Memory™ | Marketplace suggestions |

**Never wipe the company** on mode change.

---

## What Updates on Evolution

| Updates | Example |
|---------|---------|
| Mode DNA™ profile | Enterprise governance overlays |
| HQ map topology | Single → campus |
| Orb briefing style | Partner → executive |
| Recommendation engine | Launch → compliance |
| Terminology | Founder → CEO |
| Starter automations | New mode defaults merge |

---

## Evolution Ceremony

Major mode shifts deserve spatial acknowledgment — not a settings toggle:

```
1. Orb: "Your company has outgrown Entrepreneur Mode™."
2. Offer: "Explore Enterprise Mode™?"
3. Founder confirms
4. Gallery Walk™ or Executive Corridor™ transition
5. HQ topology preview — what will evolve
6. Mode DNA diff applied
7. World Event™: "A new chapter begins."
```

Minor adjustments may be **quiet** — full evolution is **ceremonial**.

---

## Triggers (Suggested)

| Signal | Suggested evolution |
|--------|---------------------|
| 10+ employees | Entrepreneur → Enterprise hint |
| First franchise location | Entrepreneur → Franchise |
| 3+ concurrent clients | Creator → Agency |
| Incubator launch | Enterprise → Entrepreneur (new company object) |

Founder **always** confirms. Orb **never** auto-switches.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Locked mode | Traps growing companies |
| Silent destructive reset | Violates Company Engine™ |
| Mode change = new billing only | Must change experience |
| Data loss on switch | Violates World Memory™ |
