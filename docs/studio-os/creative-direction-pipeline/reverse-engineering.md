# Reverse Engineering™

**Step 06 — Structured deconstruction of approved vision**

---

## Purpose

After the founder approves a concept, Studio OS **deconstructs** the approved vision into structured production data — ready for Asset Graph™ construction and Refinement Pipeline™.

**Not by guessing from pixels.**

---

## Core Law

Reverse Engineering™ combines:

```
Scene Blueprint™
        +
Company Genome™
        +
Project Genome™
        +
Creative Direction™
        +
Rendered Image (confirmation)
        =
Studio OS understands the room
```

---

## Reverse Engineering Process

```
Approved Vision locked
        ↓
1. LOAD Scene Blueprint™ (primary authority)
        ↓
2. VALIDATE image ↔ blueprint consistency
        ↓
3. INJECT genome context into every node
        ↓
4. EXTRACT object inventory → Asset Graph™ nodes
        ↓
5. MAP relationships · dependencies · zones
        ↓
6. COMPILE generation instructions per node
        ↓
7. INITIALIZE Refinement Pipeline™ state
        ↓
Ready for tap-to-refine
```

---

## What Reverse Engineering Produces

| Output | Purpose |
|--------|---------|
| **Asset Graph™** | Every object as editable node |
| **Dependency map** | What affects what |
| **Zone map** | Interactive regions |
| **Generation queue** | Pre-compiled prompts per node (background) |
| **Refinement state** | All nodes start `approved-vision` status |
| **Project Genome™ update** | Vision lock recorded |

---

## Pixel Role (Limited)

The rendered image serves as:

| Use | Authority level |
|-----|-----------------|
| Human visual confirmation | High for founder |
| Consistency validation vs blueprint | Medium — flags drift |
| Material/color confirmation | Low — blueprint governs |
| Object discovery | **Forbidden** — blueprint governs |

Computer vision may **validate** blueprint-image alignment — never **replace** blueprint.

---

## Genome Injection

Every deconstructed node inherits:

| Genome field | Applied to |
|--------------|------------|
| Company tone | Orb dialogue · signage |
| Brand colors | Material nodes |
| Room DNA sliders | Atmosphere · lighting weights |
| Project constraints | Object selection |
| Creative Direction law | Anti-pattern enforcement |

---

## Validation Gate

Reverse Engineering™ must pass before Refinement Pipeline™ opens:

| Check | Requirement |
|-------|-------------|
| Blueprint loaded | Primary source present |
| Node count | Matches furniture inventory |
| Hero object | Identified and linked |
| Dependencies | Mapped for all major nodes |
| Genome injection | Complete |
| No orphan nodes | Every node has zone parent |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| CV-only room parsing | Loses production intent |
| Skip reverse engineering | Jump straight to asset gen |
| Full regen after deconstruction | Vision already locked |
| Ignore blueprint relationships | Breaks dependency awareness |
