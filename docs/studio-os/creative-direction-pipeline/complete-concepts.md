# Generate Complete Concepts™

**Step 03 — Three complete cinematic environments**

---

## Purpose

Using the approved Creative Brief™ and locked Creative Direction™, Studio OS generates **three complete room concepts** — entire cinematic spaces, not separate assets.

---

## Core Law

**Complete environments. Not individual furniture.**

Each concept is a **full interpretation** of the creative direction — exploring different creative directions while remaining genome-faithful.

---

## The Three Concepts

| Concept | Role |
|---------|------|
| **Concept A** | Primary interpretation — closest to brief synthesis |
| **Concept B** | Alternative interpretation — different emphasis |
| **Concept C** | Bold interpretation — pushes creative boundary safely |

Each concept includes:

1. **Rendered complete environment** — cinematic full-room image
2. **Scene Blueprint™** — authoritative production document (co-generated)
3. **Concept narrative** — Orb explains the interpretation

---

## What Concepts Are NOT

| Not a concept | Why |
|---------------|-----|
| Individual wall render | Partial · no vision |
| Furniture-only mockup | Asset-first · forbidden |
| Flat mood board collage | Reference · not environment |
| Wireframe layout | Planning artifact · not vision |
| Text-only description | Must be **seen** |

---

## Generation Inputs

Every concept generation consults:

| Input | Role |
|-------|------|
| Creative Brief™ | Founder intent · references |
| Creative Direction™ | Locked creative authority |
| Company Genome™ | Brand personality · design philosophy |
| Project Genome™ | Project constraints |
| Brand DNA™ | Visual identity law |
| Room DNA™ | Aesthetic sliders |
| Golden Department spec | Department experience intent |
| Set DNA™ | Set-level identity |

---

## Concept Differentiation Strategy

| Axis | How A · B · C differ |
|------|---------------------|
| **Spatial emphasis** | Intimate vs grand vs dynamic |
| **Material weight** | Glass-dominant vs marble-dominant vs mixed |
| **Lighting mood** | Warm editorial vs cool cinematic vs dramatic contrast |
| **Hero object** | Mood Wall™ dominant vs Story Table™ vs Orb™ center |
| **Color temperature** | Warm luxury vs neutral precision vs bold accent |
| **Storytelling density** | Minimal vs rich ambient narrative |

All three remain **faithful** to Creative Direction™ — they explore interpretation, not violation.

---

## Co-Generated Scene Blueprint™

**Critical:** Concept generation **must simultaneously produce** Scene Blueprint™.

```
Concept Generation Request
        ↓
┌───────────────────┬───────────────────┐
│  Rendered Image   │  Scene Blueprint™  │
│  (visual ref)     │  (production truth) │
└───────────────────┴───────────────────┘
```

Never generate image without blueprint.  
Never infer blueprint from pixels afterward.

**Detail:** [scene-blueprint.md](./scene-blueprint.md)

## Generation Orchestration

Uses existing stack — no new engine:

| System | Role |
|--------|------|
| Prompt Compiler™ | Merges genomes + direction into concept prompt |
| Generation Manager™ | Queues 3 concept jobs · parallel where safe |
| Model Orchestrator™ | Routes to image provider (FAL · GPT Image · etc.) |
| Scene Blueprint Generator | Structured output alongside image |
| Validation Loop™ | Pre-presentation quality check |

---

## Concept Quality Gate

Before founder sees concepts:

| Check | Requirement |
|-------|-------------|
| Genome alignment | Passes Company · Brand · Room DNA |
| Creative Direction lock | No violation of art direction law |
| Scene Blueprint™ present | Every concept has blueprint |
| Blueprint ↔ image consistency | Structural match verified |
| Anti-pattern scan | No SaaS dashboard aesthetics |
| Resolution | Cinematic quality tier |

Failed concepts regenerate — founder never sees broken concepts.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| One concept only | No creative choice |
| Ten concepts | Decision paralysis |
| Image without blueprint | No production truth |
| Blueprint inferred post-hoc | Unreliable structure |
| Concepts ignoring genome | Brand drift |
