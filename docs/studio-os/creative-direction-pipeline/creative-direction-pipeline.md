# Creative Direction Pipeline™ — Master Specification

**"Vision First. Production Second."**

---

## Core Law

**Founders direct visions. Studio OS directs production.**

No founder should approve individual assets before approving the creative world those assets inhabit.

---

## The Realization

| Industry | What they approve first |
|----------|------------------------|
| Creative Director | Overall room vision — not individual walls |
| Film Director | Complete set — not isolated lighting rigs |
| Architect | Building concept — not furniture selections |

Studio OS previously asked founders to approve **assets**.  
Studio OS now asks founders to approve **visions**.

---

## What Changes from Creative Approval Pipeline™

| Creative Approval Pipeline™ | Creative Direction Pipeline™ |
|----------------------------|------------------------------|
| 10-stage asset approval | Vision lock → surgical refinement |
| Generate Environment → Architecture → Lighting → Furniture… | Generate 3 complete concepts first |
| Approve each production group | Approve one vision |
| Director Feedback per asset stage | Director Feedback per tapped object |
| Dependency unlock between asset groups | Dependency awareness within Asset Graph™ |
| Braintrust per generated asset | Braintrust per refinement |
| Pixel-first understanding | Scene Blueprint™-first understanding |

**Preserved from Creative Approval Pipeline™:**
- Creative Review™ · Braintrust™ · Orb facilitator
- Director Feedback™ (evolved to natural language)
- Dependency Awareness™ (evolved to Asset Graph™)
- Background Preparation™ (evolved to Background Intelligence™)
- Director's Notes™ → Project Genome™
- Approve™ · Regenerate™ · Branch™ (applied to refinements)

## Founder Role Evolution

| Old role | New role |
|----------|----------|
| Asset approver | **Creative Director** |
| Prompt operator | **Vision selector** |
| Queue manager | **Refinement director** |
| QA reviewer | **Final authority** (with Braintrust counsel) |

The founder asks one question at vision stage:

> **"Which direction excites me the most?"**

---

## Studio OS Role Evolution

| Old behavior | New behavior |
|--------------|--------------|
| Generate assets on founder command | Generate **complete concepts** from brief |
| Wait for per-asset approval | Wait for **vision** approval |
| Guess room structure from image | **Read Scene Blueprint™** as truth |
| Regenerate entire groups | **Refine tapped nodes** surgically |
| Block on generation | **Prepare in background** during review |

---

## Anti-Patterns

| Anti-pattern | Why forbidden |
|--------------|---------------|
| Approve walls before seeing room | Violates vision-first law |
| Reverse engineer from pixels alone | Unreliable · loses structure |
| Generate furniture before concept lock | Wastes production · wrong direction |
| Full room regen for Orb tweak | Violates surgical refinement |
| Founder writes prompts | Violates Director Feedback™ philosophy |
| Skip Scene Blueprint™ | No production truth |
| Concept without Blueprint co-generation | Blueprint must be authoritative from start |
| Asset queue as primary UX | Feels like Midjourney · not Pixar |
