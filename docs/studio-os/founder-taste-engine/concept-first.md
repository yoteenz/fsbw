# Concept First™

**Every significant creative decision begins with multiple directions**

---

## Purpose

Define the universal rule: whenever Studio OS creates something **important**, present **multiple complete concepts** — not one option · not a blank canvas · not a single asset.

This is the **primary taste signal source** for Founder Taste Engine™.

---

## Core Law

**No important creative decision without choice.**

Studio OS proposes directions. The founder reveals taste through selection.

---

## What Qualifies as "Important"

| Category | Concept examples |
|----------|------------------|
| **Environments** | Room · Set™ · Headquarters wing · office layout |
| **Digital** | Website · dashboard · UI · app experience |
| **Brand** | Logo · brand identity · photography style |
| **Product** | Packaging · product design · store design |
| **Marketing** | Campaign · advertisement · social graphic · launch campaign |
| **Content** | Copywriting direction · animation · motion system |
| **Production** | Complete room concepts (Creative Direction Pipeline™) |

**Rule of thumb:** If the founder would say "this defines our company" — Concept First™ applies.

---

## Standard Presentation

| Count | Usage |
|-------|-------|
| **3 concepts (A · B · C)** | Default for all important decisions |
| **Additional concepts** | Founder requests more directions |
| **Blend concept** | Hybrid of selected traits from A + B |

---

## Complete Concepts — Not Fragments

| Complete concept | Fragment (forbidden as concept) |
|----------------|--------------------------------|
| Full room environment | Single wall texture |
| Complete website hero | One button style |
| Full packaging system | Logo mark only |
| Campaign visual system | One social post size |
| Brand identity system | Color swatch picker |

**Aligns with** [Creative Direction Pipeline™](../creative-direction-pipeline/complete-concepts.md) — three cinematic environments.

Concept First™ **generalizes** that pattern to **all** significant creative outputs.

---

## Concept Structure

Every concept includes:

```typescript
interface CreativeConcept {
  id: string;                    // 'A' | 'B' | 'C' | ...
  category: ConceptCategory;
  completeArtifact: ArtifactRef; // full render · mockup · prototype
  productionDocument?: object;   // Scene Blueprint™ · brand spec · etc.
  narrative: string;             // Orb explains interpretation
  tasteDimensions: TasteDimensionTag[];  // for learning
  genomeAlignment: number;       // 0–100
  tasteAlignment?: number;       // 0–100 after genome established
}
```

---

## Taste Signal from Selection

When founder selects Concept B over A and C:

| Analysis | Extraction |
|----------|------------|
| **What B had** | Traits to strengthen in Taste Genome™ |
| **What A/C lacked** | Traits to weaken |
| **Comparison context** | Relative weights (B strongly preferred vs barely preferred) |
| **Feedback if any** | Director Feedback™ enriches WHY |

The important part is **not** "chose B."  
The important part is **why B resonated**.

## Low-Stakes Exception

Concept First™ may reduce to **2 concepts** for minor refinements within an approved vision — never for vision-level locks.

| Stakes | Concept count |
|--------|---------------|
| Vision lock | 3 minimum |
| Major refinement | 2–3 |
| Surgical node tweak | 1–2 (already within Canon™) |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Single generated option | No taste signal |
| Ten options | Decision paralysis |
| Concept picker grid (SaaS) | Must feel spatial · narrative |
| Fragment concepts | No vision-level learning |
| Skip concepts for "efficiency" | Efficiency destroys understanding |
