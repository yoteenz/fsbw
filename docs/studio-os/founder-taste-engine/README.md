## Mission

Studio OS should never merely remember **what** a founder clicked.

Studio OS should learn **WHY** they chose it.

Every approval · rejection · branch · regeneration · comparison · feedback · concept selection · and conversation teaches Studio OS something about the founder.

Over time, Studio OS should begin **thinking like the founder**.
