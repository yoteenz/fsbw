## World Memory™ Relationship

| System | Memory type |
|--------|-------------|
| **World Memory™** | Spatial · session · object state per company |
| **Founder Taste Genome™** | Creative identity per founder |

World Memory remembers **where you were**.  
Taste Genome remembers **how you create**.

Both feed return experience:

> Founder returns to HQ → World Memory restores position → Taste Genome shapes what Orb suggests next.

## Anti-Patterns

| Anti-pattern | Why |
