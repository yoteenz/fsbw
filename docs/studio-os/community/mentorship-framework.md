# Mentorship Framework™

**Master → Professional → Emerging**

**Version:** 1.0.0  
**Status:** Canonical mentorship architecture (docs only)  
**Parent:** [Guild System™](./README.md)

---

## Purpose

Experienced Studio Professionals™ **mentor** newer guild members — structured knowledge transfer inside each Guild™.

Studio OS encourages mentorship as **institutional duty** — not optional nicety.

---

## Mentorship Ladder (Per Guild)

```
Legendary / Master
        ↓ mentors
Professional
        ↓ mentors
Emerging
```

Example — **Architects' Guild™**:

```
Master Architect™
        ↓
Professional Architect™
        ↓
Emerging Architect™
```

**Source:** [Career Progression™](../ecosystem/career-progression.md) · [Architect Rankings™](../marketplace/architect-rankings.md)

---

## Mentor Eligibility

| Level | May mentor |
|-------|------------|
| **Emerging** | Peer study groups only |
| **Professional** | 1–2 Emerging mentees |
| **Master** | Multiple Emerging + Professional |
| **Studio Certified™** | Formal guild mentorship roster |
| **Legendary** | Guild-wide mentorship programs |

---

## Mentorship Lounge™

Physical space in every [Guild Hall™](./guild-halls.md):

| Feature | Purpose |
|---------|---------|
| Private alcoves | 1:1 sessions |
| Review table | Portfolio critique |
| Orb scheduling | Match · reminders |
| Session archive | Opt-in Knowledge Library™ clips |

---

## Matching Process

```
1. Emerging requests mentorship (or Guild assigns)
        ↓
2. Mentorship Council™ matches by specialty + taste alignment
        ↓
3. Orb introduces — *"You've been invited to mentor Emerging Architects."*
        ↓
4. Structured program (default 12 weeks)
        ↓
5. Milestone reviews — portfolio · certification prep
        ↓
6. Graduation — mentee to Professional path
        ↓
7. Reputation credit — mentor Teaching · Mentorship signals
```

---

## Mentorship Program Structure

| Week phase | Focus |
|------------|-------|
| **1–2** | Craft foundations · guild canon |
| **3–6** | First publishable work |
| **7–9** | Critique · revision |
| **10–12** | Certification submission prep |

Customizable per guild — structure is **default not rigid**.

---

## Mentor Obligations

| Obligation | Description |
|------------|-------------|
| **Honest critique** | Not empty praise |
| **Founder success lens** | Mentee work must serve founders |
| **Ethics** | No stealing mentee work |
| **Availability** | Minimum session cadence |
| **Documentation** | Optional Knowledge Library™ contribution |

---

## Mentee Obligations

| Obligation | Description |
|------------|-------------|
| **Show work** | Portfolio transparency |
| **Accept critique** | Growth mindset |
| **Publish path** | Toward Community™ or certification |
| **Credit mentor** | Attribution on collaborative work |

|--------|--------|

| Long-term mentee career | High |
