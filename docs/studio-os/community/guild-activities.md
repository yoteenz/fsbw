# Guild Activities™

**Learn · compete · celebrate · innovate**

**Version:** 1.0.0  
**Status:** Canonical activities architecture (docs only)  
**Parent:** [Guild System™](./README.md)

---

## Purpose

Define what Guilds **do** — recurring events and rituals that advance craft · build community · and recognize excellence.

Guild Halls™ host activities — not notification feeds.

---

## Activity Categories

| Category | Activities |
|----------|------------|
| **Competition** | Seasonal Challenges™ · Design Competitions™ |
| **Recognition** | Golden Build Awards™ · Editor's Choice™ |
| **Showcase** | Architecture Showcases™ · Brand Reviews™ |
| **Innovation** | Innovation Weeks™ · Hackathons™ |
| **Education** | Masterclasses™ · Live Critiques™ |
| **Collaboration** | Community Projects™ |

---

## Seasonal Challenges™

| Property | Description |
|----------|-------------|
| **Cadence** | Quarterly per guild |
| **Theme** | Guild Council™ sets craft theme |
| **Submission** | Published Headquarters Package™ or craft artifact |
| **Judging** | Certified Masters + founder satisfaction signal |
| **Outcome** | Hall of Excellence™ placement |

Example: *"Winter Editorial Challenge — luxury atelier under 90 seconds arrival."*

---

## Design Competitions™

| Property | Description |
|----------|-------------|
| **Scope** | Single Living Set™ · pipeline · brand system |
| **Duration** | 2–4 weeks |
| **Visibility** | Challenge Board™ in Guild Hall™ |
| **Prize** | Award · Featured · mentorship offer |

Not vanity contests — **craft proof**.

---

## Golden Build Awards™

| Property | Description |
|----------|-------------|
| **Eligibility** | Golden Build™ certified work |
| **Categories** | Per guild craft domain |
| **Ceremony** | Award Hall™ seasonal event |
| **Legacy** | Winners enter Hall of Legends™ consideration |

Aligns with [Production Lifecycle™](../production-lifecycle/golden-build.md).

## Orb Activity Dialogue

| Event | Orb pattern |
|-------|-------------|
| Nomination | *"The Architects' Guild nominated your Headquarters for this season's awards."* |
| Editor's Choice | *"Your Innovation Lab is Editor's Choice this month."* |
| Challenge open | *"Seasonal Challenge begins — theme: Minimal Technology Campus."* |

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Engagement bait events | Not craft advancement |
| Pay-to-win competitions | Merit only |
| Activities without Hall venue | Breaks institution law |
| Popularity vote winners | Ignores quality |
