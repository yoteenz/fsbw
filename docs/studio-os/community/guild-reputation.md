# Guild Reputation™

**Merit · craft · impact — not popularity**

**Version:** 1.0.0  
**Status:** Canonical reputation architecture (docs only)  
**Parent:** [Guild System™](./README.md)

---

## Purpose

Define how Guilds reward members — and how members earn standing **inside the institution**.

Guild Reputation™ rewards **craft and contribution** — not simply popularity.

---

## Reputation Signals

| Signal | Weight tier | Description |
|--------|-------------|-------------|
| **Innovation** | High | New genres · frameworks · techniques |
| **Originality** | High | Distinct work — not derivative |
| **Teaching** | High | Masterclasses · Library contributions |
| **Mentorship** | High | Successful mentee outcomes |
| **Founder success** | Highest | Measurable founder outcomes |
| **Community contribution** | Medium | Projects · critiques · standards |
| **Professionalism** | Medium | Ethics · reliability · collaboration |
| **Long-term impact** | Highest | Work active years later |
| **Follower count** | Low | Awareness — not merit |
| **Sales volume** | Low | Commerce — insufficient alone |

---

## Guild Standing

| Standing | Character |
|----------|-----------|
| **New Member** | Admitted · first publish |
| **Contributing Member** | Active gallery · challenges |
| **Recognized Member** | Award nominee · strong reviews |
| **Distinguished Member** | Season winner · certified |
| **Guild Fellow™** | Master + sustained impact |
| **Guild Legend™** | Hall of Legends™ inductee |

Standing is **guild-scoped** — separate per Guild™.

## Decay & Integrity

| Event | Effect |
|-------|--------|
| Decertification | Standing review |
| Ethics violation | Standing suspension |
| Inactivity | Dormant — not punished |
| New masterpiece | Standing acceleration |

---

## Anti-Gaming

| Manipulation | Prevention |
|--------------|------------|
| Fake followers | Verified professional relationships only |
| Vote brigading | Juried awards · not pure votes |
| Self-review rings | Founder-verified outcomes required |
| Volume spam | Quality gates on gallery |

## Cross-Guild Recognition

| Honor | Scope |
|-------|-------|
| Guild Fellow™ | Single guild |
| Cross-Guild Collaborator™ | Multi-guild project excellence |
| Studio World™ Citizen™ | Platform-wide contribution |

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Influencer leaderboard | Popularity over craft |
| Reputation purchasable | Destroys institution |
| Single metric dominance | Ignores mentorship · teaching |
