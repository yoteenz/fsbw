# Guild Halls™

**Every Guild has a Headquarters inside Studio World™**

**Version:** 1.0.0  
**Status:** Canonical spatial architecture (docs only)  
**Parent:** [Guild System™](./README.md)

---

## Core Law

```
GUILD HALLS™ ARE LIVING SPACES — NOT MENUS
```

Professionals **physically enter** Guild headquarters inside Studio World™.

## Arrival Experience

Entering a Guild Hall™ follows [Arrival Sequence™](../foundational-experience-systems/arrival-sequence.md):

```
Threshold — guild crest · ceremonial weight
        ↓
Arrival Zone™ — glimpse of Hall grandeur
        ↓
Orb greeting — guild-aware host line
        ↓
Discover — wander to Challenge Board · Gallery · Lounge
```

Never dump all rooms on screen at once.

## Founders in Guild Halls™

Founders may **visit** Guild Halls™ as guests:

| Access | Experience |
|--------|------------|
| Browse Gallery | Discover architects · work |
| Attend public critique | Learn craft culture |
| Commission lounge | Meet certified professionals |
| Award ceremony | Celebrate excellence |

Founders are **not** guild members by default — they are **honored guests and clients**.

## Guild Hall Evolution

Halls evolve with guild maturity per [Set Continuity™](../world/set-continuity.md):

| Stage | Hall change |
|-------|-------------|
| Launch | Core rooms · sparse gallery |
| Growth | Expanded library · busier life |
| Legacy | Hall of Legends™ wing opens |

---

## World Immersion™

Guild Halls™ connect to headquarters campus via [Transitions™](../world/transitions/README.md):

```
Founder's HQ
        ↓ corridor / skybridge
Architects' Guild Hall™
        ↓ return
Founder's HQ
```

Leaving a Guild Hall feels like **walking out of a institution** — not closing a tab.

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|

| No physical arrival | Breaks Studio World™ law |
| Identical hall for all guilds | Loses craft identity |
