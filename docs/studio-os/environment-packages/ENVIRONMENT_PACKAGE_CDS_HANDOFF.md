# Environment Package CDS Handoff

## Gate

CDS handoff requires:

- Package canonical
- Required outputs generated
- Durable handoff record in `studio_environment_package_cds_handoffs`
- Founder approval persisted

## Payload

Handoff includes canonical master, mobile/tablet companions, blueprint, construction, lighting, materials, asset manifest, bible versions, prompt version, revision, and manufacturing requirements.

CDS displays **APPROVED ENVIRONMENT PACKAGE RECEIVED** — not loose render received.

## Enable

Set `ENABLE_PACKAGE_CDS_HANDOFF=1` on server after migration verification.
