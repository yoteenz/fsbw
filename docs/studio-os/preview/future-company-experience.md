# Future Company Experience™

**Archetypes Visitors Can Step Inside**

---

## Purpose

Define **Future Company Experiences™** — curated business archetypes visitors choose before entering the interactive Headquarters™ demo.

---

## Core Law

Instead of presenting recommendations as **text** — Studio OS generates **experiences visitors can enter**.

---

---

## Experience Package Structure

Each Future Company Experience™ includes:

| Component | Description |
|-----------|-------------|
| **Archetype ID** | Stable identifier |
| **Display name** | Visitor-facing title |
| **One-line hook** | Emotional invitation |
| **Studio Original™ HQ** | Matched headquarters skin |
| **Living Set™ expression** | Environment DNA for archetype |
| **Demo departments** | 3–5 wings to walk |
| **Demo scenes** | 2–3 scenes per department |
| **Scripted moments** | Workday · launch · celebration |
| **Orb demo script** | Host lines for this archetype |
| **AI professional cameos** | Concierges visible in demo |
| **Lifestyle hint** | Post-preview simulator tie-in |
| **Conversion seed** | Path into Founder Discovery™ |

## Personalization from Light Discovery

| Discovery signal | Experience ranking |
|----------------|-------------------|
| "Creativity excites me" | Creator · Agency · Architecture |
| "Healthcare interest" | Medical Practice™ |
| "Freedom + income" | Creator · E-commerce |
| "Impact driven" | Nonprofit-adjacent archetypes (future) |
| Industry stated | Boost matching archetype |

Offer **3–5** experiences — not entire catalog at once.

---

## Demo Boundaries

| Allowed in demo | Not in demo |
|-----------------|-------------|
| Walk · pan · station nav | Real file upload |
| Scripted AI collaboration | Live generation queue |
| Sample metrics (illustrative) | Connected Stripe · CRM |
| Milestone celebration beat | Persistent company state |
| Switch archetype | Merge demo companies |

Demo state is **ephemeral** — unless visitor converts.

---

## Multiple Futures™ Switching

| Behavior | Law |
|----------|-----|
| **Switch archetype** | New HQ load · prior demo discarded |
| **Compare memory** | Orb: *"You explored salon and startup — want to compare?"* |
| **No penalty** | Exploration encouraged |
| **Session limit** | Soft cap · convert CTA after N explores |

---

## Handoff to Founder Discovery™

On conversion, chosen archetype becomes **seed**:

- Full Founder Discovery™ conversation
- Discovery Report™ pre-weighted to archetype family
- Company Preview™ uses matched Studio Original™

Preview is **shallow** — Discovery is **deep**.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| 50 archetypes day one | Quality over quantity |
| Text card pick only | Must enter experience |
| Same HQ for all | Breaks immersion |
| Demo teaches every feature | Curated only |
