# Visitor Conversion™

**Belief to Commitment**

---

## Purpose

Define conversion after Studio Preview™ — social sharing · signup · and handoff to [Founder Discovery™](../founder-discovery/README.md).

---

## Core Law

Conversion happens **only after** the preview ends.

Visitor understands exactly what Studio OS is **before** being asked to commit.

---

## Conversion Moment

Orb asks:

> **"Would you like to build this company together?"**

| Principle | Law |
|-----------|-----|
| **After belief** | Demo complete · reflection done |
| **Single clear ask** | Not feature upsell stack |
| **No urgency manipulation** | No fake scarcity |
| **Respect no** | Save · share · return |

---

## Conversion Paths

| Path | Next step |
|------|-----------|
| **Yes — build together** | Signup → Founder Discovery™ (archetype seed) |
| **Save for later** | Email/link · return token |
| **Share first** | Social cards · then optional signup |
| **Explore another future** | Multiple Futures™ loop |
| **Exit** | Thank you · optional one-tap feedback |

---

## What Visitor Understands Pre-Conversion

| Understanding | Source |
|-----------------|--------|
| Studio OS is a **headquarters** not a tool list | HQ walk |
| Work happens in **departments · scenes** | Scene Architecture™ demo |
| **Orb** guides the company | Orb Demo™ |
| **AI professionals** collaborate | Cameo moments |
| **Their future** is picturable | Identity projection |
| **Transformation** is possible | Milestone · launch beats |

No feature memorization required.

---

## Social Sharing

After preview · before or after signup:

| Shareable | Marketing value |
|-----------|-----------------|
| **My Future Company** | Archetype · hook · visual |
| **My Headquarters** | HQ render · environment |
| **My Founder Profile** | Discovery snippet |
| **My Recommended Businesses** | Top matches |
| **My Company Preview** | Story composite |

| Share rule | Law |
|------------|-----|
| **Beautiful cards** | Worth posting |
| **Link back** | Recipient enters Preview |
| **No account required to view share** | Viral loop |
| **Privacy controls** | No sensitive financial data |

Every shared preview markets **Step Into Your Future Company™**.

---

## Signup Minimization

Post-yes signup collects **minimum**:

| Required | Optional later |
|----------|----------------|
| Identity (email/OAuth) | Full profile |
| Chosen archetype seed | Payment |
| Preview session link | Team invites |

Full Founder Discovery™ begins **after** account — not at signup form.

---

## Handoff to Founder Discovery™

| Preview data | Discovery use |
|--------------|---------------|
| Light discovery answers | Genome seed |
| Chosen archetype | Report weighting |
| Explored futures | Comparison context |
| Stated preference | Path selection |
| Engagement time | Confidence signal |

Orb: *"Let's go deeper — I'll help you discover the right company to build."*

Leads to [Discovery Report™](../founder-discovery/discovery-report.md) · [Company Preview™](../founder-discovery/company-preview.md) · commit → [Adaptive Onboarding™](../onboarding/README.md).

---

## Re-Entry

Returning visitors:

| Case | Experience |
|------|------------|
| **Anonymous return** | Resume last archetype or restart |
| **Signed up · not committed** | Continue Discovery |
| **Shared link recipient** | Start their own Preview |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Paywall before demo | No belief |
| Conversion mid-walk | Breaks immersion |
| 12-field signup | Friction kills desire |
| Skip Discovery on convert | Shallow commitment |
| Share requires login | Kills viral |
