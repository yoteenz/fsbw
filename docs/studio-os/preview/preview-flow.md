# Preview Flow™

**End-to-End Visitor Journey**

---

## Purpose

Define the complete **Studio Preview™** flow from first touch to conversion — phase by phase.

---

## Flow Overview

```
PHASE 0 — ARRIVAL
PHASE 1 — INVITATION
PHASE 2 — LIGHT DISCOVERY
PHASE 3 — FUTURE SELECTION
PHASE 4 — TRANSPORT
PHASE 5 — HQ DEMO
PHASE 6 — SCRIPTED MOMENTS
PHASE 7 — MULTIPLE FUTURES™ (optional)
PHASE 8 — REFLECTION
PHASE 9 — CONVERSION
PHASE 10 — HANDOFF (if yes)
```

---

## Phase 0 — Arrival

| Property | Law |
|----------|-----|
| **No feature grid** | Immediate experiential frame |
| **No pricing** | Belief first |
| **No signup** | Frictionless entry |
| **Fast load** | Mobile-first · iPhone Safari stable |

Visitor sees Studio OS presence — then invitation.

---

## Phase 1 — Invitation

Single hero:

## **Step Into Your Future Company™**

| Element | Content |
|---------|---------|
| **Subline** | "Experience what running your business could feel like." |
| **Action** | One button · begin |
| **Duration hint** | "About 5 minutes" — honest |

---

## Phase 2 — Light Discovery

Orb conversation · **3–7 turns** target:

| Topic | Example question |
|-------|------------------|
| **Energy** | What kind of work excites you? |
| **Skills** | What do you enjoy using? |
| **Motivation** | Freedom · income · creativity · impact? |
| **Lifestyle** | What life are you building? |
| **Industry** | What industries interest you? |

**Not a quiz** — skip allowed · voice optional future.

Output: ranked Future Company Experiences™.

---

## Phase 3 — Future Selection

Present **3–5** experiences visually — enterable cards · not text list:

```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ Luxury Hair     │  │ Tech Startup    │  │ Creator         │
│ Brand™          │  │                 │  │ Business™       │
│ Step inside →   │  │ Step inside →   │  │ Step inside →   │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

Visitor taps **Step inside**.

---

## Phase 4 — Transport

| Beat | Experience |
|------|------------|
| **Transition™** | Brief · cinematic · not loader |
| **Audio** | Optional swell |
| **Orb** | "Let's go." |
| **Duration** | 2–5s · reduced motion: cut |

Instant feel — [World Streaming™](../world/transitions/world-streaming.md) philosophy.

---

## Phase 5 — HQ Demo

Visitor in **curated Headquarters™**:

| Activity | Description |
|----------|-------------|
| **Orb greeting** | "Welcome. This is what running this company could feel like." |
| **Walk HQ** | Pan · station nav · arrival zone |
| **Explore departments** | 3–5 wings |
| **Enter scenes** | Sample workspaces |
| **Living Sets™** | Environment expression visible |
| **Idle life** | Displays update · ambient motion |

Orb offers gentle guidance — not forced tour.

---

## Phase 6 — Scripted Moments

Curated beats inside demo:

| Moment | Purpose |
|--------|---------|
| **Typical workday** | Morning rhythm |
| **AI collaboration** | Professionals visible · Orb introduces |
| **Product launch** | Distribution · energy |
| **Customer interaction** | CX scene |
| **Milestone celebration** | Belief peak |

Scripted — not founder-operated. Visitor **watches and walks** — may trigger highlights.

---

## Phase 7 — Multiple Futures™ (Optional)

After first demo complete:

Orb: *"Want to explore another future? Salon was first — curious about a software company?"*

| Rule | Behavior |
|------|----------|
| **Encouraged** | No penalty |
| **Soft limit** | Convert CTA after 3 explores |
| **Compare** | Orb summarizes differences |

---

## Phase 8 — Reflection

Brief pause before conversion:

| Orb prompt | Purpose |
|------------|---------|
| "Which future felt most like you?" | Self-identification |
| "What surprised you?" | Feedback signal |
| Optional | Genome seed for signup |

---

## Phase 9 — Conversion

**Only after preview ends.**

Orb:

> *"Would you like to build this company together?"*

| Response | Path |
|----------|------|
| **Yes** | Signup · Founder Discovery™ seed |
| **Not yet** | Save preview link · share options |
| **Explore more** | Return Phase 7 |

---

## Phase 10 — Handoff (If Yes)

| Step | System |
|------|--------|
| Account creation | Minimal |
| Archetype seed | Founder Discovery™ |
| Chosen experience | Company Preview™ path |
| **Not** full onboarding | Discovery first |

---

## Session Persistence

| Data | Persisted |
|------|-----------|
| **Anonymous preview session** | Archetypes explored · duration |
| **Post-signup link** | Attach session to founder |
| **Share tokens** | My Future Company cards |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Signup at Phase 1 | Kills acquisition |
| 30-question discovery | Quiz not preview |
| No scripted moments | Static walk empty |
| Conversion mid-demo | Interrupts belief arc |
