# Founder Journey — Creative Direction Studio™ Alpha

**Discipline owners:** UX · Narrative · AI · Environment  
**Layers:** Company Genome™ · Project Genome™ · Founder Journey™ · Room DNA™

---

## Purpose

The same Creative Direction Studio **topology** adapts to **who the company is**, **what project is active**, and **where the founder is in their journey** — without rebuilding the room.

---

## Modulation Matrix

| Layer | What changes in the room | What never changes |
|-------|-------------------------|-------------------|
| **Company Genome™** | Materials · light warmth · voice · pin style · Orb register | Zone layout · object roles |
| **Project Genome™** | Mood content · Timeline labels · Brief sections · hydration | Furniture positions |
| **Founder Journey™** | Arrival length · ceremony weight · Orb chattiness · pacing | Hero object (Mood Wall) |
| **Room DNA™** | Slider intensity — luxury · editorial · glass · warmth | Envelope dimensions |

| Domain | Environmental effect | Interaction effect |
|--------|---------------------|-------------------|
| `materialLanguage` | Floor · wall · table shaders | — |
| `lightingStyle` | Key-fill · rim · ceremony | — |
| `editorialDirection` | Contrast · typography on glass | Brief pin aesthetic |

| `customerEmotions` | Mood Wall default palette | Seed mood tone |
| `thingsWeNeverDo` | Negative env cues blocked | Brand concierge gate |

### Worked Example — Same Room, Two Companies

**Frontal Slayer** enters:
- Warm marble floor · rose-gold rails · editorial drama light
- Orb: confident · fashion-forward · concise
- Mood Wall default: high contrast · noir accent pins

**Law firm** enters:
- Dark walnut · muted brass · formal balanced light
- Orb: measured · authoritative · longer pauses
- Mood Wall default: restrained palette · trust cues

Founder of each says: *"This is ours."* — not *"This is a template."*

## Founder Journey™ — Temporal Expression

| Journey stage | Arrival | Orb | Ceremony | Pacing |
|---------------|---------|-----|----------|--------|
| **Dreaming** | Extended 7s · zone reveal | Encouraging · exploratory | Light | Slow |
| **Building** | Standard 5s | Practical · status | Medium | Normal |
| **Launching** | Standard · approval nudge if pending | Urgent clarity | Heavy | Normal |
| **Growing** | Short 3.5s | Brief · metrics aware | Medium | Fast option |
| **Leading** | Short · deep work respect | Minimal proactive | Heavy when needed | Fast |
| **Legacy** | Warm · reflective tone | Chronicle aware | Ceremonial | Slow |

| Journey signal | Room response |
|----------------|---------------|
| High cognitive load | Shorter arrival · batch Orb lines |
| Creative time block | Reduced proactive · ambient only |
| First department visit | Extended Orb orientation |
| Return same day | Skip identity phase · resume camera |

## Room DNA™ — Slider Expression

17 sliders from `room-dna.json` — Alpha uses these prominently:

| Slider | Environmental effect |
|--------|------------------------|
| `luxuryLevel` | Material quality · reflection depth |
| `editorialLevel` | Light contrast · drama |
| `glassLevel` | Panel transparency · frost |
| `warmthLevel` | Color temperature global |
| `intelligenceLevel` | Orb · concierge visibility |
| `ceremonyWeight` | Approval duration · audio |
| `founderControl` | Confirm gates · AI autonomy (0.95 CDS) |

High `founderControl` (CDS default): AI **never** auto-approves · always founder gate.

## First Visit vs Return

| Aspect | First visit ever | Return |
|--------|------------------|--------|
| Arrival | 7s · zone reveal | 5s or 3.5s |
| Orb | Full zone introduction | One-liner status |
| Brief Wall | May be empty | Pins restored |
| Mood Wall | Neutral → hydrate | Crossfade if mood shift |
| Tutorial | None — discovery | — |

## Emotional Arc (Single Session)

```
Arrival     → wonder · "this is mine"
Explore     → curiosity · pin · browse
Work        → focus · branch · compare
Decision    → weight · approval ceremony
Departure   → continuity · Discover portal
```

Room lighting subtly follows arc — brighter mid-session · dim ceremony.

---

## What Founder Journey Does NOT Change

- Zone map · portal positions
- Verb set · interaction law
- Hero object identity
- Anti-SaaS environmental law
- Walk the Room path
- Object catalog IDs

## Alpha Test Matrix

| Test | Pass |
|------|------|
| Frontal Slayer · Building | Reads luxury editorial |
| Law firm · Leading | Reads formal · same layout |
| NDXBook · Launching | Reads tech minimal |

## Golden Rule Test

> A founder returning after six months recognizes **the same room** — but feels it has **grown with their company**.

Pass: Continuity of place · evolution of soul.  
Fail: Feels like new skin on same dashboard.
