# Walk the Room™ — Creative Direction Studio™ Alpha

**Discipline owners:** Creative direction · QA · Founder experience  
**Purpose:** Immersive critique path — prove the place works as a place

---

## What Walk the Room Is

Walk the Room™ is **not a slide deck review**. It is a **guided camera path** through the physical department where founder and Studio Intelligence critique the experience **in context**.

Alpha must ship a complete walk path for Creative Direction Studio.

---

## When to Walk

| Trigger | Walk type |
|---------|-----------|
| Alpha validation gate | Full path required |
| Pre-approval | Founder + Creative Director concierge |
| Post-generation | After asset cook complete |
| Return visit QA | Abbreviated path |
| Critique Session | Bound to Creative Direction Review type |

---

## Presentation Mode

Entering Walk the Room:

| System change | Behavior |
|---------------|----------|
| Orb | Moderator voice · shorter lines |
| UI chrome | Suppressed — no extra panels |
| Interruptions | Proactive Orb disabled |
| Camera | Path-driven · founder can pause |
| Lighting | Sequential zone spots |
| Audio | Bed reduces 30% · voice clear |

Exit: Orb *"End walk?"* → return to free exploration.

---

## Full Critique Path (10 stops)

Markers: `markers-walk-room-cds`

| Stop | Zone | Camera | Critique question |
|------|------|--------|-------------------|
| **1** | Entry Portal | Behind founder · wide | Does arrival feel like entering creative authority? |
| **2** | Mood Wall hero | Hero preset | Does inspiration surface feel infinite and alive? |
| **3** | Brief Wall | Orbit left | Is strategic intent readable without UI? |
| **4** | Timeline Table | Primary | Can founder understand project momentum and branches? |
| **5** | Sandbox | Pull back reveal | Does experiment space feel safe and isolated? |
| **6** | Branch Comparison | Compare screen | Can two directions be judged side by side? |
| **7** | Observatory | Alcove intimate | Does company identity visualize without charts? |
| **8** | Reference Library | Right flank | Can research be browsed like a physical library? |
| **9** | Orb Command | Orb preset | Does intelligence feel collaborative not automated? |
| **10** | Founder Review | Ceremony wide | Does approval feel weighty enough to ship direction? |

Optional stop 11: Exit portal — handoff to Discover narrative.

## Braintrust Integration (Validation)

At stops 2 · 4 · 10 — Studio Intelligence may offer **ambient critique lines** (not modal):

- *"Mood Wall scale reads editorial — hero object successful."*
- *"Timeline branch affordance visible from primary camera."*
- *"Approval ceremony weight meets golden criteria."*

Founder retains judgment. Braintrust informs.

| Stop | Fail if |

| 1 | Dashboard visible · no threshold feel |

| 3 | Brief reads as form fields |
| 4 | Timeline reads as Gantt web chart |
| 5 | Sandbox reads as second browser tab |
| 6 | Compare reads as split-screen app |
| 7 | Observatory reads as analytics dashboard |
| 8 | Library reads as file list |
| 9 | Orb reads as chatbot popup |
| 10 | Approval reads as confirm dialog |

Entry → Mood Wall → Timeline → Orb → Founder Review

~3 minutes.

## Walk After Generation

| Check | Method |
|-------|--------|

| No placeholder wireframes | Visual scan all stops |
| Genome tint correct | Walk with 2 genome presets |

---

## Documentation During Walk

Critique session outputs:

- Transcript (voice optional)
- Per-stop pass/fail
- Action items → revision scopes
- Founder decision: proceed · iterate · block

Feeds Alpha iteration loop — not a new governance doc.

---

## Golden Rule Test

> Walking the room convinces a **film director** they are scouting a set — not a product manager reviewing a prototype.

Pass: Sequential spatial narrative · environmental critique.  
Fail: Feels like clicking through Figma artboards.
