# Golden Department™

**Studio OS™ — Canonical Department Reference**

**Status:** Flagship experience standard  
**First Golden Department:** [Creative Direction Studio™](./creative-direction-studio/)

---

## Definition

A **Golden Department** is the first fully realized experience specification for a Studio OS department — the reference implementation that every future department inherits before engineering begins.

> Not a prototype. Not a dashboard. A place.

---

## Purpose

| Golden Department Provides | Future Departments Inherit |
|---------------------------|---------------------------|
| Spatial philosophy | Room as physical environment |
| Interaction patterns | Physical verbs, not forms |
| Runtime behaviors | Arrival, ceremony, collaboration |
| Object systems | SDK object classes in situ |
| Experience principles | Luxury, intelligence, possibility |
| Genome adaptation proof | Same room, different soul |
| Asset package blueprint | Compiler + Runtime contracts |

## Inheritance Rule

Before any new department enters engineering:

1. Read Creative Direction Studio™ Golden Department spec
2. Map zones to department-specific responsibilities
3. Inherit interaction, motion, audio, Genome, and runtime patterns
4. Extend object inventory — never omit SDK anatomy requirements
5. Pass SDK QA Checklist (17) + Runtime QA (20)
