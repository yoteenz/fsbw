# 03 — Interactive Zones

**Golden Department:** Creative Direction Studio™  
**Section:** Dedicated Spaces — Not Cards

---

## Zone Philosophy

Each zone is a **physical destination** in the room. Users walk cameras to zones — they do not click tabs. Every zone has spatial bounds, dedicated objects, allowed verbs, and AI presence.

---

## Zone 1: Creative Brief Wall™

### Purpose

The **strategic anchor** — mission, objective, audience, intent, and founder truth pinned where the founder can see them while working.

### Physical Form

- Full-height left wall (3.5m × 6m equivalent)
- Matte plaster with horizontal brass pin rails every 0.4m
- Sections demarcated by subtle etched lines — not UI dividers

### Content Sections (Pinned)

| Section | Source |
|---------|--------|
| Mission | Company Genome + Project brief |
| Objective | Project Intent |
| Audience | Project audience + Genome customerEmotions |
| Project Intent | Founder / Creative Direction |
| Creative Direction | Living summary — auto-updates |
| Founder Notes | Voice transcripts, sketches, comments |

### Interactions

| Verb | Behavior |
|------|----------|
| pin | Add note or reference to section |
| annotate | Draw/mark on pinned content |
| drag | Reorder section priority |
| speak | Orb adds transcribed note to section |
| compare | Two brief versions side-by-side on wall |

### AI Presence

**Creative Director** reviews brief changes — ambient note appears on rail when direction shifts.

### Genome Adaptation

Typography and pin style from editorialDirection. Law firm: leather-bound aesthetic. Beauty: rose-gold rails.

## Zone 2: Living Mood Wall™

### Purpose

**Infinite inspiration surface** — the emotional and visual heart of Creative Direction.

### Physical Form

- Entire hero back wall — double height
- Continuous surface — no frames between references
- Depth illusion via parallax layers (3 depth planes)

### Supported Reference Types

| Category | Examples |
|----------|----------|
| Social | Pinterest, Instagram, TikTok |
| Design | Behance, Dribbble |
| Photography | Editorial, product, lifestyle |
| Packaging | Physical product references |
| UI | Interface inspiration |
| Motion | Animation, video stills |
| Audio | Album art, sonic mood |
| Material | Texture swatches |
| Typography | Font specimens |
| Product | Competitor and aspirational products |

### Interactions

| Verb | Behavior |
|------|----------|
| pin | Stick reference to wall |
| drag | Move reference on wall plane |
| cluster | Group selected references (lasso) |
| compare | Split wall — two references |
| annotate | Mark up reference |
| reject | Reference dissolves to archive |
| approve | Reference glows — promoted to direction |
| reference-drop | Drop URL, image, reel from founder tools |
| scrub | Pan across infinite wall horizontally |

### Intelligence

**Research Concierge** auto-tags incoming references: lighting, composition, mood, materials, typography, motion, luxury cues, palette, hierarchy.

### Genome Adaptation

Mood Wall imagery character from photographyDirection + visualReferences. Luxury: editorial beauty. NDX: financial editorial gravitas.

## Zone 3: Company Genome Observatory™

### Purpose

**Visualize living Company Genome** — not a text settings page. The founder sees their company's DNA as a living constellation.

### Physical Form

- Left alcove — hemispherical glass vessel (1.2m diameter) on stone pedestal
- Interior: abstract visualization — orbiting domain rings
- Surrounding wall: subtle data streams connecting to Brief Wall and Mood Wall

### Visualized Domains

| Domain | Visualization |
|--------|---------------|
| Mission | Central core glow |
| Values | Orbiting principles — ring nodes |
| Brand DNA | Material texture samples on ring |
| Experience DNA | Motion trails |
| Voice | Waveform ribbon |
| Photography | Thumbnail constellation |
| Lighting | Temperature gradient arc |
| Emotion | Color field aura |

### Interactions

| Verb | Behavior |
|------|----------|
| inspect | Zoom domain — detail panel on glass |
| compare | Genome snapshot vs current Project overlay |
| speak | Orb explains domain in founder language |
| pin | Pin Genome insight to Brief Wall |

### Behavior

- Domains **pulse** when Genome updates
- New learning from Creative Direction causes ring expansion animation
- Never shows raw JSON — always visual metaphor

### AI Presence

**Brand Concierge** guards Observatory — flags Project directions that diverge from Genome.

## Zone 4: Project Timeline Table™

### Purpose

**Temporal command surface** — project evolution, branches, versions, approvals, milestones on glass.

### Physical Form

- Center stage — 2.4m × 1.0m glass table, 40mm apparent depth
- Timeline runs horizontally along table length
- Branch paths rise as glass ribbons above surface
- Founder Notes appear as floating glass cards on table

### Content

| Element | Representation |
|---------|----------------|
| Project evolution | Horizontal timeline with event nodes |
| Branches | Parallel ribbons (Luxury Editorial · Apple Launch · etc.) |
| Versions | Stacked glass sheets per milestone |
| Founder Notes | Cards pinned to events |
| Approvals | Seal markers on approved nodes |
| Milestones | Elevated crystal nodes |

### Interactions

| Verb | Behavior |
|------|----------|
| scrub | Move along timeline |
| drag | Reschedule event · move branch |
| click | Select event — detail panel |
| compare | Two timeline states side-by-side |
| branch | Create new ribbon from event |
| approve | Ceremonial stamp on direction node |
| reject | Node fades — returns to Sandbox |

### AI Presence

**Creative Director** + **Production Manager** — timeline conflict and dependency notes.

---

## Zone 5: Creative Sandbox™

### Purpose

**Experimentation without consequence** — branch ideas, test moods, compare directions. Nothing affects main Project until approved.

### Physical Form

- Behind Timeline Table — secondary glass surface + twin comparison screens
- Frosted when inactive — clears on entry
- Visually subordinate to main table (lower elevation)

### Capabilities

| Action | Behavior |
|--------|----------|
| Branch ideas | Spawn parallel concept on sandbox surface |
| Generate alternates | Orb generates 3 directions — appear as glass cards |
| Compare directions | Twin screens — slider compare |
| Test layouts | Reference arrangements without Mood Wall commit |
| Swap moods | Sandbox Mood preview — doesn't affect hero wall |
| Orb alternatives | *"Show me three luxury directions"* |

### Rule

> **Sandbox is isolated.** Approve verb promotes sandbox branch to Timeline Table main path. Until then, main Project untouched.

### Interactions

| Verb | Behavior |
|------|----------|
| branch | Create sandbox experiment |
| compare | Side-by-side concepts |
| preview | Full-screen concept preview |
| approve | Promote to main timeline |
| reject | Dissolve experiment |
| speak | Orb generates alternatives |

## Zone 6: Reference Library™

### Purpose

**Permanent visual memory** — every inspiration ever collected, categorized, searchable, expanding.

### Physical Form

- Right flank — open shelving (walnut/steel) + vertical touch surface
- Physical metaphor: luxury design archive library
- New references animate onto shelf with spine label

### Categories (Auto)

Lighting · Composition · Typography · Motion · Packaging · UI · Photography · Materials · Color · Brand · Campaign · Social

### Interactions

| Verb | Behavior |
|------|----------|
| browse | Shelf scroll — inertia physics |
| filter | Shelf sections illuminate |
| drag | Drag reference to Mood Wall or Table |
| preview | Hover — large preview without removing from shelf |
| search | Voice or type — Orb assists |
| pin | Quick pin to active project |

### Intelligence

**Research Concierge** maintains categorization. Duplicate detection. Trend clustering.

---

## Zone 7: Orb Command Center™

### Purpose

**Permanent intelligence anchor** — not a chat bubble.

### Physical Form

- Elevated pedestal — stone/metal cylinder, 0.9m height
- Orb floats 0.15m above pedestal
- Subtle command ring on pedestal surface — touch activated

### Example Commands

| Founder Says | Orb Does |
|--------------|----------|
| *"Find stronger references."* | Research Concierge search → results on Library shelf |
| *"Generate three luxury directions."* | Sandbox spawns 3 concept cards |
| *"Compare these campaigns."* | Comparison mode on Sandbox screens |
| *"Why does this feel generic?"* | Brand Concierge analysis on Observatory |
| *"Show me Apple-level art direction."* | Mood Wall filters + Creative Director brief |
| *"Change direction."* | Timeline branch ceremony initiates |
| *"Take me to Storyboarding."* | Navigation Engine departure |

### Presence

Orb always visible from primary camera. Conversation mode: camera shifts to orb preset, ambient ducks.

## Zone Relationships

```
Brief Wall ←→ Observatory (Genome alignment)
     ↓              ↓
Mood Wall ←→ Reference Library
     ↓              ↓
Timeline Table ←→ Sandbox (promote on approve)
     ↓
Orb Command Center (routes to all zones)
```
