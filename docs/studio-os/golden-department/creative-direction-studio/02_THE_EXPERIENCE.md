# 02 — The Experience

**Golden Department:** Creative Direction Studio™  
**Section:** Arrival Through Active Work

---

## Design Principle

> Nothing should feel static.

From the first frame of arrival to the last approval ceremony, Creative Direction Studio™ breathes — light shifts, references drift, audio hums, Orb acknowledges, Project hydrates onto surfaces.

---

## Arrival Sequence (First Visit)

**Duration:** 5 seconds (Genome pacing × 1.0–1.2)

| Phase | Time | What Happens |
|-------|------|--------------|
| **1. Materialize** | 0.0s | Founder appears at Entry Portal. Soft floor reflection. Ambient audio begins at 0%. |
| **2. Reveal** | 0.5–2.0s | Camera travels forward — arrival preset → hero. Living Mood Wall fills view. Ceiling light blooms. |
| **3. Identity** | 2.0–3.0s | Mood Wall crossfades from neutral to Project/Genome mood. Brief Wall pins illuminate sequentially. |
| **4. Orb greeting** | 3.0–4.0s | Orb pulse. Voice (Genome): *"Welcome to Creative Direction. Project [code] is ready."* |
| **5. Settle** | 4.0–5.0s | Camera descends to primary — Timeline Table in focus. Ambient audio reaches 20%. State → ACTIVE. |

**First visit ever:** Extended to 7s with Orb introduction to zones.

---

## Return Visit

| Condition | Arrival Variation |
|-----------|-------------------|
| Pending approval | Camera nudges toward Timeline; Approval glow on table |
| New references overnight | Mood Wall shimmer on new pins |
| Project mood changed | Mood Wall crossfade before settle |
| Blocker active | Orb notification tone; Production Manager ambient note |

## Camera Movement

| Moment | Camera Path |
|--------|-------------|
| Entry | `arrival` → `hero` — slow dolly forward, slight rise |
| Post-greeting | `hero` → `primary` — gentle descend toward Timeline Table |
| Brief Wall focus | Orbit left — Brief Wall fills 60% frame |
| Mood Wall immersion | `hero` preset hold — user scrubs references |
| Sandbox entry | Pull back — reveal Sandbox behind table |
| Orb conversation | `orb` preset — Orb center-right, table soft behind |
| Genome Observatory | Orbit left — alcove intimacy |
| Approval ceremony | `ceremony` — elevated wide, table center |
| Departure | `departure` → Exit Portal |

**Cinematic rule:** No hard cuts except ceremony stamp. Easing: cubic-bezier editorial.

## Orb Greeting

| Context | Orb Behavior |
|---------|--------------|
| First visit | Full voice introduction + zone scan animation |
| Return | Short pulse + project status one-liner |
| Active project | *"Three new references since yesterday. Timeline branch B awaits your review."* |
| No project | *"Ready to begin a new creative direction?"* — Brief Wall activates |

Orb **faces** founder during greeting — pedestal rotates 15°.

## Department Introduction (First Visit Only)

After Orb greeting, **ambient zone reveal** — not a tutorial modal:

1. Brief Wall left edge glow (1s)
2. Timeline Table surface illuminate (1s)
3. Reference Library shelf extend (1s)
4. Sandbox frosted glass clears (1s)
5. Observatory dome pulse (1s)

Founder discovers by looking — not by reading steps.

---

## Project Loading

When Project binds to department:

| Surface | Hydration Animation |
|---------|---------------------|
| Timeline Table | Events rise from glass one-by-one (stagger 150ms) |
| Brief Wall | Sections pin with stick-bounce |
| Mood Wall | References tile in from library (wave) |
| Observatory | Genome domains illuminate as rings |
| Sandbox | Active branches appear as glass cards |
| Floating status panel | Fade attach to table edge |

**Duration:** 2–3s total. Skippable after 1s.

---

## Mood Lighting

Project mood drives room lighting overlay:

| Project Mood | Lighting Shift |
|--------------|----------------|
| Luxury editorial | Warm key +0.1, soft shadows |
| High energy | Cooler key, accent saturation +15% |
| Minimal | Even fill, reduced accents |
| Dramatic | Hero key contrast +20%, table spot |
| Contemplative | Ambient −30%, Observatory glow |

Crossfade 2s on mood change. Synced with Mood Wall breathe.

---

## Ambient Audio

| Phase | Audio |
|-------|-------|
| Arrival start | Silence → room tone fade in (2s) |
| Hero reveal | Subtle string or texture layer (Genome musicStyle) |
| Active work | Room tone 20% + occasional material sounds |
| Pin reference | Soft stick sound |
| Branch create | Glass chime |
| Approval | Ceremony swell — see Motion & Audio doc |

---

## Departure Sequence

| Phase | Duration | Action |
|-------|----------|--------|
| Save state | 0ms | All pins, branches, annotations persist |
| Camera | 1.5s | Travel to Exit Portal |
| Portal | 0.5s | Shimmer + destination preview |
| Audio | 2s | Crossfade out |
| Transit | 1–3s | To next department or HQ |

Work ready for handoff → Exit Portal glows with connection to Storyboarding or Production.

---

## Experience State Machine

```
ARRIVING → INTRODUCING → HYDRATING → ACTIVE
    ↓                      ↓
FOCUSED (zone)          CEREMONY (approval)
    ↓                      ↓
COLLABORATING (AI)      CELEBRATING (launch)
    ↓
DEPARTING
```

Nothing static in any state — ambient loops always running.
