# 04 — Founder Tools

**Golden Department:** Creative Direction Studio™  
**Section:** Founder Input Layer — Every Creative Act Has a Physical Destination

---

## Design Principle

> The founder does not fill forms. They **drop**, **sketch**, **speak**, **branch**, and **approve** — and the room responds.

Every founder action maps to a **zone**, **verb**, and **state mutation**. Nothing is trapped in a modal. Inputs land on surfaces.

## Drop Pipeline

All drops follow the same runtime pipeline:

```
Founder drops asset
       ↓
Drop Zone detects type (image · video · URL · audio)
       ↓
Research Concierge extracts intelligence
       ↓
Asset lands on target surface with stick-bounce animation
       ↓
Reference Library auto-files copy
       ↓
Creative Direction summary updates (if approved-tier)
       ↓
Downstream departments notified (if direction-locked node)
```

### Drop Zone Locations

| Zone | Accepts |
|------|---------|
| Living Mood Wall™ | All visual + motion references |
| Creative Brief Wall™ | Notes, sketches, voice transcripts |
| Project Timeline Table™ | Founder note cards, approval stamps |
| Creative Sandbox™ | Experimental concepts only |
| Orb Command Center™ | Voice-first — Orb routes to correct zone |

**Rule:** Dropping on empty floor routes to Mood Wall by default. Orb confirms: *"Pinned to Mood Wall."*

## Voice Notes

| Step | Behavior |
|------|----------|
| Activation | Hold Orb ring · or Brief Wall voice icon |
| Capture | Waveform ribbon on Brief Wall during record |
| Transcription | Real-time · Creative Director summarizes key intent |
| Placement | Founder Notes section · linked Timeline card if event-specific |
| Playback | Tap card — spatial audio from Brief Wall direction |

Voice is **first-class creative input** — not a accessibility afterthought.

## Branch · Merge · Approve · Reject

### Branch

| Trigger | Result |
|---------|--------|
| Timeline branch verb | New glass ribbon above table |
| Sandbox branch verb | Isolated concept on sandbox surface |
| Orb *"branch this direction"* | Sandbox spawns 3 alternates |

Branches **never overwrite** main path. Parallel ribbons persist until merged or rejected.

### Merge

| Trigger | Result |
|---------|--------|
| Drag ribbon onto main path | Merge ceremony — ribbon flows into main |
| Orb *"merge branch B"* | Confirmation pulse · combined direction summary |

### Approve

| Trigger | Result |
|---------|--------|
| Timeline approve verb | Ceremonial seal · Creative Direction locked node |
| Mood Wall approve verb | Reference promoted to direction tier |
| Orb *"approve this direction"* | Camera → ceremony preset |

Approval triggers **Production unlock** signal to Studio Production Engine™.

### Reject

| Trigger | Result |
|---------|--------|
| Mood Wall reject | Dissolve to Library archive |
| Timeline reject | Node fades · returns to Sandbox if experimental |
| Orb *"reject this"* | Brand Concierge explains divergence if Genome conflict |

## Creative Direction Update Chain

Every founder tool feeds the **living Creative Direction**:

```
Input (any tool)
    ↓
Zone mutation (visual)
    ↓
Project state update (branch-aware)
    ↓
Creative Direction summary refresh (Brief Wall)
    ↓
Genome Observatory pulse (if brand-relevant)
    ↓
Production departments read updated direction
```

## Permissions

| Role | Capabilities |
|------|--------------|
| Founder | All tools |
| Admin collaborator | Drop, comment, sketch — no approve without permission |
| AI staff | Suggest, annotate ambient — never approve on behalf |

Permission gates use SDK runtime `creative-direction.approve` ceremony binding.

---

## Anti-Patterns

| Forbidden | Correct |
|-----------|---------|
| Upload modal with form fields | Drop on wall |
| Textarea for notes | Voice + pin cards |
| Delete reference permanently | Reject → archive |
| Auto-apply sandbox to main | Approve ceremony required |
| Chat thread for revisions | Timeline cards + Brief pins |
