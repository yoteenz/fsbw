# 06 — Genome Adaptation

**Golden Department:** Creative Direction Studio™  
**Section:** Same Room · Different Soul

---

## Design Principle

> Department **architecture stays consistent**. **Personality changes completely** based on Company Genome™.

Creative Direction Studio™ is the proof that Studio OS departments are **Genome-native environments** — not themed skins on a template.

---

## Adaptation Model

```
Fixed (Golden Department topology)
├── Zone positions
├── Object classes
├── Interaction verbs
├── Ceremony structure
└── Runtime behavior contracts

Variable (Genome-injected)
├── Materials & textures
├── Lighting temperature & rig weights
├── Exterior view plate
├── Typography on objects
├── Particle character
├── Audio palette
├── Mood Wall default imagery character
├── Observatory visualization palette
└── Orb voice register
```

**Compiler** injects at generation time. **Runtime** hot-swaps shader slots and audio stems on Genome update.

## Genome Update Behavior

When Company Genome updates mid-session:

| Phase | Runtime Response |
|-------|------------------|
| Detect | Observatory pulse · all rings expand 1s |
| Materials | Shader crossfade 2s — no pop |
| Lighting | Temperature shift 1.5s |
| Mood Wall | Optional founder confirm if direction conflict |
| Audio | Stem crossfade 1s |
| Brief Wall | Mission/values pins refresh content |

**Brand Concierge** flags Project directions that diverge from new Genome.

---

## Compiler Prompt Strategy

Each Genome field maps to **prompt modifier slots** in Asset Compiler profile `creative-direction`:

```yaml
genomeSlots:
  materialLanguage: → environment, furniture, floor prompts
  lightingStyle: → lighting-rig, particles prompts
  photographyDirection: → mood-wall-default, library-seed prompts
  editorialDirection: → brief-wall-typography, glass-panel prompts
  voice: → orb-audio, concierge-voice prompts
```

Regeneration: single slot swap without full department rebuild. See [11 — Compiler & Runtime](./11_COMPILER_AND_RUNTIME.md).
