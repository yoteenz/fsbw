# 05 — Art Direction

**Golden Department:** Creative Direction Studio™  
**Section:** Visual Philosophy — Anti-SaaS Law

---

## Design Intent

Creative Direction Studio™ should feel like stepping into:

- A **luxury architecture studio**
- An **editorial design office**
- A **Hollywood production headquarters**
- An **Apple Industrial Design Lab**
- A **fashion creative agency**
- A **high-end interior design firm**

It must **never** resemble generic SaaS, admin dashboards, or productivity software.

---

## Reference Registers

| Register | Visual Cues | Spatial Expression |
|----------|-------------|-------------------|
| **Luxury architecture** | Stone, brass, gallery proportions, intentional negative space | Double-height hero, floor reflection |
| **Editorial design** | Typography as architecture, grid as invisible structure | Brief Wall pin rails, Mood Wall as spread |
| **Hollywood production** | Command table, timeline ribbons, approval ceremony | Timeline Table as writers' room surface |
| **Apple ID Lab** | Material honesty, precise shadows, object clarity | Glass table refraction, minimal ornament |
| **Fashion agency** | Texture, fabric metaphor, mood as atmosphere | Mood Wall parallax, velvet optional seating |
| **Interior design firm** | Material samples, swatch logic, client presentation | Reference Library shelving, Genome Observatory |

Registers **blend** — never one aesthetic alone. Genome selects emphasis.

---

## Anti-SaaS Law

### Forbidden Visual Patterns

| Pattern | Why Forbidden | Replacement |
|---------|---------------|-------------|
| Card grid | Implies dashboard | Physical zones |
| Left sidebar nav | Implies app chrome | Camera travel + Orb routing |
| Top header with logo | Implies website | Genome on Mood Wall |
| White void + floating panels | Implies Figma mockup | Full room envelope |
| Data tables | Implies spreadsheet | Timeline Table spatial ribbons |
| Form fields | Implies settings page | Pin, drop, speak |
| Modal dialogs | Implies interruption | In-world glass panels |
| Toast notifications | Implies web app | Orb pulse + ambient zone glow |
| Progress bars | Implies loading screen | Environmental hydration animation |
| Chat bubble Orb | Implies support widget | Orb Command Center pedestal |
| Stock photography hero | Implies marketing site | Live project references only |
| Rounded rectangle buttons | Implies Bootstrap | Touch rings, pin gestures, glass affordances |

### The SaaS Test

Before any visual decision, ask:

> *Would this appear on Notion, Linear, or a generic admin template?*

If yes — **reject it**.

## Typography Philosophy

| Context | Treatment |
|---------|-----------|
| Brief Wall content | Editorial serif or Genome display — large, pinned physically |
| Timeline labels | Small caps sans — etched on glass |
| Mood Wall references | No overlay text on imagery — metadata on inspect only |
| Orb voice | Spoken — captions optional, never primary |
| Library spine labels | Micro typography — luxury book spine proportion |

**No UI font stack visible at room scale.** Text lives on objects, not on HUD chrome.

---

## Color Philosophy

| Layer | Rule |
|-------|------|
| Room materials | Genome materialLanguage — neutral luxury base |
| Accent | Single Genome accent — brass, rose-gold, steel per company |
| Mood Wall | Project palette — dynamic, not brand-locking entire room |
| Approval ceremony | Genome celebration color — brief, not garish |
| Reject dissolve | Desaturate — never red error state |

**No semantic color system** (green = success, red = error). States express through **light, motion, and material**.

---

## Composition Rules

| Rule | Application |
|------|-------------|
| **Hero dominance** | Mood Wall owns 55% vertical FOV from entry |
| **Human scale** | Table at 0.72m — founder stands, not sits at desk |
| **Depth layering** | Foreground table · midground shelves · background hero |
| **Asymmetry** | Orb off-center — not symmetrical dashboard layout |
| **Breathing room** | Negative space between zones — luxury is space |
| **No edge-to-edge UI** | Room has walls — content does not bleed to viewport as web page |

---

## Material Honesty

Surfaces must read as **real materials**:

| Material | Visual Requirement |
|----------|-------------------|
| Glass | Refraction, edge highlight, content behind surface |
| Stone | Subtle grain, floor reflection |
| Wood | Grain direction, warm specular |
| Brass | Patina variation, pin rail warmth |
| Plaster | Matte, pin shadow depth |

Genome swaps material families — topology stays honest.

---

## Light as Design

Lighting is **not ambient fill** — it is **direction**:

| Moment | Light Behavior |
|--------|----------------|
| Entry | Hero key blooms — revelation |
| Work | Table key crisp — clarity |
| Mood immersion | Hero wash intensifies |
| Approval | Ceiling ceremony grid |
| Reject | Soft dim — not punitive flash |

See [01 — The Room](./01_THE_ROOM.md) for rig specification.

## Motion as Design

Motion communicates **life**, not **loading**:

| Motion Type | Character |
|-------------|-----------|
| Parallax | Slow, editorial — 0.5px/s |
| Pin land | Stick-bounce — physical |
| Branch spawn | Glass ribbon rise — 600ms |
| Approve stamp | Ceremonial press — weight |
| Crossfade | Mood transition — 1.2s |

See [10 — Motion & Audio](./10_MOTION_AND_AUDIO.md).
