## Mission

Every company inside Studio OS receives a **monthly Creative Budget™**.

The budget represents **how much creative production is available** — not how many API calls remain.

Founders should think like **Creative Directors**:

- Every reused asset increases efficiency
- Every Blueprint strengthens the company
- Every approved generation becomes a long-term investment

---

## One Sentence

**Creative Budgets™** tracks monthly creative capacity — **Estimated Production Spend™**, **Creative Savings™**, reuse rollups, and **Efficiency Score™** — with the Orb coaching founders toward intelligent production.

---

## What Creative Budgets™ Tracks

| Field | Meaning |
|-------|---------|
| **Monthly Budget™** | Creative production capacity for the billing month |
| **Estimated Production Spend™** | Completed production value consumed |
| **Estimated Pending™** | Approved-but-not-yet-completed production value |
| **Creative Savings™** | Value preserved through reuse this month |
| **Efficiency Score™** | How intelligently the headquarters produced |
| **Assets Reused™** | Registry reuse count (month) |
| **Blueprint Systems Reused™** | Blueprint/System inheritance count (month) |
| **Monthly Production™** | Productions completed this month |
| **Pending Productions™** | Productions queued or in progress |
| **Completed Productions™** | Productions finished and certified |

## Engine Position

```
Monthly Creative Budget™ allocated
         ↓
Production requests → Production Estimate™ (per job)
         ↓
Founder approves → spend reserved as Estimated Pending™
         ↓
Generation Manager™ executes
         ↓
On complete → Estimated Production Spend™ increases
         ↓
Reuse savings → Creative Savings™ + Efficiency Score™
         ↓
Orb coaches toward higher reuse · maturity · consistency
```
