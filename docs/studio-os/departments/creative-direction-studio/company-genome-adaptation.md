# Company Genome Adaptation — Creative Direction Studio™

**Department ID:** `creative-direction`

## Adaptation Model

```
FIXED (Golden topology)              VARIABLE (Genome-injected)
├── Zone positions                   ├── Materials & textures
├── Object classes                   ├── Lighting temperature & rig
├── Interaction verbs                ├── Exterior view plate
├── Ceremony structure               ├── Typography on objects
├── Sandbox isolation rule           ├── Particle character
└── Runtime behavior contracts       ├── Audio palette
                                     ├── Mood Wall imagery character
                                     ├── Observatory palette
                                     ├── Orb voice register
                                     ├── AI terminology
                                     └── Environmental storytelling
```

**Compiler** injects at generation. **Runtime** hot-swaps shader slots and audio on Genome update.
