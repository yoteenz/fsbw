> It is not a logo · style guide · theme · or color palette.  
> Every Studio OS intelligence system consults it before any creative decision.

**Evolution engine:** [Living Company Genome™](./living-company-genome/README.md) — Genome Events™ · World Evolution™ · Time Capsule™ · how DNA matures in the world.

**v2 Intelligence Engine (2026-07-08):** [engines/company-genome/](./engines/company-genome/README.md) — Visual · Creative · Brand · Operational · Decision DNA™ · confidence scoring · Prompt Composer™ integration · marketplace learning · universal intelligence (no tenant hardcoding).

---

## §1 Problem Statement

Experience Studio™ can generate premium layouts — but layouts disconnected from company identity produce **generic templates**, not authentic branded experiences.

**Studio OS must never create generic experiences.**

Every output must feel **inevitable for that specific company** — as if it could only have been created for them.

---

## §5 The Genome Is Learned

Studio OS does **not** require manual completion of hundreds of fields.

Studio Intelligence™ continuously builds the Genome from:

| Source | Signal extracted |
|--------|------------------|
| Onboarding conversations | Identity · industry · aspiration |
| Founder conversations | Values · voice · judgment |
| Mood boards | Visual rhythm · palette principles |
| Pinterest · Instagram · TikTok · Behance | Reference patterns |
| Packaging · photography · videos | Material · art direction |
| Fonts · brand assets | Typography · identity markers |
| Existing websites | Current expression baseline |
| Previous projects | Proven patterns |
| Customer feedback | Emotional outcome validation |
| Creative decisions · approvals | Reinforcement |
| Founder revisions | Refinement |
| Design approvals | Canon strengthening |
| Notes | Institutional knowledge |
| **Rejected concepts** | Negative learning — critical |

Every interaction teaches Studio OS something new about the company.
