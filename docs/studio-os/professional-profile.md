# Professional Profile™ (M164)

**Living career identities that evolve — not static resumes.**

## Philosophy

Professional Profiles™ evolve alongside each person throughout their career. They are dynamic representations of professional growth — never snapshots frozen in time.

## Profile Contents

Each living profile includes:

- Experience and current role
- Skills and certifications
- Profession Brains™ linkage
- Projects and achievements
- Learning history and courses completed
- Academy progress (Studio Institute™)
- Knowledge contributions
- Mentorship and recommendations
- Leadership history
- Portfolio (projects, brains, marketplace products)
- Industries and languages
- Communication style and work preferences

## Professional Timeline™

Every profile maintains a career growth timeline:

| Event Type | Examples |
|------------|----------|
| Promotion | Role advancement |
| Project | Delivered initiatives |
| Award | Recognition |
| Certification | Studio Institute credentials |
| Leadership Role | Scope and impact |
| Skill Learned | Capability growth |
| Business Founded | Entrepreneurial milestones |
| Profession Brain™ Created | Expertise institutionalized |
| Marketplace Product Published | Expert offerings |
