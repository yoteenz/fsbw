# Studio Critique Sessions™

**Version:** 1.0.0  
**Status:** Canonical Engine Specification  
**Type:** Core Studio OS Engine — not a feature, not a department  
**Parent:** [Studio Validation Loop™](../validation-loop/README.md) · [Company Genome™](../../company-genome.md) · [Creative Direction Studio™](../../creative-direction-studio.md)  
**Engine ID:** `studio.critique-sessions.v1`

---

> **Not an approval screen. Not a scorecard. Not a checklist. A structured creative conversation.**

Studio Critique Sessions™ is the **official collaborative review experience** inside Studio OS — where the founder sits with Studio Intelligence as trusted advisors before important work is approved.

The goal is not simply to approve work. **The goal is to make the work better.**

---

## What This Engine Does

| Does | Does Not |
|------|----------|
| Host structured creative conversations | Replace Validation Loop approval gates |
| Assemble relevant AI specialists per topic | Force consensus among advisors |
| Enable natural dialogue and debate | Feel like reading comment threads |
| Capture founder decisions as institutional memory | Judge or lecture the founder |
| Generate action items and revision workflows | Auto-apply changes without founder consent |
| Connect recommendations to Production Engine | Generate departments or assets |
| Learn from outcomes post-launch | Implement React review UI |

## Final Philosophy

> Studio Critique Sessions™ should feel like gathering the leadership team of an elite creative company before making an important decision.

The founder should never feel judged. They should feel **challenged**, **supported**, **inspired**, and **equipped** to make better creative decisions.

The AI team behaves like experienced colleagues — not chatbots.
