## Evolution Phases

### Phase 1 — Canonical (Current Spec)

Mode resolution · 7 walk modes · dynamic HQ · Orb adaptation · personalization · memory

### Phase 2 — Multi-Leader

| Capability | Adaptation |
|------------|------------|
| Multiple founders | Per-founder `AdaptiveWalkMemoryProfile` |
| Department heads | Role-scoped modes · subset paths |
| Leadership teams | Shared mode · personal priority stacks |
| Board mode | Celebration + Analytics emphasis · sanitized story |

### Phase 3 — Hosted Tours

| Tour Type | Mode Profile |
|-----------|--------------|
| Investor tour | Success + opportunity story · sanitized |
| Client tour | CX + Publishing emphasis |
| New employee onboarding | Morning Brief extended · training stops |
| Training simulation | Scripted mode resolution for practice |

### Phase 4 — Immersive

AR · VR · Vision Pro — same mode resolution · same story · new renderer via `MediumAdapter` (Walk the Business 12).
