# 12 — QA Validation

**Engine Module:** `studio.asset-compiler.v1.qa`  
**Status:** Automated package validation specification  
**Philosophy:** Every package is validated before it reaches Runtime — no broken assemblies

---

## Definition

QA Validation is an **automated gate** executed at Pipeline Stage 14. Every Department Asset Package must pass validation before export, registration, or Marketplace publication.

Complements SDK [17 — QA Checklist](../../sdk/17_QA_CHECKLIST.md) (experience-level) with **compiler-level** technical validation.

---

## Validation Pipeline

```
Stage 14: QA VALIDATION
    │
    ├── 14.1  Package Structure Validation
    ├── 14.2  Asset Completeness Check
    ├── 14.3  Metadata Validation
    ├── 14.4  Genome Compliance Scan
    ├── 14.5  Lighting Conflict Detection
    ├── 14.6  Scale and Proportion Check

    ├── 14.8  Marketplace Compatibility
    ├── 14.9  Performance Budget Check
    ├── 14.10 Accessibility Compliance
    └── 14.11  Integrity Verification
```

## Validation Report

```yaml
ValidationReport:
  id: string
  packageId: string
  executedAt: datetime
  overallResult: enum               # passed | conditional | failed
  checks:
    - id: string
      category: string
      check: string
      result: enum                  # pass | fail | warning | na
      severity: enum
      message: string | null
  summary:
    total: number
    passed: number
    failed: number
    warnings: number
  blockingFailures: string[]        # must fix before export
  recommendations: string[]
```

---

## Result Actions

| Result | Action |
|--------|--------|
| **Passed** | Export to Asset Registry™; available for Runtime |
| **Conditional** | Export with warnings; flag for human review |
| **Failed** | Block export; return to regeneration with targeted fixes |

### Automatic Rejection (Failed)

- Missing required assets
- Hardcoded branding detected
- Flattened scene detected
- Broken metadata
- Interaction map invalid
- Package exceeds size budget
- Critical scale/placement errors

---

## Validation in Regeneration

After surgical regeneration (11), only regenerated assets are re-validated:

```
Full compile → Full validation (all 14.1–14.11)
Single asset regenerate → Validate asset + dependencies + integrity
Category regenerate → Validate category + cross-category conflicts
```
