# 10 — Emotional Design

**Engine Module:** `studio.walk-the-room.v1.emotional-design`  
**Status:** Experience quality targets  
**Philosophy:** Elite creative headquarters — never overwhelming.

---

## Emotional Goal

Walk the Room™ should feel like **touring an elite creative headquarters** with the world's best creative minds.

The founder should leave feeling:

| Feeling | How We Achieve It |
|---------|-------------------|
| **Inspired** | Beautiful room · visionary creative direction · live previews |
| **Confident** | Clear decisions · explicit action items · nothing lost |
| **Understood** | Concierges reference Genome · prior decisions · founder rationale |
| **Challenged** | Respectful debate · evidence-based dissent |
| **Supported** | Orb paces · concierges praise before pivot · no judgment |
| **Excited** | Live visualization · immediate possibility |
| **Never overwhelmed** | Pacing · scope options · pause anytime |

---

## Anti-Emotional Targets

| Never Feel | Prevention |
|------------|------------|
| Judged | No shame language · challenge work not founder |
| Lectured | Concierges converse · Orb facilitates |
| Buried in feedback | Paced stops · critical-only mode |
| Lost | Orb orients · path narrative · memory ghosts |
| Like a meeting | In the environment · not conference UI |
| Like a design review | Walking with executive team metaphor |
| Anxious about next steps | Action Mode at every critique · summary |

---

## Pacing Architecture

| Mechanism | Detail |
|-----------|--------|
| Welcome scope choice | Complete vs critical vs custom |
| Stop duration caps | Orb gently suggests advance if >5 min at stop |
| Pause anytime | Founder · Orb checks every 3 stops |
| Concierge queue | One speaks · one responds — no pile-on |
| Preview opt-in | Previews shown on request — not auto-spam |
| Memory layer toggle | Reduce visual history noise if founder prefers clean room |

---

## Luxury Register

Walk the Room inherits Company Genome luxury register:

| Genome Register | Walk Behavior |
|-----------------|---------------|
| Editorial luxury | Slow camera · long pauses · restrained highlights |
| High energy | Snappier transitions · still spatial — not frantic |
| Intimate | Quieter concierges · closer staging |
| Cinematic | Wider camera · ceremony weight on previews |

Brand Concierge validates emotional register alignment at Environment stop.

---

## Signature Experience Test

Before Walk the Room ships for any environment, founders must answer:

> *"Does this feel like walking through my company with my executive team?"*

If answer trends toward *"I had another design review"* — **fail** emotional gate.
