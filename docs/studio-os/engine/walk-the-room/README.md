# Walk the Room™

**The Immersive Critique Experience**

**Version:** 1.0.0  
**Status:** Canonical Experience Specification  
**Type:** Flagship Studio OS Interaction System — not a page, not a meeting  
**Parent:** [Studio Critique Sessions™](../critique-sessions/README.md) · [Studio Department Runtime™](../department-runtime/README.md) · [Experience Engine™](../../experience-engine.md)  
**Engine ID:** `studio.walk-the-room.v1`

---

> **People do not experience businesses as PDFs. People experience places. Studio OS reviews work the same way.**

Walk the Room™ is one of the **defining experiences** of Studio OS — an immersive walkthrough where the founder and Studio Intelligence physically explore a department, experience, project, campaign, or headquarters **together**, inside the environment being discussed.

Not a meeting. Not a review page. Not a comment thread.

---

## What This Experience Does

| Does | Does Not |
|------|----------|
| Review work inside the live environment | Display documents or PDFs |
| Anchor every critique to spatial objects | Detach feedback from context |
| Preview revisions live in the room | Ask founders to imagine changes |
| Guide walkthroughs with narrative paths | Random zone hopping |
| Remember prior walkthroughs per room | Forget institutional history |
| Connect actions to Production Engine | Leave founder wondering what's next |
| Implement Critique Sessions spatially | Replace Critique Sessions logic |
| Build React review dashboards | Generate comment threads |
