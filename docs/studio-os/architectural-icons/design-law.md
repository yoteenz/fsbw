# Design Law™

**The Five Rules of Signature Landmarks™**

---

## Authority

Every Signature Landmark™ in Studio World™ — Department™ or Headquarters™ — must satisfy **all five rules**.

Failure on any rule blocks:

- Golden Build™ certification
- Marketplace™ publication
- Department Generator™ approval

---

## Rule 1 — Immediately Recognizable

The landmark must be identifiable in **under three seconds** — without labels · without UI chrome · without explanation.

| Pass | Fail |
|------|------|
| Silhouette alone identifies department | Requires text label to understand |
| Founder describes it visually | Founder describes it functionally |
| Blind shoulder test passes | Could be any department's wall |

**Test:** Show a grayscale silhouette. Can a founder name the department?

**Creative Direction Studio™:** Floating illuminated table · projections · circular gathering — **Story Table™** is unmistakable.

---

## Rule 2 — Impossible to Confuse

No two departments may share a landmark **archetype**.

| Confusion risk | Resolution |
|----------------|------------|
| Two "big walls" | Differentiate: editorial wall vs command wall vs genome constellation |
| Two "tables" | Only Story Table™ is a table-landmark |
| Two "maps" | Launch Constellation™ owns suspended global map |

**Registry enforcement:** [landmark-registry.md](./landmark-registry.md) — duplicate archetypes rejected at Blueprint™.

---

## Rule 3 — Visible From Multiple Viewpoints

The landmark must read from:

- **Arrival threshold** — partial reveal · silhouette · light spill
- **Primary workstation** — full presence · functional access
- **Transition paths** — glimpse from hallway · doorway · adjacent scene
- **Routine re-entry** — founder returning knows where they are

| Pass | Fail |
|------|------|
| Landmark visible during Arrival Sequence™ | Only visible at one camera lock |
| Orb references landmark directionally | Landmark hidden behind panels |
| Walk between scenes · landmark still orients | Landmark disappears off-screen |

**Mobile note:** Multiple viewpoints achieved through camera zones · dolly · threshold peek — not desktop-only angles.

---

## Rule 4 — Functional · Not Decoration

The landmark must be the **primary surface** where the department's most important work happens.

| Landmark | Core function |
|----------|---------------|
| Story Table™ | Creative decisions · briefs · concept review |
| Living Company Genome™ | Knowledge navigation · insight discovery |
| Launch Constellation™ | Campaign deployment · market visibility |
| Capital Vault™ | Financial review · runway · investment decisions |
| Talent Observatory™ | Candidate evaluation · team assembly |
| Fulfillment Nexus™ | Order flow · logistics command |
| Charter Hall™ | Contract review · compliance · formation |
| Relationship Gallery™ | Customer story · loyalty · community |
| Operations Engine™ | System health · automation · execution |

**Decoration test:** Remove the landmark. Does the department lose its primary workflow? If no → not a landmark.

---

## Rule 5 — Emotionally Memorable

Founders should remember the landmark **years later** — even if they forget feature names.

| Signal | Meaning |
|--------|---------|
| Founder uses landmark name in speech | Memory anchored |
| Milestone tied to landmark | Event memory |
| Founder describes feeling · not feature | Emotional success |
| Preview visitors mention landmark | Acquisition success |

**Memorable qualities:**

- Scale — landmark feels larger than interface
- Light — architectural illumination · not screen glow
- Motion — subtle life · not static render
- Sound — optional spatial audio at landmark (future)
- Celebration — milestones manifest at landmark

---

## Composite Benchmark

All five rules collapse into one question:

> *"If someone walked into this room without context — would they believe this is the world's most advanced operating system for this domain — and would they remember this place tomorrow?"*

## Violations

| Violation | Remedy |
|-----------|--------|
| No landmark declared | Block department creation |
| Duplicate archetype | Redesign before registry |
| Decorative-only | Merge function into landmark or redesign |
| Hidden landmark | Revise Arrival Sequence™ · camera zones |
| Forgettable | Scale · light · motion pass |
