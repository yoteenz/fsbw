## CDS Clarification

Creative Direction Studio™ Environmental Pass V1 implemented **hero objects per station** — atmospheric focal points within scenes.

**Architectural Icons™ clarifies:**

- **Story Table™** = Signature Landmark™ (department identity)
- Mood Wall · Pipeline · Notes Desk · Library = **scenes** with hero objects — not department landmarks

No CDS redesign required — canon now names what the Story Table already is.
