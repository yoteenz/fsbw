# Orb™ · Landmark System

**The Host and the Icon**

---

## Law

The **Orb™** interacts with every Signature Landmark™.

The landmark and the Orb must **always feel connected** — never separate systems.

---

## Roles

| Entity | Role |
|--------|------|
| **Orb™** | Host · guide · intelligence · universal |
| **Signature Landmark™** | Department identity · primary work surface · memory anchor |

The Orb is not the landmark.  
The landmark is not the Orb.  
They are **partners**.

---

| Behavior | Detail |
|----------|--------|

## Context Stack Integration

[Orb Context System™](../navigation/orb-context-system.md) must include landmark layer:

```
Orb context stack:
├── Company
├── Department
├── Signature Landmark™  ← NEW LAYER
├── Scene
├── Workspace
├── Task
└── Project
```

Orb speech prioritizes landmark when department changes:

> *"We're at the Story Table now."*

Not:

> *"You're in Creative Direction Studio scene 2."*
