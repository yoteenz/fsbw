# Headquarters Landmarks™

**The Icon of Studio World™**

---

## Law

Headquarters™ is not only a container for departments.

**Headquarters™ itself possesses one Signature Landmark™** — the image people associate with Studio OS.

When someone pictures Studio World™ — they picture the **HQ landmark** first.

Departments are wings. The HQ landmark is the **front door of memory**.

---

## The Requirement

| Entity | Landmark count |
|--------|----------------|
| Each Department™ | Exactly 1 |
| Headquarters™ | Exactly 1 |
| Studio World™ (umbrella) | HQ landmark represents the world |

## Selection Criteria

HQ landmark must satisfy [Design Law™](./design-law.md) **plus**:

| HQ-specific rule | Detail |
|------------------|--------|
| **World entry** | First thing preview visitors and founders encounter |
| **Department hub** | All department portals readable from landmark vicinity |
| **Studio OS identity** | Marketing · ads · social sharing reference this image |
| **Not a department** | Must not duplicate any department landmark archetype |
| **Survives Living Set™** | Expression changes · structure persists |

---

## Relationship to Studio Preview™

[Studio Preview™](../preview/README.md) curated Headquarters™ demos should **reveal the HQ landmark** within the first 30 seconds.

Preview visitors remember:

> *"I stepped into a company with a Grand Atrium / Heart / Tree…"*

Not:

> *"I saw a dashboard."*

---

## Relationship to Walk the Business™

[Walk the Business™](../engine/walk-the-business/README.md) daily ritual begins and returns through HQ landmark vicinity.

Morning arrival:

```
Founder enters Headquarters™
        ↓
HQ Signature Landmark™ (orientation · emotional reset)
        ↓
Adaptive Walk™ routes to departments
        ↓
Return to HQ landmark (day closure)
```

## Recommended Default (Canon Proposal)

**The Grand Atrium™** is the recommended default HQ Signature Landmark™ — pending Founder Review™ at Headquarters Golden Build™.

| Reason | Detail |
|--------|--------|
| Universal recognition | Atrium = arrival · wonder · orientation |
| Department radiation | Portals to all departments visible |
| Pixar precedent | Creative headquarters cultural reference |
| Preview-friendly | Immediate belief · scale · ambition |
| Orb placement | Natural host position at center |

Alternative selection does not invalidate department landmarks.
