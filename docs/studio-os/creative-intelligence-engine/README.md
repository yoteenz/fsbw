## Mission

**Creative Direction Studio™** is no longer a page · dashboard · or collection of forms.

It is Studio OS's **Creative Intelligence Engine™** — the first immersive destination where founders walk into Pixar's creative headquarters, Apple Industrial Design Lab, a Hollywood production studio, and an architectural visualization firm **combined into one**.

Everything rebuilds around that philosophy.

**This sprint:** architecture only — not pixel perfection · not UI polish · not prototype iteration.

## Prompt Pipeline (Summary)

**Production engine:** [Generation Pipeline™](../engines/generation-pipeline/README.md)

```
Founder Intent™ → Prompt Composer™ → Scene Planner™ → Registry Check™
→ Missing Assets™ → Estimate → Provider Optimizer™ → Generation Queue™
→ Quality Inspector™ → Founder Approval™ → Scene Assembly™
→ Registry Update™ → Workspace Published™
```

Layer-by-layer: Environment → Lighting → Architecture → Furniture → Hero Objects → Atmosphere → Particles → Runtime FX.

Founders **never** write production prompts.
