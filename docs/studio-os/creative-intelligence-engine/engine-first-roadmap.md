## Build Order (Engine First)

```
PHASE 0 — FREEZE
  Stop CDS prototype UI iteration

PHASE 1 — PIPELINE CONTRACTS
  Founder Intent™ schema
  Scene Planner™ · Prompt Composer™ interfaces
  Quality Inspector™ gates
  Integration: Generation Manager™ · Asset Registry™

PHASE 2 — SCENE STACK SERVICE
  Per-layer job orchestration
  Regeneration · versioning
  Scene Assembly™ compositor spec

PHASE 3 — CDS WORKSPACE MANIFESTS
  Six workspace scene manifests (layers per room)
  Blueprint scope: Editorial Luxury™
  Production Estimate™ per workspace bootstrap

PHASE 4 — FIRST GENERATED SCENE
  Single scene proof: Story Table™ OR Arrival™
  Layer-by-layer generate · approve · compose
  Not pixel-perfect — pipeline proof

PHASE 5 — REMAINING CDS SCENES
  Mood Wall™ · Notes Desk™ · Pipeline™ · Library™
  Transitions™ between scenes

PHASE 6 — PHYSICAL PRESENTATION
  Camera · movement · Idle Life™
  Diegetic controls on objects
  Orb host behaviors

PHASE 7 — GOLDEN BUILD BENCHMARK
  Full CDS department certified
  Package export for department factory
```

**Environment presentation (Phase 6) follows pipeline proof (Phases 1–5).**

Replaces V2 order that started with visual environment before generation engine.
