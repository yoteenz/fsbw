# Physical Workspaces™

**Module:** `studio.creative-intelligence-engine.v1.physical-workspaces`  
**Status:** Design the room first — controls second

---

## Law

> **STOP building UI first.** Design the physical department first. Then determine where controls naturally exist inside that space.

---

## Arrival™

**Role:** Threshold · scale reveal · curiosity — never the full headquarters at once.

| Element | Physical description |
|---------|---------------------|
| **Threshold** | Doors · hallway · partial sightline |
| **First sight** | Story Table™ silhouette · Orb glow |
| **Scale** | Ceiling height · depth beyond walls |
| **Sound** | Distant production floor · HVAC hush |
| **Controls** | Walk forward · no forms |

**Generation focus:** Environment Shell™ · Lighting™ · Atmosphere™ — partial stack only.

---

## Story Table™

**Role:** Executive strategy · narrative command center · **Signature Landmark™**.

| Element | Physical description |
|---------|---------------------|
| **Table** | Large executive strategy table — illuminated surface |
| **Orb** | Floating above table — spatial host |
| **Holographic project cards** | Diegetic projections on table plane |
| **World map** | Embedded in table or wall flank |
| **Concept boards** | Angled boards around table perimeter |
| **Camera** | Slowly orbiting — cinematic presence |

**Natural controls:** Touch cards on table · voice to Orb · gesture approve.

**Not:** Form fields on webpage · floating React cards.

## Control Placement Rule

```
1. Identify physical object
2. Ask: "What would a creative director touch here?"
3. Map software action to that touch
4. Never invent floating HUD unless Orb diegetic
```
