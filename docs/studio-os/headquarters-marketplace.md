# Headquarters Marketplace™

**Studio OS™ — Intellectual Property Economy for Business Architecture**

**Type:** Platform philosophy + architecture (not implementation)

**Status:** Canonical direction — supersedes traditional marketplace / template-store concepts in Studio OS documentation

**Parent:** [Headquarters Engine™](./headquarters-engine.md)

---

## Executive mandate

The Studio OS Marketplace is **Headquarters Marketplace™**.

Creators sell **business architecture** — not graphics, page templates, or theme files.

Each listing installs an **entire operational capability** into a customer's existing Headquarters.

---

## What is sold

| Sold | Not sold |
|------|----------|
| Client Onboarding Department™ | Landing page template |
| Podcast Studio Expansion™ | Canva-style graphics pack |
| VIP Membership Wing™ | Feature unlock code |
| Executive Operations Center™ | Isolated SaaS app |
| Photography Studio™ | Stock photo bundle |

Every install includes **together**:

- UI surfaces and spatial layout
- AI behavior and specialist roles
- Workflows and handoff criteria
- Documentation and SOPs
- Analytics and dashboards
- Automations
- Concierge team definitions
- Knowledge structure

---

## Intellectual property economy

Creators invest months designing operational excellence — then publish for other Headquarters to install **instantly**.

Example: Six months designing the world's best **Client Onboarding Department™** → one Marketplace publish → instant install across the ecosystem.

This is an **IP economy** for how businesses run — not a asset store for files.

---

## Genome-First personalization (CA-002)

Every Marketplace install **inherits Company Genome™ + Project Genome™**.

| Stage | Genome role |
|-------|-------------|
| Discovery | Match listings to genome-known gaps · aspirations · signature moments |
| Preview | Show how expansion feels **for this company** — not generic demo |
| Install | Adapt spatial rhythm · copy · concierge tone to genome constraints |
| Post-install | Successful installs strengthen genome; rejections teach it |

**Two companies installing the same Expansion must never feel interchangeable.**

See [Company Genome™](./company-genome.md) · [Genome-First Orchestration](./master-spec/genome-first-orchestration.yaml).

---

## Cross-industry installation

Marketplace listings are **not gated by industry**.

Any Headquarters may install any Expansion or Department listing:

- Salon → Podcast Studio · Education Academy · Retail Expansion
- Law firm → Creator Studio · Membership Program
- Restaurant → Merchandise · Media Studio · Course Academy

Cross-pollination is a **platform feature**, not an edge case.

---

## Relationship to Expert Marketplace (M92)

| System | Audience | What's exchanged |
|--------|----------|------------------|
| **Headquarters Marketplace™** | Founders expanding their HQ | Operational architecture installs |
| **Expert Marketplace™ (M92)** | Consumers learning from organizations | Approved Profession Brain surfaces · academy · consultations |

Both respect the same principle: **living systems, not downloadable files**.

Headquarters Marketplace is **B2B operational architecture**. Expert Marketplace is **B2C expertise surfacing**. Documentation must not conflate them.
