## Portfolio Evolution™

> Creative Portfolios **never reset**. They **mature**.

Every event strengthens the permanent portfolio record:

| Event | Portfolio strengthening |
|-------|------------------------|
| [Expedition™](../expeditions/) | Milestone · narrative arc |
| [Routine™](../routines/) | Guided creative journeys |
| Every approved **Generation™** | Registry investment |
| **Golden Build™** | Department infrastructure |
| **Blueprint™** | IP expansion |
| **Marketplace contribution™** | Influence expansion |

```yaml
PortfolioMilestone:
  milestoneId: string
  timestamp: ISO8601
  type: expedition | routine | golden_build | blueprint | marketplace | certification
  label: string
  dimensionsAffected: string[]    # health · maturity · influence · etc.
  equityContribution: number | null
```
