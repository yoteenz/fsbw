# Visual DNA™ Stability

**Module:** `studio.creative-portfolio.v1.visual-dna`  
**Status:** Recognizability and design language coherence

---

## Principle

> Studio OS evaluates **how recognizable** the company has become — Visual DNA™ stability over time.

Distinct from [Creative Blueprint Engine Visual DNA™](../creative-blueprint-engine/visual-dna.md) definition layer — this module **measures** recognition and stability.

---

## Stability Signals

| Signal | Measures |
|--------|----------|
| **Blueprint anchoring** | % production under primary Visual DNA™ |
| **Cross-department recognition** | Consistent language detection score |
| **Genome aesthetic memory** | Company Genome™ creative strand coherence |
| **Founder Taste alignment** | Taste engine consistency over time |
| **Drift events** | Count of consistency breaks (inverse) |
| **External recognition** | Marketplace "known for" tags (future) |

---

## Visual DNA Stability Score

```
visualDnaStability = 0–100

high stability = same design language recognizable across HQ, departments, marketplace
low stability = fragmented styles · orphan generations
```
