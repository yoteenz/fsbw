# Blueprint Strength™

**Module:** `studio.creative-portfolio.v1.blueprint-strength`  
**Status:** Intellectual property vitality

---

## Principle

> Every Blueprint™ is intellectual property. **Blueprint Strength™** measures how valuable and resilient that IP has become.

---

## Metrics

| Metric | Definition |
|--------|------------|
| **Reuse frequency** | Applications per month · lifetime |
| **Cross-department compatibility** | Departments successfully inheriting |
| **Marketplace demand** | Downloads · licenses · interest signals |
| **Founder satisfaction** | Pins · approvals · collection inclusion |
| **Longevity** | Months active · still primary |
| **Variants** | Healthy variant count · not fragmentation |
| **Adaptability** | Modify-not-regenerate success rate |
| **System dependencies** | Coordinated Systems™ depth |

---

## Blueprint Strength Score

```
blueprintStrength = aggregate of top-N blueprint scores (org portfolio)

perBlueprintScore = f(reuse, compatibility, demand, satisfaction, longevity, adaptability)
```

Portfolio-level score: **0–100**.

---

## Strength Bands

| Band | Meaning |
|------|---------|
| **Anchor** | Primary design language · multi-department |
| **Strong** | High reuse · certified |
| **Developing** | Growing adoption |
| **Dormant** | Low reuse · consolidation candidate |
| **Superseded** | Replaced by stronger variant — history preserved |
