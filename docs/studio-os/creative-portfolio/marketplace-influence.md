# Marketplace Influence™

**Module:** `studio.creative-portfolio.v1.marketplace-influence`  
**Status:** External creative influence (spec only)

---

## Principle

> Creative capital grows when design language becomes **influential** — not only when it exists internally.

**No marketplace implementation this sprint** — signals and scoring only.

---

## Tracked Signals

| Signal | Definition |
|--------|------------|
| **Marketplace Sales™** | Purchases of published creative IP |
| **Blueprint Downloads™** | Blueprint pack acquisitions |
| **Department Installs™** | External HQ/department template installs |
| **Asset Licenses™** | Licensed asset use |
| **Followers™** | Org/creator follow count |
| **Architect Reputation™** | Aggregate rating · trust tier |
| **Collections™** | Featured in curated collections |
| **Featured Placements™** | Platform spotlight features |
| **Studio Certified™** | Certified marketplace listings |

---

## Influence Score

```
marketplaceInfluence = normalized composite (0–100)

weights:
  sales & licenses: 25%
  downloads & installs: 25%
  reputation & ratings: 20%
  featured & collections: 15%
  certified listings: 15%
```

Early-stage orgs may score low — Orb frames as **opportunity**, not failure.
