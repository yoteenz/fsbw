# Design Consistency™

**Module:** `studio.creative-portfolio.v1.consistency`  
**Status:** Cohesive world evaluation

---

## Principle

> The company should feel like **one cohesive world** — not a folder of unrelated images.

**Design Consistency™** measures how unified the creative language is across headquarters.

---

## Consistency Dimensions

| Dimension | Measures |
|-----------|----------|
| **Material consistency** | Surface · finish language across departments |
| **Lighting consistency** | Editorial · ambient systems aligned |
| **Architectural language** | Proportion · structure · massing |
| **Orb behavior** | Tone · presence · coaching style coherence |
| **Motion language** | Transitions · idle life · animation rhythm |
| **Environmental storytelling** | Narrative continuity across sets |
| **Typography** | Label · accent · hierarchy systems |
| **Interaction language** | Cursor · station · navigation patterns |
| **Color systems** | Palette discipline · accent usage |
| **Transition language** | Arrival · journey · departure coherence |

---

## Consistency Score

```
designConsistency = weighted average of dimension scores (0–100 each)

dimensionScore derived from:
  - Blueprint inheritance coverage
  - System reuse across departments
  - Validation Loop™ brand compliance
  - Visual DNA™ drift detection
```

---

## Drift Detection

| Signal | Consistency impact |
|--------|-------------------|
| New department without blueprint apply | Drift warning |
| Orphan material variants | Material dimension down |
| Inconsistent lighting between adjacent sets | Lighting dimension down |
| Mixed typography outside genome | Typography dimension down |

Orb recommends **Apply Existing Blueprint™** — not shame.
