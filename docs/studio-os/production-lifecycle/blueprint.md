# Blueprint™ — Creative Conception Stage

**Lifecycle Stage:** 1 of 6  
**Status:** Canonical  
**Predecessor:** None — all experiences begin here  
**Successor:** Golden Build™

---

## Purpose

Blueprint™ is the **creative conception stage**.

Ideas become direction. Vision becomes specification. Intent becomes artifacts future stages can manufacture from.

**Nothing has been built yet.**

Blueprint™ defines **intent** — not implementation.

---

## What Blueprint™ Is

| Blueprint™ Is | Blueprint™ Is Not |
|---------------|-------------------|
| Creative direction · genome · DNA · briefs | Working software |
| Department definitions · room topology | Generated assets |
| Storyboards · mood · planning | Interactive runtime |
| Founder vision captured | Founder using the experience |

---

## Primary Outputs

| Output | Description | Typical artifact |
|--------|-------------|------------------|
| **Company Genome™** | Brand DNA · materials · voice · values | `company-genome.json` |
| **Department Definitions** | Identity · purpose · zones · objects | `department.json` |
| **Room DNA™** | Feeling · sliders · forbidden tones · modifiers | `room-dna.json` |
| **Mood Boards** | Visual direction · reference palette | Mood board collection |
| **Creative Briefs** | Project intent · audience · constraints | Brief documents |
| **Storyboards** | Spatial narrative · arrival · journey | Storyboard sequences |
| **Technical Planning** | Asset manifest · dependencies · assembly | `asset-manifest.json` |
| **Founder Vision** | North star · ceremony · non-negotiables | Founder notes · vision doc |

---

## Blueprint™ Activities

```
Founder vision
      ↓
Company Genome™ definition
      ↓
Department selection / definition
      ↓
Room DNA™ + spatial storyboard
      ↓
Asset planning + interaction map
      ↓
Production group + prompt templates
      ↓
Blueprint Complete Gate
      ↓
Golden Build™ authorized
```

---

## Exit Criteria — Blueprint Complete Gate

| # | Criterion | Validator |
|---|-----------|-----------|
| 1 | Company Genome™ defined or inherited | Genome service |
| 2 | Department Definition complete (`department.json`) | Department Generator schema |
| 3 | Room DNA™ complete (`room-dna.json`) | Room DNA schema |
| 4 | Asset manifest drafted (`asset-manifest.json`) | Compiler input spec |
| 5 | Production groups defined | Studio Builder input |
| 6 | Interaction map documented | Alpha interaction-map |
| 7 | Founder vision captured | Founder sign-off |
| 8 | No generated runtime assets required | — |

**Gate detail:** [quality-gates.md](./quality-gates.md#blueprint-complete-gate)

## Anti-Patterns

| Anti-pattern | Why forbidden |
|--------------|---------------|
| Skipping Blueprint™ for "speed" | Golden Build has no intent to prove |
| Treating docs as the deliverable | Blueprint artifacts feed manufacturing — they are not the product |
| Generating assets before Blueprint Complete | Wastes generation · wrong direction |
| Hardcoding department logic in Blueprint | Uniqueness belongs in data — see Golden Build engineering rule |
