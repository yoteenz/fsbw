# Evolution™ — Continuous Improvement Stage

**Lifecycle Stage:** 5 of 6  
**Status:** Canonical  
**Predecessor:** Live™ (continuous from launch)  
**Successor:** Legacy™ (when superseded or historic)

---

## Purpose

Studio OS is **never finished**.

Evolution™ is the continuous improvement stage every Live™ experience enters immediately upon launch — and remains in until meaningful replacement triggers Legacy™.

Evolution keeps the company **alive**.

---

## Evolution Drivers

| Driver | Source |
|--------|--------|
| **Founder feedback** | Notes · decisions · Walk the Room critiques |
| **Usage analytics** | Studio Intelligence™ · heatmaps · completion |
| **AI recommendations** | Orb · Braintrust · dock advisor |
| **Company Genome™ evolution** | Brand refinement · new values |
| **Marketplace Packs™** | New objects · departments · staff |
| **New technologies** | Generation models · runtime capabilities |
| **Better interactions** | Verb refinement · ceremony tuning |

---

## Evolution™ Activities

```
Live™ experience operating
         ↓
Continuous signal collection
         ↓
Studio Intelligence™ analysis
         ↓
Recommendation → founder review
         ↓
Incremental improvement (no new lifecycle stage)
         ↓
Registry versioning · runtime updates
         ↓
Chronicle entries for significant changes
         ↓
EVOLUTION™ (ongoing)
```

---

## What Evolution™ Changes

| Changeable | Typically stable |
|------------|------------------|
| Asset versions · new production groups | Zone topology (unless major redesign) |
| Interaction polish · Orb scripts | Department identity |
| Performance · accessibility | certificationToken (re-certify on major change) |
| New Marketplace objects | Blueprint intent (unless pivot) |
| AI employee capabilities | Archive™ exhibits (frozen at Legacy™) |

**Major redesigns** may require re-Certified™ review — not a return to Golden Build™ unless engine replacement.

| Entity | Evolution pattern |
|--------|-------------------|
| **Department** | New assets · interactions · production groups |
| **Marketplace Pack™** | Version bumps · compatibility updates |
| **Asset** | Registry branches · regeneration |
| **AI Employee** | Knowledge · voice · scope refinement |
| **Workflow** | Step optimization · new triggers |
| **Headquarters** | New wings · department slots · navigation |
| **Company Genome™** | Living document — versioned |

## Versioning During Evolution™

| Artifact | Version behavior |
|----------|------------------|
| Department Package | `pkg-*-v2` on major evolution |
| Assets | Registry branch · `qualityTier` maintained |
| certificationToken | Re-issue on breaking change |
| Chronicle | New entry per significant evolution |

## Founder Experience in Evolution™

| Signal | Founder sees |
|--------|--------------|
| Stage badge | **Evolution™** (or Live™ + Evolution indicator) |
| Room state | Improving · changelog-aware · Orb mentions updates |
| Orb behavior | Advisory · "we've refined…" · recommendation-forward |
| Primary verbs | Adopt · regenerate · expand · refine |

Founder language: *"Our Concierge AI is currently in Evolution™."*

---

## Evolution™ vs New Lifecycle

| Situation | Action |
|-----------|--------|
| Incremental asset regen | Evolution™ |
| New interaction on existing department | Evolution™ |
| Entirely new department | New Blueprint™ → Golden Build™ |
| Engine replacement | New Golden Build™ for affected scope |
| Historic version preserved | Legacy™ → Archive™ |

---

## Relationship to Founder Journey™

| Journey stage | Evolution emphasis |
|---------------|-------------------|
| Building | Rapid iteration · Golden Build expansion |
| Launching | Stability + polish |
| Growing | Scale · performance · automation |
| Leading | Efficiency · delegation to AI staff |
| Legacy | Slow evolution · preservation priority |

## Transition to Legacy™

Evolution™ ends when an experience is **superseded** or **ceremonially preserved**:

| Trigger | Example |
|---------|---------|
| New Headquarters replaces old | Frontal Slayer HQ v1 → v2 |
| Department rebuilt from Blueprint™ | Original CDS → CDS v2 |
| Acquired company integrated | Historic brand enters Archive™ |
| Founder ceremony | "Preserve our first Golden Build™" |
