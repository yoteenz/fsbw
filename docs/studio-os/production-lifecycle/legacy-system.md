# Legacy™ — Preservation Stage

**Lifecycle Stage:** 6 of 6 (final)  
**Status:** Canonical  
**Predecessor:** Evolution™  
**Physical destination:** [The Archive™](./archive-system.md)

---

## Purpose

Legacy™ is the **final lifecycle stage**.

Nothing meaningful should ever disappear. Legacy™ preserves important moments in company history.

**Legacy™ is preservation — not abandonment.**

---

## What Enters Legacy™

| Category | Examples |
|----------|----------|
| **Previous Golden Builds™** | First Creative Direction Studio™ proof |
| **Historic Headquarters** | Original Frontal Slayer Headquarters |

| **Major redesigns** | Pre-redesign department versions |
| **Historic AI employees** | Retired concierges · original staff |
| **Acquired companies** | Integrated brands · preserved identity |
| **Milestone campaigns** | Breakthrough marketing moments |
| **Original Company Genome™** | Genome v1 · founding DNA |
| **Historic Founder Journeys™** | Journey snapshots · era markers |
| **Failed experiments** | Chronicle-worthy attempts |
| **First customers · first hires** | Chronicle-linked milestones |

---

## Legacy™ Criteria

Not everything goes Legacy™. Entry requires **meaning**:

| Criterion | Question |
|-----------|----------|
| **Founder significance** | Would the founder want to revisit this? |
| **Company narrative** | Does this explain how we got here? |
| **Irreplaceable moment** | Can this only be understood in context? |
| **Ceremony or system trigger** | Founder ceremony · acquisition · supersession |

Routine deprecations (unused assets · failed generations) do **not** automatically enter Legacy™ — unless Chronicle-worthy.

---

## Legacy™ Ceremony

```
Evolution™ experience superseded or founder requests preservation
         ↓
Legacy™ review — significance confirmed
         ↓
Runtime demoted — no longer default Live™ path
         ↓
Archive™ exhibit created
         ↓
Founder Chronicle™ entry authored
         ↓
Headquarters wing link — The Archive™
         ↓
LEGACY™
```

## Preservation Levels

| Level | Experience |
|-------|------------|
| **Full immersive** | Walkable Archive™ exhibit — original runtime preserved |
| **Snapshot** | Spatial snapshot · key interactions · reduced fidelity |
| **Chronicle-only** | Narrative + media — no walkable room |

Default for Golden Builds™ and Headquarters: **full immersive**.

## Anti-Patterns
