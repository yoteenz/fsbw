# Spatial Collaboration Framework™

**Status:** Canonical collaboration architecture — P0 Foundation Sprint  
**Scope:** How founders · AI · future visitors collaborate in space

---

## Collaboration Thesis

In Studio World™, collaboration is **spatial** — not threaded comments, not shared documents, not screen shares.

People collaborate by **occupying the same environment** — walking the same boards, sitting at the same table, pointing at the same objects.

---

## Collaboration Modes

### Mode 1 — Founder ↔ AI (Present)

The primary collaboration mode today.

| Collaboration type | Spatial expression |
|--------------------|-------------------|
| **Direction setting** | Founder at Story Table™ · Creative Director presents |
| **Reference curation** | Founder pins · Research Concierge annotates |
| **Concept review** | Founder seated · specialists debate at boards |
| **Refinement** | Founder points at object · specialist revises in place |
| **Branch exploration** | Founder walks between parallel sandbox boards |
| **Approval** | Founder at vault · ceremony lighting shift |

AI collaborators are **present in the room** — at desks · walls · stations — not in chat panels.

### Mode 2 — Founder ↔ Founder (Future)

Multi-founder companies.

| Collaboration type | Spatial expression |
|--------------------|-------------------|
| **Shared review** | Multiple seats at Review Theater |
| **Async handoff** | Work left on table · sticky note with name |
| **Conflict resolution** | Founder Boardroom™ · dual perspective boards |
| **Taste divergence** | Parallel preference walls per founder |

### Mode 3 — Founder ↔ Visitor (Future)

External collaborators enter headquarters.

| Visitor type | Spatial framework |
|--------------|-------------------|
| **Client** | Presentation Theater™ · curated path · guided by Orb |
| **Agency partner** | Partner Studio™ · shared boards · split attribution |
| **Photographer / contractor** | Department guest desk · scoped workspace |
| **Investor** | Executive corridor · milestone exhibits only |

### Mode 4 — AI ↔ AI (Ambient)

Specialists collaborate without founder present.

| Collaboration type | Spatial evidence |
|--------------------|------------------|
| **Pre-review preparation** | Table set · boards arranged · notes exchanged |
| **Research cross-feed** | Reference passed from Research to Art Director wall |
| **Production handoff** | Artifact placed at corridor transit point |
| **Quality debate** | Annotation layers on shared proof |

Founder discovers AI-to-AI collaboration through **evidence** — not notifications.

## Spatial Primitives

The building blocks of spatial collaboration:

| Primitive | Description |
|-----------|-------------|
| **Co-presence** | Multiple entities in same room with shared sightlines |
| **Shared surface** | Board · table · wall that multiple entities manipulate |
| **Pointer** | Spatial indication — look here · not this · try that |
| **Annotation layer** | Sticky notes · markup · voice transcript pinned to object |
| **Comparison layout** | Side-by-side boards · A/B/C arrangement |
| **Transit object** | Artifact moving between departments · collaboration handoff |
| **Assembly** | Specialists gathered for meeting · seats · projection |
| **Walk-through** | Sequential spatial review — Walk the Room™ |

## Meeting Rooms as Collaboration Infrastructure

Meetings are the **primary collaboration interface**:

```
MEETING ROOM ASSEMBLY
        ↓
Specialists gather (physical presence)
        ↓
Evidence presented (boards · reels · samples)
        ↓
Debate occurs (annotations · vocal · sticky notes)
        ↓
Founder directs (pointer · verbal · approval gesture)
        ↓
Outcomes physicalize (canon to vault · reject to shelf · branch to sandbox)
        ↓
Meeting remnants persist (notes on table · board positions)
```

| Meeting type | Room | Collaborators |
|--------------|------|---------------|
| Creative Review | Creative Review Theater | CD · AD · Brand · Orb |
| Brand Strategy Review | Brand Strategy Boardroom | Strategist · Concierge · Marketing |
| Art Direction Review | Art Direction Salon | AD · Research · Photographer |
| Packaging Review | Packaging Lab table | Packaging · Material · Industrial |
| Motion Review | Motion Screening Room | Motion · AD · Technologist |
| Production Handoff | Transit corridor station | CD · Production Manager |

## Walk the Room™ Protocol

Structured spatial review — the collaboration ceremony:

```
1. ENTRY — Orb announces session type
2. PATH — Founder walks predetermined zone sequence
3. PRESENT — Specialist at each zone explains evidence
4. CRITIQUE — Annotations accumulate on surfaces
5. DIRECT — Founder indicates keep · reject · revise · branch
6. CLOSE — Outcomes physicalize · session remnants persist
```

Walk the Room™ is collaboration **as journey** — not a checklist modal.

| Entity | Spatial permissions |

| **AI Tier 2** | Support zones · annotation · retrieval |

## Async Spatial Collaboration

Collaboration continues when participants are not co-present:

| Mechanism | How it works |
|-----------|--------------|
| **Table artifacts** | Work left in place · next participant continues |
| **Sticky note grammar** | Name · timestamp · intent pinned to object |
| **Monitor loops** | Completed work plays for next arrival |
| **Transit objects** | Artifact waits at handoff station |
| **Prepared meetings** | Room pre-set for scheduled review |
| **Orb briefing** | Orb summarizes what happened since last visit |

Async collaboration is **environmental** — not email-thread-shaped.

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Comment thread as primary feedback | Not spatial |
| Screen share instead of shared room | Not present |
| Real-time cursor in empty whiteboard | No environmental context |
| Chat panel beside 3D room | Split attention · not unified |
| Visitor gets PDF export | Visitor model violation |
| Collaboration without persistent remnants | No memory |

---

## Closing

Spatial collaboration means the founder never "sends feedback."

They **walk to the work, point at what they mean, and leave the room different than they found it.**

That is how creative organizations have always collaborated. Studio World™ digitizes the room — not the workflow.
