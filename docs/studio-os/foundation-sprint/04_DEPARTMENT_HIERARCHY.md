# Department Hierarchy™ — Taxonomy

**Status:** Canonical taxonomy — P0 Foundation Sprint  
**Scope:** All departments · destinations · organizational zones in Studio World™

---

## Taxonomy Law

A **department** is an organizational function.  
A **destination** is where that function is experienced.

Departments are **not pages**. They are **addresses** on the campus.

Every department requires:
- Physical location (building · wing · floor)
- One clear mission (Responsibility Framework™)
- At least one Set™ (built environment)
- Assigned AI staff with workspaces
- Pre-arrival life state
- Transition connections to neighbors

## Department vs. Set vs. Room

| Concept | Definition | Example |
|---------|------------|---------|
| **Department** | Organizational function | Art Direction |
| **Set™** | Built environment for that function | Visual Atelier Set™ |
| **Room** | Specialized space inside Set | Typography Review Room |
| **Zone** | Interaction area inside Room | Mood Wall zone |

**Law:** A department may contain multiple Sets™. A Set™ may contain multiple Rooms. Never collapse these layers.
