# Room Taxonomy™

**Status:** Canonical taxonomy — P0 Foundation Sprint  
**Scope:** Every room type · spatial class · assembly pattern in Studio World™

---

## Room Law

Every room is **assembled** — never hardcoded:

```
Scene Stack™ → Environment → Architecture → Lighting → Furniture
→ Hero Objects → Interactive Systems → Particles → Runtime → Finished Workspace
```

Every room requires:
- Arrival sequence (first visit) or persistence restore (return visit)
- At least one hero object
- Idle Life™ ambient state
- Pre-arrival evidence of work
- Exit transition to another place
- World Memory™ binding

## Room Zones (Inside Rooms)

Every room contains **zones** — interaction areas the founder approaches:

| Zone type | Interaction model |
|-----------|-------------------|
| **Hero zone** | Primary object — Story Table™ · Mood Wall · Orb pedestal |
| **Work zone** | Active manipulation — pin · write · arrange |
| **Review zone** | Seated observation — presentation · debate |
| **Archive zone** | Browse · retrieve · compare history |
| **Transit zone** | Pass through — corridor · doorway · elevator |
| **Ambient zone** | Non-interactive life — monitors · distant figures · audio |

**Law:** Founder approaches zones. Zones do not scroll into view.

## Room States

| State | Description |
|-------|-------------|
| **Dormant** | Minimal life — distant wing · founder away |
| **Idle** | Ambient life active — monitors · soft activity |
| **Active** | Work in progress — specialists present · evidence accumulating |
| **Review** | Meeting assembled — chairs · projection · debate |
| **Celebration** | Milestone — lighting shift · audio · World Event™ |
| **Crisis** | Urgent — tactical lighting · focused displays |
| **Construction** | Set™ being built — scaffolding aesthetic (meta) |

Room states cascade from **World States™** and **project state**.

## Room Assembly Tiers

| Tier | Quality | Purpose |
|------|---------|---------|
| **Blueprint™** | Wireframe spatial | Planning only |
| **Alpha** | Core zones · placeholder assets | Prove presence |
| **Beta** | Full Scene Stack™ · real assets | Department operational |
| **Golden™** | Certified reference quality | Inheritance template |
| **Living™** | Transforms with production stage | Continuous evolution |

Creative Direction Studio™ targets **Golden Department™** as first reference.

## Room Naming Convention

```
{Department} — {Physical Type} — {Specialization}

Examples:
- Creative Direction — Studio — Atelier (Creative Atelier™)
- Brand Strategy — Office — Library
- Motion — Theater — Screening
- Archives — Museum — Version Gallery
- Command — Center — Mission Control
```

## Anti-Patterns

| Anti-pattern | Why forbidden |
|--------------|---------------|
| Room without hero object | No focal presence |
| Room without exit | Trapped in page |
| Room without pre-life | Dead organization |
| Room as card grid | Room Is The Interface violation |
| Room without memory binding | Session amnesia |
| Generic "Workspace" label | No physical type identity |

---

## Closing

Rooms are not routes. Rooms are **places where specific kinds of work happen**.

The founder learns the taxonomy not by reading it — but by walking the campus until each room type feels inevitable.
