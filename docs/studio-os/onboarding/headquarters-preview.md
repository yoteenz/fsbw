# Headquarters Preview™

**"This is the Headquarters we'll build together."**

---

## Purpose

Once a Mode™ is selected, the Orb reveals the **future Headquarters** — the Sets™ · wings · and departments the founder is about to inhabit.

The founder should immediately see the **world they are about to build** — not a feature list or dashboard mockup.

---

## Core Law

**Show the destination before the build.**

Headquarters Preview™ is spatial storytelling — the emotional bridge between conversation and Company Genome™ initialization.

---

## Preview Sequence

```
Mode accepted (recommended or chosen)
        ↓
Orb: "This is the Headquarters we'll build together."
        ↓
HQ topology animates into preview state
        ↓
Key Sets™ introduced narratively
        ↓
Founder may explore · ask questions · accept
        ↓
Company Genome™ initialization begins
```

## Preview Experience Rules

| Rule | Meaning |
|------|---------|
| **Spatial** | Sets appear as places in HQ — not menu items |
| **Cinematic** | Slow reveal · [World Streaming™](../world/transitions/world-streaming.md) |
| **Narrated** | Orb introduces each Set — optional ambient audio |
| **Non-interactive first pass** | Tour before editing — founder receives vision |
| **Mode-weighted** | Priority Sets glow · others softly present |
| **Empty but alive** | Sets exist · awaiting founder's story (Idle Life™) |
| **No configuration** | Preview is vision — not setup |

## Founder Interactions During Preview

| Founder asks | Orb handles |
|--------------|-------------|
| "What's the Creative Atelier?" | Set purpose · what happens there · when it activates |
| "Can I add departments later?" | Expansion Center™ · departments grow with company |
| "This feels like a lot" | Reassurance · Sets unlock progressively · maturity gates |
| "Skip the tour" | Accept preview · proceed to Genome — discouraged not blocked |
| "Can I see Agency layout instead?" | Returns to Choose Another Mode™ path |

## Preview → Build Handoff

| Preview state | After Inauguration |
|---------------|-------------------|
| Ghost Sets™ (visible · empty) | Activated Sets™ with Genome content |
| Mode DNA weights | Department pack installs |
| Orb narrated priorities | Mission Control KPI emphasis |
| Founder excitement captured | World Event™: "Headquarters activated" |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Feature checklist UI | Breaks spatial philosophy |
| Dashboard screenshot | SaaS · not Headquarters |
| All Sets equal weight | Overwhelms · Mode should prioritize |
| Fully furnished Sets in preview | Implies fake company |
| Configuration forms on preview | Violates "vision first" |
| Black fade between Sets | Use corridor · gallery walk transitions |
