# Orb Conversation™

**The First Conversation — natural dialogue before configuration**

---

## Purpose

Define how the **Studio Orb™** conducts Adaptive Onboarding™ — a conversation that feels like meeting an experienced business advisor, not completing a questionnaire.

The Orb's job during The First Conversation™:

1. **Understand** what the founder is building
2. **Learn** who the founder is and how they work
3. **Gather** signals for Mode Recommendation™
4. **Seed** Company Genome™ fields without asking twice
5. **Build trust** before any configuration

---

## Opening Sequence

### 1 — Headquarters Emergence

| Beat | Experience |
|------|------------|
| Duration | 3–8 seconds (reduced motion: instant shell) |
| Visual | Arrival Plaza™ · soft light · no UI chrome |
| Audio | Ambient welcome · optional |
| Rule | No forms · no spinners · no mode grid |

### 2 — Orb Welcome

> **"Welcome to Studio OS."**  
> **"This is where your company will live."**

Returning founder:

> **"Welcome back. Let's continue building."**

### 3 — The Opening Question

> **"What are we going to build together?"**

**Not:**
- "How would you like to build today?" *(deferred to recommendation phase)*
- "What template do you want?"
- "What industry are you in?"
- "What's your business name?"

---

## Conversation Design

### Natural · Not Scripted

The conversation should feel **natural** — not like a questionnaire.

| Scripted (forbidden) | Natural (required) |
|----------------------|-------------------|
| "Question 1 of 12" | Organic follow-ups |
| Fixed question order | Adaptive based on answers |
| Multiple choice only | Open dialogue + gentle probes |
| "Please select" | "Tell me more about that" |
| Checkbox fields | Orb reflects understanding back |

### Example Prompts (Orb may use · not mandatory script)

The Orb draws from a **prompt library** — selecting based on what it still needs to learn:

| Theme | Example Orb prompts |
|-------|---------------------|
| **Building** | "What are you building?" |
| **Inspiration** | "What inspired you to start this company?" |
| **Team** | "Will you be working alone or with a team?" |
| **Stage** | "Do you already have a business, or are we creating one together?" |
| **Experience** | "What type of experience do you want your customers to have?" |
| **Vision** | "What kind of company do you hope this becomes five years from now?" |
| **Focus** | "What feels most urgent right now — brand, product, customers, or operations?" |
| **Working style** | "How do you prefer to make decisions — fast and intuitive, or deliberate and documented?" |

The Orb **never** asks all of these. It asks what the conversation requires.

---

## Conversation Phases

```
OPENING
  "What are we going to build together?"
        ↓
DISCOVERY (adaptive)
  Follow curiosity · probe gaps · reflect understanding
        ↓
CLARIFICATION (as needed)
  Team size · stage · customer · vision · urgency
        ↓
SYNTHESIS (internal)
  Orb maps signals → Mode Recommendation™ inputs
        ↓
TRANSITION
  "Based on what you've shared, I have a recommendation."
```

---

## Signal Categories

The Orb listens for signals across these dimensions:

| Category | What Orb learns | Genome / Mode impact |
|----------|-----------------|----------------------|
| **Build intent** | Product · service · brand · platform | Mode recommendation |
| **Company stage** | Idea · launching · operating · scaling | Mode + maturity |
| **Team structure** | Solo · small team · established org | Entrepreneur vs Enterprise |
| **Customer model** | B2C · B2B · clients · audience | Creator vs Agency |
| **Geographic scope** | Single · multi-location | Franchise signals |
| **Urgency** | Launch · grow · stabilize · preserve | Department priorities |
| **Vision horizon** | 1-year · 5-year · legacy | Genome vision fields |
| **Working style** | Founder-led · delegated · collaborative | Leadership style |
| **Creative emphasis** | Brand · content · product · operations | Mode DNA weights |

---

## Orb Behavior Rules

| Rule | Meaning |
|------|---------|
| **One voice** | Specialists do not interrupt The First Conversation™ |
| **Reflect back** | Orb summarizes understanding before recommending |
| **No pressure** | Skip · defer · explore allowed |
| **Short paragraphs** | Conversational — not bullet dumps to founder |
| **Company-first** | Language builds company — not configures software |
| **Spatial presence** | Orb speaks from center of arriving HQ |
| **Explain gaps** | "I'd love to understand more about…" not "Required field" |
| **Never interrogate** | One question at a time · breathe between topics |

---

## Follow-Up Intelligence

When answers are brief, the Orb probes gently:

| Founder says | Orb follow-up |
|--------------|---------------|
| "A hair brand" | "Beautiful. Are you launching products, building a salon experience, or both?" |
| "Just me for now" | "Solo founders often start in Entrepreneur Mode — I'll factor that in." |
| "I have clients already" | "Tell me about the work you deliver for them." |
| "Not sure yet" | "That's perfectly fine. What excites you most about this idea?" |
| "I run a team of 40" | "You're further along than most founders who arrive here. Tell me how the company operates today." |

**Same pattern as** [Business Discovery Blueprint™](../business-discovery-blueprint.md) conversational engine — applied to first conversation scope.

## What the Orb Does NOT Ask (First Conversation)

| Deferred topic | When addressed |
|----------------|----------------|
| Business name | Naturally in conversation OR Blueprint™ |
| Logo | Brand phase · Asset Director |
| Colors | Genome · brand direction |
| Domain | Blueprint™ · existing company path |
| Website URL | Blueprint™ · integration path |
| Industry taxonomy | Inferred · confirmed in Blueprint™ |
| Payment · billing | Expansion Center · monetization |
| Template selection | Never — Mode + Genome replace templates |

---

## Conversation Exit Criteria

The Orb transitions to Mode Recommendation™ when:

| Criterion | Minimum |
|-----------|---------|
| Build intent | Understood |
| Company stage | Classified (even if "early idea") |
| Team structure | Known or assumed solo |
| Primary focus | Identified |
| Vision signal | At least one horizon captured |

**Insufficient data:** Orb asks one more targeted question — never guesses Mode silently.

---

## Founder Interruptions

| Founder action | Orb response |
|----------------|--------------|
| "Just recommend something" | Orb summarizes what it knows · offers best recommendation · notes what it will learn later |
| "Can I pick a Mode myself?" | "Of course." → Compare Modes™ presentation |
| "I need to think" | Saves conversation state · "I'll be here when you're ready." |
| "What's Studio OS?" | Brief Company Engine™ explanation · returns to conversation |
| Long tangent | Orb listens · extracts signals · gently steers toward recommendation |

## Relationship to Orb Onboarding™ (V1)

[Orb Onboarding™](../modes/orb-onboarding.md) presented Mode selection immediately after welcome.

**Orb Conversation™** replaces that beat with dialogue. Mode presentation moves to [mode-recommendation-engine.md](./mode-recommendation-engine.md).

```
V1:  Welcome → "How would you like to build?" → Mode pick
V2:  Welcome → "What are we building?" → Conversation → Mode recommend
```

|---------|-------------------|
| Lighting | Warm · curious · not corporate |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Numbered question progress | Feels like survey |
| All specialists introduce themselves | Orb is sole voice |
| Forced video / avatar setup | Blocks conversation |
| Chat bubble UI only | Must feel spatial in HQ |
| Immediate Mode grid overlay | Skips understanding phase |
| Recording transcript visibly | Surveillance feeling |
