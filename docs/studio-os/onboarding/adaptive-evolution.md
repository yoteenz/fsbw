# Adaptive Evolution™

**Studio OS evolves with the founder — never starts over**

---

## Purpose

Define how Adaptive Onboarding™ extends beyond first entry — the recommendation engine **continues learning** and suggests Mode transitions as the company grows.

The founder never starts over. Studio OS evolves with them.

---

## Core Law

**Companies change. Modes adapt. Data preserves.**

Mode evolution is **suggestion with reasoning** — not automatic migration.

---

## Beyond First Conversation

Adaptive Onboarding™ does not end at Inauguration™.

| Phase | Adaptive behavior |
|-------|-------------------|
| First 30 days | Orb checks understanding · gentle Genome refinements |
| Growth signals | Mode evolution suggestions |
| Major milestones | Evolution ceremony offered |
| Continuous | Relationship Memory™ · Pulse™ · Predictive Organization™ feed evolution engine |

---

## Canonical Evolution Triggers

| Life event | Suggested evolution | Orb example |
|------------|---------------------|-------------|
| Solo founder hires first employees | Entrepreneur → Enterprise capabilities | "Your team is growing. Enterprise Mode™ may help with delegation and governance." |
| Solo founder hires team of 10+ | Entrepreneur → **Enterprise Mode™** | "You've built a real organization. Shall we evolve your Headquarters?" |
| Creator launches client services | Creator → **Agency Mode™** | "You're delivering for clients now. Agency Mode™ prioritizes client workflows." |
| Agency scales past 20 clients | Agency → Enterprise | "Your agency has outgrown single-founder rhythms." |
| Entrepreneur acquires second company | Enterprise + Holding support | "Multiple companies deserve a holding structure." |
| Franchise opens location 2+ | Franchise Mode™ depth | "Let's activate multi-location command." |
| Enterprise spins out venture | Enterprise → Entrepreneur (incubation) | "This new venture may want a founder-led Mode." |

**Detail:** [mode-evolution.md](../modes/mode-evolution.md)

## Suggestion Flow

```
Growth signal detected
        ↓
Evolution engine evaluates Mode fit
        ↓
Confidence threshold met?
        ↓
Orb presents suggestion WITH reasoning
        ↓
Founder: Accept · Not now · Tell me more · Never suggest this
        ↓
If accepted → Evolution Ceremony™
        ↓
Mode DNA™ diff applied · HQ topology evolves
```

## Evolution Ceremony

Major mode shifts deserve spatial acknowledgment — not a settings toggle:

```
1. Orb: "Your company has outgrown [Current Mode™]."
2. Reasoning: what signals triggered suggestion
3. Offer: "Explore [Suggested Mode™]?"
4. Founder confirms · defers · or dismisses
5. Gallery Walk™ or Executive Corridor™ transition
6. HQ topology preview — what will evolve
7. Mode DNA diff applied
8. World Event™: "A new chapter begins."
```

Minor adjustments may be **quiet** — full evolution is **ceremonial**.

## Founder Controls

| Control | Behavior |
|---------|----------|
| **Accept evolution** | Ceremony · DNA diff · HQ evolve |
| **Not now** | Snooze 30 / 90 days · signal still tracked |
| **Tell me more** | Compare current vs suggested Mode |
| **Never suggest** | Suppress this evolution path permanently |
| **Manual evolution** | Founder may request any Mode anytime via Orb |

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Automatic Mode switch | Founder must confirm |
| Data wipe on evolution | Violates preserve law |
| Evolution without reasoning | Breaks trust |
| Nagging weekly suggestions | Respect snooze · cognitive load |
| Evolution as upsell | Modes are not plan tiers |
