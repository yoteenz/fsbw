# Company Genome™ Initialization

**Conversation seeds identity — nothing entered twice**

---

## Purpose

Define how Adaptive Onboarding™ populates the **Company Genome™** from The First Conversation™ — **only after** Mode™ is selected and Headquarters Preview™ is accepted.

The onboarding conversation automatically contributes to organizational identity. Founders should never answer the same question in a form later.

---

## Core Law

**Seed once. Inherit everywhere.**

Conversation → Genome → Blueprint™ → Charter → all AI interactions.

---

## Timing

| Phase | Genome state |
|-------|--------------|
| During conversation | Signals collected · not yet written |
| Mode accepted | Genome initialization begins |
| HQ Preview accepted | Genome draft visible to founder (optional) |
| Blueprint™ starts | Genome fields inherited · not re-asked |
| Inauguration™ | Genome sealed into Organization Charter |

**Genome initialization does NOT precede Mode selection** — Mode shapes which Genome fields weight highest.

---

## Conversation → Genome Field Mapping

| Genome field | Conversation sources |
|--------------|---------------------|
| **Mission** | "What are you building?" · purpose statements |
| **Vision** | "Five years from now…" · ambition language |
| **Values** | Implicit in founder priorities · explicit if stated |
| **Industry** | Inferred from build description · confirmed later |
| **Business Model** | Revenue · customers · delivery model signals |
| **Founder Personality** | Working style · decision preferences · tone |
| **Brand Direction** | Customer experience desires · aesthetic hints |
| **Creative Style** | Content · visual · product emphasis |
| **Leadership Style** | Solo vs team · delegation signals |
| **Growth Strategy** | Urgency · scale intent · geographic signals |
| **Customer Philosophy** | "What experience do customers deserve?" |
| **Communication style** | Orb observes founder language patterns |
| **Risk tolerance** | Speed vs caution signals |
| **Approval preferences** | Founder-led vs collaborative signals |

---

## Initialization Process

```
1. EXTRACT
   Parse conversation transcript for Genome field candidates

2. INFER
   Apply Mode DNA™ weights to field confidence

3. DRAFT
   Generate Genome profile draft (not published)

4. REFLECT (optional Orb beat)
   "Here's what I understand about your company so far."
   Founder may correct · never forced form review

5. COMMIT
   Write to Organization Genome™ store

6. PROPAGATE
   Blueprint™ chapters pre-fill from Genome
   AI stack consults Genome on first post-onboarding interaction
```

## Example Orb Reflection

> **"Before we go deeper, here's what I understand about your company:"**
>
> **Mission:** Launch a premium hair brand for women who want salon-quality at home.  
> **Vision:** Become the most trusted name in accessible luxury hair within five years.  
> **Working style:** Founder-led · fast decisions · high creative involvement.  
> **Customer promise:** Confidence without gatekeeping.
>
> **"Does this feel right? You can adjust anything — or we'll refine it as we build."**

---

## Confidence Levels

| Confidence | Behavior |
|------------|----------|
| **High** | Written to Genome · Blueprint skips question |
| **Medium** | Written to Genome · Blueprint asks gentle confirmation |
| **Low** | Genome placeholder · Blueprint discovers properly |
| **Missing** | Blueprint owns discovery — no empty required fields |

Never fabricate high-confidence fields from thin signals.

---

## Mode DNA™ Interaction

Mode selection adjusts Genome emphasis:

| Mode™ | Genome fields weighted |
|-------|------------------------|
| 🚀 Entrepreneur | Mission · vision · brand direction · growth |
| 🏢 Enterprise | Leadership · governance · customer standards |
| 🎨 Creator | Brand personality · creative style · audience |
| 🤝 Agency | Customer philosophy · delivery standards |
| 🏪 Franchise | Operations standards · replication values |

Same conversation · different emphasis profiles.

---

## Blueprint™ Inheritance

[Business Discovery Blueprint™](../business-discovery-blueprint.md) chapters receive pre-fill:

| Blueprint chapter | Genome inheritance |
|-------------------|-------------------|
| Organization Identity | Mission · vision · industry draft |
| Founder Brain | Founder personality · leadership style |
| Customers | Customer philosophy |
| Growth | Growth strategy · vision |
| Decision Intelligence | Approval preferences · risk tolerance |

Blueprint goes **deeper** — Genome provides **breadth** from conversation.

**No duplicate questions.** If Genome has high-confidence mission, Blueprint opens with:

> **"You mentioned building a premium hair brand. Tell me more about the products themselves."**

Not:

> ~~"What is your company's mission?"~~

---

## Organization Charter Integration

At [Organization Inauguration™](../organization-inauguration.md), Genome fields flow into the permanent **Organization Charter**:

- Mission · vision · values
- Founder founding statement (from conversation)
- Mode™ at founding
- Genome version stamp

Immutable founding snapshot — company birth certificate.

---

## AI Consultation Activation

After Genome initialization, `consultOrganizationGenome()` activates for:

- Orb responses
- Digital Concierge tone
- Executive Council briefings
- Marketing copy generation
- Customer communication drafts

**Every AI interaction consults Genome before generating work.**

---

## Privacy & Correction

| Founder action | System response |
|----------------|-----------------|
| Corrects a field | Genome updates · Blueprint inherits |
| "That's wrong" | Orb apologizes · updates · notes correction |
| Deletes conversation | Genome retains only committed fields · export/delete per privacy controls |
| Returns days later | Conversation resumable · Genome draft preserved |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Genome form after conversation | Duplicate entry |
| Empty Genome until Blueprint complete | AI operates blind post-onboarding |
| Fabricated mission from one word | Trust destruction |
| Genome before Mode | Wrong weight profile |
| Forced review screen | Feels like form · optional reflection only |

---

## Relationship to Organization Genome™ (M95)

[M95 Organization Genome™](../organization-genome.md) is the permanent identity governance layer.

Adaptive Onboarding™ defines the **initialization path** — how Genome receives its first DNA from conversation rather than manual entry.
