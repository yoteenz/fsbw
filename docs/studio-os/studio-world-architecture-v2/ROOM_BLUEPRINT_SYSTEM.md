# Room Blueprint System™

**Version:** `room-blueprint.v1`

## Purpose

Define room intelligence **without generating assets**.

## Room types

Reception · Founder Suite · Showroom · TV Lounge · Gallery · Concierge · Story Table · Custom

## Each room blueprint stores

- Purpose and boundaries
- Camera anchors and navigation anchors
- Walkable areas
- Asset sockets (hero, furniture, decor, lighting, interaction)
- Zones: walkable · lighting · sound · interaction · visibility · navigation

## Phase

`room-blueprint` — intelligence only. Zero provider dispatch.
