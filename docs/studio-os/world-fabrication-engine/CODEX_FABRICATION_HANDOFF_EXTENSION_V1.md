# Codex Fabrication Handoff Extension V1

Extends `CodexBlenderHandoffPackage` with optional `technicalArt: CodexFabricationTechnicalArtExtension`.

Includes: lane, profile, geometry/UV/texture/material requirements, modular components, collision/LOD/navigation, rig/animation when applicable, expected package folders, validation checklist.

`executionCapabilityStatus` defaults to **`CONTRACT_ONLY`** for this sprint.

Types: `technical-art/codex-handoff-extension.ts`  
Helper: `attachTechnicalArtToCodexHandoff()`.
