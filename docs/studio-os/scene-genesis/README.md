# Scene Genesis™ (Deprecated)

**Superseded by [Scene Stack™](../scene-stack/README.md)**

---

Scene Genesis™ generated **one complete scene image per station** — this violated the layered environment law.

**Golden Build™ now produces layered environments via Scene Stack™:**

- 10 layers per station
- Independent generation · approval · regeneration · versioning
- Cursor composes approved layers — never single plates

See: `src/studio-os-core/scene-stack/`

`useSceneGenesis` re-exports `useSceneStack` for compatibility.
