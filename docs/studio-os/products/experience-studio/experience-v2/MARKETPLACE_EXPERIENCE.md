## Discovery Experience

| Element | Spec |
|---------|------|
| Categories | Wings · Departments · Workflows · Specialist Teams |
| Card | Glass · preview thumbnail · fit score · Director note |
| Search | Natural language · Orb-assisted |
| Recommended | Based on Design DNA™ · active Projects · industry |

**Director pattern:**
> "Production Wing Full matches your current Project 014 stage. Install when you're ready for Review Theater."

---

## Preview Experience

| Step | Treatment |
|------|-----------|
| 1 | Tap expansion card |
| 2 | "Walk preview" — 30s camera path through ghost building |
| 3 | Inhabit one department · tools visible · no save |
| 4 | Director summarizes what changes on campus |
| 5 | Return to plaza |

**Not:** Screenshot carousel · feature bullet list.

---

## Installation Ceremony

```
Confirm install
    ↓
Director: "Adding [Expansion] to your headquarters."
    ↓
Construction animation (600ms)
    · scaffolding lines · glass facades · lights
    ↓
Campus map updates — building now solid
    ↓
New concierge introduces at door
    ↓
Achievement plaque — Legacy Wing (quiet)
    ↓
"Visit now" or "Later"
```

## Uninstall (If Ever)

| Rule | Experience |
|------|------------|
| Availability | Rare · executive only |
| Warning | Director explains data preservation |
| Motion | Reverse construction — slower · respectful |
| Data | Projects preserved · department archived |

---

## What Marketplace Is Not

| Reject | Canonical |
|--------|-----------|
| Plugin/widget store | Headquarters Expansions™ |
| Open component marketplace | VDR-governed catalog only |
| Theme skins | DNA atmosphere within bounds |
| Competitive ratings noise | Fit score · Director recommendation |

*v1.0 Experience Studio explicitly rejects open widget marketplace — v2.0 Marketplace is **expansion of HQ**, not component store.*
