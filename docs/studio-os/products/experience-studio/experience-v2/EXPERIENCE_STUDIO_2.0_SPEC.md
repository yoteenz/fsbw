## §1 Core Experience Philosophy

### 1.1 The Founding Principle

Studio OS should **never feel like opening software**.

It should feel like **arriving at your headquarters** — a living business you own, expand, and direct.

| Anti-pattern | Canonical experience |
|--------------|---------------------|
| Logging in | **Arriving** |
| Dashboard | **Headquarters** |
| Navigation menu | **Travel** between wings and departments |
| Settings panel | **Executive Office** conversation |
| File browser | **Project productions** on a timeline |
| AI chatbot sidebar | **Studio Orb™** — ambient executive assistant |
| Onboarding form | **Discovery conversation** with Studio Intelligence™ |

### 1.2 Ownership · Immersion · Progression · Creativity

Every interaction reinforces four pillars:

| Pillar | Experience expression |
|--------|----------------------|
| **Ownership** | "Your Headquarters" · "Your Project" · "Your team" — never "the platform" |
| **Immersion** | Spatial hierarchy · environmental storytelling · no gray app frames |
| **Progression** | Departments unlock · wings expand · achievements surface quietly |
| **Creativity** | Conversation before configuration · inspiration before structure |

### 1.3 Inherited Systems (Do Not Redesign)

This specification **uses** — never replaces:

- Studio Constitution™ · Master Specification™ · `experience-architecture.yaml`
- Headquarters Experience™ V2 wings (Executive Lobby through Legacy)
- Studio Production Engine™ ten departments
- Design Governance™ · Component Catalog `comp-*`
- Experience Studio™ v1.0 Creative Wing · DNA stack · AI Creative Director™
- Company Onboarding Intelligence™ · Arrival Experience™ · Awakening Sequence™

### 1.4 Interaction Philosophy Sources

Borrow **interaction philosophy** — not visual aesthetics:

```
Movies     → Ceremonial pacing · act breaks · reveal on merit
Sims       → Build · expand · inhabit · personalize over time
Watch Dogs → Seamless traversal · intelligence in the world
Xbox       → Progression visible · mastery celebrated quietly
Studio OS  → Marble · glass · calm · unmistakably premium
```

## §2 Arrival Experience (Part 1)

**Goal:** First login feels like **stepping into possibility** — not completing setup.

### 2.1 Arrival Sequence (First-Time Founder)

```
AUTHENTICATE
    ↓
THRESHOLD — soft fade · no "welcome back" SaaS chrome
    ↓
STUDIO ORB AWAKENING™ — one-time per organization (M89.4)
    ↓
DIRECTOR GREETING — Studio Intelligence™ introduces itself by name
    ↓
HEADQUARTERS CONCEPT — "You're about to build the headquarters your business deserves"
    ↓
COMPANY DISCOVERY — Company Onboarding Intelligence™ (conversation, not form)
    ↓
HEADQUARTERS GENERATION — see §3
    ↓
ARRIVAL CEREMONY™ — quiet confidence · M73.6
    ↓
MISSION CONTROL — first inhabitation of Headquarters
```

### 2.2 How Users Are Welcomed

| Moment | Treatment |
|--------|-----------|
| **Threshold** | Marble environment materializes · no loading spinner · Director copy: "Welcome. Let's build your headquarters." |
| **Orb introduction** | Orb breathes into presence · single line: "I'm Studio Intelligence™ — your executive team, always within reach." |
| **HQ concept** | Environmental pan — not a diagram. Narration: "This is not a dashboard. This is where your business lives." |
| **No feature tour** | Never a 12-slide product tour. Discovery through **doing** — first Project within 15 minutes |

### 2.3 How Headquarters Concept Is Explained

**Show, don't tell:**

1. Empty marble plaza — potential, not emptiness
2. Ghost outlines of wings that **will** exist
3. Director: "These wings grow as you do. Today, we start with what matters most."
4. First wing materializes (Innovation Wing / Creative Direction Studio)

### 2.4 Department & Concierge Introduction

Departments are introduced as **teams with destinations** — not feature modules:

| Introduction pattern | Example |
|---------------------|---------|
| Name + purpose + personality | "The Development Department is your writers' room — mood boards, scripts, creative direction." |
| Concierge as host | "Your Creative Concierge will guide you through first production." |
| AI specialist as colleague | "Your Art Director AI joins when you enter Development." |

**Rule:** Maximum **three** departments introduced on day one. Others appear as locked destinations with preview ghosting.

### 2.5 Living World vs Dashboard

| Dashboard signal (never) | Living world signal (always) |
|------------------------|------------------------------|
| Dense data tables | One hero · one focus per viewport |
| Permanent sidebar | Travel · Orb · radial destinations |
| "Modules installed" | "Departments staffed" |
| Static background | Subtle environmental presence (M82.5 Living HQ) |
| User ID in corner | Organization name engraved in environment |

## §3 Headquarters Generation (Part 2)

**Goal:** HQ creation feels **magical** — a conversation that becomes architecture.

### 3.1 Discovery Conversation (Not a Form)

Studio Intelligence™ asks **one question at a time** in a floating glass panel — Orb present throughout.

| Phase | Question archetype | Example |
|-------|-------------------|---------|
| Business type | Identity | "What kind of world are you building?" |
| Offerings | Scope | "What do you create or deliver?" |
| Personality | DNA seed | "How should people feel when they encounter your brand?" |
| Immersion level | Experience DNA | "Whisper luxury — or declare it?" |
| Departments needed | Structure | "What do you need running on day one?" |
| Future interest | Expansion seed | "What might you grow into?" |

**Skip path:** "Use my industry template" — still generates, never blank template.

### 3.2 What Studio Intelligence Generates

| Output | Experience treatment |
|--------|---------------------|
| **Headquarters** | Marble campus · named wings · environmental lighting from Design DNA™ |
| **Departments** | Staffed destinations with concierge assignment |
| **Initial workspaces** | Creative Wing · Production Wing entry · Executive Lobby |
| **Concierge team** | Named hosts per wing — warm · not robotic |
| **AI specialists** | Art Director · Strategist · Production Lead — introduced on first visit |
| **Suggested expansions** | Ghost buildings in Marketplace preview — "Available when you're ready" |

### 3.3 Generation Motion

```
Answers complete
    ↓
Orb → thinking (600ms)
    ↓
Marble plaza — blueprint lines draw in (ceremonial 800ms)
    ↓
First wing rises — glass facades catch light (600ms)
    ↓
Department lights activate sequentially (stagger 120ms)
    ↓
Concierge avatars appear at entrances (fade · not pop)
    ↓
Director: "Your headquarters is ready. Step inside."
```

## §4 Headquarters Experience (Part 3)

**Goal:** Users **move through** Headquarters — never paginate through admin.

### 4.1 Navigation Philosophy

```
You are not clicking links.
You are traveling to destinations.
```

| Mechanism | Role |
|-----------|------|
| **Walking / scrolling** | Primary — vertical travel through wing interiors |
| **Department cards** | Destinations — Executive IA rhythm (one hero · cards · focus) |
| **Studio Orb™** | "Take me to…" — voice and text navigation |
| **Environmental doors** | Visual portals between wings — ceremonial transition |
| **Command palette** | Power users — ⌘K destination jump |

### 4.2 Canonical Destinations

Inherited from Headquarters Experience™ V2 + Production Engine + Creative Wing:

| Destination | Wing | Experience character |
|-------------|------|---------------------|
| **Executive Lobby** | HQ Core | Arrival · priorities · today's pulse |
| **Creative Direction Studio** | Innovation / Creative | Inspiration · mood boards · project birth |
| **Experience Studio™** | Creative Wing | Canvas authoring · v1.0 spec |
| **Production Stage** | Production Wing | Assembly · asset creation |
| **Review Theater** | Production Wing | Quality · preview · approval drama |
| **Publishing Control Room** | Production Wing | Go-live · celebration |
| **Intelligence Center** | Operations | Analytics · performance · learning |
| **Knowledge Library** | Knowledge | Assets · brand · institutional memory |
| **Marketplace Plaza** | Expansion | Headquarters Expansions™ |
| **Executive Office** | Executive | Settings · prefs · Founder Notes |

### 4.3 Headquarters Feels Alive

Living Headquarters™ (M82.5) expressions:

| Signal | Restraint |
|--------|-----------|
| Subtle light shift by time of day | Never disco |
| Department status glow when active | Never alarm colors |
| Concierge presence at doors | Never blocking |
| Project progress visible on campus map | Never gamification noise |
| Seasonal environmental storytelling (M106) | Optional · respectful |

## §5 Creative Direction Studio (Part 4)

**Goal:** Creative work feels **collaborative** — directing a team, not using tools.

### 5.1 Project Birth

```
Enter Creative Direction Studio
    ↓
"What's the production?" — natural language or type selection
    ↓
Inspiration injection (optional · encouraged)
    ↓
Interview + DNA blend (v1.0 flow)
    ↓
Project™ object created — visible on HQ campus map
    ↓
Enter Experience Studio™ canvas OR Production pipeline
```

### 5.2 Inspiration Workflows

| Input | Experience |
|-------|------------|
| **Instagram Reel URL** | Drop on inspiration wall · Director extracts mood · palette · rhythm |
| **Reference images** | Mood board rail — drag · compare · branch |
| **Competitor URL** | Director analyzes · "Here's what to borrow · what to avoid" |
| **Voice note** | Orb listens · transcribes · proposes creative brief |
| **Founder Notes** | Persistent per-Project — pinned in studio |

### 5.3 Mood Boards & Branching

- **Compare mode:** Side-by-side boards · slider divider (like version history)
- **Branch:** "Explore direction B" — creates branch · never destroys main
- **Merge:** Director proposes merge · human approves
- **Reject:** Branch archives · lesson captured in AI Memory

### 5.4 Orb in Creative Studio

- Ambient suggestions — max 1 per 5 minutes
- "Generate three better concepts" → proposal cards · confidence · preview
- Never silent mutation — always approve

## §6 Project Experience (Part 5)

**Goal:** Projects™ are **productions you direct** — not files you edit.

### 6.1 Project as Primary Object

```
Project™
├── Identity — name · number · type · status
├── Timeline — acts · departments visited · versions
├── Creative Direction — brief · mood boards · branches
├── Department Progress — 10-stage pipeline position
├── Founder Notes — pinned intentions
├── Outputs — experiences · assets · published artifacts
├── Analytics — post-publish intelligence
└── AI Memory — decisions · rejections · learned preferences
```

### 6.2 Project Dashboard (Not a Table)

| Zone | Content |
|------|---------|
| **Hero** | Active production — large preview · status · next action |
| **Timeline** | Horizontal act structure — Discover → Publish |
| **Department cards** | Where production is · who's working · what's blocked |
| **Founder Notes** | Your pinned intentions — always visible |
| **Outputs rail** | Artifacts produced so far |

**Never:** Dense sortable tables as default view.

### 6.3 Status Language

| Internal state | User-facing language |
|----------------|---------------------|
| `draft` | In development |
| `in_production` | On the Production Stage |
| `in_review` | In the Review Theater |
| `approved` | Cleared for publish |
| `live` | Live · performing |
| `archived` | In the Legacy Vault |

## §7 Studio Production Engine (Part 6)

**Goal:** Every department is a **destination with identity** — travel, don't scroll.

### 7.1 Department Experience Template

Each of the ten departments inherits:

| Attribute | Requirement |
|-----------|-------------|
| **Identity** | Unique tagline · atmosphere · entry ceremony |
| **Tools** | Department-specific · never full platform |
| **AI specialists** | Named role · visible when active |
| **Concierge** | Host greets on entry · explains exit criteria |
| **Objectives** | One sentence — "What must be true to leave?" |
| **Success criteria** | Visible checklist · Design Health™ where applicable |
| **Entry** | Ceremonial door · brief context recap |
| **Exit** | Handoff animation to next department · asset travels with you |

### 7.2 Ten Destinations (Inherited Canon)

| # | Department | Atmosphere | Exit artifact |
|---|------------|------------|---------------|
| 01 | Discover | Research library · opportunity board | Approved Creative Brief |
| 02 | Development | Writers' room · mood board wall | Production Package |
| 03 | Assembly | Production floor · staging | Production Ready |
| 04 | Production | Main stage · creation | Master Content Asset v1 |
| 05 | Review | Theater · preview seats | Quality Approved |
| 06 | Expansion | Remix gallery · derivatives | Derivative Library |
| 07 | Approval | Executive chamber · signatures | Publishing Authorization |
| 08 | Publishing | Control room · monitors | Campaign Live |
| 09 | Intelligence | Analytics observatory | Performance Report |
| 10 | Learning | Reflection garden · archives | Improvement Actions |

### 7.3 Travel Between Departments

```
Complete exit criteria
    ↓
Concierge: "Ready to move to [Next Department]?"
    ↓
Ceremonial transition (400–600ms) — door · corridor · arrival
    ↓
Next department concierge greets with asset context
    ↓
Never: browser tab switch feeling
```

## §10 Orb Experience (Part 9)

**Goal:** Studio Orb™ is the **executive assistant** — navigate · explain · teach · collaborate.

### 10.1 Natural Commands

| User says | Orb does |
|-----------|----------|
| "Take me to Production" | Travel to Production Department · concierge greet |
| "Show me today's priorities" | Executive Lobby · focus panel · three items max |
| "Let's review Project 014" | Open Project dashboard · Review Theater if in review |
| "Generate three better concepts" | Creative Studio · three proposal cards |
| "Projects waiting for approval" | Approval Department queue · sorted by urgency |
| "What is Discover Department?" | Teach mode · 30-second explanation · offer to visit |

### 10.2 Orb Behavior Model

| State | When | Visual |
|-------|------|--------|
| **Idle** | Default | Breathe · bottom-center |
| **Listening** | Voice active | Ripple |
| **Thinking** | Processing | Amber glow · canvas dims 5% |
| **Opportunity** | Suggestion ready | Gold ring once |
| **Navigating** | Travel initiated | Brief pulse · corridor transition |

### 10.3 Orb Never

- Opens modal over active inline editor
- Silently mutates content
- Shows more than one unprompted suggestion per 5 minutes
- Competes with canvas for focus

## §12 First Successful Project™ — Complete Journey

The canonical v2.0 journey from login to first success:

```
DAY 0 — ARRIVAL
  Login → Orb Awakening → HQ Generation → Mission Control

DAY 0 — FIRST PROJECT (within 15 minutes)
  Creative Direction Studio → Inspiration drop → Interview
  → Project 014 created → Experience Studio canvas
  → First section composed → Design DNA™ blend

DAY 0–1 — PRODUCTION
  Travel: Development → Assembly → Production departments
  → Master Content Asset v1 composed

DAY 1 — REVIEW & PUBLISH
  Review Theater → Design Health™ PASS
  → Publishing Control Room → Live
  → Quiet celebration → Legacy Wing first entry

DAY 7+ — GROWTH
  Marketplace preview → first Expansion consideration
  → HQ campus shows second wing ghost
```
