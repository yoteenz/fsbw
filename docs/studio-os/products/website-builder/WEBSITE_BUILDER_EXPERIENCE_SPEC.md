## §1 — Product Vision

### 1.1 One-Sentence Vision

**Studio Website Builder™** is an AI creative operating system where founders and executives **converse, compose, and refine** living digital experiences — with cinematic quality, component intelligence, and Studio OS canon — never traditional drag-and-drop page software.

### 1.2 Why This Is the Flagship

The Website Builder is the clearest proof that Studio OS is an **organizational operating system**, not SaaS:

| OS Principle | How the Builder Demonstrates It |
|--------------|--------------------------------|
| **Places, not pages** | Users enter a *Creative Studio* — not an admin screen |
| **Conversation-first** | Studio Orb™ and Creative Director dialogue precede panels |
| **Design DNA™ / Experience DNA™** | No themes — inherited organizational genome |
| **AI as Creative Director** | Critiques, harmonization, copy — with *why*, not autocomplete |
| **Registry-driven** | Every component, page, token registered in System Registry™ |
| **Release Channel governance** | Preview → Stable promotion through QA Engine™ |

### 1.3 What We Are Building

A **conversation-first, visual-first, AI-assisted** environment for authoring:

- Marketing websites · landing pages · brand sites
- Client portals · booking flows · academy surfaces
- Storefront experiences (when connected to commerce packs)

Built on **component-driven architecture** with live preview, multi-device frames, and a theme engine rooted in Design DNA™ — not third-party templates.

### 1.4 What We Are NOT Building

| Anti-pattern | Our response |
|--------------|--------------|
| WordPress / Wix / Squarespace | No theme marketplace · no widget soup |
| Shopify page editor | Commerce is a *pack*, not the builder identity |
| Webflow canvas clone | No box-editing mental model as primary |
| Figma duplicate | Design tool ergonomics, OS product outcomes |
| Canva simplicity | Premium depth · executive audience |
| Generic AI page generator | Governed Creative Director with Genome + Registry context |

### 1.5 Design Synthesis (Reference DNA — Not Imitation)

We absorb **principles**, not interfaces:

| Reference | What we take |
|-----------|--------------|
| **Claude Design** | Calm intelligence · conversational creation · respectful pacing |
| **Framer** | Live canvas · responsive preview · motion fluency |
| **Figma** | Inspector precision · component instances · variant thinking |
| **Linear** | Command palette · keyboard fluency · density when needed |
| **Apple HIG** | Hierarchy · materials · clarity · accessibility |
| **Notion AI** | Inline AI collaboration · contextual suggestions |

**Unified outcome:** A single Studio OS surface that feels **cinematic, premium, futuristic**.

### 1.6 Success Criteria (Launch)

1. A founder can **start from conversation** and reach a publishable preview in one session
2. **90%+ session time** on canvas/preview — panels are ephemeral
3. Creative Director provides **actionable critiques with rationale**
4. Design Health™ score visible and improvable without leaving builder
5. Remix™ adjusts atmosphere without destroying information architecture
6. Multi-device preview accurate for mobile · tablet · desktop
7. All artifacts register in Knowledge Registry™ + System Registry™
8. Release Channel Preview gate passes QA Engine™ checklist

### 1.7 Relationship to Existing Systems

| System | Role |
|--------|------|
| **Digital Architect™** | Solution architecture · IA · ecosystem map (preserved) |
| **Experience Studio™** | Current UI session layer — **evolves into Website Builder shell** |
| **Design DNA™ / Experience DNA™** | Token + atmosphere genome |
| **Studio Orb™** | Primary interaction — not a sidebar chatbot |
| **Conversation Engine™** | Session orchestration for builder dialogue |
| **Organization Genome™** | Voice, tone, values constrain AI output |
| **Component Registry™** | Canonical component library source |
| **Design Token Engine™** | Theme resolution |

## §2 — UX Journey

### 2.1 Primary Personas

| Persona | Goal | Anxiety we remove |
|---------|------|-------------------|
| **Founder / Executive** | Launch a premium brand presence fast | "I don't know design" |
| **Creative Director (human)** | Refine atmosphere without fighting tools | "Tools flatten luxury" |
| **Studio Operator** | Maintain canon across workspaces | "Every site looks different" |

### 2.2 Entry Journey — *Arrive at the Studio*

```
Headquarters → Creative Wing → Website Builder
        ↓
   Studio Orb greets (ambient, not modal spam)
        ↓
   "What are we creating today?" — conversation-first
        ↓
   Experience type card select (Website · Landing · Portal · …)
        ↓
   3-step Creative Interview (style · audience · feeling)
        ↓
   Canvas awakens — live preview occupies viewport
```

**Emotional arc:** Curiosity → Confidence → Creative flow → Pride

### 2.3 Creation Journey — *Collaborate with the Director*

```
User describes intent (voice or text via Orb)
        ↓
AI Creative Director proposes layout + copy direction
        ↓
User accepts · refines · or asks "why?"
        ↓
Visual edit mode — direct manipulation on canvas
        ↓
Inspector docks for precision (typography · spacing · motion)
        ↓
Design Health™ surfaces gaps
        ↓
Remix™ explores atmosphere variants (same IA)
        ↓
Multi-device check → responsive AI optimization
        ↓
Save milestone → registry registration
```

### 2.4 Refinement Journey — *Polish, Don't Rebuild*

```
Open existing site from Registry
        ↓
Director briefs current Design Health™
        ↓
Targeted critiques ("hero hierarchy weak · why: …")
        ↓
Component swap from library (canon-safe)
        ↓
AI color harmonization from Design DNA™
        ↓
Preview share link (internal) → approval path
```

### 2.5 Exit Journey — *Ship Intentionally*

```
Publish readiness check (QA Engine™ · Preview channel)
        ↓
Release notes auto-generated
        ↓
Handoff to Campaign Engine™ (Phase 2) or live deploy
        ↓
Studio Intelligence™ learns from session → Memory Engine™
```

### 2.6 Orb-Centric Interaction Moments

| Moment | Orb behavior |
|--------|--------------|
| Idle on canvas | Soft breathe · no clutter |
| Director thinking | Crystal pulse · thinking state |
| Critique available | Opportunity glow · tap for rationale |
| Voice command | Voice Mode radial → builder context |
| Overwhelmed user | Progressive disclosure — "show me one thing" |

### 2.7 Failure & Recovery Paths

| Situation | Recovery |
|-----------|----------|
| AI proposal off-brand | Genome constraints shown · one-tap revert |
| Layout breaks mobile | Responsive AI suggests fix · diff preview |
| User lost in panels | Close all · return to canvas · Orb recap |
| Quota / offline | Local session preserved · sync on reconnect |

## §6 — Design Language

> **Governance:** This section describes **composition and product atmosphere** for Website Builder — not a parallel design system. Global visual rules inherit from [Studio Design Constitution™](../../design/STUDIO_DESIGN_CONSTITUTION.md) · [Design Language System™](../../design/DESIGN_LANGUAGE_SYSTEM.md) · [Component Catalog™](../../design/COMPONENT_CATALOG.md). Product-specific tokens (e.g. `--wb-*`) express Design DNA™ atmosphere within constitutional bounds.

### 6.1 Material Philosophy

**Marble · Glass · Crystal · Light**

The builder itself is a luxury environment — users are *inside* Headquarters' Creative Wing, not inside a gray SaaS app.

| Material | Usage |
|----------|-------|
| **Marble** | Environment background · continuity with HQ |
| **Frosted glass** | Docks · HUD · panels (40–55% opacity) |
| **Crystal acrylic** | Canvas frame · preview chrome |
| **Thin uppercase metadata** | Labels · section IDs · status |
| **Editorial headlines** | Page content default · large calm type |

### 6.2 Color System

| Token | Value | Usage |
|-------|-------|-------|
| `--wb-brand` | Org primary (Design DNA™) | Accent · selection |
| `--wb-studio-red` | `#EB1C24` | Studio OS canon accent |
| `--wb-chrome` | `rgba(255,255,255,0.92)` | Top metadata bar |
| `--wb-glass` | `rgba(255,255,255,0.38)` | Panel fill |
| `--wb-glass-edge` | `rgba(255,255,255,0.78)` | Borders |
| `--wb-shadow` | `0 24px 64px rgba(0,0,0,0.08)` | Floating depth |
| `--wb-text` | `#1a1a1a` | Primary copy |
| `--wb-text-muted` | `rgba(26,26,26,0.55)` | Metadata |

### 6.3 Typography

| Role | Font | Size rhythm |
|------|------|-------------|
| Metadata / labels | Futura PT Medium | 7–8px · 0.12–0.14em tracking |
| UI actions | Futura PT Medium | 9–10px uppercase |
| Director voice | System serif accent optional | 13–15px sentence case |
| Canvas headline | Org display (Design DNA™) | 48–72px editorial |
| Canvas body | Org body | 16–18px · 1.5 leading |

### 6.4 Spacing & Density

- **Canvas-first density:** UI chrome ≤15% viewport height combined
- **Breathing room:** 24px minimum panel padding · 48px section gaps on canvas
- **No cramped inspector:** Expand on demand · never permanent 300px sidebar

### 6.5 Iconography & Affordances

- Minimal emoji in product chrome (Orb radial only)
- Line-weight icons · 1.5px stroke · glass buttons
- Selection: crystal ring + soft red glow (brand)
- Drag: ghost opacity 0.6 · snap guides gold whisper

### 6.6 Anti-Patterns (Visual)

- ❌ Dark mode builder chrome (breaks HQ marble continuity)
- ❌ Rainbow template picker
- ❌ Grid of 50 thumbnails
- ❌ Persistent chat sidebar
- ❌ Bootstrap admin tables inside builder

## §8 — Motion System

### 8.1 Motion Principles

| Principle | Implementation |
|-----------|----------------|
| **Calm by default** | No gratuitous animation on load |
| **Cinematic transitions** | 400–600ms ease-out · blur + scale |
| **Responsive feedback** | 120–180ms micro-interactions |
| **Never blocking** | Motion never prevents input >300ms |
| **DNA-driven** | Experience DNA™ `motion` slider scales amplitudes |

### 8.2 Motion Tokens

| Token | Duration | Easing | Usage |
|-------|----------|--------|-------|
| `wb-fade-in` | 480ms | `cubic-bezier(0.22, 1, 0.36, 1)` | Panel open |
| `wb-fade-out` | 320ms | `ease-in` | Panel close |
| `wb-scale-in` | 520ms | `cubic-bezier(0.22, 1, 0.36, 1)` | Canvas focus |
| `wb-blur-in` | 400ms | `ease-out` | Conversation backdrop |
| `wb-slide-dock` | 380ms | `cubic-bezier(0.32, 0.72, 0, 1)` | Dock enter |
| `wb-micro` | 140ms | `ease-out` | Button · chip |
| `wb-breathe` | 3.2s | `ease-in-out` infinite | Orb idle (inherited) |

### 8.3 Scene Transitions

| Transition | Motion |
|------------|--------|
| Home → Interview | Marble fade · headline crossfade |
| Interview → Canvas | Blur backdrop · canvas scale 0.96→1 |
| Open Director | Dock slide + thread fade stagger 40ms/line |
| Remix apply | Canvas atmosphere crossfade 600ms |
| Device switch | Frame morph width · content reflow spring |
| Publish success | Crystal shimmer once · calm settle |

### 8.4 Reduced Motion

- Respect `prefers-reduced-motion` — instant cuts · no breathe
- Experience DNA™ motion=0 → disable ambient animations

### 8.5 Sound (Optional)

- Inherited from `studioOrbSounds.ts` — **off by default**
- Builder-specific: subtle crystal tap on milestone save (opt-in)

The **AI Creative Director™** is not a chatbot — it is a collaborative senior designer:

- Proposes · critiques · explains *why*
- Defers to Organization Genome™ voice
- Never overwrites without explicit accept
- Uses **Design Health™** as objective vocabulary

```

                     ▼

                     ▼
```

1. Constitution™ + Core Philosophy™ excerpts (governance)
