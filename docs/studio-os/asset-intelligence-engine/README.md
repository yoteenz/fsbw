## Mission

Traditional AI systems regenerate nearly identical assets repeatedly — wasting tokens, time, compute, and consistency.

Studio OS behaves differently.

**Before generating… always remember.**

Every approved asset becomes part of **Company Memory™**. Before any generation request begins, Studio OS searches existing assets first. **Generation is always the last option. Never the first.**

---

## One Sentence

**Asset Intelligence Engine™** is the permanent intelligence layer that searches the **Asset Registry™**, evaluates compatibility, recommends reuse or modification, learns founder preferences, and protects **Company DNA™** — so Studio OS accumulates creative knowledge instead of repeating it.

## New Generation Order

```
Founder requests: "Generate Story Table."
         ↓
Asset Intelligence Engine™ searches Asset Registry™
         ↓
Find similar assets · evaluate compatibility
         ↓
Recommend: Reuse · Modify · Upgrade · Generate New
         ↓
Founder chooses (always)
         ↓
Only if needed → Generation Manager™ → providers
         ↓
Approved asset → Registry → Company Memory™
```

See [generation-order.md](./generation-order.md).
