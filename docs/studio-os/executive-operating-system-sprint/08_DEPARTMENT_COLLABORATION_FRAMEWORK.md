# Department Collaboration Framework™

**Status:** Canonical collaboration architecture — P0 Executive OS Sprint  
**Scope:** How departments work together as an operating company

---

## Collaboration Thesis

A company is not a collection of departments. It is a **network of handoffs, debates, shared timelines, and mutual accountability** — all visible in physical space.

The Department Collaboration Framework™ defines how creative, production, strategic, and executive departments **collaborate as one operating organization**.

---

## Collaboration Model

```
                    FOUNDER OFFICE™
                    (strategic oversight)
                          │
              ┌───────────┼───────────┐
              ▼           ▼           ▼
    CREATIVE DIRECTION   BRAND      MARKETING
         STUDIO™      STRATEGY™     GALLERY™
              │           │           │
              └───────────┼───────────┘
                          ▼
              SPECIALIST DEPARTMENTS
         (Art · Photo · Motion · Packaging · etc.)
                          │
                          ▼
              STUDIO WAREHOUSE™
                    (production)
                          │
                          ▼
              HEADQUARTERS™ / DISTRIBUTION
                          │
                          ▼
              STUDIO ARCHIVES™
                    (memory)
```

Collaboration flows **downstream** (direction → production → distribution) and **laterally** (specialist debate → arbitration → alignment).

## Collaboration Types

### Type 1 — Direction Cascade

Creative intent flows from CDS to all departments:

| Stage | From | To | Artifact in transit |
|-------|------|-----|---------------------|
| Brief approved | Founder Office | Creative Direction Studio™ | Signed brief on Story Table™ |
| Direction locked | CDS | All production departments | Direction board · genome overlay |
| Visual standards set | Art Direction | Photo · Motion · Packaging | Visual language document |
| Brand guard active | Brand Strategy | All departments | Genome divergence alerts |

### Type 2 — Specialist Cross-Review

Departments review each other's work before founder meeting:

| Review | Participants | Output |
|--------|--------------|--------|
| Creative ↔ Brand | CD · Brand Strategist | Position summary for founder |
| Art ↔ Motion | AD · Motion Director | Visual-motion alignment check |
| Packaging ↔ Industrial | Packaging · Industrial | Structural feasibility note |
| Marketing ↔ Creative | Marketing · CD | Campaign coherence assessment |
| Production ↔ All | Production Director · leads | Feasibility flags |

Cross-reviews produce **pre-meeting debate evidence** — not founder-burdening noise.

### Type 3 — Production Handoff

Physical artifact transit between departments:

```
Creative Direction Studio™
    │ transit artifact: approved direction board
    ▼
Art Direction Studio™ (execution)
    │ transit artifact: visual proof set
    ▼
Studio Warehouse™ (manufacture)
    │ transit artifact: production package
    ▼
Quality Theater (validation)
    │ transit artifact: certified deliverable
    ▼
Distribution Dock (publish)
```

Handoffs are **journeys** — corridor stations · transit tables · Orb announcements.

### Type 4 — Executive Arbitration

When lateral debate cannot resolve:

```
Specialist disagreement detected
        ↓
Cross-review evidence compiled
        ↓
Orb schedules Arbitration Session
        ↓
Founder Boardroom™ — positions summarized
        ↓
Founder decides
        ↓
Decision cascades to all affected departments
```

### Type 5 — Intelligence Feed

External and internal intelligence flows into departments:

| Source | Feeds | Expression |
|--------|-------|------------|
| World Knowledge Engine™ | Brand Strategy · Marketing | Competitive briefing |
| Organization Pulse™ | Command Center · Founder Office | Health alerts |
| Analytics Observatory | Marketing · Production | Performance feedback |
| QA Headquarters | Production · Creative | Quality patterns |
| Archives | All departments | Historical reference |

| **Ambient audio** | Adjacent department presence | Notifications |
| **Orb routing** | Founder navigation | Command execution |
| **Genome alerts** | Brand divergence | Approval requests |

## Collaboration Timing

Departments operate on **shared organizational clock**:

| Rhythm | Collaborative activity |
|--------|------------------------|
| **Overnight** | Research · prep · generation · cross-review |
| **Morning** | Briefing summarizes cross-department state |
| **Pre-meeting window** | Specialist assembly · evidence mounting |
| **Meeting** | Debate · founder decision |
| **Post-meeting** | Handoff dispatch · follow-up scheduling |
| **Between meetings** | Production continues · next gate prepares |

Founder experiences **synchronized organization** — not siloed departments.

---

## Healthy Tension Between Departments

| Tension pair | Productive friction | Resolution path |
|--------------|--------------------|-----------------|
| Creative ↔ Brand | Vision vs. audience | Founder arbitration |
| Creative ↔ Production | Ambition vs. feasibility | Production Readiness gate |
| Brand ↔ Marketing | Positioning vs. channel | Campaign Readiness review |
| Art ↔ Motion | Static vs. kinetic | Motion Review meeting |
| Packaging ↔ Industrial | Tactile vs. manufacture | Packaging Approval |
| Marketing ↔ Production | Launch date vs. quality | Launch Decision gate |

Friction is **scheduled and surfaced** — not suppressed or escalated as surprise conflict.

## Department Accountability

Each department reports organizational state:

| Department | Accountable for | Reports via |
|------------|-----------------|-------------|
| Creative Direction | Direction clarity · branch state | Morning brief · CDS boards |
| Brand Strategy | Genome alignment · positioning | Observatory · divergence alerts |
| Art Direction | Visual standards · consistency | Mood Wall · comparison boards |
| Production | Timeline · budget · deliverables | Warehouse floor · readiness meetings |
| Marketing | Launch readiness · channel fit | Campaign War Room |
| QA | Quality · compliance | Quality Theater |
| Archives | Preservation · history access | Archive vault state |

Accountability is **visible** — boards · tickers · ambient displays — not hidden status fields.

---

## Collaboration Anti-Patterns

| Anti-pattern | Failure |
|--------------|---------|
| Siloed departments | No handoff artifacts |
| Chat-based handoffs | Not spatial |
| Founder as courier | Role inversion |
| Debate hidden from founder | Unhealthy suppression |
| Debate dumped on founder unprepared | Missing cross-review |
| No transit evidence | Handoff invisible |
| Departments unaware of each other | No ambient context |
| Parallel calendars | No shared rhythm |
