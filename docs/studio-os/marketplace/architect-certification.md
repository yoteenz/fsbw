# Architect Certification™

**Studio Certified™ — the highest recognition in Studio Marketplace™**

**Version:** 1.0.0  
**Status:** Canonical architect certification (docs only)  
**Parent:** [Studio Architects™](./studio-architects.md)

---

## Purpose

Define **Studio Certified™** as prestigious architect and headquarters recognition — not a participation badge.

Certification becomes the **highest recognition** inside Studio Marketplace™.

Not everyone receives it.

---

## Certification Scope

Studio Certified™ applies to:

| Object | Certification |
|--------|---------------|
| **Headquarters Package™** | Environment certified for install |
| **Studio Architect™** | Architect earns Certified status via portfolio |
| **Architect Collection™** | Entire collection certified as bundle |

Architect certification requires **sustained certified work** — not one listing.

## Certification Path

```
Private™ HQ
    ↓
Share With Team™ (optional proof)
    ↓
Submit For Review™
    ↓
Community Marketplace™ (uncertified listing allowed)
    ↓
Studio Certified™ review (full dimension gate)
    ↓
Featured Collection™ (editorial)
```

Community™ listing does **not** require certification.

Studio Certified™ is **opt-in excellence path**.
