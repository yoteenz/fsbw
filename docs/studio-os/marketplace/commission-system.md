# Commission System™

**Studio Architects™ as premium creative professionals**

**Version:** 1.0.0  
**Status:** Canonical commission architecture (docs only)  
**Parent:** [Studio Architects™](./studio-architects.md)

---

## Purpose

Define how founders eventually **commission custom work** from Studio Architects™ — transforming architects from publishers into **premium creative professionals**.

Distinct from **Premium Generation™** (AI pipeline) — commissions are **human architect relationships**.

---

## Core Law

```
COMMISSIONS ARE RELATIONSHIPS — NOT CHECKOUT BUTTONS
```

## Commission Flow (Future)

```
1. Founder requests commission (scope · budget range · timeline)
        ↓
2. Architect accepts · declines · or requests discovery call
        ↓
3. Discovery — Company Genome™ · Taste · Creative Brief™ shared
        ↓
4. Proposal — concept boards · scope · milestones
        ↓
5. Founder approves proposal
        ↓
6. Architect designs (may use Premium Generation™ as tool)
        ↓
7. Walkthrough review · revision rounds
        ↓
8. Golden Build™ delivery → Headquarters Package™ sealed
        ↓
9. Install · Headquarters History™ records commission lineage
        ↓
10. Optional — founder publishes with architect attribution
```

## Commission vs Premium Generation™

| Dimension | Commission | Premium Generation™ |
|-----------|------------|---------------------|
| **Author** | Named Studio Architect™ | Founder-directed AI pipeline |
| **Relationship** | Professional engagement | Self-serve creative |
| **Price** | Architect sets · negotiates | Generation Credits |
| **Output** | Bespoke sealed package | Private™ auto-package |
| **GPU** | Architect absorbs design GPU | Founder-funded GPU |
| **Prestige** | Highest — named architect | Premium — personal unique |

Both produce **Headquarters Packages™** — different relationship model.
