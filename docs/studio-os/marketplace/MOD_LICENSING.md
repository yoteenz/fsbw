# Mod Licensing

**Version:** `mod-licensing.v1`

## License types

| Type | Scope |
|------|-------|
| `PERSONAL_HEADQUARTERS_LICENSE` | One founder org · no redistribution |
| `COMMERCIAL_HEADQUARTERS_LICENSE` | One commercial org · internal use |
| `MULTI_PROPERTY_LICENSE` | Multiple properties · same organization |
| `CREATOR_DERIVATIVE_LICENSE` | Derivatives under explicit terms |
| `ENTERPRISE_LICENSE` | Negotiated multi-org / franchise |

## License defines

- Allowed installations
- Modification rights
- Resale and derivative rights
- Attribution
- Update and support access
- Transferability and expiration

## Buyer installation

Buyer receives a **brand-neutral marketplace package** — not Frontal Slayer's live scene instance or private source data.
