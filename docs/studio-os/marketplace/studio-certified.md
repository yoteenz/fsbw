## The Four Quality Levels

### Studio Originals™

| Property | Value |
|----------|-------|
| Creator | Studio OS (official) |
| Quality | Premium · curated · canonical |
| GPU at install | Never |
| Default | Every founder onboarding |
| Certification | Implicit Studio Certified™ |

Official Studio OS experiences — handcrafted · maintained.

---

### Private™

| Property | Value |
|----------|-------|
| Creator | Founder or creator (personal) |
| Visibility | Owner only |
| Marketplace | Not listed |
| Purpose | Personal HQ · draft · Premium Generation™ output |

Every headquarters begins Private™ until published.

---

### Community™

| Property | Value |
|----------|-------|
| Creator | Published creators · founders |
| Visibility | Public marketplace |
| Requirements | Golden Build™ · valid Headquarters Package™ |
| GPU for buyer | Never (pre-built) |
| Revenue | Creator earns per install |

Community-reviewed — not Studio-guaranteed. Ranking surfaces best.

---

### Studio Certified™

| Property | Value |
|----------|-------|
| Creator | Any publisher passing full review |
| Visibility | Marketplace + Certified badge |
| Quality | Reviewed by Studio OS · production-ready |
| Featured | Eligible for Featured Collection™ |
| Trust | Highest buyer confidence |

**Premium quality · Featured · Trusted.**

Only approved headquarters receive Studio Certified™ status.

---

## Certification Gate

| Requirement | Validation |
|-------------|--------------|
| Headquarters Package™ schema valid | Automated |
| Framework Lock™ zones complete | Automated + human walkthrough |
| Arrival + Idle Life™ profiles | Human |
| Genome adaptation (≥2 industries) | Integration test |
| Install / uninstall clean | Automated |
| Preview = install fidelity | Human |
| Performance SLA | Automated |
| IP originality | Human review |
| Golden Build™ minimum | Lifecycle gate |
| Marketplace Certified™ | Per production lifecycle |
