## Purpose

Define how Studio OS recommends **Studio Architects™** and their **Headquarters™** through Founder Taste Genome™ — beyond generic marketplace sorting.

Recommendations become **deeply personal**.

Extends [taste-recommendations.md](./taste-recommendations.md) to **architect-level** matching.

## Architect-Level Matching

Architects develop **taste signatures** from portfolio:

| Signature vector | Derived from |
|------------------|--------------|
| Material vocabulary | Published Environment DNA™ |
| Lighting philosophy | Portfolio lighting profiles |
| Spatial restraint | Envelope genres across HQ |
| Emotional target | Mood fields · storytelling |
| Industry affinity | Company Types served |

Founder Taste Genome™ ↔ Architect signature = **Architect Taste Match™**.
