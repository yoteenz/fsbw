## Studio Originals™ vs Company Expression

Studio Original™ provides **starting genre**.

[Company Expression System™](../world/company-expression-system.md) modulates within the Original:

| Layer | Behavior |
|-------|----------|
| Studio Original™ | Architectural genre · default materials |
| Company Genome™ | Brand-specific props · product presence |
| Founder Taste™ | Refinement · restraint adjustments |
| Set Continuity™ | Accumulated history over time |

Original is **foundation** — not permanent ceiling.

Founders **Renovate™** or **Premium Generate™** when ready.
