# GPU Strategy™

**Predictable infrastructure · intentional creativity**

**Version:** 2.0.0  
**Status:** Canonical cost architecture (docs only)  
**Parent:** [The Economy of Studio World™](./README.md)

---

## Core Law

```
GPU GENERATION IS A PREMIUM PRODUCTION RESOURCE — NOT THE DEFAULT
```

GPU generation is treated like **hiring an elite architectural firm**.

Only when the founder intentionally requests original work.

---

## Priority Order

| Priority | Path | GPU usage |
|----------|------|-----------|
| **1** | **Studio Originals™** | **None** — handcrafted · pre-built |
| **2** | **Marketplace Installations™** | **None** — pre-built Headquarters Packages™ |
| **3** | **Renovations™** | **Light** — parametric packs · pre-authored swaps |
| **4** | **Premium Original Concept Generation™** | **Full** — Creative Direction Pipeline™ |

This keeps infrastructure costs **predictable** while maximizing founder creativity.

---

## Priority 1 — Studio Originals™ (No GPU)

- Handcrafted at platform level
- Installed at onboarding
- Every founder — day one
- Zero generation queue

**Detail:** [studio-originals.md](./studio-originals.md)

---

## Priority 2 — Marketplace Installations™ (No GPU)

- Creator absorbs design-time GPU
- Buyer receives sealed Headquarters Package™
- `gpuRequired: false` — mandatory
- One-click walk-in install

**Detail:** [headquarters-packages.md](./headquarters-packages.md)

---

## Priority 3 — Renovations™ (Light GPU)

| Renovation type | GPU |
|-----------------|-----|
| Refresh Lighting™ · Seasonal HQ™ (pack) | None |
| Replace Story Table™ · Mood Wall™ (pack) | None |
| Material refinish pack | None |
| **Custom Renovation™** (unique redesign) | Full → Priority 4 |

Default renovations use **pre-authored packs** — not open-ended generation.

**Detail:** [renovation-system.md](./renovation-system.md)

---

## Priority 4 — Premium Original Concept Generation™ (Full GPU)

Founder explicitly chooses **Generate New Concepts™**.

```
Creative Brief™
        ↓
Generate 3 Complete Concepts™ (A · B · C)
        ↓
Founder selects vision
        ↓
Scene Blueprint™
        ↓
Reverse Engineering™
        ↓
Asset Graph™
        ↓
Refinement™
        ↓
Golden Build™
        ↓
Auto-packaged Private™ Headquarters Package™
```

**Source:** [Creative Direction Pipeline™](../creative-direction-pipeline/README.md)

Generation becomes **premium** — not default.

## Orb Gate (Mandatory)

Orb never silently triggers GPU.

| Option | GPU tier |
|--------|----------|
| Continue Working™ | 0 |
| Renovate Headquarters™ | 0–light |
| Browse Marketplace™ | 0 |
| Generate New Concepts™ | Full |

---

## Cost Control Principles

| Principle | Implementation |
|-----------|----------------|
| No generation on signup | Studio Originals™ only |
| No generation on marketplace install | Package law |
| Concept batch as one unit | A/B/C = one premium commission |
| Refinement bounded | Pipeline caps per session |
| Transparent estimate | Orb states scope before GPU |

---

## Business Alignment

| Revenue stream | GPU bearer |
|----------------|------------|
| Studio Originals™ | Studio OS (craft time) |
| Marketplace purchase | Creator (design) · buyer (zero) |
| Generation Credits | Requesting founder |
| Renovation Packs | Pre-built (zero/light) |

**Detail:** [business-model.md](./business-model.md)

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Unlimited generation per founder | Cost explosion |
| GPU on marketplace install | Breaks Priority 2 |
| Silent background generation | Breaks intentionality |
| Generation as onboarding default | Breaks Priority 1 |
