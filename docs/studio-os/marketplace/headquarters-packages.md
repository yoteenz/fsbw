## Auto-Packaging Pipeline

When creator or founder publishes:

```
1. Validate Framework Lock™ zones
2. Collect Scene Blueprint™ · Environment DNA™ · Asset Graph™
3. Resolve transitions · audio · animations · cameras
4. Seal Orb configuration
5. Build genome adaptation matrix
6. Strip creator-specific company identity
7. Schema validate · provenance seal
8. Enter certification queue (if publishing)
```

Creator never manually zips files.
