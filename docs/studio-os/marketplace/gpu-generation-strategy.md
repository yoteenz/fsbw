## Purpose

Define when Studio OS allocates **GPU production resources** — and when it does not.

Generation is always treated as a **premium creative resource**.

Default paths require **zero GPU**.

---

## Core Law

```
GPU RUNS ONLY WHEN THE FOUNDER EXPLICITLY REQUESTS NEW CREATIVE CONCEPTS
```

---

## Default Paths (No GPU)

| Path | Resource | Founder experience |
|------|----------|-------------------|
| **Studio Originals™** | Pre-built Headquarters Package™ | Instant · polished · day one |
| **Marketplace purchase** | Pre-built creator package | One-click install |
| **Renovation™** | Pre-authored upgrade packs · parametric refresh | Homeowner upgrade |
| **Genome modulation** | Intelligence layer reweight | Expression shift without regen |
| **Set Continuity™ props** | Milestone artifacts (pre-cataloged) | History accumulation |

These paths scale to millions of founders **without linear GPU cost**.

## Orb Gate

Orb never silently triggers generation.

Orb offers explicit choice:

| Option | GPU |
|--------|-----|
| **Continue Working™** | No |
| **Renovate Headquarters™** | No (default renovations) |
| **Browse Marketplace™** | No |
| **Generate New Concepts™** | **Yes** |

Founder must **opt in** to GPU cost.

## When Renovation™ Uses GPU

| Renovation type | GPU |
|-----------------|-----|
| Refresh Lighting™ (pack) | No |
| Seasonal Headquarters™ (pack) | No |
| Replace Story Table™ (marketplace object swap) | No |
| **Custom Renovation™** (founder requests unique redesign) | Yes — enters Premium Generation™ |

Default renovations are **pack-based** — not open-ended generation.

**Detail:** [renovation-system.md](./renovation-system.md)

## Creator GPU Usage

| Creator activity | GPU |
|------------------|-----|
| Design HQ for publication | Creator may use Premium Generation™ |
| Published package install by buyer | **No** — buyer gets pre-built |
| Creator Evolution™ version bump | Creator GPU · optional regen scope |

Creators absorb design-time GPU — buyers do not.

## Failure Mode Prevention

| Risk | Mitigation |
|------|------------|
| Accidental generation on navigation | Orb gate · no auto-gen hooks |
| Generation as onboarding default | Studio Originals™ mandatory path |
| Unbounded refinement spend | Pipeline caps · founder confirm |
| Marketplace install triggers gen | `gpuRequired: false` package law |

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Generate HQ on every new signup | Cost explosion |
| GPU theme refresh | Should be Renovation pack |
| Silent background generation | Breaks intentional creativity |
| Buyer GPU on marketplace install | Breaks package promise |
