# ARTICLE-E05 — Studio Exchange™

**The Professional License System™**

**Version:** 1.0.0  
**Status:** Canonical architecture (docs only)  
**Parent:** [The Economy of Studio World™](./README.md)  
**Supersedes customer-facing marketplace language:** "Marketplace" · "Buy Course" · "Enroll" · "Subscription"

---

## Mission

Studio World should never sell courses.

Studio World grants entry into professions.

The commercial economy is not transactional education. It is a living professional civilization where citizens obtain professions, expansions, businesses, assets, knowledge, and opportunities.

---

| Old framing | ARTICLE-E05 framing |
|-------------|---------------------|
| Marketplace | **Studio Exchange™** |
| Storefront | **Professional economy** |

| Subscription | **Ongoing world membership / license access** |
| Course completion | **Certification Ceremony™ + world unlocks** |

The Studio Exchange™ is not a storefront.

It is the civic exchange layer of Studio World™.

## Studio Exchange™ Definition

The **Studio Exchange™** is where citizens obtain:

- Professional Licenses™
- Career Expansions™
- Businesses
- Assets
- Knowledge
- Opportunities
- Mentorship
- Certifications
- Professional services
- World access

The Exchange should feel like joining an industry, not buying content.

---

## Professional Licenses™

A **Professional License™** grants entry into an entire **Career World™**.

It includes access to:

| License entitlement | Meaning |
|---------------------|---------|
| **Profession Brain™** | The intelligence layer for the profession |
| **Career World™** | Persistent profession environment |
| **AI Mentors™** | Guided instruction and feedback |
| **Simulations™** | Practice, scenarios, and professional judgment |
| **Career Progression™** | Levels, milestones, reputation, and status |
| **Professional Memory™** | Long-term record of work and decisions |
| **Knowledge Retention™** | Spaced return to mastered concepts |
| **Community** | Peers, guilds, teams, cohorts |
| **Competitions** | Industry challenges and events |
| **Certifications™** | Quality-gated credentials and ceremonies |
| **Lifetime World Updates** | The Career World evolves after entry |

The license is the gateway to a living profession.

It is not a course SKU.

## License Acquisition Experience

```
Discover profession
    ↓
Preview Career World™
    ↓
Meet Profession Brain™ + mentor
    ↓
Acquire Professional License™
    ↓
License ceremony / onboarding arrival
    ↓
Enter Career World™
    ↓
Progression · simulations · memory · community
```

The purchase moment should feel like being admitted into a field.

Orb language should avoid cart/checkout metaphors when possible and emphasize:

- "Enter Hair World™"
- "Claim Professional License™"
- "Begin your industry journey"
- "Join the profession"
- "Unlock the Career World™"

## Career Expansions™

Every Career World™ supports optional **Career Expansions™**.

These are not DLC in the traditional sense. They are professional specializations.

Example for **Hair World™**:

| Expansion | Professional meaning |
|-----------|----------------------|
| **Color Lab™** | Color theory, formulation, correction, advanced tone systems |
| **Luxury Salon™** | Premium client experience, service design, hospitality |
| **Celebrity Stylist™** | High-profile styling, discretion, speed, reputation |
| **Editorial Fashion™** | Campaign styling, art direction, runway/editorial work |
| **Texture Specialist™** | Textured hair expertise, curl systems, cultural fluency |
| **Hair Extension Mastery™** | Install methods, safety, maintenance, transformation |
| **Salon Franchise™** | Business scaling, teams, standards, operations |

Expansion purchases must deepen a profession, not fragment it.

## Certification Ceremonies™

Studio World should never simply issue downloadable PDFs.

Every certification becomes an in-world event:

- Graduation ceremony
- Mentor speech
- Awards stage
- Crystal credential presentation
- Career celebration
- Professional announcements
- Community recognition
- Career World archival moment

The learner experiences the achievement.

The credential is a world event first, a document second.

---

## Certification Unlocks

Every certification unlocks meaningful opportunities.

| Unlock class | Examples |
|--------------|----------|
| **Districts** | New Career World™ areas, advanced labs, industry halls |
| **Businesses** | Salon, studio, agency, academy, franchise paths |
| **Clients** | Higher-tier clients, special briefs, celebrity simulations |
| **Mentorship** | Access to master mentors or right to mentor apprentices |
| **Competitions** | Industry events, seasonal challenges, championships |
| **Teaching rights** | Ability to host classes, cohorts, or critiques |
| **Exchange benefits** | Discounts, credits, priority expansion access |
| **Hero Objects™** | Profession-specific artifacts earned through mastery |
| **Industry events** | Ceremonies, showcases, community announcements |
| **Advanced AI mentors** | Specialist mentors unlocked by competence |

Never reward only a certificate.

Always expand the world.

## Mentor Economy™

Master professionals should eventually mentor apprentices.

Mentoring is a respected profession itself.

Mentors can earn:

- Mentor Points™
- Industry Reputation™
- Community Prestige™
- Exclusive Hero Objects™
- Exchange Credits™
- Founder Collectibles™
- Expansion discounts
- Invitations to ceremonies and competitions

Mentor rewards must prioritize contribution quality over volume.

---

## Legacy Businesses™

Citizens eventually create businesses inside Career Worlds™.

Legacy Businesses™ continue operating as part of the persistent world.

They can:

- Hire AI
- Hire citizens
- Train apprentices
- Expand
- Earn reputation
- Participate in events
- Publish opportunities through Studio Exchange™
- Leave lasting impact

A professional economy becomes powerful when citizens can build institutions that outlive individual lessons.

---

## Studio Economy™

The Studio Economy™ revolves around contribution rather than consumption.

Citizens earn recognition by:

- Teaching
- Innovating
- Mentoring
- Creating
- Collaborating
- Researching
- Building

World value increases because citizens improve the world.

---

## Relationship to Existing Marketplace Canon

ARTICLE-E05 does not delete historical marketplace architecture.

It upgrades the customer-facing and civilization-level economy language:

| Existing system | E05 relationship |
|-----------------|-----------------|
| Studio Marketplace™ | Renamed/elevated to Studio Exchange™ for civic economy |
| Expert Marketplace™ | Becomes professional/expertise supply inside the Exchange |
| Headquarters Marketplace™ | Becomes built-environment offering inside the Exchange |
| Creator Economy™ | Evolves into contribution and professional reputation economy |
| Studio Professionals™ | Supply-side professional identities |
| Career Worlds™ | Demand-side world entry via Professional Licenses™ |
| Profession Brain™ | Intelligence included in each license |
| Studio Institute™ | Institutional learning layer, not course storefront |

Future implementation may retain legacy route names temporarily for compatibility, but product language should migrate toward **Studio Exchange™** and **Professional Licenses™**.
