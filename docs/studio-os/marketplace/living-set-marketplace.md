## Purpose

Define how **Living Sets™** are bought, sold, installed, and discovered in Studio Marketplace™.

The primary unit remains a **complete environment** — a department-scale production set with full Framework Lock™ zones intact.

---

## Core Law

```
BUY A LIVING SET™ — NOT A MOOD WALL TEXTURE
```

Marketplace encourages **complete worlds**.

---

## Marketplace Product Types

| Product | Scale | Example |
|---------|-------|---------|
| **Living Set™** | Single department | Creative Direction Studio™ — Luxury Editorial Atelier |
| **Department Pack™** | Department + adjacent support | CDS + Founder Review annex |
| **Creative Headquarters™** | Creative wing multi-set | CDS · Reference · Screening |
| **Production Floor™** | Manufacturing environment | Media production · culinary line |
| **Brand World™** | Full brand expression | Frontal Slayer-class campus slice |
| **Entire Headquarters™** | Complete HQ topology | Full installable campus |

Ascending scale — all use **Headquarters Package™** format.

## Living Set™ Listing Requirements

Every marketplace Living Set™ must include:

| Requirement | Source |
|-------------|--------|
| Framework Lock™ zones present | [Living Sets™](../world/living-sets.md) |
| Environment DNA™ complete | [environment-dna.md](../world/environment-dna.md) |
| Arrival Sequence™ | Foundational Experience Systems™ |
| Idle Life™ profile | Ambient behaviors |
| Orb placement manifest | Host anchor above Story Table™ |
| Production stations mapped | Pipeline · Review · Branch · Timeline |
| Transitions™ in/out | World Immersion™ compatible |
| Genome adaptation matrix | Works across purchaser Company Genome™ |

Rejected if: props-only · texture pack · missing framework zones.

## Installation Experience

```
Founder browses Living Set™
        ↓
Preview arrival (sandbox — short ceremony)
        ↓
Taste match score displayed
        ↓
One-click purchase (future commerce layer)
        ↓
Headquarters Package™ deploys to org
        ↓
Company Genome™ modulates expression
        ↓
Founder walks into new department — no GPU wait
```

Installation is **environment deployment** — not plugin activation.

Extends [Marketplace Set System™](../world/marketplace-set-system.md) installation model.

## Genome Adaptation on Install

Purchased Living Sets™ adapt to buyer — never hardcoded to creator's company:

| Layer | Adapts | Preserves |
|-------|--------|-----------|
| Company Genome™ | Materials · props · industry artifacts | Set architectural genre |
| Founder Taste Genome™ | Refinement weights | Creator's design intent |
| Framework zones | Placement only | Zone identity |
| Creator signature | Optional attribution plaque | Environmental design |

Same Luxury Editorial Atelier **genre** — buyer's brand **expression**.
