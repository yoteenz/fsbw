# Production Complexity™

**Module:** `studio.production-estimates.v1.complexity`  
**Status:** Scope tier classification

---

## Tiers

| Tier | Profile | Typical Scope |
|------|---------|---------------|
| **Low** | Reuse-dominant | ≥70% reuse · 0–1 new assets · systems inherited |
| **Medium** | Balanced production | Mixed reuse/modify · 2–4 new assets · 1 blueprint |
| **High** | Creative expansion | New variant · 5+ items · multi-layer deps |
| **Signature** | Landmark / golden | Signature Landmark™ · full stack · certification QA |

---

## Scoring Model (0–100)

| Signal | Weight |
|--------|--------|
| New assets generated | 25% |
| Assets modified | 15% |
| Systems net-new | 15% |
| Blueprint fork/variant | 15% |
| Layer count (Scene Stack) | 10% |
| Dependency depth | 10% |
| Golden Build tier | 10% |

| Score | Tier |
|-------|------|
| 0–25 | Low |
| 26–50 | Medium |
| 51–75 | High |
| 76–100 | Signature |

## CDS Story Table™ = Medium

| Factor | Contribution |
|--------|--------------|
| 8 assets reused | Lowers score |
| 3 modified · 2 new | Medium band |
| Editorial Luxury Blueprint™ inherited | Lowers score |
| 5 systems reused | Lowers score |
| Landmark layer (signature-landmark) | Raises score |

**Result: Medium** — balanced reuse with targeted new work.
