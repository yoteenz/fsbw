# Studio Production Estimates™

**Estimate Productions — Not Images**

**Version:** 1.0.0  
**Status:** Canonical production planning system (docs only)  
**Type:** Founder-facing production intelligence — not billing, not providers  
**Engine ID:** `studio.production-estimates.v1`  
**Tagline:** *Creative work has value. Studio OS estimates productions—not images.*

---

> **Studio OS should always feel like a production company planning a creative project. Not an AI image generator.**

---

## Mission

Founders should understand the **scope of a creative production** before it begins.

Instead of exposing image generation, GPU providers, or raw API pricing, Studio OS presents a **Production Estimate™** — the same way an architecture firm or film production studio quotes creative scope.

---

## One Sentence

**Studio Production Estimates™** calculates and presents **Estimated Production Cost™**, time, reuse breakdown, savings, and complexity — with Orb narration explaining **WHY** — before any production begins.

---

## What Every Estimate Includes

| Field | Meaning |
|-------|---------|
| **Estimated Production Cost™** | Abstract production dollar value (not API invoice) |
| **Estimated Production Time™** | Wall-clock creative production duration |
| **Assets Reused™** | Registry links · zero new generation |
| **Blueprints Reused™** | Creative Blueprints™ applied |
| **Systems Reused™** | Coordinated Systems™ inherited |
| **Assets Modified™** | Duplicate & Modify™ partial production |
| **New Assets Generated™** | Net-new creative units only |
| **Estimated Savings™** | Value preserved via reuse intelligence |
| **Production Complexity™** | Low · Medium · High · Signature |

---

## Example (CDS Story Table™)

```
Production Estimate™

Estimated Cost        $2.48
Estimated Time        2m 12s
Assets Reused         8
Assets Modified       3
Assets Generated      2
Estimated Savings     $4.86
Complexity            Medium
```

**Orb:** *"I found compatible Lighting and Material Blueprints. This reduced production cost by 63%. I only recommend generating two completely new assets."*
