# Savings Model™

**Module:** `studio.production-estimates.v1.savings`  
**Status:** Reuse value in production dollars

---

## Principle

> Estimated Savings™ proves Asset Intelligence and Blueprint inheritance have **production value** — without exposing how providers price calls.

---

## What Savings Measures

| Included | Excluded |
|----------|----------|
| Avoided new asset generation | Founder review time |
| Blueprint/system inheritance | Post-production edits |
| Registry exact reuse | Marketplace purchase price |
| Modify vs full generate delta | Platform subscription fees |

---

## Formula

```
Estimated Savings™ = Hypothetical Full Production Cost™ − Estimated Production Cost™

Savings % = Estimated Savings / Hypothetical Full Production Cost
```

Hypothetical = same scope with **zero** reuse intelligence (all generate new).

---

## Line-Item Savings

Each reuse/modify line shows `savingsVsGenerateUsd`:

```yaml
- label: Editorial Lighting System™
  action: reuse
  productionCostUsd: 0.08
  savingsVsGenerateUsd: 0.62

- label: Signature Landmark™ layer
  action: generate
  productionCostUsd: 0.85
  savingsVsGenerateUsd: 0
```
