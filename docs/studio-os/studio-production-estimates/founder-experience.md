# Founder Experience™

**Module:** `studio.production-estimates.v1.founder-experience`  
**Status:** Production planning UX contract (spec only)

---

## Experience Goal

Founder feels like reviewing a bid from:

- An **architecture firm** scoping an atelier renovation
- A **film production studio** planning a scene shoot

Not like configuring an AI image API.

---

## Estimate Placement

| Moment | Estimate appears |
|--------|------------------|
| Before first station generation | Full station stack |
| Before layer regen | Single layer unit |
| Before Golden Build stage | Stage manifest |
| Before department bootstrap | Department production plan |
| On scope revision | Delta estimate |

**Never after** production completes as first cost visibility.

---

## Approval Flow

```
Founder requests production
         ↓
Brief "Calculating Production Estimate™…" (1–2s)
         ↓
Production Estimate™ card + Orb narration
         ↓
Founder: Approve Production™ | Revise Scope™ | Cancel
         ↓
On Approve → Generation Manager™ queue (locked scope)
         ↓
Progress: "Producing… 1m 40s remaining" (time only)
         ↓
Complete: "Production complete — on estimate" (optional variance summary)
```

---

## Revise Scope™

Founder can:

| Action | Effect |
|--------|--------|
| Force more reuse | Re-run intelligence with stricter floor |
| Allow more new work | Loosen reuse · recalculate |
| Remove line items | Narrow scope |
| Pin blueprint variant | Recalculate systems |

Each revision → new estimate ID.
