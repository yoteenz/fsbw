# Milestone System™

**Permanent Moments in Company Memory™**

---

## Purpose

Define **Milestones™** — meaningful moments within Expeditions™ that become permanent records in Company Memory™ and The Founder's Story™.

---

## Core Law

Every Expedition™ contains **meaningful milestones**.

Milestones are not task checkboxes — they are **company history**.

---

## Milestone vs Task vs Routine Complete™

| Level | Meaning | Example |
|-------|---------|---------|
| **Task™** | Atomic action | Approve stage 3 |
| **Routine Complete™** | Operational leg done | Hire Employee™ done |
| **Milestone™** | Company history moment | First Employee™ |
| **Stage Complete™** | Expedition phase done | Brand stage complete |
| **Expedition Complete™** | Transformation done | Launch Company™ complete |

## Milestone Ceremony

When a Milestone™ is earned:

| Beat | Content |
|------|---------|
| 1. **Detection** | Engine confirms criteria |
| 2. **World State™** | Celebration · Launch Day™ if appropriate |
| 3. **Orb acknowledgment** | Specific · emotional · brief |
| 4. **Living Timeline™** | Permanent entry |
| 5. **HQ evolution** | Visual beat if applicable |
| 6. **Chronicle** | Founder Chronicle™ chapter marker |
| 7. **Archive** | Artifact preservation |

---

## Milestone Persistence

| Property | Stored |
|----------|--------|
| **Date · time** | Precise |
| **Expedition · stage** | Context |
| **Artifacts** | Screenshots · Golden Builds · notes |
| **Founder reflection** | Optional capture |
| **Team present** | Who shared the moment |
| **Metrics snapshot** | If applicable |

Milestones are **never deleted** — only annotated.

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Milestone = checkbox | Must be meaningful |
| Too many milestones | Dilutes weight |
| Silent milestones | Celebration required |
| Milestones without artifacts | Nothing to revisit |
| Reversible without annotation | History matters |
