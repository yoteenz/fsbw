# Routine vs Expedition™

**Two Categories of Work**

---

## Purpose

Define when work is a **Routine™** vs an **Expedition™** — and how they relate inside Studio World™.

---

## Core Law

| | Routine™ | Expedition™ |
|---|----------|-------------|
| **Verb** | Operate | Transform |
| **Question** | *"What needs doing today?"* | *"Where are we taking this company?"* |

---

## Comparison Matrix

| Dimension | Routine™ | Expedition™ |
|-----------|----------|-------------|
| **Duration** | Minutes · hours · days | Weeks · months |
| **Frequency** | Daily · weekly · monthly | Once · rarely · per major chapter |
| **Repeatability** | Highly repeatable | Unique · contextual |
| **Scope** | Single or few departments | Many departments · entire company |
| **Outcome** | Operational completion | Strategic transformation |
| **Progress model** | Steps · tasks | Stages · milestones |
| **Memory weight** | Patterns · shortcuts | Institutional story · legacy |
| **HQ impact** | Ambient · minor | Visual evolution · unlocks |
| **Orb tone** | Efficient · today-focused | Patient · roadmap-focused |
| **Celebration** | Routine Complete™ | Milestone™ · stage complete |

---

## Routine™ Examples

| Routine™ | Nature |
|----------|--------|
| Weekly Executive Review™ | Recurring executive rhythm |
| Launch Campaign™ | Repeatable go-to-market motion |
| Publish Content™ | Content operations |
| Approve Golden Build™ | Production gate (within project) |
| Hire Employee™ | Repeatable hiring flow |
| Performance Review™ | People operations |
| Monthly Planning™ | Planning cadence |
| Inventory Review™ | Operations check |

```
Routine™ → Repeatable → Operational → Short Duration → Frequent
```

## Expedition™ Examples

| Expedition™ | Nature |
|-------------|--------|
| Launch Company™ | Zero to operating company |

| Build New Headquarters™ | Physical HQ reinvention |
| International Expansion™ | Geographic transformation |
| Fundraising™ | Capital · investor journey |
| Product Line Expansion™ | New product category |
| AI Transformation™ | Operating model shift |
| Acquisition™ | M&A integration |
| Market Expansion™ | New market entry |
| Platform Migration™ | Technical transformation |

```
Expedition™ → Transformational → Strategic → Long Duration → Milestone Driven
```

---

## Decision Tree

```
Is this objective...
    │
    ├─ Repeatable on a schedule? ──────────────► Routine™
    │
    ├─ Completes in hours/days typically? ─────► Routine™ (or sub-routine of Expedition)
    │
    ├─ Fundamentally changes company trajectory? ► Expedition™
    │
    ├─ Spans months with major milestones? ──────► Expedition™
    │
    └─ Will be remembered as a company chapter? ─► Expedition™
```

---

## Relationship: Expedition Contains Routines

Expeditions **compose** routines — they do not replace them.

```
Expedition™: Launch Company™
    Stage: Brand
        └── Routine™: Create Brand™ (may run as routine)
    Stage: Hiring
        └── Routine™: Hire Employee™ (× N)
    Stage: Launch
        └── Routine™: Launch Product™
```

| Layer | Role |
|-------|------|
| **Expedition™** | Strategic arc · stages · milestones |
| **Routine™** | Operational legs within stages |
| **Scene Architecture™** | Physical places where legs happen |

---

## Orb Routing

When founder expresses intent:

| Founder says | Orb classifies |
|--------------|----------------|
| "Hire someone" | Routine™: Hire Employee™ |
| "Launch the company" | Expedition™: Launch Company™ |
| "Weekly review" | Routine™: Weekly Executive Review™ |
| "We're rebranding everything" | Expedition™: Complete Rebrand™ |
| "Run this campaign" | Routine™: Launch Campaign™ |
| "Expand to Europe" | Expedition™: International Expansion™ |

Orb may suggest upgrading a routine to expedition stage when scope reveals transformation.

---

## Explorer Mode™

Both categories respect [Explorer Mode™](../routines/explorer-vs-routine.md):

- Expeditions can be paused · explored · resumed
- Routines can run inside or outside expeditions
- Same headquarters · different orchestration depth

---

## Memory Separation

| Memory store | Primary content |
|--------------|-----------------|
| **Routine Memory™** | Habits · shortcuts · bottlenecks |
| **Expedition Memory™** | Strategies · milestones · story |

Both feed Company Memory™ — different retrieval patterns.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Every task is an expedition | Dilutes meaning |
| Launch Company as 50 routines only | Loses narrative · milestones |
| Expedition with no routines inside | No operational legs |
| Same UI for both | Orb · map · ceremony must differ |
