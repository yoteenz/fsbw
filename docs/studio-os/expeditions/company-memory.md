# Company Memory™ (Expeditions)

**Expedition Memory™ and The Founder's Story™**

---

## Purpose

Define how Expeditions™ become **institutional knowledge** and the **living autobiography** of a company.

---

## Core Law

Every completed Expedition™ becomes institutional knowledge.

Years later, the founder revisits the journey — Studio OS remembers.

---

## Memory Layers

```
Expedition Memory™
    ├── Living Timeline™      (event stream)
    ├── Milestone Registry™   (permanent moments)
    ├── Decision Archive™     (strategic choices)
    ├── Artifact Vault™       (Golden Builds · versions)
    ├── Lessons Learned™      (synthesized wisdom)
    └── Founder's Story™      (narrative autobiography)
```

---

## What Expedition Memory™ Learns

| Learning | Used for |
|----------|----------|
| **Decision patterns** | Future expedition suggestions |
| **Preferred sequences** | Stage ordering adaptation |
| **Typical bottlenecks** | Proactive Orb warnings |
| **Successful strategies** | Playbook inheritance |
| **Creative evolution** | Version lineage |
| **Founder behavior** | Pace · ceremony preferences |
| **Duration actuals** | Honest estimates next time |

Future Expeditions become increasingly intelligent — parallel to [Routine Memory™](../routines/routine-memory.md) at strategic scale.

## The Founder's Story™

Narrative mode over raw timeline:

| Chapter | Source expedition |
|---------|-------------------|
| "The day we started" | Launch Company™ |
| "Our first headquarters" | Build New Headquarters™ |
| "The rebrand that changed everything" | Complete Rebrand™ |
| "Going global" | International Expansion™ |
| "Our first acquisition" | Acquisition™ |

Orb can **replay** chapters:

> *"Here's the Mood Wall from launch week — your note said 'editorial luxury, never loud.'"*

## Lessons Learned™

Captured at stage and expedition completion:

| Prompt | Example lesson |
|--------|----------------|
| What worked? | "Braintrust before founder review saved two weeks" |
| What stalled? | "Legal stage waited on external counsel" |
| What surprised? | "Brand stage took half expected time" |
| What would you tell past self? | "Lock vision before creative" |

Lessons feed [Studio Advisors™](../ecosystem/advisors.md) playbooks · Guild knowledge libraries.

## Privacy & Ownership

| Rule | Law |
|------|-----|
| Memory belongs to company | Founder accesses · team may share |
| Sensitive stages | Fundraising · M&A — access controls future |
| Export for board · investors | Chronicle summaries |
| Never sell memory | Not data product |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Expedition completes without memory write | Story lost |
| Timeline editable without audit | History integrity |
| No revisit path | Memory unused |
| Lessons optional always | Wisdom compounds when captured |
