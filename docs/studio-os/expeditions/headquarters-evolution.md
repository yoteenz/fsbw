# Headquarters Evolution™ (Expeditions)

**The Headquarters Responds During Expeditions**

---

## Purpose

Define how **Headquarters™** visually and architecturally **evolves** during Expeditions™ — the company physically grows around the founder.

**Complements:** [Headquarters Evolution™ — world scale](../world/headquarters-evolution.md)

---

## Core Law

**The Headquarters should visually evolve during Expeditions.**

Walls update. Displays change. Celebrations appear. Awards are displayed. New departments unlock.

---

## Expedition vs World HQ Evolution

| System | Scope | Trigger |
|--------|-------|---------|
| **[World Headquarters Evolution™](../world/headquarters-evolution.md)** | Campus · skyline · lifetime | Company lifecycle |
| **Expedition HQ Evolution™** | Active transformation beats | Expedition stages · milestones |

Expedition evolution is **dramatic and narrated**. World evolution is **continuous and cumulative**.

---

## Evolution Triggers

| Trigger | HQ response |
|---------|-------------|
| **Stage complete** | Wing lighting · corridor signage |
| **Milestone™** | Plaque · display · celebration props |
| **Golden Build™ / Golden Brand™** | Hero exhibit in department |
| **Go Live™** | Launch banners · energy shift |
| **First Employee™** | Hiring wing unlocks · desk appears |
| **International Expansion™** | Globe display · new timezone clocks |
| **Fundraising close** | Investor wall · milestone case |
| **Acquisition complete** | Integration corridor · dual branding period |
| **Expedition Complete™** | Permanent memorial · skyline change |

## Department Unlocks

Expeditions may **unlock new departments** in headquarters:

```
Pre-expedition HQ: Creative · Intelligence · Operations
        ↓
Launch Company™ progresses
        ↓
Post-expedition HQ: + Marketing · Distribution · Analytics · Hiring · Finance
```

Unlock is **physical** — door opens · light spills · Orb introduces wing.

---

## Celebrations & Awards

| Celebration type | Expression |
|----------------|------------|
| **Milestone™** | Confetti particle · audio swell · Orb line |
| **Stage complete** | Corridor procession · gallery update |
| **Expedition complete** | Skyline event · Hall of Legacy™ entry |
| **World State™** | Launch Day™ · Celebration™ cascade |

Celebrations respect `prefers-reduced-motion` — dignity preserved.

---

## Living Displays

HQ surfaces update from expedition state:

| Display | Content |
|---------|---------|
| **Lobby screen** | Expedition Map™ progress |
| **Corridor frames** | Latest Golden Builds™ |
| **Mission wall** | Vision · values · live |
| **Milestone gallery** | Earned plaques |
| **Timeline scroll** | Living Timeline™ excerpt |

Displays update via [Idle Life™](../foundational-experience-systems/idle-life.md) — never static during active expedition.

---

## Reversion Law

| Rule | Law |
|------|-----|
| **No silent revert** | HQ growth is permanent |
| **Rebrand replaces** | Prior preserved in Archive™ |
| **Failed expedition** | Progress kept · status annotated |
| **Living Set™ expression** | Company Genome™ drives look · structure persists |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Static HQ during 6-month expedition | World feels dead |
| Unlock without physical beat | No discovery |
| Celebration only in modal | Diegetic required |
| HQ change without timeline entry | Memory gap |
