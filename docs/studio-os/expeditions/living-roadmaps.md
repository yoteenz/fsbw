# Living Roadmaps™

**Expedition Map™ and Living Timeline™**

---

## Purpose

Define the **living roadmap** experience for Expeditions™ — Expedition Map™ (forward view) and Living Timeline™ (persistent history).

---

## Core Law

Every Expedition™ should feel like a **living roadmap**.

The founder always understands **where they are** and **what comes next**.

---

## Expedition Map™

The forward-looking strategic view:

```
┌─────────────────────────────────────────────────────────────┐
│  LAUNCH COMPANY™                              Week 8 of ~24 │
├─────────────────────────────────────────────────────────────┤
│  ✓ Vision    ✓ Brand    ● Creative    ○ Legal    ○ Finance │
│  ○ Website   ○ Marketing   ○ Launch    ○ Growth              │
├─────────────────────────────────────────────────────────────┤
│  CURRENT: Creative Stage™                                   │
│  NEXT: Legal Stage™ (unlocks when Golden Build™ approved)   │
└─────────────────────────────────────────────────────────────┘
```

**Diegetic expression:** Map lives in headquarters — corridor display · Orb projection · strategy room wall — not a SaaS progress widget.

---

## Map Properties

| Property | Description |
|----------|-------------|
| **Stages** | Ordered transformation phases |
| **Current stage** | Highlighted · expanded |
| **Completed stages** | Visually earned · not hidden |
| **Locked stages** | Visible · requirement hinted |
| **Branch paths** | Optional stages (e.g. Fundraising branch) |
| **Time context** | Elapsed · estimated remaining — honest not punitive |
| **Department preview** | Which wings each stage visits |

---

## Canonical Map: Launch Company™

| Stage | Primary departments | Unlock signal |
|-------|---------------------|---------------|
| **Vision** | Intelligence™ · Creative Direction™ | Mission · north star locked |
| **Brand** | Brand™ | Golden Brand™ |
| **Creative** | Creative Direction Studio™ | Golden Build™ |
| **Legal** | Legal™ (future) | Entity · terms complete |
| **Finance** | Finance™ | Structure · accounts ready |
| **Website** | Digital Architect™ | Experience live |
| **Marketing** | Marketing™ · Brand™ | Campaign ready |
| **Launch** | Distribution™ | Go Live™ routine complete |
| **Growth** | Analytics™ · Growth Architect™ | First metrics baseline |

Stages unlock **naturally** — founder never surprised by locked content without explanation.

---

## Living Timeline™

The backward-looking persistent history:

| Entry type | Content |
|------------|---------|
| **Milestone™** | First Customer™ · First Sale™ · … |
| **Decision** | Strategic choice · rationale · who |
| **Version** | Brand v2 · HQ renovation · genome snapshot |
| **Golden Build™** | Certified artifact reference |
| **Founder Note™** | In-context reflection |
| **Lesson Learned™** | Post-stage synthesis |
| **Celebration™** | Earned beat · World State™ |
| **Routine Complete™** | Operational leg within stage |
| **Photo / artifact** | Chronicle media |

Nothing is forgotten.

---

## Timeline Behavior

| Behavior | Law |
|----------|-----|
| **Append-only** | History not rewritten |
| **Searchable** | Orb · Founder's Story™ retrieval |
| **Replayable** | Revisit milestone moments |
| **Shareable** | Chronicle export · board · legacy |
| **Branch preserved** | Alternate paths recorded not deleted |

---

## Map ↔ Timeline Relationship

```
Expedition Map™     =  WHERE WE'RE GOING  (future)
Living Timeline™    =  WHERE WE'VE BEEN    (past)
Current stage       =  NOW                 (present)
```

Orb narrates all three tenses:

> *"We completed Brand last Tuesday. Creative is active. Legal opens when Golden Build™ certifies."*

---

## Map Evolution During Expedition

The map itself may evolve:

| Event | Map change |
|-------|------------|
| **Scope discovery** | New stage inserted · Orb explains |
| **Branch taken** | Fundraising path appears |
| **Stage merged** | Intelligent shortcut · timeline notes |
| **Expedition extended** | International stage added |

Changes are **chronicled** — not silent edits.

---

## Revisit Mode

Completed expeditions remain on map as **legendary paths**:

- Gray-gold completed stages
- Milestone markers glow
- Orb offers story replay
- HQ exhibits expedition artifacts

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Gantt chart UI | Project management not roadmap |
| Hidden future stages | Founder needs orientation |
| Timeline as delete-able log | Memory is permanent |
| Map disconnected from HQ | Must be diegetic |
| No "what's next" | Anxiety breaks trust |
