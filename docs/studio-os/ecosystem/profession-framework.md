# Profession Framework™

**How Studio Professional™ disciplines are defined**

**Version:** 1.0.0  
**Status:** Canonical framework (docs only)  
**Parent:** [Studio Professionals™](./README.md)

---

## Purpose

Define the **structural model** for every Studio Professional™ discipline — purpose · scope · outputs · certification · collaboration boundaries.

---

## Discipline Schema

Every recognized profession includes:

| Component | Description |
|-----------|-------------|
| **Purpose** | Why this profession exists |
| **Primary focus** | Core craft domain |
| **Specializations** | Sub-disciplines within profession |
| **Outputs** | What professionals produce |
| **Marketplace products** | Publishable artifacts |
| **Certification** | Studio Certified™ path |
| **Professional Level™** | Career progression ladder |
| **Collaboration edges** | Professional Graph™ relationships |
| **Founder interface** | How founders engage this profession |

---

## Founder vs Studio Professional™

| Dimension | Founder™ | Studio Professional™ |
|-----------|----------|------------------------|
| **Role** | Company owner · inhabitant | Specialist · contributor |
| **Authority** | Final decisions | Expert recommendation |
| **Primary home** | Headquarters | Profession craft + portfolio |
| **Progression** | Company maturity | Professional Level™ |
| **Certification** | N/A (founder is role) | Per-discipline Certified™ |

Founders may **also** hold professional credentials (e.g. certified architect who runs a company) — dual identity allowed.

## Profession Boundaries

| Rule | Law |
|------|-----|
| **One primary profession** | Profile declares primary discipline |
| **Secondary skills** | Specialties list — not profession hopping |
| **Output ownership** | Clear artifact type per profession |
| **No profession overlap without collaboration** | Brand Designer + Architect collaborate — not merge |
| **Certification per profession** | Separate paths |

---

## Professional Level™ (Universal)

Shared progression language across professions:

| Level | Character |
|-------|-----------|
| **Emerging** | First published work |
| **Professional** | Consistent quality · growing reputation |
| **Master** | Recognized body of work |
| **Studio Certified™** | Platform-verified excellence |
| **Legendary** | Cultural impact · mentorship legacy |

Per-profession thresholds differ — levels share **names and philosophy**.

**Detail:** [career-progression.md](./career-progression.md)

## Engagement Models

How founders work with professionals:

| Model | Description |
|-------|-------------|
| **Follow** | Subscribe to professional updates |
| **Purchase** | Marketplace install of published work |
| **Commission** | Custom scoped engagement |
| **Collaborate** | Multi-professional team on one company |
| **Hire** | Ongoing retainer (Operators · Advisors) |
| **Learn** | Courses · playbooks (Advisors) |

---

## Quality Contract

Every profession commits to:

1. **Founder success** — work improves company outcomes
2. **Studio World™ integrity** — places and systems integrate correctly
3. **Certification honesty** — earn · don't buy prestige
4. **Collaboration** — Professional Graph™ over silos
5. **Long-term impact** — reputation over volume

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| One "generic creator" profession | Loses discipline clarity |
| Profession without certification path | No quality gate |
| Seller-only identity | Not a career |
| Profession competes with Founder authority | Founders decide |
