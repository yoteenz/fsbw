# Certification Framework™

**Per-profession excellence — genuine not generic**

**Version:** 1.0.0  
**Status:** Canonical certification architecture (docs only)  
**Parent:** [Studio Professionals™](./README.md)

---

## Purpose

Every Studio Professional™ discipline has its own **certification path**.

Certifications represent **genuine excellence** — not participation badges.

---

## Certification Types

| Certification | Profession |
|---------------|------------|
| **Studio Certified Architect™** | Studio Architects™ |
| **Studio Certified Brand Designer™** | Studio Brand Designers™ |
| **Studio Certified Director™** | Studio Directors™ |
| **Studio Certified Operator™** | Studio Operators™ |
| **Studio Certified Advisor™** | Studio Advisors™ |
| **Studio Certified [Future]™** | Future Professions™ |

Professionals may hold **multiple certifications** — each earned independently.

---

## Universal Principles

| Principle | Law |
|-----------|-----|
| **Selective** | Majority never certified |
| **Earned** | Never purchased |
| **Maintained** | Decertification possible |
| **Walkthrough-verified** | Human review for excellence |
| **Founder-outcome-weighted** | Success matters |
| **Profession-specific** | Dimensions match craft |

## Certification Path

```
Emerging professional
        ↓
Publish work (Private™ → Community™)
        ↓
Submit For Review™
        ↓
Profession-specific review gate
        ↓
Studio Certified [Profession]™
        ↓
Featured / Legendary eligibility
```

Aligns with [Studio Certified™](../marketplace/studio-certified.md) marketplace tier.

## Multi-Profession Teams

Team certifications:

| Pattern | Rule |
|---------|------|
| Certified team badge | All leads certified in their profession |
| Collaborative certification | Joint walkthrough for integrated deliverables |
| Attribution | Each profession certified independently |

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| One generic certification | Ignores craft differences |
| Pay-to-certify | Destroys trust |
| Auto-certify on publish | No excellence gate |
| Certification without founder outcomes | Vanity metric |
