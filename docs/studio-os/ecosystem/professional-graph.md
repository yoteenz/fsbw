# Professional Graph™

**The collaborative ecosystem inside Studio World™**

**Version:** 1.0.0  
**Status:** Canonical relationship architecture (docs only)  
**Parent:** [Studio Professionals™](./README.md)

---

## Purpose

Studio OS should understand **relationships** between founders and Studio Professionals™ — and among professionals themselves.

The Professional Graph™ makes Studio OS a **collaborative ecosystem** — not isolated seller profiles.

## Canonical Collaboration Patterns

### Founders follow Architects

```
Founder™ ──follows──► Studio Architect™
        ◄──notifies── new HQ · collections · Certified™
```

Founders discover **places** through **people**.

---

### Architects collaborate with Brand Designers

```
Studio Architect™ ◄──collaborates──► Studio Brand Designer™
                              │
                         Company rebrand
                              │
                    Environment DNA™ + Company Genome™
```

Identity and place must **co-evolve**.

---

### Operators hire Advisors

```
Studio Operator™ ──hires──► Studio Advisor™
                    │
              Playbook implementation
                    │
              Founder operations improve
```

Performance needs **wisdom**.

---

### Directors work with Architects

```
Studio Director™ ──works-with──► Studio Architect™
                        │
              Production stations in physical space
                        │
              Pipeline meets furniture
```

Systems must exist **somewhere**.

---

### Professionals build teams

```
Founder commissions full company transformation
        │
        ├── Studio Architect™ (HQ)
        ├── Studio Brand Designer™ (Genome)
        ├── Studio Director™ (Pipeline)
        ├── Studio Operator™ (Launch ops)
        └── Studio Advisor™ (Founder coaching)
```

**Team graph** — single project node linking all professionals.
