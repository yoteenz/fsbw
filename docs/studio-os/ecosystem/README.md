# Studio Professionals™

**The Careers Inside Studio World™**

**Version:** 1.0.0  
**Status:** Canonical professional ecosystem architecture (docs only)  
**Phase:** Platform ecosystem (post-Studio Architects™)  
**Scope:** All professional disciplines inside Studio OS

---

> **Studio OS is not creating users. Studio OS is creating a new generation of professionals.**

---

## Mission

Studio OS should become more than software.

Studio OS should become an **ecosystem where people build careers**.

Not everyone inside Studio World™ is a founder.

Some people **design**. Some **strategize**. Some **automate**. Some **operate**. Some **teach**. Some **review**. Some **innovate**.

Studio OS should recognize these as **distinct professional disciplines**.

---

## One Sentence

**Studio Professionals™** are the recognized digital careers inside Studio World™ — each contributing expertise that helps founders build better companies through places · identity · production · performance · and wisdom.

---

## Foundational Philosophy

Studio OS is creating an entirely new category of **digital professionals**.

| Wrong framing | Right framing |
|---------------|---------------|
| Marketplace sellers | **Studio Professionals™** |
| Users | **Career builders** |
| Gig workers | **Recognized disciplines** |
| Plugin authors | **Company Engine™ contributors** |

Every professional contributes to helping founders build **better companies**.

Founders are **not** Studio Professionals™ — they are the **reason** the ecosystem exists.

| Focus | Examples |

| **Leadership** | Decision authority |
