## Purpose

## Core Law

```
THE ECOSYSTEM EXPANDS — IT DOES NOT FRAGMENT INTO GENERIC CREATORS
```

Every new profession must have: purpose · outputs · certification · collaboration edges.

## Extension Process (Spec)

```
1. PROPOSE profession
   Purpose · gap · founder need

2. DEFINE discipline schema
   Outputs · marketplace products · certification dimensions

3. MAP Professional Graph™ edges
   Who collaborates with whom

4. PILOT with founders
   Quality · outcome evidence

5. CANONIZE
   Add to profession registry · certification path

6. MARKETPLACE ENABLE
   Product types · browse category
```

## Relationship to Launch Professions

Launch five professions are **foundational** — not exhaustive:

```
Studio Architects™      — WHERE (place)
Studio Brand Designers™ — WHO (identity)
Studio Directors™       — HOW (production)
Studio Operators™       — PERFORMANCE (operations)
Studio Advisors™        — WISDOM (teaching)
```

Future professions fill **gaps** without overlapping core five.

---

## Anti-Patterns

| Anti-pattern | Violation |
|--------------|-----------|
| Unlimited micro-professions | Fragmentation |
| Profession without certification | Quality collapse |
| Generic "creator" absorbs all | Loses discipline clarity |
| Profession without marketplace outputs | No career path |

Studio OS becomes the **platform where those careers are first recognized**.
