# Canon Preservation Policy

**Section 21** — permanent Studio OS policy  
**Canonical source:** `StudioOS_StudioDNACapsule_v1.0/CANON_PRESERVATION_POLICY.md`  
**Registry:** `StudioOS_StudioDNACapsule_v1.0/CANON_REGISTRY.md`

---

## Summary

**New ideas do not automatically become canon.**

A concept becomes canonical only after:

1. **Explicit founder approval**, or  
2. **Repeated adoption** into the documented operational model  

Each canonical concept is recorded in **CANON_REGISTRY** with:

- Date introduced  
- Approval status  
- Source conversation or decision reference  
- Current maturity (Concept · Planned · In Progress · Implemented · Deprecated)  
- Related systems  
- Dependencies  

---

## Agent rule

Before implementing from any vision doc or sprint spec, verify **maturity** in the canon registry. Label replies as **Documented**, **Inferred**, or **Unknown**.
