# Studio DNA Capsule™

**Section 20** — preserves **HOW Studio OS thinks**.  
Companion to **AI Context Capsule™** (WHAT Studio OS knows).

---

## Purpose

Source code captures implementation. It does **not** capture:

- Founder design philosophy and taste  
- Architectural judgment under uncertainty  
- Creative direction instincts  
- Communication and sprint preferences  
- Canon rules and maturity  

The **Studio DNA Capsule** encodes that judgment for AI collaborators and long-term institutional continuity.
