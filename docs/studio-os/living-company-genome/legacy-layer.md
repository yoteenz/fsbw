# Legacy Layer™ — Architecture Becomes Storytelling

**Module:** `studio.living-company-genome.v1.legacy-layer`  
**Status:** Founders experience memories in space

---

## Principle

> Years later, a founder walks through headquarters and experiences memories — not decoration.

---

## Legacy Anchors™

Narrative bindings between **Genome Events™** and **physical locations**:

```yaml
LegacyAnchor:
  anchorId: string
  eventId: string
  quote: string
  location:
    type: landmark | wing | department | station | exhibit
    ref: string
  mediaRefs: string[]
  orbNarration: string
  discoverable: walk-by | guided | museum-only
```

**Examples:**

- *"This was our first logo."* → Founder Hall™
- *"This was our first campaign."* → Launch Gallery™
- *"This was the room where Version 1 was born."* → CDS Story Table™ station
- *"This was the launch that changed everything."* → Launch milestone exhibit

## Environmental Storytelling

Architecture carries history without SaaS dashboards:

| Element | Story function |
|---------|----------------|
| Plaques | Date · event · quote |
| Exhibits | Campaign artifacts · product stills |
| Timeline walls | Evolution Timeline™ embedded in stone/glass |
| Landmark evolution | Visual "growth rings" on Signature Landmarks™ |
| Audio ghosts | Optional ambient replay of launch day (reduced-motion safe) |
