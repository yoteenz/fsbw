# Company Genome™ Integration — Aesthetic Memory

**Module:** `studio.creative-blueprint.v1.genome`  
**Status:** Blueprints become part of Company Genome™

---

## Mission

Blueprints should become part of **Company Genome™**.

Studio OS learns founder aesthetic **before** generation begins.

---

## Genome Slots (Creative)

Creative Blueprint Engine extends genome with design-language slots:

```yaml
CompanyGenomeCreative:
  visualDnaId: visual-dna:editorial-luxury
  primaryBlueprintId: blueprint:editorial-luxury-v1
  aestheticMemory:
    preferredMaterials: [bronze, dark-marble, smoked-glass]
    favoriteLighting: editorial-volumetric-warm
    favoriteArchitecture: double-height-atelier
    favoriteProportions: generous-ceiling · wide-threshold
    preferredTransitions: gallery-walk · slow-arrival
    preferredAtmosphere: soft-haze · low-particle
    preferredLayouts: hero-landmark-center · orbital-flow
    preferredInteractionStyles: orb-hosted · hotspot-minimal
  learnedFrom:
    - founder-taste-engine
    - blueprint-evolution-history
    - asset-intelligence-reuse-patterns
```

## Genome Consultation Gate

Before blueprint resolution:

```
consultCompanyGenome(orgId)
    ↓
Merge aestheticMemory with Mode™ · Industry · Visual DNA™
    ↓
Rank blueprint candidates
    ↓
Default Apply Existing™ when genome + blueprint align
```

Aligns with Organization Genome™ `consultOrganizationGenome()` pattern.

Studio OS learns and applies:

| Dimension | Genome Key |
|-----------|------------|

| Favorite architecture | `favoriteArchitecture` |
| Favorite proportions | `favoriteProportions` |
| Preferred transitions | `preferredTransitions` |
| Preferred atmosphere | `preferredAtmosphere` |
| Preferred layouts | `preferredLayouts` |
| Preferred interaction styles | `preferredInteractionStyles` |

Used by:

- Creative Blueprint Engine (blueprint ranking)
- Asset Intelligence (compatibility weighting)
- Department Generator™ (manifest defaults)

## Genome ↔ Blueprint Sync

| Event | Genome Update |
|-------|---------------|
| Blueprint activated | Set `primaryBlueprintId` |
| System evolved | Update aestheticMemory |
| Visual DNA™ chapter | Bump `visualDnaId` · archive prior |
| Marketplace blueprint licensed | Merge template memory |

Bi-directional: genome informs blueprint · blueprint strengthens genome.

## Relationship to Organization Genome™

| Genome | Scope |
|--------|-------|
| **Organization Genome™** | Who the org is — voice · values · leadership |
| **Company Genome™ (creative)** | How the org **looks and feels** |

Both consulted before AI generates customer-facing or immersive work.
