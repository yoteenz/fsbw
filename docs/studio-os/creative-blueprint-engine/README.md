# Creative Blueprint Engine™

**The Company's Visual DNA**

**Version:** 1.0.0  
**Status:** Canonical design intelligence (docs only)  
**Type:** Core Studio OS Intelligence — sits above Asset Registry™  
**Engine ID:** `studio.creative-blueprint.v1`  
**Tagline:** *The Company's Visual DNA*

---

> **Assets create rooms. Blueprints create worlds.**

---

## Mission

**Asset Registry™** remembers individual assets.

Companies are not visually consistent because they reuse individual assets. They are consistent because they reuse **entire design systems**.

Studio OS should think like an **Architecture Firm** — not an image generator.

---

## One Sentence

**Creative Blueprint Engine™** is the design intelligence layer that defines **Visual DNA™**, orchestrates **Creative Blueprints™** and coordinated **Systems™**, and ensures every department inherits a cohesive architectural language before a single asset is generated.

---

## Foundational Philosophy

| Concept | Definition |
|---------|------------|
| **Asset** | An object — chair, light rig, marble slab |
| **Blueprint™** | A complete design language — materials · lighting · motion · audio travel together |
| **Visual DNA™** | The company's recognizable aesthetic identity |

> An asset is an object. A Blueprint™ is a complete design language.

Blueprints become reusable across every department, headquarters, scene, and future company.

---

## Hierarchy (Mandatory)

```
Company
    ↓
Visual DNA™
    ↓
Creative Blueprints™
    ↓
Systems™
    ↓
Assets™
    ↓
Runtime
```

Every layer inherits from the one above it.

---

## Engine Position

```
Founder · Department · Scene request
         ↓
CREATIVE BLUEPRINT ENGINE™ (this system)
  Visual DNA™ · Blueprint selection · Systems bundle
         ↓
Asset Intelligence Engine™ (search blueprint-aligned assets)
         ↓
Asset Registry™ (individual assets)
         ↓
Generation Manager™ (only when blueprint + intelligence require)
         ↓
Runtime (assembled world)
```

**Creative Blueprint Engine™** = design language (what world should feel like).  
**Asset Intelligence Engine™** = asset memory (what objects already exist).  
**Asset Registry™** = object library.
