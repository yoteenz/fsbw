## Prime rule

Creative Direction Studio™ should not generate videos.

Creative Direction Studio™ should generate experiences.

Every meaningful creative output begins as a **Narrative Experience™** before it
becomes a video, campaign, page, email, shoot, package, ad, or social asset.

---

## What Narrative Intelligence™ owns

Narrative Intelligence™ owns:

- Narrative Genome™
- Production Genome™
- Experience Arc™
- Moment Map™
- Proof System™
- Emotional Journey™
- Storyworld Graph™
- Production Brief™
- Narrative / production canonization path

It does **not** own media generation.

---

## Permanent hierarchy

```text
Narrative Intelligence™
  -> Narrative Genome™
    -> Production Genome™
      -> Experience Arc™
        -> Moment Map™
          -> Proof System™
            -> Emotional Journey™
              -> Production Brief™
                -> Runtime / Production Execution™
```

---

## Experience Arc™

Default experiential sequence:

1. Arrival
2. Recognition
3. Tension
4. Desire
5. Proof
6. Transformation
7. Invitation
8. Memory

This is not a story template. It is an experience-design structure.

---

## Production Genome™

Production Genome™ is reusable execution DNA.

It defines:

- production intent
- moment requirements
- proof captures
- product/founder/customer roles
- environment requirements
- sensory direction
- motion/camera/edit rhythm
- copy posture
- channel adaptations
- quality gates
- anti-patterns

One Production Genome™ can generate many outputs without changing the narrative
truth.

---

## Governance

1. Content is an output container; narrative is the source object.
2. Production begins only after a Narrative Experience™ is resolved.
3. Every Narrative Experience™ must define arc, moments, proof, emotion, and
   production brief.
4. Rejected stories and anti-stories are valuable memory.
5. Founder approval is required before narrative canonization.
