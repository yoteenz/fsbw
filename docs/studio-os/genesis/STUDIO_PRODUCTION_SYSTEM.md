## Prime rule

Creative Direction Studio™ is not a content generator.

Creative Direction Studio™ is an AI production company.

Every approved Narrative Blueprint™ becomes a managed **Production Package™**
that moves through production departments before assets are generated, reviewed,
distributed, and measured.

---

## Permanent flow

```text
CREATE CONTENT
  -> Topic
  -> Brand DNA™
  -> Audience DNA™
  -> Narrative Intelligence™
  -> Approved Narrative Blueprint™
  -> Production Genome™
  -> Assign Production Departments™
  -> Generate / assemble approved assets
  -> Quality Review™
  -> Distribution Intelligence™
  -> Performance Analytics™
```

No downstream asset should be created until a Narrative Blueprint™ has been
approved and a Production Package™ has been assembled.

## Production Package™

The canonical production object stores:

- approved Narrative Blueprint™ reference
- Production Genome™ reference
- production type
- production departments
- AI specialists
- casting plan
- production design plan
- camera plan
- sound plan
- post-production plan
- distribution plan
- approval gates
- quality gates
- generated asset manifest
- publishing manifest
- performance learning

## Department contract

Every Production Department™ owns:

- Responsibilities
- Inputs
- Outputs
- Approval Gates
- AI Specialists
- Knowledge Sources
- Success Metrics
- Escalation Rules

This makes the studio pipeline explainable, auditable, and reusable.

## Governance

1. Approved Narrative Blueprint™ required before production.
2. Production Package™ required before department execution.
3. Department gates required before downstream handoff.
4. QC pass required before distribution.
5. Founder approval required before publishing unless a governed automation policy
   explicitly allows otherwise.
6. Performance learning may propose Production Genome™ updates, but Canon Engine™
   review and founder approval are required.
