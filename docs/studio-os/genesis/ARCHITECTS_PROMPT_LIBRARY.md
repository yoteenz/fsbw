## Purpose

The Architect's Prompt Library™ is Studio OS's permanent knowledge repository for architecture prompts, implementation prompts, validation prompts, research prompts, design prompts, and future AI workflows.

It is not a folder of prompts.

It is an institutional knowledge system where every approved prompt becomes:

- searchable
- versioned
- canonical
- connected
- discoverable
- expandable
- reviewable
- reusable

---

## Experience

The Library lives inside the **Institute of Knowledge™** and should feel like entering Headquarters' architectural library.

The environment communicates:

- precision
- permanence
- craftsmanship
- institutional memory

Orb acts as **Library Curator** — recommending prompts, explaining relationships, identifying missing coverage, surfacing stale/conflicting prompts, and recommending model choice.

## Prompt lifecycle

```text
Draft
  -> Review
  -> Execution
  -> Output Review
  -> Founder Approval
  -> Genesis References Updated
  -> Canonized
  -> Archived
```

Every stage must be tracked.

## Quality and model intelligence

Every prompt receives quality scores:

- Architectural Quality
- Implementation Quality
- Output Consistency
- Reusability
- Platform Value
- Business Value
- Founder Value
- Knowledge Value

The Library also tracks model performance by category:

- speed
- consistency
- architecture
- implementation
- reasoning
- creative direction
- technical accuracy
- long-form output
- prompt success rate

Model recommendations must be evidence-backed by execution history.
