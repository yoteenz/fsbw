# Build Report Schema — Studio Generation Manager™

**Schema ID:** `studio.generation-manager.v1/build-report`  
**Output file:** `generation-build-report.md` (alongside Compiler `build-report.md`)

---

## Purpose

When a generation job completes, Manager produces a **Generation Build Report** — human-readable production record complementing Compiler pre-cook report.

Compiler report = *what to generate*. Manager report = *what was generated*.

---

## Required Sections

1. **Generation Summary**
2. **Assets Generated**
3. **Assets Reused**
4. **Assets Adapted**
5. **Assets Failed**
6. **Assets Retried**
7. **Validation Results**
8. **Registry Updates**
9. **Estimated Runtime Cost**
10. **Suggestions**
11. **Future Improvements**

---

## Relationship to Compiler Build Report

| Report | When | Focus |
|--------|------|-------|
| `build-report.md` (Compiler) | Package seal · pre-cook | Prompts · reuse opportunities · est. time |
| `generation-build-report.md` (Manager) | Job complete · post-cook | Actual provider results · cost · registry |

Both ship in cooked package root. Production dashboard shows both.
