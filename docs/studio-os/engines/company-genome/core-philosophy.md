# Core Philosophy™

**Engine Module:** `studio.company-genome.v2.philosophy`  
**Status:** Foundational beliefs

---

## The Problem

Traditional software treats company identity as **configuration**:

- Fill out brand forms
- Upload a style guide
- Pick colors from a palette
- Re-explain preferences every project

Studio OS rejects this model.

---

## The Principle

> **Every decision a founder makes should teach Studio OS something about that company.**

Identity is **observed** from behavior — not declared in onboarding forms alone.

---

| Category | Genome learns |

| Aesthetic | Visual DNA™ |

| Standards | Operational DNA™ · quality |

**Nobody asks the founder to repeat information already in the Genome.**

```
Day 1:     Sparse genome · low confidence · asks clarifying questions

Year 1:    Studio OS describes company identity better than founder prose
Long-term: Founders describe outcomes · Genome fills creative gaps
```
