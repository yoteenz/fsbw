# Company Genome™ — The Living DNA Engine (v2)

**Version:** 2.0.0  
**Status:** Canonical intelligence engine specification — architecture sprint  
**Type:** Universal intelligence layer — not profile · not analytics · not CRM  
**Engine ID:** `studio.company-genome.v2`  
**Tagline:** *Studio OS learns your company — so you never explain yourself twice.*

---

> **Company Genome™ is the living DNA of every company built inside Studio OS.**

> **NOT a user profile. NOT analytics. NOT CRM.**

---

## Mission

Every decision a founder makes should teach Studio OS something about that company.

The software becomes **increasingly intelligent over time**.

Eventually Studio OS should understand a company's identity **better than the founder can describe it**.

---

## Core Philosophy

Founders should **not** repeatedly explain:

- Aesthetic · tone · standards · quality expectations
- Favorite layouts · preferred lighting · visual language
- Camera style · materials · typography · creative philosophy

**Studio OS learns all of this automatically.**

---

## Law

```
Every decision → Genome update
Every generation → Genome consultation
Every company → Universal schema (no hardcoded tenants)
```

| Forbidden | Required |
|-----------|----------|
| User profile / CRM model | Living DNA engine |
| Analytics dashboard as Genome | Confidence-scored beliefs |
| Hardcode Frontal Slayer | Universal per-org schema |
| Manual 200-field forms | Learned from behavior |
| Settings page presentation | Living intelligence (UI later) |
| Skip Genome before Prompt Composer™ | Mandatory compose query |

---

## Continuous Evolution

Company Genome™ **continuously evolves**. Every signal updates it:

| Signal | Genome effect |
|--------|---------------|
| Approval | Strengthen belief · raise confidence |
| Rejection | Negative learning · lower weight |
| Regeneration | Refinement · preference delta |
| Edit | Domain value update |
| Marketplace purchase | New taste signal |
| Reused asset | Reinforce compatible patterns |
| Generated department | Spatial · creative expansion |
