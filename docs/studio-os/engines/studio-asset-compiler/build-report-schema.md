# Build Report Schema — `build-report.md`

**Schema ID:** `studio.asset-compiler.v1/build-report`  
**Output file:** `build-report.md` (root of DepartmentPackage.zip)

---

## Purpose

Human-readable manufacturing report — assets · warnings · timing · suggestions. Complements machine-readable `package-manifest.json`.

---

## Required Sections

Every `build-report.md` must include:

1. **Build Summary**
2. **Assets Generated**
3. **Assets Reused**
4. **Assets Adapted**
5. **Missing Assets**
6. **Warnings**
7. **Suggestions**
8. **Estimated Generation Time**
9. **Estimated Runtime Performance**
10. **Future Improvements**

---

## Failure Report
