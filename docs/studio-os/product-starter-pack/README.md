## Quick Start — New Product

```
1. Read START_HERE.md + PRODUCT_DEVELOPMENT_RULES.md
2. Copy PRODUCT_CREATION_CHECKLIST.md → products/{product-id}/
3. Copy PRODUCT_README_TEMPLATE.md → products/{product-id}/README.md
4. Complete templates in lifecycle order
5. Pass Product Review Board (9 reviews)
6. Receive Founder Approval
7. Implement per PRODUCT_FOLDER_STRUCTURE.md
8. Pass Definition of Done (12 gates)
9. Launch · Lessons Learned · Governed Evolution
```
