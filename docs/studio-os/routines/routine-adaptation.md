# Routine Adaptation™

**Intelligent Shortcuts™ and Founder Taste™**

---

## Purpose

Define how Routines™ become **smarter over time** — skipping completed work · reusing assets · carrying decisions forward · and adapting to Founder Taste™.

---

## Core Law

Every Routine™ should become smarter over time.

Routines are guided — not rigid scripts.

---

## Intelligent Shortcuts™

Before each step activates, the engine evaluates:

| Check | Shortcut if true |
|-------|------------------|
| **Work already complete** | Skip step · verify signals |
| **Assets already exist** | Reuse · link to existing |
| **Prior decisions apply** | Carry forward · no re-approval |
| **Step optional + no delta** | Skip with Orb confirm |
| **Taste suggests reorder** | Suggest different step order |
| **Parallel work done elsewhere** | Merge completion |

### Shortcut Ceremony

Orb always explains:

> *"Your Golden Build™ was approved Tuesday — we'll carry that forward and move to Distribution."*

Founder can **decline shortcut** — full step runs.

---

## Carry Forward Rules

| Artifact | Carry forward when |
|----------|-------------------|
| **Golden Build™ approval** | Same project · no direction change |
| **Brand system** | Create Brand complete · no rebrand flag |
| **Creative direction** | Canon locked · no branch promotion |
| **Hire decision** | Offer accepted · role unchanged |
| **Campaign config** | Same product · same channels |

| Do not carry forward when |
|---------------------------|
| Direction rejected · regenerated |
| Company Genome™ major change |
| Founder explicitly requests fresh start |
| Validation token expired |

## Founder Taste™ Adaptation

From [Routine Memory™](./routine-memory.md) and [Founder Taste Engine™](../founder-taste-engine/README.md):

| Learned pattern | Adaptation |
|-----------------|------------|
| "Reviews lighting before architecture" | Suggest lighting review sub-step first |
| "Publishes after sleeping on Golden Build" | Suggest overnight pause before Distribution |
| "Compares three concepts" | Pre-load three branches at comparison step |
| "Skips analytics initially" | Deprioritize · offer at end |
| "Prefers Braintrust deep dive" | Default review path to Deep Dive™ |
| "Morning creative · afternoon ops" | Time-suggest routine ordering |

**Law:** Suggestions — not mandates. Founder confirms via Orb.

| **L1 — Company** | Company Memory™ · prior instances |
| **L2 — Founder** | Taste Genome™ · cross-company patterns |

---

## Bottleneck Adaptation

When Routine Memory™ identifies stalls:

| Bottleneck | Adaptation |
|------------|------------|
| Creative approval slow | Pre-brief Braintrust · extend estimate |
| Asset generation fails | Alternate provider route · Orb prep |
| Founder skips step repeatedly | Make optional · or remove from default |
| Same dependency blocks twice | Spawn setup sub-routine |

---

## Routine Evolution™

Routine **definitions** may evolve — founder progress preserved:

| Change type | Migration |
|-------------|-----------|
| New step added | Insert · mark prior complete if equivalent |
| Step removed | Archive · no re-do |
| Step reordered | Map by step ID · not position |
| Dependency changed | Re-validate · Orb explain |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Silent skip | Founder must know |
| Skip without verification | Stale completion dangerous |
| Taste forced without confirm | Founder owns decisions |
| Never adapt | Wastes returning founders |
| Over-adapt (unrecognizable routine) | Trust breaks |
