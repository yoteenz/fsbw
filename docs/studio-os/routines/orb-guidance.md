# Orb Guidance™

**The Routine Guide**

---

## Purpose

Define how the **Orb™** guides founders through Routines™ — knowing context · narrating progress · and leading without saying *"Click here."*

---

## Core Law

The Orb becomes the **guide**.

Not a menu. Not a chatbot. The intelligent host of the workday.

---

## Routine-Aware Context Stack

Extends [Orb Context System™](../navigation/orb-context-system.md):

| Context | Orb knows |
|---------|-----------|
| **Current Routine™** | Active journey · goal |
| **Current step** | Order · department · scene |
| **Remaining steps** | What's ahead |
| **Dependencies** | Blockers · prerequisites |
| **Progress** | Percent · time · milestones |
| **Shortcuts available** | What can be skipped |
| **Recommendations** | Taste-adapted suggestions |
| **Interruption state** | Paused · resumed |

---

## Guidance Modes

| Mode | Orb behavior |
|------|--------------|
| **Routine Start™** | Welcome · objectives · journey preview |
| **Step entry** | Scene orient · what to do here |
| **In-step** | Quiet unless stuck · ambient insight |
| **Step complete** | Acknowledge · preview next |
| **Transition** | Narrate movement · maintain context |
| **Blocked** | Explain blocker · offer paths |
| **Shortcut** | Explain skip · confirm |
| **Paused** | Save acknowledgment · resume invite |
| **Complete** | Celebrate · summarize · suggest next |

---

## What the Orb Says

| Instead of | Orb says |
|------------|----------|
| "Click here" | "The Mood Wall is ahead — we'll review inspiration first." |
| "Go to Distribution" | "Next we'll cross the glass bridge to Distribution." |
| "Step 3 of 5" | "Two more stops — Marketing, then Analytics." |
| "Task incomplete" | "Golden Build™ needs your approval at the production board." |
| "Error" | "We're waiting on Braintrust — they'll be ready in a moment." |

---

## Proactive Guidance

Orb initiates when appropriate:

| Trigger | Orb line example |
|---------|------------------|
| **Routine due** | "Weekly Executive Review™ — ready when you are." |
| **Bottleneck predicted** | "Last launch, creative took longest — shall we start there?" |
| **Shortcut available** | "Your brand system exists — we can skip to review." |
| **Taste pattern** | "You usually compare three concepts — I've prepared branches." |
| **Return after pause** | "Welcome back — we were at the Offer Room." |

---

## Guidance Restraint

| Situation | Orb behavior |
|-----------|--------------|
| **Founder in flow** | Minimal · ambient only |
| **Explorer Mode™** | Advisory · not directive |
| **Experienced founder** | Shorter lines · fewer prompts |
| **New founder** | Fuller orient · encouragement |
| **Reduced motion** | Text-first · no animated lead |

---

## Orb and Multiple Concierges

During routine steps, Orb coordinates department concierges:

```
Orb (routine host)
    ├── Creative Director (creative steps)
    ├── Brand Concierge (brand steps)
    ├── Operations Advisor (ops steps)
    └── Braintrust (review steps)
```

Orb introduces specialists — does not disappear.

---

## Routine Recommendations

When founder asks *"What should I do today?"*:

| Input | Orb uses |
|-------|----------|
| Company stage | Lifecycle-appropriate routines |
| World State™ | Morning · Launch Day · Crisis |
| Routine Memory™ | Habits · bottlenecks |
| Founder Taste™ | Preferred workflows |
| Pending work | Blocked routines · reviews |
| Calendar | Scheduled routines |

Orb presents **outcomes** — not feature list.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Orb as notification center | Software not host |
| Step checklist UI in Orb speech | Diegetic progress elsewhere |
| Ignoring routine on transition | Context loss |
| Generic guidance | Must use full context stack |
| Forcing routine on experts | Explorer Mode™ respect |
