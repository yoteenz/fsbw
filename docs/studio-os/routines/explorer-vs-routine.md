# Explorer vs Routine™

**Two Modes — One Headquarters**

---

## Purpose

Define **Explorer Mode™** and **Routine Mode™** — supporting experienced self-guided founders and new Orb-guided founders within the same Studio World™.

---

## Core Law

Experienced founders may ignore routines.

New founders may rely on them.

**Both operate within the same headquarters.**

---

## Routine Mode™

| Property | Description |
|----------|-------------|
| **Entry** | "What are we building today?" · routine picker · Orb suggest |
| **Navigation** | Orb-guided · step orchestration |
| **Movement** | Routine Transitions™ between steps |
| **Progress** | Visible journey · remaining steps |
| **Adaptation** | Intelligent Shortcuts™ active |
| **Best for** | New founders · complex objectives · first-time workflows |

### Routine Mode™ Behaviors

- Orb leads · explains · previews
- Steps activate in order (with shortcuts)
- Routine Start™ ceremony on begin
- Routine Complete™ ceremony on end
- Resume System™ on pause

---

## Explorer Mode™

| Property | Description |
|----------|-------------|
| **Entry** | Walk headquarters · enter any department freely |
| **Navigation** | Self-guided · Scene Architecture™ only |
| **Movement** | Walk · pan · station nav · Orb route on request |
| **Progress** | No routine progress bar — founder owns path |
| **Adaptation** | Taste suggestions · not step enforcement |
| **Best for** | Experienced founders · creative exploration · quick tasks |

### Explorer Mode™ Behaviors

- Orb advisory · not directive
- Any department · scene · workspace accessible
- No required step order
- Routines available on request — not imposed
- Interruption™ of active routine → pause · explore · resume later

---

## Mode Switching

| From | To | Behavior |
|------|-----|----------|
| **Routine → Explorer** | Pause routine · save stack · explore freely |
| **Explorer → Routine** | Offer matching routine · or pick from library |
| **Routine → Routine** | Complete or abandon before new start |
| **First visit** | Suggest Routine Mode™ · Explorer always available |

Orb never locks founder into Routine Mode™.

---

## Discovery™

How founders learn routines exist:

| Mechanism | When |
|-----------|------|
| **Orb morning greeting** | "Launch Product™ is ready" |
| **Routine library browse** | Headquarters · objectives catalog |
| **Contextual suggest** | In department · "This is part of Hire Employee™" |
| **Post-Explorer nudge** | Repeated manual path → "Want a routine for this?" |
| **Guild / Advisor** | Studio Advisors™ recommend playbooks |

**Law:** Suggest · never force.

---

## Same Headquarters Guarantee

| Element | Both modes |
|---------|------------|
| Departments | Same destinations |
| Scenes | Same places |
| Workspaces | Same activities |
| Orb | Same host · different guidance level |
| Transitions™ | Same physical movement |
| Memory | Same Routine Memory™ · World Memory™ |
| Immersion | Same Idle Life™ · alive headquarters |

**No separate "simple mode" world.** One headquarters · two guidance levels.

---

## Founder Maturity Progression

| Stage | Typical mode |
|-------|--------------|
| **First week** | Routine Mode™ primary |
| **First month** | Mixed · Explorer growing |
| **Experienced** | Explorer primary · routines for complex objectives |
| **Executive** | Walk the Business™ + selective routines |

[Founder Journey™](../engine/founder-journey/01_JOURNEY_OVERVIEW.md) influences default suggestions — not restrictions.

---

## Routine Mode™ Without Prison

Even in Routine Mode™:

| Freedom | Preserved |
|---------|-----------|
| Pause anytime | Yes |
| Switch to Explorer | Yes |
| Decline shortcuts | Yes |
| Skip optional steps | Yes |
| Abandon routine | Yes |
| Ask Orb for detour | Yes |

Routine Mode™ is **guided** — not **locked**.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Explorer mode = degraded experience | Same world quality |
| Routine mode = no freedom | Prison breaks trust |
| Hide departments in Routine Mode™ | Both modes see all places |
| Force routines on experts | Respects maturity |
| Two different UIs | One headquarters |
