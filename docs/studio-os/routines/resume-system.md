# Resume System™

**Interruptions™ — Return Exactly Where You Left Off**

---

## Purpose

Define how founders **leave** a Routine™ at any time — and return to the **exact** department · scene · workspace · task · and open decisions.

---

## Core Law

Founders should leave a Routine™ at any time.

When they return — the Orb resumes exactly where they left off.

---

## What Gets Saved on Interruption™

| State | Persisted |
|-------|-----------|
| **Active Routine™** | ID · goal · started at |
| **Current step** | Step ID · order |
| **Department™** | Current destination |
| **Scene™** | Camera · position |
| **Workspace™** | Active activity |
| **Task™** | In-progress · partial |
| **Open decisions** | Pending reviews · uncommitted branches |
| **Pending reviews** | Braintrust · founder review queue |
| **Director feedback** | Draft notes not submitted |
| **Transition state** | Mid-transit if applicable |
| **Shortcuts declined** | Don't re-offer immediately |

**Storage concept:** Session resume stack + World Memory™

---

## Interruption Triggers

| Trigger | Behavior |
|---------|----------|
| **Founder exits explicitly** | "Pause routine" · Orb confirms save |
| **Explorer Mode™ switch** | Routine paused · not cancelled |
| **Department exit** | Prompt save · or auto-save |
| **Session end** | Auto-save resume stack |
| **Nested routine** | Parent paused · child active |
| **Blocker timeout** | Paused with blocker noted |

---

## Resume Ceremony

When founder returns:

| Beat | Content |
|------|---------|
| 1. **Orb recognition** | "Welcome back." |
| 2. **Context restore** | Routine name · step · time away |
| 3. **State summary** | What was in progress |
| 4. **Open items** | Pending reviews · decisions |
| 5. **Choice** | Resume · restart step · abandon routine |
| 6. **Camera restore** | Exact scene · workspace |
| 7. **Continue** | Task™ state intact |

Abbreviated arrival — not full Routine Start™.

---

## Resume vs Restart vs Abandon

| Action | Effect |
|--------|--------|
| **Resume** | Continue from saved stack |
| **Restart step** | Current step only · prior steps preserved |
| **Restart routine** | Full Routine Start™ · memory of prior attempt kept |
| **Abandon** | Routine archived incomplete · friction signal to memory |

---

## Multi-Day Routines

Some routines span days (Launch Product™ · Create Brand™):

| Rule | Behavior |
|------|----------|
| **Progress persists** | Across sessions · devices |
| **World continues** | Background prep during absence |
| **Orb on return** | "While you were away…" summary |
| **Stale check** | Re-validate dependencies on resume |
| **No penalty** | Pausing is normal |

---

## Concurrent Work

| Scenario | Resolution |
|----------|------------|
| **Routine paused · Explorer work** | Explorer independent · routine stack preserved |
| **Two routines started** | Orb asks which to resume |
| **Routine + Walk the Business™** | Walk can reference paused routine |
| **External edit while paused** | Re-validate on resume |

---

## Open Decisions Preservation

Critical for creative workflows:

| Open state | On resume |
|------------|-----------|
| **Braintrust in progress** | Review panel restored |
| **Founder review path unselected** | Paths still available |
| **Branch comparison active** | Gallery state restored |
| **Regeneration impact pending** | Warning re-shown |
| **Unsaved founder note** | Draft preserved |

---

## Privacy and Session

| Rule | Law |
|------|-----|
| Resume stack per company | Not mixed across companies |
| Founder auth required | Resume binds to founder |
| Abandon is explicit | No silent discard |
| Memory on abandon | Friction learning only · not failure shame |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Resume loses pending review | Data loss · trust break |
| Force restart on return | Punishes interruption |
| No pause — only cancel | Real work is interruptible |
| Resume to wrong scene | Disorienting |
| Stale state without warning | Dangerous approvals |
