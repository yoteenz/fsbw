# Headquarters Continuity™

**One World — Many Departments**

---

## Purpose

Define the **shared architectural language** every department inherits — so the founder always knows they are still inside Studio World™.

---

## Core Law

Every department develops its own atmosphere.

Every department preserves **one unified headquarters**.

## Hallway Continuity

Departments connect via physical paths:

```
Headquarters Lobby™
    ├── Executive Corridor™ → Creative Direction Studio™
    ├── Glass Hallway™ → Marketing™ · Brand™
    ├── Innovation Tunnel™ → Research™ · Automation™
    ├── Operations Wing™ → Operations™ · Analytics™
    └── Marketplace Gallery™ → Marketplace™
```

Founder sees **adjacent departments** — not a flat menu.

**Source:** [Living Architecture™](../world/living-architecture.md)

## Breaking Continuity (Forbidden)

| Break | Why forbidden |
|-------|---------------|
| Department with no Orb | Orphan experience |
| Department with no arrival | No scale |
| Different scroll model | Webpage not world |
| Isolated color system | Breaks headquarters |

| Unique back-button behavior | Software not place |
