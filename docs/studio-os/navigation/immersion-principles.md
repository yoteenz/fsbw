# Immersion Principles™

**The Headquarters Never Waits**

---

## Purpose

Define immersion requirements for Scene Architecture™ — departments and scenes that feel **alive** before the founder interacts.

---

## Core Law

**The founder joins work already in progress.**

Departments never feel empty. Scenes feel active. The headquarters never waits.

---

## Alive Headquarters

| Principle | Manifestation |
|-----------|---------------|
| **Background work continues** | AI employees · pipeline prep · displays update |
| **Displays update** | Mood boards breathe · KPIs tick · calendars shift |
| **Lights shift** | World State™ · time · activity focus |
| **Ambient systems move** | HVAC · screens · subtle motion |
| **Audio bed present** | Department stem · not silence |
| **Evidence of others** | Professional society · guild activity · team presence |

---

## Idle Life™ (Mandatory)

When founder is idle 30+ seconds:

| Behavior | Scene-level |
|----------|-------------|
| Mood Wall tiles shuffle subtly | Hero scene |
| Pipeline board status LED pulses | Production scene |
| Reference volumes spine glow | Library scene |
| Story Table projection cycles | Command scene |
| Orb ambient insight line | Any scene |

**Source:** [Idle Life™](../foundational-experience-systems/idle-life.md)

---

## Scene-Level Immersion

Every scene must feel **occupied** on entry:

| Scene type | Active signals |
|------------|----------------|
| **Arrival** | Light spill · distant activity · audio swell |
| **Creative** | Inspiration updating · AI suggestions |
| **Production** | Stage preparing · next prompt caching |
| **Review** | Braintrust assembling · specialists ready |
| **Intelligence** | Data orbits · predictions refreshing |
| **Operations** | KPIs live · alerts queued |
| **Hiring** | Candidate pipeline moving · interviews scheduled |

---

## Empty State Law

**Forbidden:** Blank white panels · "No data yet" cards · skeleton loaders as hero.

**Required:** Environmental storytelling for empty states:

| Instead of | Use |
|------------|-----|
| Empty mood board card | Wall waiting for first pin · ghost frames |
| Empty pipeline list | Board with locked stages · prep lights |
| Empty library shelf | Labeled empty volumes · invitation to fill |
| Empty notes desk | Blank illuminated surface · pen ready |

---

## Immersion and Performance

| Rule | Mobile requirement |
|------|-------------------|
| Ambient animation ≤ 3 concurrent | iPhone Safari |
| CSS transforms over layout | GPU |
| No continuous blur | Stability |
| Audio opt-in on mobile | Autoplay policy |
| Reduced motion = static beauty | Accessibility |

## Immersion Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Static screenshot room | Dead place |
| Load spinner as scene content | Not Transition™ |
| Silent department | No audio bed |
| Founder-only activity | World doesn't breathe |
| Notification badges as immersion | Software not environment |
