# Workspace Framework™

**Activity Layer — Scene Describes Place, Workspace Describes Work**

---

## Purpose

Define the **Workspace™** layer — the activity happening inside a Scene™.

---

## Core Law

```
Scene™       =  WHERE  (the place)
Workspace™   =  WHAT   (the activity)
```

A scene may contain **one or more** workspaces.

---

## Workspace Definition

| Property | Description |
|----------|-------------|
| **Activity name** | What work happens (verb-noun) |
| **Parent scene** | Physical place hosting the workspace |
| **Inputs** | What founder brings in |
| **Outputs** | What the workspace produces |
| **Tools** | Diegetic objects enabling work |
| **Completion signal** | How founder knows work is done |

---

| Workspace™ | Activity | Typical parent scene |
|------------|----------|---------------------|
| **Content Creation Workspace™** | Write · script · editorial copy | Story Table · Content Studio |

| **Hiring Workspace™** | Evaluate candidates · plan teams | Interview Studio · Talent Discovery |

| **Review Workspace™** | Critique · Braintrust · approval | Founder Review · Review Area |
| **Publishing Workspace™** | Package · channel prep · schedule | Launch Center · Content Queue |
| **Research Workspace™** | Browse · analyze · synthesize | Reference Library · Research Lab |
| **Comparison Workspace™** | A/B/C branch evaluation | Branch Gallery · Candidate Comparison |
| **Monitoring Workspace™** | KPIs · health · alerts | Performance Wall · Command Floor |

---

## Workspace vs Interaction vs Task

```
Workspace™     →  sustained activity  ("I am creating content")
Interaction™   →  moment of engagement ("I pin this reference")
Task™          →  atomic unit         ("I approve this stage")
```

| Level | Duration | Example |
|-------|----------|---------|
| Workspace™ | Session-scale | Content Creation Workspace™ |
| Interaction™ | Moment | Drag reference to Mood Wall |
| Task™ | Atomic | Approve Golden Build™ stage 3 |

---

## Single vs Multi-Workspace Scenes

### Single-workspace scene

The scene **is** the workspace.

```
Mood Wall Scene™
  └── Inspiration Workspace™ (pin · cluster · compare)
```

### Multi-workspace scene

One place · multiple activities.

```
Story Table Scene™
  ├── Brief Workspace™
  ├── Command Workspace™ (Orb)
  └── Timeline Workspace™
```

**Rule:** Multi-workspace scenes require clear spatial separation — not tabs.

---

## Workspace Inheritance

Workspaces inherit from parent scene and department:

| Inherited | Source |
|-----------|--------|
| Company Genome™ | Brand · industry · voice |
| Project Genome™ | Active project context |
| Creative Direction™ | Canonical intent (when relevant) |
| Founder Taste Genome™ | Personal preferences |
| Department capabilities | What tools exist |
| Scene tools | Physical objects available |

---

## Workspace State

| State | Behavior |
|-------|----------|
| **Idle** | Ambient life continues · displays update |
| **Active** | Founder engaged · tools illuminated |
| **Complete** | Output saved · Orb acknowledges |
| **Blocked** | Dependency unmet · Orb explains |

Workspaces do not reset on navigation away — state persists in World Memory™.

---

## Workspace and Pipeline

Production workspaces connect to [Creative Direction Pipeline™](../creative-direction-pipeline/README.md):

| Workspace | Pipeline stage |
|-----------|----------------|
| Asset Creation Workspace™ | Generation · refinement |
| Review Workspace™ | Braintrust · Founder Review |
| Production Pipeline Workspace™ | Stage approval sequence |

**Law:** Pipeline status expressed **diegetically** (board lights · console screens) — not floating panels.

---

## Forbidden Patterns

| Anti-pattern | Why |
|--------------|-----|
| Workspace = browser tab | Software pattern |
| Workspace without scene parent | Orphan activity |
| Workspace = modal form | Not a place |
| Generic "Workspace" label | Must name the activity |
