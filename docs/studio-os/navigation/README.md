# Scene Architecture™

**The Workspace System of Studio World™**

**Version:** 1.0.0  
**Status:** Canonical operating system navigation architecture (docs only)  
**Phase:** OS architecture sprint (post-department · post-world-building)  
**Scope:** Navigation philosophy for **all** of Studio OS

---

> **Studio OS is not a collection of pages. It is a living headquarters.**

---

## Mission

We have reached a fundamental realization.

| Wrong mental model | Right mental model |
|--------------------|-------------------|
| Departments are **pages** | Departments are **destinations** |
| Scenes are **pages** | Scenes are **workspaces** |
| Navigation is **software** | Navigation is **walking** |

**Scene Architecture™** becomes the navigation philosophy for the entire operating system.

---

## One Sentence

**Scene Architecture™** defines how founders move through Studio World™ — from headquarters to department to scene to workspace — as physical places where work happens, never as webpages that were needed.

---

## The Hierarchy

```
Studio World™
    ↓
Headquarters™
    ↓
Department™          ← destination (major business function)
    ↓
Scene™               ← focused workspace (a place with one clear purpose)
    ↓
Workspace™           ← activity layer (what work happens here)
    ↓
Interaction™         ← how founder engages the place
    ↓
Task™                ← atomic unit of work
```

**Law:** Everything inherits from the level above.

---

## Core Philosophy

Studio World™ should feel like **walking through a living headquarters**.

- Every department is a **destination** you choose to visit
- Inside every department is a **collection of scenes**
- Every scene exists because **work happens there**
- Never because another page was needed
