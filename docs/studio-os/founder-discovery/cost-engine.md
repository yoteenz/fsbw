# Cost Engine™

**Realistic Financial Model**

---

## Purpose

Define how Studio OS generates a **realistic financial model** for each Discovery Report™ recommendation — so founders understand what launching actually requires.

---

## Core Law

The founder understands **exactly** what launching this business will realistically require.

No hidden costs. No fantasy numbers.

---

## Cost Categories

### One-Time Startup Costs

| Category | Examples |
|----------|----------|
| **Business registration** | State fees · formation |
| **Professional licensing** | Industry-specific permits |
| **Insurance** | Initial policies · deposits |
| **Software** | Tools · subscriptions (year 1 prepaid) |
| **Equipment** | Hardware · production gear |
| **Inventory** | Initial stock · materials |
| **Website** | Build · launch · domain |
| **Marketing** | Launch campaign · brand assets |
| **Branding** | Identity · photography |
| **Legal** | Formation · contracts · terms |
| **Accounting** | Setup · first filings |

### Ongoing Monthly Costs

| Category | Examples |
|----------|----------|
| **Software subscriptions** | Stack · SaaS |
| **Marketing** | Ads · content · agency |
| **Insurance** | Monthly premiums |
| **Accounting / tax** | Bookkeeping · CPA |
| **Taxes** | Estimated obligations (advisory) |
| **AI services** | API · generation credits |
| **Studio OS subscription** | Platform tier |
| **Concierge team** | AI + human support allocation |
| **Employees** | Wages · benefits when applicable |
| **Contractors** | Regular freelancers |
| **Office** | Rent · coworking if applicable |
| **Cloud infrastructure** | Hosting · storage if applicable |
| **Inventory replenishment** | COGS rhythm |

### Reserves

| Category | Purpose |
|----------|---------|
| **Emergency reserve** | 3–6 month buffer (archetype-dependent) |
| **Working capital** | Operations float |
| **Expected monthly burn** | Net outflow before profit |
| **Projected break-even window** | Range · assumptions explicit |

---

## Cost Engine Outputs

| Output | Format |
|--------|--------|
| **Startup total** | Itemized · summed · range |
| **Monthly operating** | Itemized · summed · range |
| **Runway calculator** | Budget ÷ burn = months |
| **Break-even timeline** | Revenue assumptions stated |
| **Sensitivity** | "If revenue 50% slower…" |
| **Outsource vs DIY** | Cost delta per line item |

Linked to [Discovery Report™](./discovery-report.md) sections.

## Personalization Inputs

| Input | Effect |
|-------|--------|
| **Founder budget** | Feasibility flag · path filter |
| **Region** | Registration · license costs |
| **DIY vs outsource** | Labor line items |
| **Team structure** | Payroll projection |
| **Studio tier** | Platform subscription line |
| **AI usage estimate** | Generation credits |

---

## Transparency Rules

| Rule | Law |
|------|-----|
| **Ranges not false precision** | "$8K–$14K" not "$11,247" |
| **Assumptions listed** | Every projection traceable |
| **Update on change** | Region · team · model shift |
| **Advisory disclaimer** | Tax · legal · insurance — verify professional |
| **Include Studio costs** | No hidden platform fees |

## Cost vs Lifestyle Simulator

Cost Engine and [Business Simulator™](./business-simulator.md) align:

| Simulator says | Cost Engine includes |
|----------------|---------------------|
| "20 hrs/week owner time" | Lower contractor line items |
| "Full-time + first hire month 6" | Payroll ramp |
| "High travel sales" | Travel · entertainment budget |

## Post-Launch Cost Tracking

Cost Engine evolves from **estimate** to **actual**:

- Expedition Launch Company™ links estimates to real spend
- Variance learning improves future discovery reports
- Orb: *"Your actual marketing spend is 30% below discovery estimate."*

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Underestimate to sell | Ethical breach |
| Exclude platform subscription | Dishonest |
| Single point estimate | False confidence |
| No runway math | Founder blindsided |
