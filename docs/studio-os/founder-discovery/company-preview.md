# Company Preview™

**See the Company Before It Exists**

---

## Purpose

Define the **Company Preview™** — showing founders their future Headquarters™ · departments · and operating rhythm before company creation.

---

## Core Law

Before creating the company, the founder can **literally see** what they are choosing to build.

Inspiration before commitment.

---

## Preview Contents

| Element | What founder sees |
|---------|-------------------|
| **Future Headquarters™** | Studio Original™ · environment · metaphor |
| **Departments™** | Which wings exist at launch |
| **Scenes™** | Example workspaces inside departments |
| **Workspace examples™** | Day-one activities illustrated |
| **Orb capabilities™** | How Orb will guide post-launch |
| **AI Team™** | Concierges · roles · coverage |
| **Business roadmap™** | First-year arc from Discovery Report™ |
| **Growth projections™** | Honest ranges · assumptions |

---

## Preview Experience (Conceptual)

Not a static mockup — a **walkable preview**:

```
Founder selects path from Discovery Report™
        ↓
Cost Engine™ + Simulator reviewed
        ↓
Orb: "Let me show you what this company could feel like."
        ↓
Preview Headquarters™ loads (pre-company space)
        ↓
Walk abbreviated departments · sample scenes
        ↓
See suggested Routines™ · Expeditions™ on map
        ↓
Founder: Commit · Explore more · Choose different path
```

Preview uses [Scene Architecture™](../navigation/README.md) vocabulary — founder learns navigation model early.

## Commitment Gate

| Action | Result |
|--------|--------|
| **Commit to this path** | Adaptive Onboarding™ · company object created |
| **Save for later** | Preview state preserved · genome locked to path |
| **Choose different path** | Return to Multiple Paths™ |
| **Need more conversation** | Return to Orb · no penalty |

Orb: *"When you're ready, we'll build this for real."*

---

## Preview vs Live HQ

| Preview | Live (post-commit) |
|---------|-------------------|
| Ephemeral · explorable | Persistent · World Memory™ |
| Sample data | Real Project Genome™ |
| No routines running | Routines™ activate |
| Illustrative metrics | Real analytics |

Transition is [Adaptive Onboarding™](../onboarding/README.md) inauguration moment.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Preview = screenshot | Must feel walkable |
| Full company day one | Overwhelming · dishonest |
| Commit before preview | No inspiration gate |
| Preview ignores cost reality | Must align with Cost Engine™ |
