# Business Matching Engine™

**Multi-Dimensional Fit — Every Match Explains WHY**

---

## Purpose

Define how Studio OS **matches** founders to business opportunities across multiple dimensions — philosophy only, no algorithms this sprint.

---

## Core Law

Every recommendation must explain **WHY**.

Matching is multi-dimensional — never single-score black box.

---

## Matching Inputs

| Input source | Weight grows with |
|--------------|-------------------|
| **Founder Genome™** | Confidence per facet |
| **Conversation signals** | Recency · depth |
| **Simulator feedback** | Explicit fit/reject |
| **Market intelligence** | Industry viability (advisory) |
| **Studio catalog** | Known business archetypes |
| **Regional context** | Licenses · structures when available |

---

## Matching Dimensions

Each business opportunity scored (conceptually) across:

| Dimension | Question answered |
|-----------|-------------------|
| **Highest Profit Potential™** | Revenue ceiling vs founder ambition |
| **Lowest Startup Cost™** | Capital required vs budget |
| **Fastest To Launch™** | Time to first revenue |
| **Most Passive™** | Owner hours post-stabilization |
| **Highest Creativity™** | Creative genome utilization |
| **Best Lifestyle Match™** | Hours · travel · stress · family |
| **Highest Long-Term Growth™** | Scalability · market expansion |
| **Most Flexible™** | Location · schedule independence |
| **Most Stable™** | Predictability · downturn resilience |
| **Highest Automation Potential™** | Systems · AI ops fit |
| **Highest AI Leverage™** | AI-native business models |
| **Most Enjoyable™** | Intrinsic motivation alignment |
| **Mission Driven™** | Values · purpose fit |

Dimensions are **transparent** — founder sees tradeoffs.

## Multiple Paths™ Generation

For each discovery cycle, engine produces path bundles:

| Path | Selection logic |
|------|-----------------|
| **Best Overall Match™** | Weighted genome fit across dimensions |
| **Highest Profit™** | Top profit dimension · viable for founder |
| **Lowest Risk™** | Stability + budget + time fit |
| **Fastest Launch™** | Speed dimension leader |
| **Lifestyle Favorite™** | Lifestyle match leader |
| **Wild Card™** | High fit · unexpected · expands imagination |
| **Mission Match™** | Values alignment leader |

Minimum **3 paths** · target **5–7** — never exactly one.

---

## WHY Explanation Structure

Every match includes:

```
WHY IT FITS YOU™
├── Strength alignment: "Your background in X…"
├── Motivation alignment: "You said you want Y…"
├── Lifestyle alignment: "This typically allows Z hours…"
├── Risk alignment: "Matches your stated tolerance for…"
├── Tradeoff honesty: "Lower passive income than option B…"
└── Confidence: "Based on 12 conversation signals (high confidence)"
```

No match without tradeoff honesty.

---

## Negative Matching

Equally important — what **not** to recommend:

| Signal | Effect |
|--------|--------|
| Stated hatred of sales | Deprioritize high-touch B2B |
| Zero technical interest + no budget | Deprioritize SaaS build |
| Need immediate income | Deprioritize long R&D plays |
| Values conflict | Hard exclude with explanation |

---

## Re-Matching Triggers

| Event | Action |
|-------|--------|
| Genome facet confidence up | Re-rank paths |
| Founder rejects path | Learn · regenerate |
| Market advisory update | Refresh viability notes |
| Post-company performance | Suggest pivot archetypes |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Opaque ML score | No trust |
| Single "perfect" business | No agency |
| Affiliate-driven suggestions | Conflict of interest |
| Static catalog only | No founder uniqueness |
| Match without lifestyle | Discovery is whole-person |
