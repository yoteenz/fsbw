# Founder Genome™ (Discovery)

**Built Before Judgment**

---

## Purpose

Define how **Founder Genome™** is constructed during Founder Discovery™ — before any company exists.

**Extends:** [Founder Genome™ — Intelligence](../intelligence/founder-genome.md)

---

## Core Law

Discovery continuously builds the Founder Genome™.

Nothing is decided from one questionnaire.

The Genome evolves before it judges.

---

## Discovery-Phase Genome Facets

In addition to post-company leadership profile, discovery adds:

| Facet | Discovery signals |
|-------|-------------------|
| **Skills inventory** | Stated · inferred · validated |
| **Experience map** | Industries · roles · years |
| **Hobbies & interests** | Passion · energy sources |
| **Education** | Formal · self-taught · certifications |
| **Income goals** | Target · timeline · flexibility |
| **Lifestyle goals** | Location · hours · family |
| **Risk tolerance** | Financial · career · creative |
| **Leadership style** | Solo · collaborative · delegating |
| **Creative interests** | Visual · writing · product · none |
| **Technical ability** | Build · operate · outsource |
| **Available time** | Hours/week · seasonality |
| **Available budget** | Startup capital · runway |
| **Family situation** | Constraints · support · obligations |
| **Long-term vision** | Empire · lifestyle · mission · exit |
| **Motivations** | Freedom · impact · wealth · craft |
| **Mission & purpose** | Stated north star |
| **Values** | Non-negotiables |

---

## Confidence Model

Each facet carries **confidence** — not binary filled/empty:

| Confidence | Meaning |
|------------|---------|
| **Low** | Single mention · needs exploration |
| **Medium** | Corroborated across conversation |
| **High** | Explicit · repeated · behavioral signal |

Business Matching™ weight increases with confidence.

Orb may ask targeted follow-ups for low-confidence critical facets.

---

## Genome Update Triggers

| Trigger | Update |
|---------|--------|
| Conversation turn | Incremental facet signals |
| Simulator feedback | "This doesn't feel right" → lifestyle adjust |
| Report path rejection | Negative signal · re-rank |
| Company operating | Observed behavior refines genome |
| Life event (stated) | Manual refresh invite |
| Market shift | Opportunity layer · not identity |

---

## Genome Before Company

| Property | Pre-company state |
|----------|-------------------|
| **companyId** | null |
| **founderId** | authenticated or session |
| **journeyStage** | Dreaming™ |
| **companies** | [] |
| **discoveryComplete** | false until report accepted |

On company creation, genome **travels** — does not reset.

---

## Relationship to Taste Genome™

| Genome | When seeded |
|--------|-------------|
| **Founder Genome™** | Discovery conversation |
| **Founder Taste Genome™** | Light signals in discovery · deepens post-creative work |

Discovery may note: *"You respond strongly to editorial minimal environments"* — taste seed only.

---

## Privacy & Sensitivity

| Data class | Handling |
|------------|----------|
| **Financial** | Optional depth · never shared |
| **Family** | Used for lifestyle match only |
| **Weaknesses** | Supportive framing · growth paths |
| **Failed ventures** | Learning signal · no shame |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Genome from 10 dropdowns | Low fidelity |
| Frozen at signup | Discovery Never Ends™ |
| Genome replaces conversation | Both continuous |
| Judgment labels | "Low potential" forbidden |
