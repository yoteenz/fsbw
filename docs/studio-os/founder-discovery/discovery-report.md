# Discovery Report™

**The Recommendation Package**

---

## Purpose

Define the **Discovery Report™** — the comprehensive deliverable presented when Founder Discovery™ reaches sufficient genome confidence.

---

## Core Law

At discovery culmination, Studio OS presents **several recommended businesses** — each a complete package with transparent WHY.

---

## Report Structure

### Per-Recommendation Sections

| Section | Contents |
|---------|----------|
| **Business Overview™** | What it is · who it serves · model summary |
| **Why It Fits You™** | Genome-aligned explanation |
| **Founder Compatibility Score™** | Multi-dimension breakdown (not single number) |
| **Estimated Startup Cost™** | One-time launch capital |
| **Monthly Operating Cost™** | Ongoing burn estimate |
| **Estimated Time Commitment™** | Hours/week by phase |
| **Recommended Team Structure™** | Solo · contractors · first hires |
| **Projected Concierge Needs™** | AI team · human roles |
| **Suggested Headquarters™** | Studio Original™ · environment metaphor |
| **Suggested Studio Original™** | Specific HQ package if applicable |
| **Suggested Departments™** | Launch department set |
| **Suggested AI Workforce™** | Concierges · automations |
| **Recommended Routines™** | Day-one operational rhythms |
| **Potential Expeditions™** | Launch Company™ · Rebrand™ · etc. |
| **Potential Revenue Models™** | Pricing · streams · unit economics concept |
| **Business Risks™** | Honest downside · mitigation |
| **Growth Opportunities™** | Expansion paths |
| **Expected Difficulty™** | Honest challenge level |
| **Estimated Time To Profit™** | Range · assumptions stated |
| **Recommended First-Year Roadmap™** | Month-by-month arc |
| **Required Licenses** | Region-specific when available |
| **Typical Insurance Needs** | Liability · professional · etc. |
| **Common Legal Structures** | LLC · S-Corp · etc. — advisory |
| **Key Skills To Learn** | Gaps · learning paths |
| **Outsourcing Opportunities** | What to delegate early |
| **Automation Opportunities** | AI · systems leverage |

## Report Presentation (Diegetic Concept)

Report is experienced — not PDF dump:

| Expression | Location |
|------------|----------|
| **Strategy room** | Pre-headquarters preview space |
| **Orb narration** | Walks founder through each path |
| **Comparison wall** | Multiple Paths™ side-by-side |
| **Drill-down** | Tap archetype → full section |

**No UI this sprint** — structure only.

## Compatibility Score™

| Axis | Example display |
|------|-----------------|

## Report Versioning

| Version | When |
|---------|------|
| **v1** | First sufficient genome |
| **v2+** | Re-discovery · life change |
| **Delta** | What changed · why paths shifted |

Prior reports preserved in Founder Chronicle™ pre-company chapter.

## Handoff

| Founder action | Next system |
|----------------|-------------|
| **Explore path** | Business Simulator™ |
| **Select path** | Cost Engine™ · Company Preview™ |
| **Commit** | Adaptive Onboarding™ · company creation |
| **Decline all** | Deeper conversation · recalibrate |

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Report without WHY | Trust failure |
| Hidden costs | Cost Engine™ separate but linked |
| One recommendation only | Multiple Paths™ required |
| Legal advice certainty | Advisory only |
