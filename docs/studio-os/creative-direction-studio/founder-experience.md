# Founder Experience™

**Walking the creative headquarters — not using software**

---

## Purpose

Define the **emotional contract** for Creative Direction Studio™ V2 — what the founder should think and feel.

---

## Forbidden Founder Thoughts

| Never think |
|-------------|
| "I'm filling out a form." |
| "I'm clicking a dashboard." |
| "I'm editing software." |
| "I need to find the pipeline panel." |
| "I'll scroll down to the next section." |

---

## Required Founder Thoughts

| Must think |
|------------|
| "I'm walking through the creative headquarters of my company." |
| "I'm directing a production team." |
| "I'm physically inside the world's first Company Engine™." |
| "I want to see what's around that corner." |
| "The Orb knows what I'm trying to do." |

---

## Observer Benchmark (Screen Recording)

First reaction must **NOT** be:

> "Nice UI."

Must be:

> **"Wait… is this a game?"**  
> **"Is this an interactive production studio?"**  
> **"I've never seen software feel like a real place before."**

Anything less = still designing software.

---

## Session Rhythm

```
ARRIVE     — transition · threshold · partial reveal
ORIENT     — Orb welcome · forward step
INSPIRE    — Mood Wall · references
DIRECT     — Story Table · concepts · pipeline board
REFINE     — Asset Console · Review Area
APPROVE    — Braintrust · Canon lock
DEPART     — transition out · world continues
```

---

## Language Law (In-Room)

| Software term | In-room term |
|---------------|--------------|
| Dashboard | Department |
| Panel | Workstation |
| Click | Approach · touch |
| Scroll | Walk · pan |
| Save | Leave in room memory |
| Settings | Story Table context |
| User | Founder · Creative Director |

## Relationship to Company Engine™

CDS is evidence the **company has a creative brain** — not a feature of admin software.

[Company Engine™](../philosophy/company-engine.md): the company is the product. CDS is where creative intent lives as **place**.
