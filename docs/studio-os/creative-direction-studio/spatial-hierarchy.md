# Spatial Hierarchy™

**Build the department like a real creative headquarters**

---

## Purpose

Define **foreground · midground · background** layering for Creative Direction Studio™ — every area has purpose · depth · and sightline priority.

---

## Core Law

**Every area has purpose. Nothing is decorative filler.**

---

## Three Layers

### Foreground — Interactive Objects

| Object | Purpose |
|--------|---------|
| Story Table™ + Orb™ | Spatial · emotional center |
| Founder Notes™ desk | Personal creative capture |
| Review Area™ seating | Human-scale collaboration |
| Entry threshold markers | Arrival Zone™ boundary |

**Founder proximity:** arm's reach · touch · sit

### Midground — Primary Workstations

| Object | Purpose |
|--------|---------|
| Living Mood Wall™ (hero) | Inspiration · compare · cluster |
| Timeline Table™ | Project chronology · branch |
| Creative Pipeline™ board | Production status · stage flow |
| Asset Console™ | Refinement · generation operate |
| Brief Wall™ | Active brief pins |

**Founder proximity:** walk-to · stand work · primary labor

### Background — Architecture & Atmosphere

| Element | Purpose |
|---------|---------|
| Ceiling · skylight · light rigs | Scale · mood · genome lighting |
| Glass wall · windows | World beyond · headquarters context |
| Reference Library™ shelving | Depth · knowledge volume |
| Genome Observatory™ alcove | Data beauty · discoverable |
| Displays · holograms | Ambient intelligence |
| Doors · hallways | Transitions™ to other departments |
| Distant silhouettes · activity | Living HQ |

**Founder proximity:** discover · orbit camera · atmosphere

## Parallax & Depth Cues

| Technique | Application |
|-----------|-------------|
| **Parallax** | Foreground moves faster than background on camera pan |
| **Depth of field** | Soft background when focused on foreground workstation |
| **Light falloff** | Background dimmer · foreground key lit |
| **Scale gradient** | Larger hero objects midground · human-scale foreground |
| **Occlusion** | Foreground objects partially block midground until orbit |
| **Reflections** | Floor · glass table catch background light |

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Flat single-plane layout | No depth · illustration |
| All objects same visual weight | No hierarchy |
| Background as dead JPEG | Breaks immersion |
| Foreground clutter | Blocks hero sightlines |
