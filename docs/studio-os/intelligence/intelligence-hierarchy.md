**Every level inherits · every level preserves identity**

## Purpose

Define the **canonical intelligence stack** — how Founder · Company · and Project layers compose from highest identity to production artifacts.

---

## Inheritance Law

**Every level inherits intelligence from levels above while preserving its own identity.**

| Direction | Rule |
|-----------|------|
| **Downward** | Child consults all ancestors before generation |
| **Upward (taste)** | Creative decisions feed Founder Taste Genome™ |
| **Upward (founder)** | Leadership patterns feed Founder Genome™ |
| **Sideways** | Siblings (projects) do not mutate each other |
| **No skip** | Generation never ignores Company Genome for taste alone |

---

## Consultation Order (Generation)

When Studio OS creates anything:

```
1. Founder Genome™        — who is deciding · how they lead
2. Founder Taste Genome™  — creative instinct alignment
3. Company Genome™        — brand · voice · identity law
4. Project Genome™        — initiative constraints · notes
5. Room DNA™              — department aesthetic sliders
6. Scene Blueprint™       — spatial production truth (if exists)
7. Asset Graph™           — node context (if refining)
```

Prompt Compiler™ · Studio Intelligence™ · and Concept generators merge this stack.

## Hierarchy vs Studio Intelligence Context Engine

Studio Intelligence Architecture™ defines 10 trusted context sources.

Founder Intelligence Hierarchy™ **feeds** Context Engine:

| Context source | Hierarchy source |
|----------------|------------------|
| Organization context | Company Genome™ |
| Founder context | Founder Genome™ |
| Creative context | Taste Genome™ + Project Genome™ |
| Production context | Room DNA™ · Blueprint · Graph |

**No new engine** — hierarchy defines **consultation order**.
