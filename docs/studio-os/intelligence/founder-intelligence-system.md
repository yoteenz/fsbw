**"The Memory Behind Studio OS"**

## Core Law

**Remember people — not data.**

Studio OS intelligence is built from **understanding founders and companies** — not from larger language models alone.

Every interaction feeds the system:

| Category | Signals |
|----------|---------|

## Learning Pipeline

```
Interaction event
        ↓
1. CLASSIFY — founder · taste · company · project signal?
        ↓
2. CAPTURE — context · artifacts · comparison set
        ↓
3. ANALYZE — extract patterns (WHY not just WHAT)
        ↓
4. ROUTE — update appropriate genome layer(s)
        ↓
5. PROPAGATE — hierarchy inheritance · predictive models
        ↓
6. SURFACE — Orb observation · proactive recommendation
```

## Three Genomes — Responsibilities

### Founder Genome™

**Who the founder is** — leadership · communication · decision style · goals · journey.

Evolves as the founder evolves. Travels across all companies.

### Founder Taste Genome™

**How the founder creates** — architecture · materials · motion · luxury level · creative risk.

Learned from every creative decision. Travels across all companies.

### Company Genome™

**What makes this company unique** — mission · brand · audience · operations.

Belongs to the company. Does not travel with founder to new ventures.

## Relationship to Other Memory Systems

| System | Role | Distinction |
|--------|------|-------------|
| **Founder Intelligence System™** | Umbrella memory architecture | Three Genomes™ + hierarchy |
| **Founder Taste Engine™** | Taste learning implementation spec | Subsystem of taste genome |
| **Relationship Memory™** | Operational familiarity | How founder **works** day-to-day |
| **Memory Engine™** | Organizational outcomes memory | What **worked** for the company |
| **World Memory™** | Spatial session persistence | Where founder **was** in HQ |
| **Organizational Consciousness™** | Unified intelligence bus | Consumes all layers |

**Founder Intelligence** = who founder is + how they create + what company is.  
**Relationship Memory** = meeting preferences · approval batching · reporting format.  
**Memory Engine** = project outcomes · lessons learned · prove-it-forever.

## Intelligence Maturity Model

| Stage | Behavior |
|-------|----------|
| **Nascent** | Equal exploration · maximum learning |
| **Developing** | Mixed prediction + exploration |
| **Established** | Strong predictive alignment · one outlier concept |
| **Deep** | Concepts feel pre-imagined · minimal explanation needed |

Measured per Founder Genome™ · Taste Genome · and company context.

## Anti-Patterns

| Anti-pattern | Why forbidden |
|--------------|---------------|
| Remember clicks without WHY | Shallow memory |
| Single genome for everything | Founder ≠ company |
| Company taste locked to founder | New ventures need fresh identity |
| Manual preference forms | Teach through living |
| Model upgrade = smarter OS | Understanding must compound |
| Silent prediction | Breaks trust |
| Delete rejected concepts | Lose branches · lose learning |
