# Canon™ vs Alternate Branch™

**Official truth · preserved explorations**

---

## Purpose

Define how Founder Intelligence System™ records **approved creative history** (Canon™) and **preserved explorations** (Alternate Branch™) — both feeding taste learning and company memory.

**Deep spec:** [../founder-taste-engine/canon-and-branches.md](../founder-taste-engine/canon-and-branches.md)

---

## Canon™

### Definition

**Canon™** = the founder's approved creative direction — the **current official truth** of the company in that domain.

### What becomes Canon™

| Domain | Canon event |
|--------|-------------|
| Environment / Set™ | Founder Selects Vision™ |
| Brand identity | Brand Architect approval |
| Campaign | Campaign direction lock |
| Packaging · product | Concept approval |
| Refinement | Node approved in Asset Graph™ |
| Golden Build™ | Certification locks Canon |

### Properties

| Property | Meaning |
|----------|---------|
| **Authority** | Production truth |
| **Single active** | One Canon per domain at a time |
| **Versioned** | History chain preserved |
| **Company-scoped** | Belongs to organization |
| **Taste signal** | Strong positive learning |

---

## Alternate Branch™

### Definition

**Alternate Branch™** = rejected or exploratory concept **preserved** — not deleted.

> Rejected concepts are not failures.

### What Branches preserve

- Creative experiments
- Future inspiration
- Parallel timelines
- Alternative directions

Studio OS **remembers every branch**.

### Properties

| Property | Meaning |
|----------|---------|
| **Non-canonical** | Not production truth |
| **Preserved** | Full artifact + blueprint |
| **Searchable** | Revisit anytime |
| **Taste signal** | Nuance · exploratory dimension |
| **Promotable** | May become new Canon (ceremony) |

---

## Decision Flow

```
Concepts A · B · C presented
        ↓
Founder selects B
        ↓
B → Canon™ (company creative history)
        ↓
A · C → archived
        ↓
Orb: "Preserve A or C as Alternate Branches?"
        ↓
Founder saves branches → taste learning on all three
```

---

## Intelligence Feeding

| Outcome | Genome impact |
|---------|---------------|
| **Canon selection** | Strong positive taste weights |
| **Rejection (no save)** | Negative taste weights |
| **Branch saved** | "Also resonates" — non-binary nuance |
| **Branch → Canon later** | Taste evolution signal |
| **Canon version chain** | Company history in Memory Engine™ |

## Storage Layers

| Layer | Stores |
|-------|--------|
| **Company** | Active Canon per domain |
| **Project Genome™** | Canon ref · branch IDs |
| **Founder Taste Genome™** | Trait snapshot at lock |
| **Legacy Vault™** | Milestone Canon events |
| **Archive™** | Immutable certified Canon |

## Cross-Company Behavior

| Artifact | Travels? |
|----------|----------|
| Canon™ | **No** — company-specific |
| Alternate Branch™ | **No** — company-specific |
| Taste learning from Canon | **Yes** — feeds Founder Taste Genome™ |

Teena's Frontal Slayer Canon does not apply to NDXBOOK. Her taste learning from selecting Concept B **does**.

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Delete rejected concepts | Lose branches · lose learning |
| Multiple active Canon | Production confusion |
| Canon without taste snapshot | Lose historical context |
| Branch without blueprint | Incomplete exploration |
