## The Nine-Stage Pipeline

```
Stage 01  Creative Direction™     Genome · brief · mood · art direction · approval
    ↓
Stage 02  Asset Planning™         Environment · objects · interactions · languages
    ↓
Stage 03  Asset Generation™       Compiler packages → Generation Manager orchestrates providers
    ↓
Stage 04  Asset Review™           Quality · genome · scale · immersion · founder gate
    ↓
Stage 05  Registry™               Approved assets → permanent library
    ↓
Stage 06  Department Assembly™    Cursor wires modular scene — no baked flats
    ↓
Stage 07  Runtime™                Orb · concierges · interactions · state
    ↓
Stage 08  Validation™             Walk the Room™ · critique · performance
    ↓
Stage 09  Golden Department™      Reference implementation · inheritance law
```
