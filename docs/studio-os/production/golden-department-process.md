## Purpose

Certify Creative Direction Studio™ as the **reference implementation** — the department every future Studio OS department inherits from.

Golden status is **earned**, not declared.

## Golden Definition

A Golden Department is:

| Attribute | Meaning |
|-----------|---------|
| **Certified** | Passed full Validation Pipeline with `validationApprovalToken` |
| **Registered** | All assets in Studio Asset Registry™ as `qualityTier: golden` |
| **Documented** | Experience spec + Definition + production record complete |
| **Inheritable** | Future departments copy principles, not pixels |
| **Measurable** | Success criteria in `validation-criteria.md` — all pass |

## Inheritance Law

Every future Studio OS department **must** answer before Golden consideration:

| Question | CDS Reference |
|----------|---------------|
| Does it feel as **alive** as Creative Direction Studio™? | Emotional register · zone walk |
| Is the **hero object** declared and delivered? | Mood wall |
| Are assets **modular** — no flattened scene? | 35 independent assets |
| Does **Company Genome** change soul without layout drift? | 7 industry examples |
| Is **Walk the Room™** supported? | Path markers · critique |
| Do **concierges collaborate** without auto-approving? | AI team rules |
| Does it pass **anti-SaaS** law? | Art direction |
| Can it run the **full production pipeline** (Stages 01–09)? | This methodology |

**Inheritance is principles + schema** — not copying CDS furniture into a law office.
