## What Is a Reference Implementation™?

A **Reference Implementation™** is the official product that **validates the entire Studio OS stack** by intentionally exercising every governance artifact, validator, registry, and design principle in production.

**Experience Studio™** is that product.

---

## Golden Product™

Experience Studio™ is also the **Golden Product™** — the proving ground where foundational capabilities ship first before graduating platform-wide.

| Rule | Detail |
|------|--------|
| New Orb capabilities | Validate in Experience Studio first |
| New catalog components | VDR ratified here first |
| New Design Registry versions | Tested here first |
| New AI collaboration patterns | Reference here first |
| New accessibility patterns | Benchmark here first |

### Graduation Criteria

A capability graduates from Experience Studio to platform when:

1. Design Health™ PASS for 2 release cycles
2. Product Review Board documents the pattern
3. VDR or DR filed (as appropriate)
4. Catalog or Master Spec updated
5. At least one other product inherits successfully

## How Future Products Inherit

```
Experience Studio™ (Reference Implementation™)
        ↓
    ┌───┴───┬───────────┬──────────────┐
    ↓       ↓           ↓              ↓
Website   Campaign   Publishing   Relationship
Builder   Engine     Studio       Intelligence
(special)  (future)   (future)     (future)
```

### Inheritance Pattern

| Inherit | How |
|---------|-----|
| Product lifecycle | Product Starter Pack templates |
| Design governance | designCompliance · COMPONENT_USAGE_MAP |
| Component patterns | Same `comp-*` catalog |
| AI collaboration | Director model · approval boundaries |
| QA gates | Definition of Done · Product Health™ |
| Engineering structure | PRODUCT_FOLDER_STRUCTURE |
| Review Board | Same 10 reviews |

### Specialization Pattern

Products **specialize** — they do not fork:

| Product | Specialization |
|---------|----------------|
| Website Builder™ | Website experience type · publish pipeline depth |
| Campaign Engine™ | Marketing experience types · campaign flows |
| Publishing Studio™ | Distribution · multi-channel publish |
