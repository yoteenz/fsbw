# Director Mode™

## Definition

Director Mode is the **primary creative interaction model** of Studio World.

It governs how founders interact with every creative artifact — from logos to campaigns to rooms to products — through a single lifecycle:

```
Vision → Blueprint → Direction → Approval → Manufacturing → Verification → Living World
```

Director Mode is **not** an image editing system. It is the foundational interaction model for the future of Studio World.

## Parent relationship to Blueprint Author

Blueprint Author is formally recognized as the **planning subsystem** within Director Mode.

```
Director Mode™
├── Philosophy & Constitution
├── Directable Objects
├── Creative Workspaces (Director Studios)
├── Blueprint Author™          ← planning (shipped)
├── Construction Mode™         ← founder walkthrough (shipped foundation)
├── Manufacturing Engine™      ← factory (shipped foundation)
├── Approval Engine            ← planned
├── Iteration Engine           ← planned
├── Quality Guard              ← verification
├── Immune System              ← maintenance
└── Living World               ← deployed environment
```

Blueprint Author is **not** replaced. It is **elevated** — one department inside the larger directing company.

## Core operations

| Operation | Founder action | System response |
|-----------|----------------|-----------------|
| **Inspect** | Select object | Object Inspector opens |
| **Direct** | Replace, change material, move | Bounded manufacturing job queued |
| **Approve** | Accept blueprint | Manufacturing authorized |
| **Iterate** | Modify selected object | Object-local version bump only |
| **Verify** | Review inspection | Quality Guard + Immune System |
| **Deploy** | Accept living world | Object enters Living World runtime |

## What Director Mode is not

- Not Midjourney-style prompting
- Not Figma-style pixel editing
- Not a scene graph editor
- Not a folder tree of assets
- Not anonymous generation output
