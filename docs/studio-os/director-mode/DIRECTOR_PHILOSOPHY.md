# Director Philosophy

## The shift

### Current AI (rejected model)

```
Prompt → Generate → Hope → Edit
```

The founder describes what they want in natural language and hopes the model understood.

### Studio World (Director Mode)

```
Vision → Direct → Approve → Manufacture → Verify → Deploy
```

The founder **directs** specialized creative workers. Workers **execute** approved specifications.

## Principles

1. **The founder is never prompting AI.** The founder is directing a creative team.
2. **AI does not redesign.** AI executes bounded manufacturing jobs.
3. **Nothing exists as anonymous pixels.** Every artifact is a directable object with identity.
4. **Selection replaces prompting.** If it can be selected, it must not be described.
5. **Approval precedes manufacturing.** No AI compute without founder authorization.
6. **Iteration is object-local.** Changing a desk does not regenerate a room.
7. **Materials are inherited.** Objects reference the library; they never duplicate materials.
8. **Verification compares to Blueprint.** Immune System asks "What differs?" not "Did AI finish?"

## Founder identity

The founder feels like a **Creative Director** — not an AI prompt engineer.

Every interaction resembles directing a luxury creative agency:

- "Replace the desk" — not "generate a reception with a circular desk"
- "Change the marble" — not "make it more luxurious"
- "Swap the model" — not "use a different person in the scene"
