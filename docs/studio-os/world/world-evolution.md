# World Evolution™

**The headquarters grows as the company grows**

---

## Purpose

Studio World™ itself **evolves**. The founder should feel they are **literally building their company's world over years** — not upgrading a subscription tier.

---

## Evolution vs Events vs States

| Concept | Duration | Example |
|---------|----------|---------|
| **World State™** | Hours · days | Launch Day™ lighting |
| **World Event™** | Minutes · one-shot | Golden Build celebration |
| **World Evolution™** | Permanent | New wing unlocked |

Evolution **changes topology**. States and events **animate** existing topology.

## The Reveal Ceremony

Major evolution uses **Transitions™** — never instant map swap:

```
1. Orb: "A new wing is ready."
2. Walk to construction veil / curtain
3. Transition: Gallery Walk™ or Executive Corridor™
4. Veil opens — architecture revealed
5. Arrival Sequence™ into new Set™
6. Optional World Event™ · Legacy exhibit queued
```

Small evolutions (new object · decor) may be **ambient** without ceremony.

## Visual Growth Language

| Maturity | Architectural expression |
|----------|-------------------------|
| **Startup** | Single building · few Sets™ · intimate |
| **Growth** | Wings · courtyard · visible expansion scars |
| **Established** | Multi-floor · skyline silhouette |
| **Enterprise** | Campus · multiple structures |
| **Holding** | Interconnected lots · skybridges |
| **Legacy-rich** | Archive wing prominence · museum density |

Company Genome™ modulates materials — evolution adds **structure**.

---

## Topology Versioning

```
worldTopology v1  — founding HQ
worldTopology v2  — + Marketing wing
worldTopology v3  — + Finance vault floor
worldTopology v4  — skybridge to second brand lot
```

| Rule | Behavior |
|------|----------|
| Version bump | Migration script for edges · transitions |
| Old transitions | Remap or deprecate with Orb notice |
| World Memory™ | Migrate anchors · never silent loss |
| Legacy | Prior topology photos in Archive™ |

---

## Deprecation & Relocation

Departments rarely **delete** — they **graduate** to Legacy:

| Action | World response |
|--------|----------------|
| Retire Set™ | Door sealed · Hall of Legacy™ link |
| Relocate | New edge · redirect transition |
| Merge departments | Combined Set™ · wing consolidation |

Founder always walks the change — not a settings toggle.

## Relationship to Monetization

| Monetization layer | Evolution expression |
|--------------------|---------------------|
| Headquarters License | Base lot size |
| Department Packs | New wings · Sets™ |
| Digital Workforce | Staff presence in evolved wings |
| Marketplace | Architectural SKU installs |

**Never** "unlock feature." Always **"open wing."**

---

## Anti-Patterns

| Anti-pattern | Why |
|--------------|-----|
| Instant wing pop-in | Breaks journey philosophy |
| Evolution without map update | Spatial lie |
| Shrinking HQ silently | Memory loss |
| Evolution = UI tab added | Not spatial |
| Reset topology on reinstall | Violates World Rules™ |
