# Sets™ Philosophy — Studio OS World-Building

**Version:** 1.0.0  
**Status:** Canonical world-building concept  
**Phase:** Philosophy & architecture (post-platform freeze)  
**Scope:** All Studio OS experiences — departments · headquarters · marketplace

---

> **Founders do not navigate software. Founders walk through their company.**

---

## Mission

Studio OS should **no longer think** in terms of:

| Forbidden vocabulary | Replacement |
|---------------------|-------------|
| Pages | **Sets™** |
| Screens | **Sets™** |
| Views | **Sets™** |
| Dashboards | **Sets™** |
| Tabs | **Spatial zones within Sets™** |

Everything inside Studio OS is a **Set™** — a physical place where work happens.

---

## What Is a Set™?

A Set™ is inspired by:

- **The Movies** — production environments built for story
- **Hollywood backlots** — walkable lots of distinct worlds
- **Film production** — every scene has a built environment
- **Theme parks** — immersive lands with consistent world language
- **Game worlds** — persistent spaces with identity and behavior

A Set™ is **not** a React route.  
A Set™ is **not** a CMS page.  
A Set™ is a **built environment** — architecture · lighting · props · mood · soundtrack · AI · tools · personality.

---

## Hollywood Studio Lot Metaphor

Think of Studio OS headquarters as a **Hollywood studio lot**.

| Lot concept | Studio OS equivalent |
|-------------|---------------------|
| Soundstage | Department boundary |
| Set on stage | **Set™** |
| Backlot walkway | Headquarters circulation |
| Set dressing | Interactive objects · ambient storytelling |
| Director | Founder |
| Crew | AI employees · Orb · concierges |
| Call sheet | Project Genome™ · production queue |

Each soundstage is different.  
Each set has its own architecture · lighting · props · mood · soundtrack · AI · tools · personality.

**Studio OS should feel exactly the same.**

## Department → Set Relationship

**Departments are organizations.**  
**Sets™ are the physical environments inside those departments.**

```
Department (organization)
    └── Set™ (physical environment where work happens)
            └── Zones · objects · hero asset · AI · Orb
```

A department may contain **one primary Set™** (alpha model) or multiple Sets™ in future expansion.

## World Building

Studio OS is **one connected headquarters**.

Walking from one Set™ to another should feel like **moving through the same building** — not opening another page.

| Principle | Meaning |
|-----------|---------|
| **Shared architectural language** | Marble · editorial thresholds · Orb · circulation grammar |
| **Unique Set personality** | Each Set™ expresses department emotion |
| **Continuous lot** | No hard cuts · no white admin frames between Sets™ |
| **Doorway transitions** | Department fade → arrival in next Set™ |

**Detail:** [headquarters-layout.md](./headquarters-layout.md)

## Founder Language (Success Criteria)

Founders should naturally say:

- *"I'm walking over to Production."*
- *"I'm heading into the Creative Atelier."*
- *"Let's meet inside the Discovery Lab."*
- *"The Marketing War Room is ready."*
- *"The Hall of Legacy has been updated."*

These must feel like **real places** inside their company's headquarters.
