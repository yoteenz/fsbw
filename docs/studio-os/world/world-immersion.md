# World Immersion™

**Continuous headquarters — not page loads**

**Version:** 1.0.0  
**Status:** Canonical immersion architecture (docs only)  
**Parent:** [Living Sets™](./living-sets.md)

---

## Purpose

When a founder leaves one department and enters another, they must **not** feel like another page loaded.

They must feel like they **physically walked through headquarters** into another department.

World Immersion™ defines the **continuity of place** across Studio World™.

---

## Core Law

```
MOVEMENT IS PART OF THE STORY
```

Doors · hallways · elevators · glass corridors · reception · ambient sounds · employees.

The headquarters remains **one connected property**.

---

## The Failure Mode

| SaaS pattern | Studio World™ pattern |
|--------------|------------------------|
| Route change · instant swap | Transition™ · journey · arrival |
| Sidebar teleport | Walk · corridor · threshold |
| Full-screen loader | World Streaming™ · visible approach |
| Isolated white page | Glass wall · adjacent department audio |
| Browser back | Exit portal · lobby return |
| Tab switch | Wing change · floor change |

If the founder senses **software navigation**, immersion failed.

## Immersion Layers

### Layer 1 — Topological Continuity

Headquarters is a **graph of places** — not a route table.

```
Executive Lobby™
    │ corridor (marble · muffled meeting)
    ▼
Creative Direction Studio™  ← Living Set™
    │ skybridge (glass · city view)
    ▼
Marketing War Room™
    │ elevator (brass · floor indicator)
    ▼
Production Floor™
```

**Source:** [Headquarters Layout™](./headquarters-layout.md) · [Transitions™](./transitions/README.md)

---

### Layer 2 — Sensory Continuity

| Sense | Continuity rule |
|-------|-----------------|
| **Sight** | Shared time-of-day · weather · campus beyond glass |
| **Sound** | Cross-fade ambient — never hard cut to silence |
| **Scale** | Corridor proportion matches destination grandeur |
| **Materials** | HQ-wide material family — departments vary expression |
| **Life** | Employees · carts · distant figures — lot stays busy |
| **Orb** | Present across transitions — host continuity |

---

### Layer 3 — Living Set™ Continuity

Each department is a **Living Set™** — but expression shares HQ DNA:

| Shared | Per-department |
|--------|----------------|
| Campus beyond windows | Industry envelope |
| World State™ (morning · launch day) | Company Expression |
| Founder presence | Department function |
| Archive™ accessibility | Framework zones |

Switching from Frontal Slayer™ CDS to NDX™ CDS is **not** a theme swap — it is **walking to a different wing** that belongs to a different company expression while headquarters topology persists.

## Department Exit & Entry

### Leaving a Living Set™

1. Founder approaches **exit threshold** (door · portal · corridor)
2. Ambient audio **cross-fades** — destination corridor bleeds in
3. Camera **follows movement** — never cut
4. **World Memory™** persists room state (Mood Wall · timeline position)
5. Orb optional line — *"Marketing is through the glass corridor."*

### Entering a Living Set™

1. **Threshold moment** — door weight · light shift
2. **Arrival Zone™** — never full room reveal immediately
3. **Transformation Engine™** expression visible before UI copy
4. Orb host line — company-aware · continuity-aware
5. **Idle Life™** already running — room was alive before founder arrived

**Source:** [Creative Direction Studio™ Arrival Zone™](../creative-direction-studio/arrival-zone.md)

## World Streaming™

No black full-screen loaders between departments.

| Technique | Purpose |
|-----------|---------|
| **Approach pre-load** | Destination set warms during corridor |
| **Visible transition** | Founder sees where they are going |
| **Persistent shell** | HQ chrome · time · weather never unmounts |
| **Audio cross-fade** | Continuous sound field |
| **State handoff** | World Memory™ · Orb context carry |
