# Company Expression System™

**How every company inhabits the same framework differently**

**Version:** 1.0.0  
**Status:** Canonical expression architecture (docs only)  
**Parent:** [Living Sets™](./living-sets.md)

---

## Purpose

Define how **Company Genome™** becomes **recognizable physical place** — so a founder's headquarters never feels like generic Studio OS, and an observer identifies the company without seeing a logo.

The Company Expression System™ is the **translation layer** between organizational identity and environmental language.

---

## Core Law

```
SAME FRAMEWORK  +  DIFFERENT EXPRESSION  =  YOUR HEADQUARTERS
```

Every company uses identical department topology.

Every company speaks a **unique environmental dialect**.

## Expression vs Skinning

| Skinning | Company Expression |
|----------|-------------------|
| CSS variables | Architecture regeneration |
| Logo swap | Material · prop · display grammar |
| Dark mode | Lighting physics · atmosphere |
| Component theme | Furniture · equipment · audio |
| Same room mesh | Different envelope · scale · story |

**Test:** Remove all text and logos. Can you still identify the company?

If no → expression failed.

## Blind Shoulder Benchmark

Success requires passing the **shoulder test**:

1. Observer sees founder's screen — no logos · no copy
2. Within 3 seconds, observer names the company
3. Observer describes *place* — not *software*

| Pass | Fail |
|------|------|
| *"That's the hair luxury brand"* | *"That's a nice dashboard"* |
| *"That's the tech media company"* | *"Is that dark mode?"* |
| *"That's a law firm HQ"* | *"That looks like Notion"* |
