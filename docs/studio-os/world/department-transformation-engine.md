# Department Transformation Engine™

**Intelligence layers → physical Living Set™**

**Version:** 1.0.0  
**Status:** Canonical generation pipeline (docs only)  
**Parent:** [Living Sets™](./living-sets.md)

---

## Purpose

Define how Studio World™ converts permanent intelligence into a **regenerated department environment** — not a theme, not a skin, not a component variant.

The Department Transformation Engine™ is the **compiler** between understanding and place.

---

## Core Law

```
INTELLIGENCE  →  EXPRESSION  →  PLACE
(understanding)   (design)       (Living Set™)
```

If a layer is missing, the engine **degrades gracefully** — never invents identity the founder has not earned.

## Layer Responsibilities

### 1 — Company Genome™

**Answers:** *What makes this business unique?*

| Influences | Examples |
|------------|----------|
| Industry envelope | Law chamber vs culinary studio vs luxury atelier |
| Brand materials | Marble/chrome vs walnut/glass vs stainless/white |
| Cultural signals | Editorial fashion vs tech museum vs hospitality warmth |
| Product presence | Wig displays · UX prototypes · menu boards · case files |
| Ambient story | What artifacts belong on walls and shelves |

**Source:** [Company Genome™](../intelligence/company-genome.md)

## Compilation Pipeline

```
1. RESOLVE INTELLIGENCE
   Load genomes · department DNA · project · stage · direction

2. MERGE WEIGHTS
   Company (identity) · Taste (style) · Founder (leadership)
   Department (topology) · Project (now) · Stage (time)

3. GENERATE ENVIRONMENT DNA™
   Full regeneration manifest — not theme tokens

4. PRESERVE FRAMEWORK
   Lock invariant zones · objects · workflow graph

5. REGENERATE SURROUNDING WORLD
   Architecture · materials · lighting · props · audio · life

6. APPLY SET CONTINUITY™
   Inject historical artifacts · milestone props

7. REGISTER LIVING SET™
   Version · lineage · Archive™ eligibility

8. BRIEF ORB™
   Host explains transformation in founder language
```

## Modulation Rules

| Rule | Law |
|------|-----|
| **Framework immutability** | Arrival Zone™ · Orb™ · Story Table™ · etc. never removed |
| **Expression supremacy** | Company + Taste override generic department defaults |
| **Stage accumulation** | Growth adds — does not erase Blueprint history |
| **Project overlay** | Temporary props clear when project archives |
| **Taste veto** | Taste Genome can reject identity-conflicting materials |
| **Founder ceremony** | Founder Genome sets approval ritual weight |
| **No anonymous HQ** | Unresolved Company Genome → engine waits · never generic glass |

| Field | Orb uses for |
