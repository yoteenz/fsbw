# World Rules™

**The operational laws of a persistent headquarters**

---

## Purpose

Studio World™ is **persistent**. These rules govern what "persistent" means in practice — for founders, departments, AI, and systems.

---

## Rule 1 — The World Never Resets

The headquarters **never** returns to a blank default because:

- The founder closed a tab
- The session expired
- The founder navigated away
- A deploy occurred (runtime may update; **world state** restores)

| Persists | Does not reset |
|----------|----------------|
| Set™ object positions · notes · mood boards | Founder work-in-progress |
| Last known location in HQ | Walking position |
| Orb conversation context | Recent dialogue thread |
| Generation queue progress | In-flight jobs |
| World State™ | Active Launch Day™ · Celebration™ |
| Lighting time-of-day | Natural cycle position |

**Detail:** [world-memory.md](./world-memory.md)

---

## Rule 2 — The World Continues Without the Founder

When the founder is away:

| Continues | Behavior |
|-----------|----------|
| **Departments** | Operational logic · scheduled tasks |
| **Projects** | Progress states update from real data |
| **AI employees** | Background work · queued recommendations |
| **Generation jobs** | Render · validate · register |
| **Ambient life** | Idle Life™ in active/nearby Sets™ |
| **Lighting** | Time-of-day cycle · World State™ overlays |
| **Displays** | Metrics · tickers · mood walls (data-driven) |

The lot does not **pause**. It **dims** distant wings and **activates** what matters.

**Detail:** [../foundational-experience-systems/idle-life.md](../foundational-experience-systems/idle-life.md)

---

## Rule 3 — Every Entity Has a Place

| Entity | Must resolve to |
|--------|-----------------|
| Department | Wing · floor · map node |
| Set™ | Physical environment on lot |
| Project | Anchor object in a Set™ |
| AI concierge | Station · desk · Orb-adjacent role |
| Approval | War room · vault · executive surface |
| Marketplace Pack™ | Install target on topology graph |
| Archive entry | Hall of Legacy™ · The Archive™ |

**No orphan features.** If it cannot be placed, it is not Studio World™-complete.

---

## Rule 4 — Movement Is Continuous

Transitions between Sets™ obey [Transitions™](./transitions/README.md) law:

- No freeze
- No fade to black
- No spinners
- Founder keeps moving while next Set™ streams

World Streaming™ applies at umbrella level: [world-streaming.md](./world-streaming.md)

---

## Rule 5 — State Cascades From World to Set

**World States™** influence everything below:

```
World State™ (global)
    → Headquarters atmosphere
    → Transition DNA™ variants
    → Set™ lighting/audio overlays
    → Orb dialogue tone
    → AI employee behavior
    → Ambient storytelling density
```

Local Set™ state **never overrides** global crisis/safety states without explicit founder override.

**Detail:** [world-states.md](./world-states.md)

---

## Rule 6 — Memory Is Append-Only for Legacy

World Memory™ **updates** work-in-progress freely.

**Legacy surfaces** (Archive™ · Hall of Legacy™ · Founder Chronicle™) are **append-only** — history is not rewritten.

| Mutable | Immutable |
|---------|-----------|
| Mood board order | Certified™ milestone exhibits |
| Camera last position | Founding Charter |
| Draft founder notes | Published Legacy™ artifacts |

---

## Rule 7 — Genome Shapes the World, Not the Reverse

**Company Genome™** · **Project Genome™** · **Set DNA™** flow **down** into Studio World™ expression.

The world engine **never** mutates genome without founder-approved evolution paths.

---

## Rule 8 — Scale Without Philosophy Change

Studio World™ supports growth from solo founder to enterprise campus **without** changing rules:

| Scale | Same philosophy |
|-------|-----------------|
| Single-founder HQ | One lot · few Sets™ |
| Agency | Multiple client wings · shared services |
| Holding company | Campus graph · skybridges between buildings |
| Enterprise | Floors™ · international nodes |
| Future multiplayer | Shared presence · same persistence rules |

Topology expands. Rules do not weaken.

---

## Rule 9 — Marketplace Installs Into the World

Marketplace content is not a "theme toggle."

| Install type | World integration |
|--------------|-------------------|
| Set™ pack | New or replacement destination |
| Transition™ SKU | Edge on topology graph |
| Decor collection | Prop layer across Sets™ |
| Seasonal event | World State™ + prop overlay |
| Wing pack | New HQ graph node |

**Detail:** [marketplace-set-system.md](./marketplace-set-system.md) · [transitions/marketplace-transition-system.md](./transitions/marketplace-transition-system.md)

---

## Rule 10 — Evolution Is Visible

When the company grows, the founder **sees** it:

- New wings appear on the map
- Skyline changes
- Courtyards open
- Departments relocate
- Archive expands

Growth is not a settings panel. Growth is **architecture**.

**Detail:** [world-evolution.md](./world-evolution.md)

---

## Enforcement Summary

| Violation | Severity |
|-----------|----------|
| Session-only project state | Critical — breaks World Memory™ |
| Pausing ambient life on nav | Critical — breaks Rule 2 |
| Black-frame transition | Critical — breaks Rule 4 |
| Feature with no spatial anchor | Major — breaks Rule 3 |
| Rewriting legacy exhibit | Critical — breaks Rule 6 |
| Silent genome mutation | Critical — breaks Rule 7 |
