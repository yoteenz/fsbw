# Headquarters Layout — Connected Studio Lot

**Version:** 1.0.0  
**Status:** Canonical world-building spec  
**Scope:** One connected headquarters · all Sets™ on same lot

---

## Purpose

Studio OS should feel like **one connected headquarters**.

Walking from one Set™ to another should feel like **moving through the same building** — not opening another page.

Every Set™ belongs to the **same architectural language** while expressing its own personality.

## Shared Architectural Language

All Sets™ share headquarters DNA — **lot consistency**:

| Element | Shared language |
|---------|-----------------|
| **Thresholds** | Marble · brass · editorial portals between Sets™ |
| **Circulation** | Corridors · not page transitions |
| **Typography in space** | Futura · Grace — environmental not UI chrome |
| **Orb** | Present across Sets™ — behavior modulates per Set DNA™ |
| **Floor grammar** | Stone · wood · editorial materials family |
| **Audio handoff** | Crossfade ambient — not silence between Sets™ |
| **Company Genome™** | Materials · voice modulate all Sets™ consistently |

## Transition Between Sets™

**Forbidden:** Hard cut · white admin frame · instant spawn in center.

**Required:** Doorway transition sequence.

```
Founder in Set A
    ↓
Exit verb or corridor walk
    ↓
Set A fades · corridor glimpse (shared lot language)
    ↓
Arrival Sequence™ for Set B begins (exterior → doors → glide)
    ↓
Set B ACTIVE
```

Transition duration: 2–5s between Sets™ · full Arrival for first entry per session.

Cross-ref: [Arrival Sequence™](../foundational-experience-systems/arrival-sequence.md)

## Headquarters Zones (Non-Set Spaces)

| Space | Role | Is Set™? |
|-------|------|----------|
| **Arrival Plaza** | First headquarters impression | Circulation — not work Set™ |
| **Executive Corridor** | Connects wings | Circulation |
| **Mission Control** | Status overview · doorway layer | Hub — not department Set™ |
| **Corridors** | Walk between Sets™ | Circulation |
| **Archive Wing threshold** | Lighting · music shift before Hall of Legacy™ | Transition |

Mission Control is the **doorway/navigation layer** — founder overview, not a replacement for Sets™.

## Spatial Persistence Across Lot

| Persisted | Scope |
|-----------|-------|
| Last Set™ visited | Headquarters |
| Set™ internal state | Per Set™ per project |
| Corridor direction memory | Optional breadcrumb — environmental not textual |
| Generation jobs | Continue across Set™ transitions |

World Persistence™ applies per Set™ and at headquarters level.

## Mobile Headquarters

On mobile, the lot model holds:

| Principle | Mobile expression |
|-----------|-------------------|
| Full-viewport Set™ | No admin card frame |
| Horizontal corridor pan | Optional between wing zones |
| One Set™ at a time | Full immersion |
| Transition | Fade + short arrival — not tab switch |

## Genome Adaptation Across Wings

Company Genome™ modulates **all wings** consistently:

| Genome domain | Lot-wide effect |
|---------------|-----------------|
| `materialLanguage` | Shared floor · wall family |
| `lightingStyle` | Key light warmth baseline |
| `voice` | Orb + concierge across Sets™ |
| `editorialDirection` | Contrast · drama baseline |

Set DNA™ modulates **per room** within genome baseline.
