# Transition Philosophy™ — Master Specification

**Version:** 1.0.0  
**Status:** Canonical  
**Schema:** `studio.transitions.v1`  
**Tagline:** *The Journey Between Sets™*

---

## Purpose

**Transitions™** govern how founders move between Sets™ inside one connected Headquarters.

A founder should feel like they **traveled** — never like they **changed pages**.

---

## Core Laws

### Law 1 — Every Destination Deserves a Journey

The transition is not overhead. It is **story**.

A hallway · elevator · bridge · staircase · vault corridor · glass walkway · rooftop terrace — each tells part of the company's narrative.

### Law 2 — Departments Do Not Simply Appear

| Forbidden | Required |
|-----------|----------|
| Instant spawn in Set center | Arrive via threshold |
| Hard cut between routes | Continuous environmental motion |
| Tab switch metaphor | Physical movement metaphor |

### Law 3 — One Continuous Headquarters

The illusion of **one living building** must never break.

Founder continues moving while next Set™ streams in. World does not pause.

### Law 4 — Transitions Are Not Loaders

| Loader pattern | Transition pattern |
|----------------|-------------------|
| Fade to black | Lighting handoff |
| Spinner | Ambient motion continues |
| Freeze | Walk · elevator · glide continues |
| Progress bar | Environmental progress (doors opening · floors passing) |

### Law 5 — World Continues During Movement

| Continues while founder travels |
|--------------------------------|
| People working (background) |
| Doors opening |
| Elevators traveling |
| Lights changing |
| Displays updating |
| Ambient activity |
| Idle Life™ behaviors |
| Generation queue progress |

Nothing pauses because the founder is moving.

---

## Transitions™ vs Arrival Sequence™

| Concept | Scope |
|---------|-------|
| **Arrival Sequence™** | Entering a **Set™** — doors · glide · Orb wake · interaction unlock |
| **Transitions™** | **Journey between** Sets™ (or into Headquarters) |

Arrival Sequence™ is a **specialized transition** — the final beats of entering a destination Set™.

All arrivals are transitions. Not all transitions are full Set arrivals.

**Detail:** [arrival-system.md](./arrival-system.md)

## Transition Graph

Headquarters is a **graph** of Sets™ connected by Transition edges:

```
Node = Set™
Edge = Transition™ (typed: Walk · Elevator · Skybridge · …)
Weight = duration · emotion · storytelling density
```

## Transition DNA™

Every transition inherits context and adapts:

- Company Genome™
- Department personality
- Architectural language
- Founder Journey™ stage
- Time of day
- Business state (Launch Day™ · Celebration™ · Crisis™)
- Adaptive Walk™ routing

## The Orb During Transitions

The Orb becomes **guide** — not loader mascot.

Transitions are opportunities for **contextual conversation**:

- *"Creative Direction has prepared new concepts."*
- *"Marketing has requested approval."*
- *"We've reached the Finance Vault."*

**Detail:** [orb-guidance.md](./orb-guidance.md)

## Marketplace Vision

Transitions™ become **Marketplace assets** — Luxury Marble Hallway™ · Glass Skybridge™ · Executive Elevator™ · etc.

Headquarters share one engine · unique architectural identity via purchased transition packs.

**Detail:** [marketplace-transition-system.md](./marketplace-transition-system.md)

## Anti-Patterns

| Anti-pattern | Why forbidden |
|--------------|---------------|
| React Router instant swap | Breaks world illusion |
| Full-screen loading overlay | Loader not transition |
| Silent teleport | No journey · no story |
| Same transition for all edges | Each path should feel intentional |
| Pause Idle Life during walk | World must stay alive |
| Admin white frame between Sets™ | Breaks Headquarters continuity |
