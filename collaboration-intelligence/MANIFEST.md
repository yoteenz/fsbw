## Memory maturity levels

Every entry in this capsule should be tagged (in prose or tables) with one maturity level:

| Level | Meaning |
|-------|---------|
| **Experimental** | Explored; not approved for implementation |
| **Historical** | True at a point in time; may be superseded |
| **Working** | Active assumption in current collaboration |
| **Approved** | Founder-approved policy or pattern |
| **Canonical** | Binds future work; do not contradict without override |
| **Deprecated** | Replaced; retained for historical lookup only |

See `MEMORY_MATURITY.md` for application rules.
