# Studio World Canon™

**Four-layer governance hierarchy · Ratified 2026-07-08**

---

## Hierarchy

```
Design Principles™        — philosophy (north star)
        ↓ inherits
World Physics™            — natural laws (gravity)
        ↓ inherits
Constitutional Law™       — governance (legislation)
        ↓ inherits
Implementation Standards™ — engineering (handbook)
        ↓
Code → Runtime → Experience
```

| Layer | Changes | Governs | Folder |
|-------|---------|---------|--------|
| **Design Principles™** | Almost never | What founders *feel* | `knowledge/canon/design-principles/` |
| **World Physics™** | Almost never | What is *possible* | `knowledge/canon/physics/` |
| **Constitutional Law™** | Rarely | What is *allowed* | `knowledge/canon/constitution/` |
| **Implementation Standards™** | Continuously | How we *build* | `knowledge/canon/implementation-standards/` |

**Design Principles guide Physics. Physics constrains Constitution. Constitution guides Standards.**
