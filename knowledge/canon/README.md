# Studio World Canon™

**Three-tier hierarchy · Ratified 2026-07-08**

---

## Hierarchy

```
FOUNDATIONAL PHYSICS™     — immutable natural laws (gravity)
        ↓ constrains
CONSTITUTIONAL LAW™       — behavioral governance (legislation)
        ↓ guides
IMPLEMENTATION STANDARDS™ — engineering patterns (evolves continuously)
```

| Tier | Changes | Governs | Folder |
|------|---------|---------|--------|
| **Foundational Physics™** | Never | What is *possible* | `knowledge/canon/physics/` |
| **Constitutional Law™** | Rarely | What is *allowed* | `knowledge/canon/constitution/` |
| **Implementation Standards™** | Continuously | How we *build* | `knowledge/canon/implementation-standards/` |

**Physics never changes. Constitution changes rarely. Implementation Standards evolve continuously.**

---

## Relationship

- **Constitution** cannot violate **Physics** — legislation cannot repeal gravity.
- **Implementation Standards** implement Physics and Constitution in code, CI, and repository structure.
- **World Graph™** registers all three tiers as nodes with `depends-on` / `implements` edges.
- **Documentation** is a projection — graph nodes are authoritative.

---

## Long-term vision

Studio World should feel internally consistent — every department, company, scene, AI, marketplace product, innovation, and collaboration obeys the same invisible laws. The founder should never have to remember them manually. World Graph, Canon, and Physics layers enforce them automatically.
