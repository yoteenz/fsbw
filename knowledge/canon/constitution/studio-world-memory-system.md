# Studio World Memory System™

**Article:** K23  
**Layer:** Constitutional Law™  
**Status:** Accepted  

---

## Law

Studio World must distinguish between Conversation™, Knowledge™, History™, and Canon™.

Conversations are history. Knowledge is understanding. Canon is approval.

---

## Enforcement

- Significant design conversations are preserved exactly in Conversation Archive™.
- Knowledge Ingestion™ extracts decisions, principles, updates, ADR candidates, prompt standards, implications, opportunities, and open questions.
- Architect Review™ is required before extracted knowledge enters the Knowledge Core™.
- Extraction reports are not canon until reviewed.
- Memory Graph™ connects conversation → extraction → founder approval → Knowledge Core → ADR → implementation → historical impact.
- Architect’s Memory™ stores recurring architectural preferences as living principles.
