# World Graph Is Truth™

**Constitutional Article · Studio World Knowledge System**

---

## Article

The **World Graph™** is the single canonical source of truth for Studio World civilization.

All surfaces are **projections** generated from the graph:

- Studio World Bible™
- Knowledge Library™
- Studio World Atlas™
- Orb Archivist™
- Dependency Maps™
- Engineering documentation
- Search indices
- Museum exhibits

No projection may override the graph. No projection may become a competing source of truth.

---

## Corollaries

1. **Documentation-first** means graph-first — prose is a projection or canon body attached to nodes.
2. **Knowledge objects** are one node type in the civilization graph, not a separate system.
3. **Implementation sprints** must register nodes and edges before code ships.
4. **Historical nodes** are never deleted — only transitioned to `historical` or `legacy` lifecycle.
5. **motherboard** and agent memory sync summaries *into* the graph — they do not define canon.
