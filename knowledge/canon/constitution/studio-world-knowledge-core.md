# Studio World Knowledge Core™

**Article:** K22  
**Layer:** Constitutional Law™  
**Status:** Accepted  

---

## Law

Studio World must become its own memory.

The Knowledge Core™ is the canonical internal memory system for decisions, principles, canon, experiments, prompt standards, architectural consistency, and system evolution.

---

## Enforcement

- Every major prompt that changes Studio World creates a Knowledge Entry.
- Every Knowledge Entry receives exactly one canonical status.
- Only Canon™ entries may influence future architecture automatically.
- Major revisions create new versions; previous versions are preserved.
- Knowledge Entries compile into the World Graph™ as `knowledge-object` nodes.
- Knowledge must be searchable by relationship, not browsed only through folders.
- Architect's Memory™ preserves architectural consistency, not personal conversation memory.
