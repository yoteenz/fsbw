# Design Principles™

**Layer 1 governance · Studio World philosophy**

| # | Principle | Summary |
|---|-----------|---------|
| 1 | Immersion Over Pages™ | Physical destinations, not webpages |
| 2 | World First™ | Connected places in one living world |
| 3 | Reuse Before Regeneration™ | Reuse assets before generating |
| 4 | Memory Before Intelligence™ | Understand itself before reasoning |
| 5 | Progressive Disclosure™ | Reveal complexity when useful |
| 6 | Everything Has A Home™ | Every feature has a place |
| 7 | Beauty Through Function™ | Elegant and purposeful |
| 8 | Founders Build Worlds™ | Amplify creativity, not admin |
| 9 | Hero Objects Over Icons™ | Collectible living artifacts, not software iconography |

**Code:** `src/studio-os-core/design-principles/principles.ts`

*Design Principles guide every architectural decision when multiple valid solutions exist.*
