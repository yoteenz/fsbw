# Relationship to AI Context Capsule™

Studio OS maintains **three complementary exports**. None replaces the others.

| Dimension | Context | DNA | Founder Intelligence |
|-----------|---------|-----|----------------------|
| **Question** | What is true? | How to decide? | Why we exist? |
| **Reader order** | 1st | 2nd | 3rd |

---

## Analogy

- **Context Capsule** = operational briefing + map of the territory  
- **DNA Capsule** = constitution + design constitution + decision heuristics  

Git clones code. Together, the capsules clone **organizational understanding**.

---

## When to update each

| Trigger | Update Context | Update DNA |
|---------|----------------|------------|
| Feature shipped | ✓ | Only if principle emerged |
| New blocker | ✓ | — |
| Founder states recurring preference | — | ✓ append + version |
| Canon approved | ✓ registry sync | ✓ CANON_REGISTRY |
| Vision brainstorm (unapproved) | — | ✗ not yet |

---

## Single rule

**Never implement from DNA alone without Context.**  
**Never implement from Context alone without DNA alignment on taste, canon, and quality.**

---

*Pair both capsules for every high-stakes AI onboarding.*
