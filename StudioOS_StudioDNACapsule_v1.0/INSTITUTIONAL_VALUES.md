# Institutional Values

**Capsule:** Studio DNA Capsule 1.0.0  
**Scope:** Enduring principles that outlive individual features and sprints.

---

## Principles

### Knowledge compounds

Every expert interview, approved lesson, and documented decision increases organizational capability. Systems must **preserve and connect** knowledge — not reset each session.

### Institutional memory is an asset

Motherboard, capsules, canon registry, and Knowledge Vault exist because **re-explaining is waste**. Memory is infrastructure, not documentation debt.

### Experts should be amplified, not replaced

Expert Capture, Trust Framework, and Institute interviews honor human judgment. AI assists transcription and structure; **experts approve** what enters training.

### Trust is a product feature

Private invites, protection cards, agreements, PIN gates, and calm unavailable states treat trust as **designed**, not assumed.

### Education is infrastructure

Studio Institute is woven through the organization — not a bolt-on LMS. Learning lives where work lives.

### Transparency builds confidence

Autosave status, progress percentages, canon maturity labels, and documented-vs-inferred onboarding reduce anxiety and hidden state.

### Great systems preserve context

Resume links, invite tokens bound to sessions, dual capsules (Context + DNA), and audit logs — context survives browser close and agent handoff.

### Great platforms outlive individual conversations

Studio OS is built for **decades** — infill districts, not redesigns. Platforms absorb new orgs, professions, and domains without rewrite.
