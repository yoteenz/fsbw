# Communication DNA

**Capsule:** Studio DNA Capsule 1.0.0  
**Scope:** How the founder prefers to collaborate with AI and production contributors.

---

## Sprint and delivery preferences

### Comprehensive production-ready Composer sprints

High-priority work arrives as **structured sprints** with phases, success criteria, and explicit non-goals (“do not redesign interview intelligence”). Agents implement completely — build, test, document, single deploy.

### Prompts inside copyable code blocks

Formal sprint specs use fenced code blocks for easy copy into Composer. Sections numbered; scope boundaries explicit.

### Professional formatting for formal correspondence

Invitation messages, trust copy, and owner-facing tools use **complete sentences**, calm tone, no jargon — DocuSign/Loom/Notion Invite quality, not Google Form.

### Explicit separation: documented fact · inference · unknown

Onboarding reports, handoffs, and agent replies label what is **in the capsule**, **inferred**, or **unknown**. Guessing is failure mode.

### Clear success criteria

Sprints end with checklists — not “done when it feels done.” Each criterion is verifiable.

### Minimal ambiguity

Route names, env vars, and file paths stated fully. “The dashboard” is insufficient — name the route.

### Deterministic onboarding

AI Context Capsule + Studio DNA Capsule + ONBOARDING_REPORT protocol — new agents reconstruct state without re-interviewing the founder.

### Teaching alongside implementation

Agents explain tradeoffs, document in motherboard, and leave the repo **more legible** than they found it.

---

## Motherboard and memory

- `motherboard/MEMORY.md` — conversation outcomes, append-only  
- `motherboard/CORE.md` — permanent stack/flow facts  
- Auto-add after completed tasks; one commit + push per user request on `master`  

---

## Git and deploy communication

- Work on **`master`** directly (no feature branches unless explicitly requested)  
- **One Vercel deploy per completed task** — MEMORY and code in same commit  
- Commit messages: complete sentences, descriptive  

---

## Tone

Direct, professional, respectful of founder time. No engagement baiting. Proportional response length. High-quality prose — not telegraphic bullet chains in user-facing summaries.

---

*Communication DNA applies to agents, docs, and expert-facing copy alike.*
