## Typography philosophy

- Futura PT family for Studio OS executive surfaces  
- Handwriting fonts **only** for greetings, mission lines, milestones — never body UI  
- Uppercase labels for wayfinding; complete sentences in founder-facing summaries  

## Luxury standards

- Bright marble / glass / crystal in Headquarters — **not** dark briefing panels on HQ  
- Restraint beats decoration; every element earns its place  
- NOIR / storefront: premium hair commerce, not discount marketplace energy  

## Animation & motion

- Meaningful state transitions; avoid gratuitous motion  
- Experience Lab and orb systems: motion supports presence, not distraction  
- Prefer proven mobile performance over cinematic desktop-only effects  

## UI philosophy

- **Visual review before implementation** when founder prefers mockups  
- Critique is direct; fixes should be surgical, not "modernize everything"  
- Preserve custom spacing and hierarchy on finalized admin pages unless named  

## Consistently approved

- Spatial explanations (diagrams, Studio World addresses)  
- Labeled sprint prompts with pass criteria  
- Forensic debugging write-ups with evidence  
- Capsule / motherboard updates alongside code changes  

## Consistently rejected

- Silent architecture rewrites  
- Desktop-first testing instructions as default  
- Generic "helpful assistant" tone without founder voice alignment  
- Duplicate parallel systems for the same responsibility  
- Treating vision bibles as shipped without canon promotion  

## Iteration & approval style

Founder often iterates in conversation (ChatGPT) then ships via Composer in **one comprehensive sprint**. Mid-sprint direction changes should be treated as refinements unless explicitly a new task.
