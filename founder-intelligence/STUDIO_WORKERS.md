## Lifecycle stages

| Stage | Description |
|-------|-------------|
| **Recruitment** | Founder selects role from pack or custom concierge |
| **Onboarding** | Shadow Mode™ — Observe → Recommend → Assist → Automate |
| **Training** | Profession Brain™ + Studio Institute paths |
| **Knowledge transfer** | Brain updates, Wisdom Capture™, Memory Engine™ |
| **Apprenticeship** | Low-confidence tasks with human approval |
| **Promotion** | Higher autonomy when confidence thresholds met |
| **Continued education** | Brain sync when regulations/processes change |
| **Specialization** | Department-specific concierges (Marketing, Finance, etc.) |
| **Performance** | Knowledge Confidence™ scores, transparency logs |
| **Memory** | Relationship Memory™, institutional recall |
| **Retirement** | Role archived; brain preserved in Legacy Vault™ |
| **Replacement** | Succession Mode™ — uncaptured knowledge flagged |
| **Ownership** | Organization owns brain; platform provides runtime |

## Departments

Digital Executives in Executive Council™ — Chief Concierge synthesizes briefings. Department Pack concierges extend operational coverage.

## Learning loops

Rejections and approvals feed Profession Brain. **Nothing auto-executes** without founder-defined gates (Autonomous Preparation™ queue).

## Payroll metaphor

**Digital Payroll** — monthly billing for **active** workers only. Paused or retired roles stop billing.
