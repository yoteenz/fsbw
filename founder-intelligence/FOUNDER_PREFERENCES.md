## Non-negotiables

- **Canon is sacred** — no silent contradictions to glossary or spatial rules  
- **One deploy per task** — MEMORY + code in one commit  
- **Mobile-first QA** — real phone default  
- **No duplicate systems** — extend existing modules  
- **Forensic debugging** — evidence before repair  

## Working rhythms

- Architecture conversations (ChatGPT) separated from implementation sprints (Composer)  
- Prefers **one comprehensive sprint prompt** over fragmented messages  
- Iteration mid-task usually means **refinement**, not cancel — unless explicitly new direction  

## Review preferences

- Visual review before implementation when design is unsettled  
- Executive summaries first for long topics  
- Spatial framing — "where does this live in Studio World?"  

## Communication channels

| Channel | Use |
|---------|-----|
| **ChatGPT** | Creative Director, architecture, Terra review |
| **Composer** | Production implementation sprints |
| **Capsules** | Session memory for any new AI |

## Anti-patterns (avoid)

- Desktop-centric test instructions as default  
- Bold/`backtick` decoration overload in summaries  
- Engagement bait at end of responses ("say the word and I'll…")  
- Pushing to master twice to fix commit message
