## Principles

| Principle | Meaning |
|-----------|---------|
| **Experience over interface** | Users feel a place, not a panel stack |
| **Place over menu** | "Where would you like to go?" |
| **Luxury through restraint** | Fewer elements, higher intention |
| **World-building over dashboards** | Districts, wings, rooms — not widget dumps |
| **Environmental storytelling** | Context in the environment, not tooltips alone |
| **Interactive architecture** | Spaces respond; they are not static admin CRUD |
| **Intentional motion** | Animation communicates state, never decorates blindly |
| **Premium materials** | Marble, glass, crystal in HQ — not flat gray SaaS |
| **Immersive navigation** | Travel metaphors (Atlas, districts) over flat sidebars |

## Frontal Slayer storefront (host org)

- Brand red `#EB1C24`, Futura PT typography, marble textures  
- Mobile-first; desktop is a later phase  
- Uppercase labels common; Covered By Your Grace for accent numbers  

## Admin / Studio OS

- Executive IA: Hero → Department Cards → Focus Panel → Collapsible history  
- Graphics-first summaries (health rings, pipeline viz)  
- Surgical alignment — coherence without forced uniformity
