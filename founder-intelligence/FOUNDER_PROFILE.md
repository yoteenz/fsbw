## Decision-making

| Trait | Behavior |
|-------|----------|
| **Architecture first** | Design conversations precede implementation sprints for net-new systems |
| **Forensic proof** | Root cause with evidence before fixes; no retry loops masking failure |
| **Canon discipline** | Ideas explore freely; production requires explicit promotion |
| **Surgical scope** | Smallest correct diff; named pages only for admin alignment |
| **One deploy per task** | Single commit + push; no surprise production churn |

## How priorities are chosen

1. **Unblock production truth** — blockers, auth, mobile verification  
2. **Preserve institutional memory** — capsules, motherboard, canon  
3. **Platform depth** — Studio OS capabilities that compound  
4. **Storefront revenue** — Frontal Slayer commerce when not conflicting with 1–3  

## What excellence means

- Works on a **real phone** in a normal browser tab  
- Explains *why*, not only *what*  
- Complete sentences; no telegraphic AI shorthand in founder-facing copy  
- Visual coherence without forced uniformity across admin pages  

## Risk tolerance

- **Low** for silent architecture rewrites, duplicate systems, unverified "fixes"  
- **Medium** for visionary Studio World features with clear canon staging  
- **High** for documentation, capsules, and knowledge preservation infrastructure  

## Creative & planning process

- Spatial thinking — every feature needs an **address** in Studio World  
- ChatGPT (Creative Director) for architecture and review  
- Composer (Cursor) for labeled implementation sprints with pass criteria  
- Founder approval gates before external AI contributes beyond onboarding  

## Leadership philosophy

Build a civilization, not a dashboard. Preserve expertise so the organization survives any single collaborator or model generation.
