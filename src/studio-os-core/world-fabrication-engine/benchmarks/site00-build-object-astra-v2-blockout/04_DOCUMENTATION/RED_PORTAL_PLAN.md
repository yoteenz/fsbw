# Red portal reconstruction plan

## Reference requirement

Deep **crimson interlocking translucent structure** — primary identity element. V1 failure: twin acrylic boxes (`build_astra_v1.py` pattern).

## Blockout approach

1. **Silhouette first** — trace portal outer boundary against reference overlay on hero camera.
2. **Thickness** — minimum **two visible parallel crimson planes** plus connecting edge faces (L/T intersections), not a single 0.02 m slab.
3. **Depth layering** — portal must read **in front of and through** adjacent glass (overlap ordering explicit in outliner).
4. **Openings** — if reference shows internal voids in red volume, subtract boolean or inset faces; do not leave solid monolith unless reference shows solid.
5. **Materials (Stage 01)** — diagnostic red Principled: high saturation, transmission > 0.5; final acrylic tuning deferred.

## Landmarks for overlay check

- Top edge height ≈ tallest vertical feature except small roof boxes.
- Width narrower than central glass bay; positioned **right-of-center**.
- Strong vertical edge parallel to image plane right side of portal cluster.

## Anti-patterns (reject)

- Two identical red cubes.
- Single vertical slab with no intersection geometry.
- Thin red outline frame only.
