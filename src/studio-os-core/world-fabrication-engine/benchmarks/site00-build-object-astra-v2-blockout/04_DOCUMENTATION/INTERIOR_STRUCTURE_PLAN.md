# Interior spatial structure plan

## Reference density

Reference shows **multi-level floors**, **vertical partitions**, and **arched openings** deep in the left-center volume — architectural proposal density, not random columns.

## Blockout targets

| Feature | Action |
|---------|--------|
| Floor levels | 3–4 horizontal plates aligned with glass bays |
| Arches | At least one arched portal visible on hero camera deep interior |
| Corridors | Implied path via offset openings between partitions |
| Supports | Columns only where they separate visible bays |

## Coherence rule

Every major interior element must survive **side and elevated inspection cameras** without looking like filler geometry.

## Stage 01 limitation

Interior detail is **massing-level** (simple boxes + arch primitives). Fine moldings deferred.

## Humans

**No** founder-facing silhouettes in hero render. Optional hidden empties for scale only (`HUMAN_GUIDE_*`), excluded from render layer.
