## Purpose

### Why Frontal Slayer distributes **stories**, not reposts

Frontal Slayer is a **studio**, not a feed. One **chapter** (launch, Lounge episode, education season) should unfold as **many experiences**—each platform a different **door** into the same mansion, not the same clip pasted six times.

| Repost model | Story distribution model |
| --- | --- |
| Same file everywhere | **One production → many deliverables** |
| Platform drives creative | **Story drives platform adaptation** |
| Audience fatigue | **Curiosity reward** for following across surfaces |
| Brand feels noisy | Brand feels **interconnected** |

### Every platform deserves its own creative experience

Members choose **context**—scroll in public, lean back on YouTube, read email privately, explore the website immersively. The **emotional job** differs; the **canon** does not. Distribution assigns **platform experiences** that match intent while preserving universe continuity.

### Curiosity over repetition

**Curiosity** pulls members through the universe more sustainably than algorithm hacks. A teaser **asks**; a Reel **reveals one angle**; long-form **completes**; email **deepens**; the site **hosts**. Repeating the master film in every channel trains ignore—not exploration.

### Reward for multi-platform following

Explorers should find **exclusive angles**, **extended beats**, **alternate perspectives**, and **callbacks**—not duplicate uploads. Following Frontal Slayer across surfaces should feel like **collecting scenes**, not seeing the same trailer six times.

### Interconnected, not duplicated

All deliverables share **visual language**, **protagonist/guide grammar**, and **timeline**—but differ in **perspective**, **length**, **information density**, and **entry beat**. Continuity = same universe; variety = different **scenes** from the chapter.

## Distribution Philosophy

Permanent creative principles—filter every Content Package decision.

### One Story. Many Perspectives.

One **chapter narrative**; deliverables may use **customer POV**, **PSA host**, **founder fireside**, **cinematic omniscient**, **BTS documentary**, etc. Perspectives are **intentional**, not random crops.

### One Production. Many Deliverables.

Shoot/generate once with a **deliverable matrix** in pre-production ([`episode-development-bible.md`](./episode-development-bible.md) EDP). Efficiency serves **depth**, not laziness.

### One Universe. Many Entry Points.

A member may **start** on TikTok, email, or lobby—any entry must **orient** without requiring prior clips. Each entry **invites** deeper rooms.

### Additional principles

| Principle | Meaning |
| --- | --- |
| **Story before surface** | No “Instagram first” briefs |
| **Invitation before interruption** | Soft sequel hooks, not demand |
| **Luxury pacing everywhere** | Even :15 feels edited |
| **Canon truth always** | Catalog and continuity non-negotiable |
| **Information gardening** | Some platforms **ask**, some **answer** |
| **Evergreen chapters** | Packages produce value for weeks/months |
| **No filler publishing** | Silence beats low-effort noise |

## Story-First Distribution

### Workflow (mandatory)

```
Story (chapter + beats + objectives)
        ↓
Production (master capture / EDP)
        ↓
Distribution (Content Package + platform experiences)
```

### Forbidden defaults

| Never lead with | Why |
| --- | --- |
| **Instagram first** | Format shrinks story before it exists |
| **TikTok first** | Trend speed breaks luxury pacing |
| **Facebook first** | Legacy feed thinking ≠ mansion metaphor |
| **Algorithm first** | Optimizes repetition, not universe |

**Story brief** includes: universe placement, protagonist beat, pillar map, perspective plan, **Content Package outline**—before platform owners assign specs.

## Content Package Philosophy

### Definition

A **Content Package** is the **master production unit**: one approved **chapter** (campaign beat, episode, launch wave) plus the **planned ecosystem of deliverables** derived from shared production assets.

### Why packages matter

| Benefit | Effect |
| --- | --- |
| **Consistency** | One color grade, one PSA wardrobe tier, one timeline ID |
| **Efficiency** | One shoot, many scenes in the matrix |
| **Immersion** | Audience discovers **layers** of the same chapter |
| **Continuity** | Registry-friendly (future `continuity-registry.md`) |
| **Luxury** | Nothing looks like afterthought crop |

**Rule:** No “single hero video” launch without a **Package v0.1** doc—even if phase 1 ships only master + trailer.

## Content Package Structure

Each deliverable is a **role**, not a checkbox. Adapt to chapter; **declare** which apply.

| Asset | Role in universe | Typical perspective / beat |
| --- | --- | --- |
| **Master film** | Canonical chapter completion | Full beat chain |
| **Trailer** | Invitation; curiosity spike | Hook + mystery |
| **Teaser** | Pre-launch question | Minimal reveal |
| **Instagram Reel** | One moment, one feeling | Single beat, vertical |
| **TikTok version** | Native pace; one lesson or hook | Discovery or education flash |
| **YouTube Short** | Search/discovery entry | Hook + invitation |
| **Long-form version** | Complete or extended cut | Full arc + optional extras |
| **Carousel** | Stepwise discovery/education | Swipe = beats |
| **Story sequence** | Ephemeral scenes (24h layer) | BTS, countdown, poll as **in-world** |
| **Behind-the-scenes** | Craft trust; precision pillar | Documentary perspective |
| **Character spotlight** | PSA or member chapter | Guide or protagonist |
| **Wallpaper** | Quiet brand presence | Visual world-building |
| **Website hero** | Mansion entry / chapter door | Arrival beat |
| **Email header** | Chapter typography in inbox | Scene still |
| **Thumbnail** | Curiosity frame (honest) | Never clickbait lie |
| **Press images** | Editorial stills | Omniscient / lifestyle |
| **Blog assets** | Written chapter companion | Educational expansion |
| **Launch graphics** | Tier 4 campaign layer | Event identity |
| **Advertising variations** | Paid entry points | Story wrapper; disclosure compliant |
| **Future platform adaptations** | Same spine, new safe zones | Document in Package |

**Not every chapter needs every asset**—but **skipped assets are explicit N/A**, not forgotten.

## Perspective Distribution System

**Core rule:** Same chapter, **different POV** = different deliverable—not a repost.

| Perspective | When to use | Emotional purpose | Platform fit |
| --- | --- | --- | --- |
| **Customer (protagonist)** | Transformation, install, choice | Agency, pride | Reels, carousels, ads (OTS/hands) |
| **PSA (guide)** | Teach, host, welcome | Trust, clarity | Lounge, tutorials, Threads, email |
| **Founder** | Rare standards, launch authority | Conviction, heritage | YouTube fireside, email, X |
| **Omniscient cinematic** | Launch films, trailers | Wonder, scale | Master film, heroes, TV |
| **Community** | Spotlights (consent) | Belonging | FB, IG, email |
| **Educational** | Lab, step logic | Confidence | YouTube, Pinterest, blog |
| **Documentary / BTS** | Craft, precision | Trust in process | Stories, BTS cuts |
| **Luxury lifestyle** | Mood, materials | Aspiration | Pinterest, wallpapers, press |
| **Behind-the-scenes** | Human crew, set | Authenticity | Stories, TikTok |
| **Future perspectives** | AR, personalized PSA | Intimacy at scale | Product-gated |

**Multi-perspective strength:** Member pieces together **one chapter** like scenes after a film—drives **cross-platform exploration** without confusion (same **timeline ID**, same **chapter title** in metadata).

## Continuity Between Platforms

### Connected discovery, not reposts

| Rule | Implementation |
| --- | --- |
| **Chapter ID** | Every deliverable tags `chapter-{slug}` + season/campaign |
| **Timeline** | Forward continuity ([`cinematic-universe-bible.md`](./cinematic-universe-bible.md)) |
| **Visual** | Visual Language + PSA tiers ([`../visual-language/visual-language.md`](../visual-language/visual-language.md), character continuity) |
| **Emotional** | Same chapter arc; platform may show **one beat** only |
| **Callbacks** | Reference prior chapters explicitly when rewarding explorers |
| **No spoiler chaos** | Teasers **ask** without contradicting master film |

**Audience feeling:** “I found another scene”—not “I saw this already.”

## Information Distribution

Strategic **release** of story information across surfaces.

| Platform role | Information job |
| --- | --- |
| **Teaser / X** | Create **questions** |
| **Reel / TikTok** | Answer **one** small question |
| **Master / YouTube** | Complete **core** chapter |
| **Email** | **Deepen** relationship + exclusive line |
| **Website** | **Host** full context + next doors |
| **Blog** | **Expand** education |
| **BTS** | **Reveal craft** without breaking mystery before launch |

**Clarity rule:** Any single entry point must include **orient** (where am I in universe?) + **invitation** (where next?). Avoid requiring arbitrary order—**reward** order for explorers.

## Audience Reward System

Explorers earn **depth**, not discounts alone.

| Reward type | Example |
| --- | --- |
| **Exclusive scenes** | Email-only PSA line; extended cut |
| **Extended conversations** | Director’s commentary tone (craft) |
| **Alternate perspectives** | Customer vs PSA cut of same beat |
| **Additional story details** | Blog lore-light craft facts (true) |
| **Hidden visual references** | Mansion motif in background |
| **Callbacks** | Prior Lounge episode nod |
| **Character moments** | PSA host aside |
| **World-building** | Wallpaper, pin set |
| **Educational expansions** | Carousel steps not in Reel |
| **Future easter eggs** | Continuity registry planted refs |

**Ethics:** Rewards are **delight**, not manipulative FOMO or paywalls on core education.

## Content Hierarchy

```
Brand Universe (cinematic-universe-bible)
        ↓
Chapter (campaign / episode / launch wave)
        ↓
Content Package (production unit + deliverable matrix)
        ↓
Platform Experience (IG, YouTube, email, web…)
        ↓
Individual Deliverables (Reel, trailer, hero…)
        ↓
Audience Interaction (comment, click, visit, purchase)
```

| Level | Owns |
| --- | --- |
| **Universe** | Canon, tone, protagonist/guide |
| **Chapter** | One complete narrative contribution |
| **Package** | Shared assets + perspective plan |
| **Platform experience** | Format-native beat selection |
| **Deliverable** | Single file/post/send |
| **Interaction** | Measured in Story Dept as **invitation success**, not vanity alone |

Aligns with [`story-department-overview.md`](./story-department-overview.md) story hierarchy (brand → campaign → season → episode).

## Campaign Structure

Launch **chapters** as structured waves—not single drops.

| Stage | Purpose |
| --- | --- |
| **Chapter launch definition** | Package brief, timeline ID, objectives |
| **Countdown** | Curiosity; hospitality—not panic |
| **Teasers** | Questions; perspective fragments |
| **Main film** | Canonical completion |
| **Expansion content** | Perspectives, BTS, educational splits |
| **Community engagement** | Consent spotlights, Q&A as scenes |
| **Educational content** | Lab/YouTube/carousel depth |
| **Follow-up content** | Invitation to next chapter |
| **Evergreen content** | Long-tail entry points (SEO, pins) |

**Paid ads** enter as **platform experiences** with story wrapper—never bypass Package QA.

## Repurposing Standards

| Term | Definition | FS standard |
| --- | --- | --- |
| **Repurposing** | Reuse assets for **new deliverable role** | **Default**—with new beat/perspective |
| **Re-editing** | New cut structure, pacing, audio | Required across platforms |
| **Reframing** | Aspect ratio / crop for platform | Required; check safe zones |
| **Re-contextualizing** | New copy, new entry beat, new thumbnail | Required for non-duplicative feel |
| **Perspective shifting** | Alternate POV from same production | **Preferred** over identical repost |
| **Reposting** | Same file, same context | **Rare**—exception: cross-post master trailer **once** with clear “full film on…” |

**Identity test:** Would an explorer following three platforms see **three scenes** or **one duplicate**?

## Cross-Platform Storytelling

Audiences **loop** through doors:

```
Website → Social → Email → Short video → Long video → Website (deeper room)
```

Each hop should **increase depth**, not repeat:

- **Website** → orient + host  
- **Social** → hook or single beat  
- **Email** → personal invitation + exclusive angle  
- **Short** → curiosity satisfied partially  
- **Long** → chapter completion  
- **Return web** → **next room** (BAW, Lounge, shop with context)

**Design for curiosity:** End with **invitation**, not “follow us.” End with **“see the full chapter”** / **“enter the Lab”** / **“next episode.”**

## Content Longevity

One chapter should **keep giving**:

| Technique | Description |
| --- | --- |

| **Expansion cuts** | Week 2 perspective release |
| **Sequencing** | Email arc days 1–5 |

## Luxury Standards

Every deliverable— including “small” posts:

- **Intentional** frame and copy  
- **Cinematic** edit rhythm (even :15)  
- **On-brand** materials and PSA tiers  
- **No filler** “engagement bait”  
- **No trend chase** that breaks Visual Language  
- **No low-effort** crop-and-post  

QA: story Episode checklist + Character QA when PSA visible + Visual Language spot check.

## Common Mistakes

| Mistake | Harm | Avoid |
| --- | --- | --- |
| **Identical post everywhere** | Fatigue, cheap feel | Perspective + re-context |
| **Platform-first brief** | Shrunken story | Story-first workflow |
| **Over-explaining in social** | Lecture, scroll-past | One beat per Reel |
| **Continuity break** | Universe trust loss | Chapter ID + bible review |
| **Luxury cheapening** | Hype, clutter, urgency | Restraint standards |
| **Inconsistent edit** | Amateur brand | Package color/sound bible |
| **Ignored emotional arc** | Flat middle | Beat map per deliverable |
| **Audience fatigue** | Unfollow | Information gardening + rewards |
| **Spoiler mismatch** | Confusion | Teaser rules |
| **PSA influencer tone** | Guide break | Character bibles |
| **Algorithm chasing** | Off-brand trends | Story philosophy |
| **Publishing to publish** | Noise | No filler rule |

## Content Distribution Manifesto

**Frontal Slayer does not create posts.**  
**Frontal Slayer creates worlds.**

One story runs through the mansion, the Lounge, the Lab, the inbox, and the feed.  
Every platform is **another doorway**—not a mirror of the last.  
Every deliverable is a **scene**, a **question**, or an **answer**—never noise.  
**Curiosity** moves the audience forward.  
**Consistency** holds the universe together.  
**Luxury** is the standard in every frame and every line.  
The audience is not scrolling through content.  
**They are moving through an experience.**
