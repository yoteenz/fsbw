## Purpose

### Why structured episode development exists

An **episode** in Frontal Slayer is any **complete narrative unit**—a Lounge chapter, a :60 film, a tutorial, an email arc, a social mini-arc, a PSA-guided flow—not only “TV.” Without a shared development system:

| Failure | Consequence |
| --- | --- |
| **Ad-first thinking** | Opens on SKU; breaks universe trust |
| **Inconsistent beats** | Some pieces educate, others only hype |
| **Character drift** | PSA becomes influencer or bot |
| **Unrepeatable AI/film workflow** | Missing refs, continuity, shot intent |
| **Orphan content** | No season, no sequel hook, no mansion placement |

Structured development ensures every episode **maps to universe canon**, **serves multiple business goals without feeling commercial**, and **hands off clean packages** to Production, Character, and AI teams.

**Blueprint rule:** No camera rolls and no generation batch starts until **Episode Development Package** (EDP) passes review (see Lifecycle).

## Episode Objectives

Every episode should **stack objectives**—not lead with conversion alone.

| Objective | Episode must deliver | Luxury constraint |
| --- | --- | --- |
| **Education** | One repeatable **why** or skill | Scene-embedded, not lecture |
| **Entertainment** | Worth watching without purchase | Earned pacing, not gimmick |
| **Luxury branding** | Restraint, space, material truth | No discount energy |
| **Customer trust** | Catalog-true claims; honest limits | No fake urgency |
| **Emotional connection** | Named feeling → action | No manipulation |
| **Product discovery** | Fit/criteria, not SKU spam | Discovery beat before CTA |
| **Community building** | Belonging, recognition | Consent for member stories |
| **Conversion** | **Optional beat** after trust | Invitation, not pressure |
| **Retention** | Sequel hook—next episode/room/lesson | Continuity memory |

**Development worksheet (required):** Rank **primary** (1) and **secondary** (2–3) objectives. If **conversion** is primary → **reject** or redesign unless Founder exception (e.g. limited paid retargeting with story wrapper).

```
     ↓

     ↓

     ↓

     ↓

     ↓

```

### 1 — Initial Idea

| Input | Output |
| --- | --- |
| Seed (member question, launch, season gap, PSA scenario) | **Idea card**: one sentence, pillar map, hierarchy level (episode/season/campaign) |

**Gate:** Does this **strengthen the universe** ([`cinematic-universe-bible.md`](./cinematic-universe-bible.md))? If no → archive.

### 2 — Concept Development

Expand idea into **concept brief**:

- Protagonist beat (what member **does** or **feels**)  
- Guide beat (what PSA **clarifies**)  
- Environment **purpose** (not full env bible)  
- Primary + secondary objectives  
- Target length / platform family  
- Continuity links (prior episode, room, lesson)

**Output:** Concept v0.1 (1–2 pages internal).

### 3 — Creative Review

**Reviewers:** Story lead + ECD delegate (+ Brand if product-heavy).

| Check | Pass? |
| --- | --- |
| Protagonist/guide grammar | |
| Pillar alignment | |
| Five-year / timeless test | |
| No universe reset | |

**Outcomes:** Greenlight story development · Revise · Kill.

### 4 — Story Development

Build **narrative spine** (see Episode Structure, Story Development):

- Beat outline  
- Emotional arc  
- Education outcome (“member can repeat back…”)  
- Product integration points (if any)  
- Dialogue **mode** (not final script unless scripted format)—reference [`../psa/dialogue.md`](../psa/dialogue.md)

**Output:** Story outline v1.0 + beat timing estimate.

### 5 — Production Planning

Translate story to **production plan**:

- Format (live action, AI-assisted, hybrid, UI capture)  
- Departments touched (Character, Environment, Audio)  
- Asset dependencies from [`../psa/character-reference-library.md`](../psa/character-reference-library.md)  
- Schedule milestones  
- Risk flags (likeness, new slug, new room)

**Output:** Production plan v1.0.

### 6 — Shot Planning

**Not a storyboard bible**—define **shot intent**:

- Coverage goals (host, hands, product, environment)  
- Required angles for continuity  
- Platform-safe zones (9:16, 16:9)  
- Reference to [`../psa/character-turnaround.md`](../psa/character-turnaround.md) REF IDs where applicable

**Output:** Shot requirements doc / shot list draft.

### 7 — Production

Execute capture/generation per plan. Character and continuity bibles **in force**.

### 8 — Editing

Cut to **beat structure**; luxury pacing; audio/music direction applied; platform masters planned.

### 9 — Quality Review

[`../psa/character-qa-checklist.md`](../psa/character-qa-checklist.md) where PSA appears; story Episode Review Checklist (below); continuity tier tagging.

### 10 — Publishing

Register in future continuity registry; update kits if new refs; publish with **invitation** metadata (next episode ID).

## Episode Structure

Recommended **Frontal Slayer beat stack** (adapt length; short-form may use subset).

### Hook

**Purpose:** Curiosity in **≤3 seconds** (social) or **≤15s** (long-form)—never hype scream.  
**Tools:** Mystery of room, member question, visual wonder, PSA direct address (host).  
**Avoid:** Price, logo slam, “Buy now.”

### Introduction

**Purpose:** Orient—**where** in mansion/universe, **what** question this episode answers.  
**Tools:** Arrival beat, host welcome, title card in-world (Lounge), PSA greet once.  
**PSA:** Guide tone; [`../psa/acting.md`](../psa/acting.md) host cadence for TV.

### Discovery

**Purpose:** Member **finds**—product, technique, or truth—not told first.  
**Tools:** Showroom browse, comparison, PSA question, demo reveal.  
**Emotion:** Wonder → interest.

### Education

**Purpose:** Deliver **one** core teaching (why or how).  
**Tools:** Lab precision, step demo, analogy, on-screen clarity.  
**Rule:** Member could **repeat back** one sentence of learning.

### Transformation

**Purpose:** Emotional or skill peak—**member agency** (install, choice, confidence).  
**Tools:** Mirror, reveal, before/after with protagonist framing, celebration **brief**.  
**PSA:** Encourage → **next step**, not PSA stardom.

### Resolution

**Purpose:** Integrate meaning—“what this means for **you**.”  
**Tools:** Reflection line, recap, calm confidence.

### Call-to-action (invitation)

**Purpose:** **Invitation to continue**—next episode, room, lesson, consult—not pressure close.  
**Tools:** Soft CTA copy per [`../psa/dialogue.md`](../psa/dialogue.md); visual next tile.  
**Luxury:** One clear door, not five buttons.

### Beat map by format

| Format | Typical beats |
| --- | --- |
| **:15–:30 social** | Hook → Discovery or Education flash → Invitation |
| **:60 commercial** | Hook → Trust → Discovery → Invitation |
| **Lounge 8–15 min** | Intro → Discovery → Education → Transformation → Resolution → Invitation |
| **Tutorial** | Intro → Education (steps) → Transformation → Invitation |
| **Email arc (3–5)** | Each email = one scene; arc = Discovery → Education → Invitation |

## Story Development

### From idea to compelling story

| Engine | Question for writers |
| --- | --- |
| **Conflict** | What **friction** does member face? (confusion, fear, wrong fit, time pressure)—**never** brand vs member |
| **Curiosity** | What do they **want to know**? |
| **Discovery** | What do they **find** themselves? |
| **Reward** | What **competence or confidence** do they gain? |
| **Transformation** | What **changes** by end? |
| **Satisfaction** | What **feeling** do they leave with? |

**Conflict types (allowed):** skill gap, decision overload, install anxiety, event deadline—**resolved through education + choice**.

**Forbidden conflict:** shame, fear-selling, “you’re broken without this.”

### Story spine template

```
Member situation → Curiosity trigger → Discovery moment →
Education (why) → Application (how) → Transformation →
Reflection → Invitation
```

## Character Usage

**Reference Character Department—do not redefine.**

| Role | Episode usage | Docs |
| --- | --- | --- |
| **PSA** | Guide/host; screen time OK, **story function** secondary | identity, personality, performance-system, facial-expressions, voice, dialogue, acting |
| **Customer (Slayer)** | Protagonist—hands, OTS, silhouette, consent spotlights | storytelling-philosophy protagonist rules |
| **Founder** | **Rare**—authority, standards, launch fireside; not weekly host | story approval; gravitas dialogue |
| **Supporting** | Experts, guest educators, members (consent)—**subordinate** arcs | future cast registry |

**PSA integration checklist:**

- [ ] Guide, not hero  
- [ ] One primary expression slug per beat (facial-expressions)  
- [ ] Scenario objectives from behavioral-scenario-library  
- [ ] No sales pressure; honest pushback if needed  

**Customer integration:**

- [ ] Protagonist POV default  
- [ ] Transformation credited to member  
- [ ] Diversity through **identification**, not token casting

## Environment Selection

Environments are **story tools**—pick by **narrative function** ([`cinematic-universe-bible.md`](./cinematic-universe-bible.md) location taxonomy).

| Story need | Environment purpose |
| --- | --- |
| Orient new viewers | Reception / Lobby |
| Compare options | Showroom |
| Explain science/craft | Lab |
| Customize | BAW Atelier |
| Emotional peak | Transformation Suite |
| Serialized entertainment | TV Lounge |
| Recognition | Rewards Gallery |
| Authority (rare) | Founder Suite |

**Rule:** One **dominant** room mood per episode; avoid room-hopping without transition motivation.

**Do not** document room specs here—Environment Department / future mansion bible.

## Product Integration

| Stage | Integration |
| --- | --- |
| **Discovery** | Product appears as **option** in member search |
| **Education** | Unit explains **criteria** (density, lace, color family) |
| **Application** | Member tries/configures (BAW) |
| **Invitation** | “When you’re ready” path—no countdown |

**Anti-patterns:** cold-open SKU; spec dump; fake scarcity; comparison to “ inferior” competitors.

**Canon:** Real names, real capabilities ([`cinematic-universe-bible.md`](./cinematic-universe-bible.md) product truth).

## Emotional Design

### Pacing

Luxury = **room to breathe**. Allow pauses after teaching and after celebration.

| Phase | Tension / energy |
| --- | --- |
| **Hook** | Low→medium curiosity |
| **Discovery** | Rising interest |
| **Education** | Steady focus (no panic) |
| **Transformation** | Peak **brief** |
| **Resolution** | Release, calm |
| **Invitation** | Forward energy **soft** |

### Curiosity build

Questions before answers; visual mystery; partial reveals; PSA “let’s look at…”

### Satisfaction delivery

Pay off the **opening question**; celebrate member; **do not** leave anxiety open unless sequel hook is explicit next step.

## Educational Design

| Principle | Practice |
| --- | --- |
| **Edutainment** | Lesson **is** the scene |
| **One core lesson** | Split series if needed |
| **Progressive difficulty** | Reference prior episodes |
| **Plain luxury language** | Expert, not jargon wall |
| **Show, then tell** | Demo before bullet |

**Never:** slide-deck voiceover; 10 facts in :30; quiz without context.

**Assessment:** “Can member repeat one **why**?” ([`story-department-overview.md`](./story-department-overview.md)).

## Luxury Standards

Every episode reinforces premium positioning through:

- **Pacing** — no frantic cuts unless genre-justified (never default)  
- **Materials** — Visual Language truth  
- **Audio** — clean, not loud; music supports, not drowns  
- **Host dignity** — PSA composed  
- **Honesty** — including “not for everyone”  
- **Invitation CTAs** — no screaming end cards  

Cross-check [`../visual-language/visual-language.md`](../visual-language/visual-language.md) and story Decision Framework.

## Platform Adaptation

Same **story spine**; adapt **length, crop, caption, CTA placement**. Full **Content Package** matrix, perspective distribution, continuity, and campaign sequencing: [`content-distribution-bible.md`](./content-distribution-bible.md).

| Platform | Adaptation rules |
| --- | --- |
| **Instagram** | Hook in 1s; vertical safe; text minimal; invitation in caption or end card |
| **TikTok** | Faster hook; one lesson; native pace; avoid ad tone |
| **YouTube** | Long-form beats full; chapters; host intros; end-screen invitation |
| **Website / Lounge** | 16:9; navigation to next episode; mansion context |
| **Email** | Scene-as-email; one beat each; plain luxury prose |
| **Paid advertising** | Story wrapper mandatory; disclosure compliant; no bait switch |
| **Future platforms** | Inherit spine + QA; document new safe zones |

**Rule:** Do not **change** protagonist/guide roles per platform.

| Package item | Description |

## Common Mistakes

| Mistake | Why it hurts | Avoid |
| --- | --- | --- |
| **Ad cold open** | Breaks immersion | Start with curiosity/host |
| **PSA as hero** | Breaks guide canon | Member wins |
| **Lecture middle** | Edutainment fail | Scene-based teach |
| **Too many lessons** | Overwhelm | One core lesson |
| **Hype tone** | Cheap luxury | Restrained celebration |
| **Fake urgency** | Trust loss | Honest timing |
| **Orphan episode** | No retention | Season + invitation |
| **Wrong room mood** | Universe break | Environment purpose table |
| **Uncanny AI face** | Likeness break | Reference library + QA |
| **CTA pile-up** | Pressure | One invitation |
| **Trend meme format** | Dated in 6 months | Timeless beats |
| **Ignoring prior lessons** | Continuity break | Callback when advanced |

## Best Practices

1. **Develop episodes as chapters**, not one-offs.  
2. **Write the invitation last**—after trust is earned.  
3. **One question, one answer, one feeling** per short-form piece.  
4. **PSA clarifies; member decides.**  
5. **Show craft**—hands, lace, light—before spec.  
6. **Build EDP before pixels**—especially for AI.  
7. **Review with sound off and sound on**—luxury reads in both.  
8. **Log continuity** for the next creator.  
9. **When stuck, return to [`storytelling-philosophy.md`](./storytelling-philosophy.md).**  
10. **If it feels like an ad, rebuild as a scene.**
