## Narrative Design Mandate

Narrative Design **eliminates structural uncertainty** before drafting. Writers answer **what the audience knows when**, **what changes dramatically**, and **what remains unresolved**—not how lines read on the page.

## Narrative Purpose

**Film I narratively exists to:**

1. **Introduce the world** as primary subject—product, technology, and business model are **subordinate or absent** as story drivers.  
2. **Establish the dramatic question** *What is Frontal Slayer?* and **refuse** to close it.  
3. **Deliver one myth beat:** the house **opens because the guest arrives** (CLOSED → OPEN = **guest state change**, not retail hours).  
4. **Seed Film II** with a **trust** question—not a **commerce** question.  
5. **Align** with Chapter One relationship beat: **Who are you?** (brand/world identity at first-impression depth only).

**Narrative success is not** “audience understands the company.” **Narrative success is** “audience **needs** the next film.”

---

## Dramatic Premise

**Premise (structural):**  
A guest **notices** a threshold, **pauses**, and **chooses** to approach; the world **observes**, **responds**, and **opens**; the guest **crosses** and **glimpses** depth without receiving a map; the story **stops** before belonging or proof.

**Premise is not:** She shops. She learns the catalog. She meets the founder pitch. She converts.

**World premise:** Frontal Slayer behaves like a **property with host logic**—arrival is **ceremony**, not **transaction start**.

---

## Story Promise

To the audience, Film I **promises**:

| Promise | Narrative evidence |
| --- | --- |
| **This is a place** | Architecture, host behavior, partial interior |
| **Someone competent hosts** | PSA guide role, calm response |
| **More exists** | Glimpses, sound/light spill, unwalked vector |
| **You will not be sold in Chapter One** | Withhold commerce spine |
| **The story continues** | Unfinished door / path; Chapter Two language optional in end matter |

**Broken promise (structural failure):** Film resolves as **60-second product ad** or **complete boutique tour**.

## Story Payoff

**Payoff type:** **Emotional + dramatic partial completion**

| Completed | Withheld |
| --- | --- |
| Guest **entered** world (threshold crossed) | Full **layout** |
| Host **introduced** (guide function) | Host **biography** |
| **Myth beat** delivered (open for her) | **Proof** of standards (Film II) |
| **Wonder** sampled | **Belonging** (later season) |
| Question **sharpened** | Question **answered** |

**Payoff feeling:** *Recognition without closure* → forwards to Film II.

## Central Dramatic Question

**Primary (Chapter One lock):**

> **What is Frontal Slayer—and why does it feel like somewhere instead of something?**

**Film I operational sub-question:**

> **What opened for her—and what is still hidden?**

**Questions Film I must not accidentally answer as primary:**

- What should I buy?  
- How much?  
- How does the app work?  
- Who owns the company? (unless **ambient**, non-expository)

## Narrative Spine

**Spine = causal chain of dramatic **states** (not scene list):**

```
NOTICE → PAUSE → APPROACH → HOST RECOGNITION → WORLD STATE CHANGE (OPEN)
→ THRESHOLD CROSS → ORIENT IN PARTIAL INTERIOR → GLIMPSE DEPTH
→ TRUST SEED → UNRESOLVED FORWARD VECTOR
```

Each state **must** change what the audience **believes** about the world:

| After state | Audience belief shift |
| --- | --- |
| NOTICE | “This is **not** a typical ad subject.” |
| PAUSE | “**Pause** is allowed here.” |
| APPROACH | “I am **invited** to lean in.” |
| HOST RECOGNITION | “There is a **host**.” |
| WORLD STATE CHANGE | “The world **responds** to **guest**, not clock.” |
| THRESHOLD CROSS | “I am **inside** a property.” |
| GLIMPSE DEPTH | “Scale **>** one room.” |
| TRUST SEED | “They might be **real**.” |
| FORWARD VECTOR | “I **need** the next chapter.” |

**Spine break:** Any state skipped without **equivalent dramatic substitute** (e.g., OPEN without **recognition**) weakens myth.

---

## Structural Philosophy

| Principle | Application |
| --- | --- |
| **One spine, one evening** | Single arrival arc; no B-plot commerce |
| **World as protagonist’s mirror** | World **changes** when guest acts |
| **Economy of events** | Few **high-meaning** turns; no filler montage |
| **Mystery forward** | Each turn **adds** question debt |
| **Hospitality causality** | Host action **motivated** by arrival, not schedule |
| **Exit open** | End = **vector**, not **button** |
| **Canon POV** | Hybrid recommended: **figure → POV** (Discovery Packet) |

**Structural models (spirit, not copy):** Invitation fables; **key-turn** host myths; Nolan-style **information discipline**; Pixar **clear want** (guest: safe curiosity); A24 **withhold**.

## Information Architecture

**Information classes:**

| Class | Film I policy |
| --- | --- |
| **A — Atmospheric** | Liberal (materials, light, tone) |
| **B — Relational** | Host exists; guest **seen** |
| **C — Spatial** | Partial—**corridor**, not **map** |
| **D — Craft** | Glimpse only—**integrity**, not **spec sheet** |
| **E — Commerce** | **Withhold** hero spine |
| **F — Lore** | **Withhold** (PSA origin, mansion name taxonomy) |
| **G — Product truth** | **Only** if visible object **without** name/price pitch |

**Flow rule:** **A → B → C** in order; **D** touches once lightly; **E/F** deferred; **G** ambient optional.

**Anti-pattern:** **Front-load** Class E or F in VO.

---

## Mystery Architecture

**Mystery engine:** **Scale of world** + **host logic** + **unwalked space**

| Mystery layer | Audience status at end |
| --- | --- |
| **What is this place?** | **Open** (primary) |
| **How big is it?** | **Partially felt**, not measured |
| **Why did it open for her?** | **Felt** (myth), not **explained** (rules) |
| **What happens in hidden rooms?** | **Open** |
| **Can I belong?** | **Teased**, not **answered** |

**Mystery integrity:** Honest about **visible** craft; **never** lie about **material** product when shown.

## Reveal Strategy

| Reveal | Timing band (hero) | Method |
| --- | --- | --- |
| **Exterior exists** | Early | Visual Class A |
| **Interior warmth/pull** | Early–mid | Contrast |
| **Host awareness** | Mid | Behavior through glass / interior |
| **OPEN ritual** | Mid (**peak**) | Sign / state change |
| **Entry permitted** | Mid | Threshold |
| **Interior scale hint** | Mid–late | Single **strong** axis glimpse |
| **Craft seriousness** | Late | Micro Class D |
| **Forward path** | End | Unentered vector |

**Reveal discipline:** **One** major spatial reveal beat—not **five** equal rooms.

## Curiosity Management

| Phase | Curiosity | Technique |
| --- | --- | --- |
| **Open** | Low → spike | Pattern break |
| **Pre-OPEN** | Rising | Withheld interior |
| **OPEN** | Plateau (emotion) | **Hold** ritual—do not cut for pace |
| **Post-entry** | Rise | New angles only |
| **Close** | **High unresolved** | Path + question |

**Curiosity budget:** Net **+2** major questions at end vs start (minimum).

## Narrative Perspective

**Primary mode:** **Cinematic third** with **guest-aligned** identification.

**Hybrid POV strategy (recommended canon from Discovery):**

| Movement | Perspective | Narrative function |
| --- | --- | --- |
| **Exterior / approach** | Limited third on **figure** (silhouette, back, reflection) | Universal **Slayer** without narrow cast |
| **Recognition / OPEN** | Split: **host view** + **guest view** acceptable | Myth **legible** |
| **Cross + interior** | **POV / OTS** dominant | **Audience becomes guest** |
| **End vector** | Guest-aligned **look** toward unwalked | **Longing** |

**Forbidden default:** Omniscient **catalog narrator** or **founder explainer**.

---

## Point-of-View Strategy

| POV use | When | Why |
| --- | --- | --- |
| **Guest POV** | Post-threshold | Protagonist grammar |
| **Host POV** | OPEN ritual optional beat | Clarify **ceremony** without dialogue |
| **Objective wide** | Scale glimpse | **Wonder** architecture |
| **PSA subjective** | **Avoid** long stretch | Prevents guide-as-hero |

**POV handoff rule:** Max **one** clean handoff exterior→interior; interior **stay guest-aligned**.

---

## Escalation Strategy

Escalation is **dramatic stakes of curiosity and recognition**, not **danger**.

```
Stakes level 1: Will this hold attention? (pattern break)
Stakes level 2: Will guest cross? (agency)
Stakes level 3: Will world receive her? (OPEN)
Stakes level 4: Is world **real** beyond facade? (depth + craft seed)
Stakes level 5: What happens if she goes deeper? (Film II hook)
```

**No** escalation via **price drops**, **conflict**, or **villain**.

---

## Tension Strategy

**Tension type:** **Soft suspense**—social/emotional, not thriller.

| Tension | Source | Release |
| --- | --- | --- |
| **Will host notice?** | Pre-OPEN | Recognition |
| **Will door open?** | Pre-OPEN | Ritual |
| **Is this retail trap?** | Approach | Pace + no hard sell |
| **Can I stay?** | Entry | Breathing room inside |

**Tension ceiling:** Low—**never** horror, chase, or humiliation.

---

## Wonder Strategy

**Order:** **Intimate → expansive → incomplete**

1. **Intimate wonder:** Material, light, detail.  
2. **Expansive wonder:** One **axis** revealing depth.  
3. **Incomplete wonder:** Path **not taken**.

**Wonder must attach to guest POV**—not **detached beauty montage**.

---

## Transition Strategy

**State transitions** (dramatic, not edit list):

| From → To | Transition mechanism |
| --- | --- |
| Notice → Pause | **Stillness** |
| Pause → Approach | **Pull** (light/sound) |
| Approach → Recognition | **Host motion** |
| Recognition → OPEN | **Ritual object** (sign) |
| OPEN → Cross | **Permission** (unlock) |
| Cross → Glimpse | **Movement vector** |
| Glimpse → End | **Stop before satisfaction** |

**Transition failure:** Montage **without** state change.

---

## Beginning Function

**Narrative job:** Establish **guarded attention → arrest**; introduce **threshold**; **withhold** interior payoff.

**Must achieve by end of beginning:** Audience **wants** interior; guest **has paused** (mirrored).

**Must avoid:** Logo manifesto; price; **explaining** FS.

**Approximate dramatic weight:** ~20–25% of spine states (notice, pause, approach start)—**emotion doc** governs pacing length.

---

## Middle Function

**Narrative job:** **HOST RECOGNITION → OPEN → CROSS → first interior proof**

**Middle carries:** Primary myth beat; **primary emotional peak** (Honor).

**Must achieve:** World **state change**; guest **inside**; **one** depth glimpse.

**Must avoid:** Product grid; dialogue exposition; **complete** tour.

**Approximate weight:** ~50%—**peak centered**, not back-loaded montage only.

---

## Ending Function

**Narrative job:** **Trust seed + forward vector**; **sharpen** central question.

**Must achieve:** Audience **longing** for Film II; **trust question** planted.

**Must avoid:** CTA; **summary** VO; **belonging** climax.

**Approximate weight:** ~25–30%—**slow** relative to middle peak.

---

## Ending Image Philosophy

**Ending image = dramatic **question** made visual.**

| Qualities | Purpose |
| --- | --- |
| **Unwalked** | Path, door, light, sound **ahead** |
| **Guest-aligned** | Protagonist grammar |
| **Open** | No **button** |
| **Quiet** | Luxury **withhold** |
| **Memorable** | One **icon** (path or glow—not **logo**) |

**Ending image is not:** Smile + product; **closed door** on guest; **sunset cliché** without **interior** mystery.

**Conceptual families (writer picks one in script phase):** Down-axis path · Side door **ajar** · Light from **unseen** room · Host **waiting** at distance · Guest **step** toward **unknown** zone.

---

## Setup for Film II

**Film II narrative question (trust):** *Why should I trust you?*

**Film I must plant:**

| Plant | Film II payoff type |
| --- | --- |
| **Craft glimpse** | **Proof** scenes |
| **Host competence** | **Teaching** without condescension |
| **Honest pace** | **Integrity** under scrutiny |
| **Unverified claim feeling** | Audience **wants verification** |

**Bridge emotion:** Intrigue → **respectful skepticism** (“Show me.”)

**Do not plant in Film I:** Full **lesson**, **SKU** story, **membership** pitch.

---

## What Must Never Be Revealed

(Align Chapter One + Discovery + Experience bibles.)

- Full product catalog / pricing architecture as **narrative spine**  
- App / AI / tech stack as **explainer**  
- Founder mission **speech**  
- PSA origin / full biography  
- Complete mansion map / room taxonomy **labeled**  
- Membership mechanics  
- “It’s just a store” **as sole conclusion**  
- Hard conversion **as ending beat**  
- **Villain** or **competitor**  
- **Genre break** (fantasy/sci-fi plot)

---

## What Must Be Clearly Communicated

*Without dialogue if possible.*

- A **distinct world** exists (not generic ad)  
- **Guest pause** is honored  
- **Host** responds with **ceremony**  
- **OPEN** is **for guest arrival** (subtext clear on mute)  
- Guest **enters** partial interior  
- **More** exists beyond first vista  
- **Tone:** luxury hospitality + editorial craft  
- Central question **still alive** at fade-out  

---

## What Must Only Be Implied

- **Full scale** of property  
- **Lounge / media** layer (sound/light OK)  
- **Build-A-Wig / authorship** rooms  
- **Everyone** receives ritual (implied by **confidence** of host—not **stated**)  
- **Hair as artifact** (object in space, not **pitch**)  
- **Season/chapter** serialization (optional **minimal** end typography—Experience law: **invitation**, not **marketing**)  
- **Trust** will be **tested** next

## Narrative Risks

| Risk | Structural symptom |
| --- | --- |
| **Retail read** | OPEN = hours; shopping bags |
| **Cast narrow protagonist** | Identification breaks |
| **Over-explain OPEN** | Mystery collapse |
| **Montage middle** | No state change |
| **PSA hero arc** | Guide steals spine |
| **Product hero ending** | Chapter One violation |
| **Closed ending** | No Film II pull |
| **Surveillance host** | Trust poison |
| **Duplicate information** | Same reveal twice |
| **B-plot** | Spine fracture |

## Narrative Opportunities

| Opportunity | Structural gain |
| --- | --- |
| **Hybrid POV** | Canon protagonist + legible ritual |
| **Single strong axis glimpse** | Efficient scale |
| **Sonic Lounge tease** | Serial world **without** label |
| **One craft micro-beat** | Film II plant |
| **Parallel platform POV cuts** | Distribution—not **hero spine** change |
| **Guest agency at end** | **Choice** toward path—Film II **active** |

## Failure Indicators

| Indicator | Diagnosis |
| --- | --- |
| “Clear ad structure” | Spine collapsed to AIDA |
| Audience can **brief the business** | Information leak |

| End feels **safe complete** | Longing failure |
| PSA **arc** complete | Guide-as-hero |
| **Same info** 3x | Architecture redundancy |
| Writer adds **B-plot** | Scope violation |
