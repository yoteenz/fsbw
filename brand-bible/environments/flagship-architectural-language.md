## PURPOSE

Before the flagship **building** is designed, define the **permanent architectural language** — systems, materials, color, light, furniture rules, and environmental signatures — that every future space, render, animation, and Mansion room must obey.

This is the **architectural equivalent of a brand style guide**: vocabulary and law, not a building.

**Golden rule:** Define **systems**, not rooms. No space in Phase 4B may introduce a material, color, or fixture family not accounted for here.

---

## DESIGN PHILOSOPHY

The Frontal Slayer Flagship is a **destination before it is a salon**. Architecture speaks before copy.

| Quality | Architectural read |
| --- | --- |
| **Luxury** | Restraint, material honesty, generous void |
| **Precision** | Alignments, thin metal lines, crisp glass edges |
| **Confidence** | Open sightlines without exposing private service |
| **Calm** | Low visual noise; acoustics as luxury |
| **Innovation** | Integrated tech — never bolt-on gadgets |
| **Hospitality** | Recognition at human scale; warmth in light and touch |
| **Femininity** | Soft curves, rose/floral life, never infantilizing or pink cliché |
| **Exclusivity** | Earned depth — hidden until invited |

The building must **never feel intimidating**. Threshold scale welcomes; private zones protect.

**Technology** disappears into architecture: screens read as glass, sensors as trim, booking as concierge — not kiosks in plastic shrouds.

## ARCHITECTURAL LANGUAGE — SYSTEM VOCABULARY

Each system is a **family of rules**. Phase 4B assigns dimensions; Phase 4A assigns **identity**.

### Exterior architecture

| Attribute | Language |
| --- | --- |
| **Character** | Timeless luxury boutique — not mall, not clinic, not nightclub |
| **Massing** | Vertical clarity; storefront as **jewel box**; calm crown, no gimmick rooflines |
| **Facade rhythm** | Long horizontal calm (marble/glass bands) + one vertical **entry gesture** |
| **Signage** | Minimal wordmark; architecture carries brand; no banner clutter |
| **Campaign** | Exterior must read **identical** in trilogy morning light and daily retail |

**Twin:** Strict identity — Mansion exterior **echo** (facade grammar) without fake weather.

---

### Interior architecture

| Attribute | Language |
| --- | --- |
| **Spatial idea** | **Gallery-hospitality hybrid** — art museum calm + five-star lobby service |
| **Volume** | Generous height in public spine; intimate scale in private suites |
| **Structure expression** | Structure **refined**, not raw industrial (no exposed duct chic) |
| **Zoning** | Phase 3 zones expressed through **light, material shift, threshold** — not color explosions |
| **Reveal** | Every public zone **hints** one deeper destination (Phase 3 visibility program) |

**Twin:** Strict grammar; Mansion may **extend** depth virtually, not change materials.

---

### Ceiling systems

| Type | Use | Rule |
| --- | --- | --- |
| **Floating plane** | Public spine, showroom | Light cove at plane edge; no visible grid |
| **Flush minimal** | Consult, suites | Acoustic backer; tiny aperture downlights |
| **Feature cove** | Reception, celebration | Indirect wash — **warm**, never pink |
| **Dark ceiling** | TV Lounge only | Matte black with controlled pin spots — **named exception** |

Never: acoustic tile grid, exposed T-bar, busy coffered ornament.

---

### Window systems

| Type | Use | Rule |
| --- | --- | --- |
| **Frameless storefront** | Vitrine + threshold | Maximum clarity; anti-reflective where camera crosses |
| **Structural glass wall** | Showroom daylight | UV/c fade discipline for product |
| **Frosted / reeded glass** | Private zone borders | Silhouette only — no readable chaos |
| **Clerestory** | Deep plans (future) | Borrow daylight without street glare |

Campaign: morning natural light **dominates** exterior-facing glass per trilogy canon.

---

### Door systems

| Type | Use | Rule |
| --- | --- | --- |
| **Pivot / flush slab** | Private suites | Full-height; soft close; **no** cheap lever chrome |
| **Glass door** | Semi-private | Same glass family as partitions; minimal hardware |
| **Hidden jamb** | Atelier, transformation | **HI** zones — door **is** architecture, not signage |
| **Staff/service** | Z9/Z10 | Distinct hardware family — never visible from vitrine |

Hardware: **brushed stainless / champagne** — one family site-wide.

---

### Wall treatments

| Treatment | Permitted | Never |
| --- | --- | --- |
| **Book-matched marble slab** | Hero walls, reception backdrop | Fake printed marble |
| **Warm white plaster** | Majority of wall area | Gray office paint |
| **Micro-cement (warm)** | Wet zones, repair bar (future) | Cold industrial gray |
| **Acoustic fabric panel** | TV Lounge, event hall | Cheap polyester tile |
| **Glass partition** | Spines, consult ante | Plastic film “frost” |

**Accent wall rule:** One hero plane per zone maximum — marble **or** glass feature, not both competing.

---

### Columns

| Language | Rule |
| --- | --- |
| **Round or soft-square** | Wrapped in marble or plaster — not raw concrete |
| **Spacing** | Frame sightlines; never block vitrine story |
| **Capital** | Minimal — metal **ring** or flush transition, no classical orders |

Columns are **compositional**, not decorative trophies.

---

### Balustrades & railings

| Context | Language |
| --- | --- |
| **Guest areas** | Glass balustrade with brushed cap **or** plaster wall guard — no ornate iron |
| **Stairs** | Solid marble tread + hidden stringer light |
| **Service stairs** | Functional metal — **not** visible from guest spine |

Handrail height and grip feel **hospitality**, not code-minimum cold.

---

### Flooring

| Material | Zone | Rule |
| --- | --- | --- |
| **Polished white marble** | Public spine, showroom, reception | Veining **calm**; anti-slip treatment in wet paths |
| **Honed marble** | Atelier, consult (optional) | Less specular for camera + comfort |
| **Textile rug (ivory/wool)** | VIP, consultation waiting | Bound edge; no busy pattern |
| **Matte stone inset** | Threshold airlock | Signals transition |

Never: vinyl wood look, black glossy tile maze, red carpet.

---

### Stair language & vertical circulation

| Principle | Detail |
| --- | --- |
| **Primary guest path** | Prefer **single-level** luxury spine — stairs are **support**, not main retail climb |
| **Stair as sculpture** | Marble tread, glass guard, concealed lighting |
| **Elevator (if required)** | Marble + glass cab; mirror **one** surface max |
| **Service vertical** | Isolated — no shared landing with guest reveal |

Escalators: **avoid** — reads mall, not boutique.

---

### Reception language

| Element | Rule |
| --- | --- |
| **Desk** | Monolithic stone or stone + glass **waterfall** edge; human height engagement |
| **Backdrop** | Marble or soft plaster + **one** floral signature |
| **Queue** | Invisible — roam hosts, not stanchions |
| **Tech** | Under-counter; screens face staff, not guest |
| **Lighting** | Cove + portrait fill for faces — trilogy-compatible |

Reception is **Hero** architecture — must photograph from unlimited angles.

---

### Retail display language

| Element | Rule |
| --- | --- |
| **Pedestals** | Floating plinths; marble or acrylic block; **one** unit hero |
| **Wall display** | Vertical **gallery** niches; not pegboard density |
| **Comparison alcove** | Paired plinths + neutral backdrop |
| **Touch** | Gloves or sanitized touch policy — fixtures assume handling |
| **Security** | Invisible — no cage aesthetic |

Product is **sculpture**; architecture frames, never competes with lace/curl detail.

---

### Salon language (styling / install bays)

| Element | Rule |
| --- | --- |
| **Chair** | Matte leather; chrome base minimal; **no** racing stripes |
| **Mirror** | Architectural scale; integrated lighting at sides — not Hollywood bulbs |
| **Station storage** | Hidden; tools disappear |
| **Floor** | Honed or rug island within marble field |

Salon reads **suite**, not open warehouse floor.

---

### Consultation language

| Element | Rule |
| --- | --- |
| **Seating** | Two–three seat conversation cluster; low table |
| **Privacy** | Solid + glass layering; acoustic seal |
| **Display** | Tablet in leather folio; samples in **closed** trays |
| **Mood** | Brighter than therapy office, softer than boardroom |

---

### Lounge language (TV Lounge + VIP)

| Element | Rule |
| --- | --- |
| **TV Lounge** | **Cinematic dark** envelope; materials still **honest** (glass edge, marble side table) |
| **VIP** | Hospitality living room — sofa depth, rug, bar **quiet** |
| **Screen** | Architectural black rectangle; no sports-bar scale in boutique |

Dark ≠ cheap — **material tier unchanged**, luminance drops.

---

### Hospitality language (lockers, refreshment, departure)

| Element | Rule |
| --- | --- |
| **Refreshment** | Concealed service; fine china or minimal cup — no paper stack |
| **Lockers** | Hidden panel; attended |
| **Departure** | Soft light increase toward exit; Mansion bridge as **glass portal** metaphor |
| **Restroom** | Full marble/glass language; floral refresh; no plastic signage |

## MATERIAL LIBRARY (OFFICIAL PALETTE)

For each material: **purpose, finish, reflection, texture, durability, emotion, permitted zones, forbidden zones.**

| Material | Primary purpose | Finish | Reflection | Texture | Durability | Emotional effect | Permitted | Never |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **Natural stone (general)** | Structure, mass | Honed or polished per zone | Low–high controlled | Mineral truth | High | Permanence, trust | Floors, walls, desks | Exterior faux stone on interior hero |
| **White marble (hero)** | Brand anchor plane | Polished (public), honed (work) | Medium specular | Soft vein | High with care | Luxury, calm | Z1–Z2 spine, reception, Mansion marble UI | Yellow overload vein; fake repeat tile |
| **Glass (clear)** | Openness, partition | Optically clear | High | Smooth | Medium | Honesty, modernity | Storefront, partitions, rails | Green tint cheap |
| **Crystal / acrylic block** | Display, depth | Polished edge | Medium | Glass-like | Medium | Precision, jewel | Pedestals, awards, UI depth | Disco sparkle |
| **Chrome (polished)** | Accent only | Mirror | Very high | Smooth | Medium | Precision | Thin trim, hardware | Large mirror walls |
| **Brushed metal (steel/champagne)** | Structure, hardware | Directional brush | Low–medium | Fine grain | High | Craft, quiet tech | Handles, frames, legs | Mixed gold/silver chaos |
| **Acrylic (frosted)** | Diffuse light, privacy | Matte frost | Low | Micro-rough | Medium | Softness | Light panels, signage backup | Yellowing cheap panels |
| **Fabric (luxury wool, velvet)** | Acoustic, comfort | Matte | None | Soft nap | Medium | Warmth, femininity | Rugs, lounge, acoustic | Busy prints |
| **Leather (matte)** | Seating | Matte | Low | Natural grain | High | Confidence | Chairs, folios | Shiny pleather |
| **Wood (light oak / walnut)** | Human warmth accent | Oiled matte | Low | Fine grain | High | Approachability | Furniture accents, rare shelf | Rustic farmhouse |
| **Mirror (architectural)** | Depth, suite | Silver | High | Smooth | Medium | Transformation | Suite walls (one plane) | Mirror mazes, ceiling mirror |
| **Vegetation (planted)** | Life, calm | Natural | Low | Organic | Living care | Fresh luxury | Reception periphery, quiet room | Fake dusty plants |
| **Fresh florals (roses)** | Signature hospitality | Natural | Low | Soft | Days | Recognition, femininity | Reception, celebration, restrooms | Plastic flowers; excessive volume |
| **Water (feature)** | Calm, transition | Moving or still | Medium | Liquid | Maintained | Serenity | Optional threshold **small** feature | Loud fountain mall noise |

**Material triad (default interior):** marble plane + glass plane + one brushed metal line.

## COLOR SYSTEM

Implementation hex for product red: **`#EB1C24`** (signature action). Architectural roles below.

### Primary architectural colors

| Role | Description | Use |
| --- | --- | --- |
| **Architectural white** | Warm white, not blue | Walls, ceilings, marble base |
| **Ivory / cream** | Skin-adjacent warmth | Upholstery, plaster tint |
| **Champagne** | Quiet celebration | Metal hints, event tone |

### Secondary architectural colors

| Role | Description | Use |
| --- | --- | --- |
| **Warm gray** | Meta, secondary planes | Joints, subtle borders |
| **Soft black** | TV Lounge, screen fields | Controlled dark zones |
| **Marble veining gray** | Natural pattern | Floor/wall — not painted mimic |

### Accent colors

| Role | Rule |
| --- | --- |
| **Signature red** | **Pulse only** — see discipline below |
| **Rose-gold** | Rare hardware — never dominant field |

### Natural material colors

Stone veining, wood grain, skin, hair fiber **outrank** paint — do not paint over material truth.

### Lighting temperatures (architectural)

| Context | CCT band (target) |
| --- | --- |
| **Daylight retail** | 5000–5600K **filtered warm** (never green) |
| **Hospitality fill** | 3000–3500K |
| **TV Lounge** | 2700K accents on **low** dim; screens neutral |
| **Campaign morning** | Natural sun dominant — supplement, don’t fight |

### Brand color integration

Red appears in: **one** physical accent per vista (rose in floral, thin line, brand object), CTAs in digital twin, **never** full walls or floors.

### Red discipline (without overwhelming)

1. **One red moment per sightline** — floral stem, object, or digital CTA — not all three.  
2. **Never** red upholstery fields or red marble.  
3. **Never** red light on skin as key.  
4. Physical red **echoes** digital action color — same family, not new oranges.  
5. In dark zones, red **withdraws** — black and marble edge lead.

## LIGHTING LANGUAGE

Lighting supports **emotion**, not decoration. Aligns with [`visual-language.md`](../visual-language/visual-language.md) and trilogy **morning natural** exterior grammar.

### Natural daylight

| Condition | Architectural response |
| --- | --- |
| **Morning** | Primary campaign truth — soft angle, long gentle shadow |
| **Afternoon** | Diffuse blinds; protect product fade |
| **Evening** | Transition to cove + warm fill; storefront glow **inviting** |
| **Golden hour** | Exterior hero only; interior holds neutral |
| **Cloudy day** | Even skylight; no flat depression — fill coves gently |

### Campaign lighting

Exterior-facing zones **accept** natural key; interior supplements **invisible**. No “film set” visible instruments in guest spine during retail hours.

### Photography & film lighting

| Rule | Detail |
| --- | --- |
| **Key** | Upper front-quarter; soft |
| **Faces** | Kind; no horror under-chin |
| **Marble** | Highlight roll-off; no strobe veining |
| **Product** | Rim for lace/curl read |
| **Angles** | Set built for **360°** — light must work from trilogy pedestrian camera |

### Night lighting

Storefront: **warm interior glow** through glass; no Vegas strip. Security lighting **down**, not blasting facade.

### Mansion enhancements

| Physical | Mansion |
| --- | --- |
| Same cove grammar | **Interactive** dim scenes by room |
| Static sun | **Time-of-day** optional for mood — materials unchanged |
| Dark TV set | **Expanded** episode lighting presets — still matte dark envelope |

## FURNITURE LANGUAGE (RULES, NOT SKUS)

All furniture belongs to **one family**: low visual weight, matte + metal base, curved hospitality forms.

| Category | Principles |
| --- | --- |
| **Reception desk** | Monolithic or floating slab; standing guest + seated staff heights; cable-free surface |
| **Display tables** | Pedestal or thin-leg; max one hero per table |
| **Consultation seating** | Low lounge chairs + side table; conversation distance |
| **Salon stations** | Hydraulic quiet; mirror integrated; tools hidden |
| **Waiting lounges** | Sofa depth, arm support, rug anchor |
| **Coffee tables** | Stone top or glass; no clutter storage visible |
| **Pedestals** | Marble/acrylic; **float** with shadow gap |
| **Mirrors** | Large format, thin frame or frameless; side light not bulbs |
| **Display cases** | Glass vitrine; metal base; internal light **soft** |

**Prohibited:** Big-box retail fixtures, glossy MDF, mixed wood species, neon-edged gaming chairs.

## ARCHITECTURAL PRINCIPLES (PERMANENT LAW)

1. **Destination before salon** — public spine reads gallery-hospitality, not open barber hall.  
2. **Every space reveals another destination** — visibility program is law, not marketing.  
3. **Natural light is the primary storyteller** — artificial light **supports**, rarely dominates day.  
4. **Technology disappears into architecture** — no bolt-on screens or plastic shrouds.  
5. **No decorative element without purpose** — florals, water, art serve hospitality or story.  
6. **Architecture serves experience and cinematography** — set must shoot from unlimited angles.  
7. **Marble + glass + one metal** — default triad; exceptions documented (TV Lounge dark).  
8. **Red is pulse, not paint** — one red moment per vista maximum.  
9. **Femininity through material and life** — curve, rose, soft light — never cliché pink retail.  
10. **Calm is luxury** — acoustics, void, and slow sightlines beat density.  
11. **Private zones feel earned** — hidden until invited; never exposed from street.  
12. **Staff and production remain invisible** — service paths don’t cross guest reveal.  
13. **Dark zones stay honest** — TV Lounge dark envelope, same material tier.  
14. **Timeless over trendy** — no micro-trend finishes in permanent build.  
15. **Twin truth** — Mansion enhances depth; **never** changes marble/glass/metal identity.  
16. **Accessibility is designed luxury** — quiet room, clear paths, seated rest — not afterthought kit.  
17. **Comparison and education precede hard sell** — display grammar educates before price.  
18. **Campaign and retail share one set** — no duplicate “film facade” vs “real store.”  
19. **Touch and sanitation assumed** — materials survive luxury handling protocols.  
20. **If it isn’t in this language guide, it isn’t in the flagship** — Phase 4B must not invent orphan systems.

## DIGITAL TWIN COMPATIBILITY (BY SYSTEM)

| System | Physical flagship | Mansion |
| --- | --- | --- |
| **Exterior / storefront** | Strict | Echo facade grammar (Strict identity) |
| **Interior planes (marble/plaster)** | Strict | Identical materials + Enhanced parallax depth |
| **Glass / partition language** | Strict | Enhanced — interactive portals |
| **Ceiling / cove light** | Strict | Enhanced — scene presets, same warmth |
| **Doors / thresholds** | Strict | Enhanced — animated invites, same hardware look |
| **Retail display** | Strict | Enhanced — infinite catalog on same plinth grammar |
| **Salon / consult furniture** | Strict | Enhanced — optional virtual stylist overlay |
| **TV Lounge dark envelope** | Strict set | Enhanced — full library, interactive episodes |
| **Reception / PSA** | Strict | Enhanced — PSA concierge depth |
| **Checkout ritual** | Strict tone | Enhanced flow + Mansion-only order halls |
| **Fresh florals / scent** | Physical | Suggested digitally (subtle) — not gamified |
| **Water features** | Physical optional | Enhanced ambient sound only |
| **Staff / inventory / receiving** | Physical only | Not guest-navigable |
| **Campaign-only lighting rigs** | Physical production | Behind-the-scenes content optional |

**Summary:** **Strict** = material and proportion identity. **Enhanced** = depth, interactivity, scale. **Physical-only** = operations. **Never** Mansion-only cheap UI that breaks marble/glass law.
