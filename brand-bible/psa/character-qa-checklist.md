## Introduction — QA as Final Safeguard

PSA is a **long-horizon luxury ambassador**. Each published asset trains member trust. **Quality assurance** is the last line of defense before an image, clip, line of copy, or interactive state reaches a member.

QA protects:

| Risk | Without QA |
| --- | --- |
| **Likeness drift** | “Wrong person” at FAB scale |
| **Luxury erosion** | Hype, clutter, cheap light |
| **Performance fracture** | Smiling face + pressure copy |
| **Catalog untruth** | Support and revenue damage |
| **Universe break** | Mansion / guide role confusion |

**QA is not anti-creativity.** It ensures **excellence within canon**—the same standard as a flagship host on a premium network. Creative exploration belongs in **Tier 5 experimental** ([`character-continuity.md`](./character-continuity.md)); **publication** requires pass.

**Rule:** No member-facing PSA asset ships without **documented QA pass** per [`character-qa-checklist.md`](./character-qa-checklist.md).

---

## QA Philosophy

| Principle | Meaning |
| --- | --- |
| **Consistency over novelty** | Recognition compounds; novelty must serve guide intent |
| **Luxury through precision** | Small errors read as careless, not “authentic” |
| **Every detail signals quality** | Nails, metadata, and white balance all matter |
| **Small inconsistencies compound** | One wrong earring today; full identity loss in a year |
| **Invisible production** | Members feel one woman—not “app PSA vs ad PSA” |

**Excellence bar:** Would this pass **continuity supervisor + ECD** review on a **slow screen** at **thumbnail size**?

## Failure Classification

| Severity | Definition | Ship rule | Typical action |
| --- | --- | --- | --- |
| **Critical** | Tier 1 identity, likeness, truth, guide role, illegal/misleading | **Do not ship** | Reject; rebuild from reference |
| **Major** | Cohesion break, wrong slug, deprecated asset, catalog error | **Do not ship** | Fix layer; full re-QA |
| **Moderate** | Tier 3 drift (grade, minor wardrobe), channel misfit | **Do not ship** until fixed | Department fix + spot re-QA |
| **Minor** | Fixable metadata, crop, non-visible continuity | **Ship only if** ≤1 minor and ECD delegate OK | Fix + log |
| **Cosmetic** | Pixel-level retouch within bible | **Ship** with note | Optional fix |

**Threshold (aligns Gate 7):**

| Condition | Decision |
| --- | --- |
| **Any Critical** | Automatic reject |
| **Any Major** | Automatic reject |
| **≥2 Moderate** | Reject |
| **1 Moderate + any Minor** | Reject unless ECD exception documented |
| **≤1 Minor, 0 Moderate+** | Pass with revision note |
| **Psychology / truth fail** | Critical—always reject |

## Approval Workflow

| Stage | Owner | Deliverable |
| --- | --- | --- |
| **1 Creator review** | Artist / writer / eng | Self-check against this doc |
| **2 Department review** | Lead (animation, CX, brand) | Section pass notes |
| **3 Creative Director review** | ECD delegate | Canon compliance |
| **4 Brand review** | Brand Ops + continuity | Tier + universe |
| **5 Final QA approval** | QA lead / continuity supervisor | Signed checklist ID |
| **6 Publication** | Channel owner | Release + catalog `PUBLISHED` |
| **7 Archive** | DAM admin | Metadata on replace/deprecate |

**Sign-off record (minimum):** Asset ID or release ticket · date · reviewer · severity log · pass/fail.

  ├─ ≥2 Moderate? ──YES──▶ REJECT
  │
  NO
  │
  ├─ Unregistered asset (R4)? ──YES──▶ REJECT

## Metrics & Reporting

Track per **release train**, **campaign**, and **department** (quarterly ECD review):

| Metric | Definition | Use |
| --- | --- | --- |
| **QA pass rate** | Approved / submitted first pass | Vendor onboarding |
| **Recurring issues** | Top 5 fail codes (I7, P7, R4, …) | Bible/training updates |
| **Revision count** | Rounds to pass | Production efficiency |
| **Department performance** | Fail rate by team | Coaching |
| **Severity mix** | Critical/Major/Moderate counts | Risk trend |
| **Time to approve** | Draft → Final QA | Pipeline health |

**Issue coding:** Use section prefix + number (e.g. `I7-HAIR-COLOR`, `P7-COHESION`).

**Quality improvement loop:** Recurring **Major** on same code → bible clarification or automated check (future AI-assisted QA).
