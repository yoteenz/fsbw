## Introduction

PSA’s **accessories are punctuation**, not the paragraph. They signal **quiet luxury**, **professional permanence**, and **institutional trust**—the same signals as a flagship salon or premium broadcast host. When earrings, chains, or props **compete with PSA’s face**, education fails. When accessories **vanish or churn** between expressions, **recognition** fails.

This document is **permanent production specification** for every **jewelry piece and accessory object** PSA wears or handles. It is **not** a prompt library, fashion lookbook, shopping guide, or affiliate catalog. It defines **what may appear**, **how it reads on camera**, **how layers stack**, and **what is forbidden** without a versioned master-reference update.

> **Hierarchy:** Face → expression → hair → wardrobe → **accessories (quiet layer)**. Brand red `#EB1C24` belongs to **wardrobe/brand embroidery and UI**, not **noisy jewelry**.

> **Master reference authority:** The **canonical signature stack** is observed on the approved master portrait / expression library (`public/assets/psa-avatar-*.png`). Measured drawings and SKU vault links live in *Future Expansion*.

> **Expression discipline:** Per [`identity.md`](./identity.md), expression variants change **musculature only**—**same jewelry set**, same scale, same metal family, unless a new accessory bible version is approved.

## Accessory Philosophy

| Principle | Production meaning |
| --- | --- |
| **Quiet reinforcement** | Accessories **confirm** luxury; they **never** headline the frame. |
| **Recognition without noise** | A **stable gold stack + stud** supports “that’s PSA” at thumbnail scale. |
| **Education first** | Hands, face, and product/demo subjects stay **primary**; props **serve** the lesson. |
| **Timelessness** | No trend cycles, novelty shapes, or logo jewelry. |
| **Material honesty** | Metal reads **metal**; leather reads **leather**; glass reads **glass**—no plastic costume. |
| **One system** | All categories obey **one restraint grammar** (scale, finish, count). |

**Emotional communication (collective):** Competence, warmth, permanence, **earned** luxury—not display wealth or influencer flex.

## Luxury Through Restraint

Frontal Slayer luxury is **edited**, not **accumulated**.

| Restraint rule | Why |
| --- | --- |
| **Cap piece count** | More objects = more failure points (AI duplicates, clipping, FAB clutter). |
| **Cap visual weight** | Heavy chain is allowed **once** in the stack—not chain + huge pendant + belt + cuffs. |
| **Cap color** | **Warm gold** family dominant; **no** rainbow stones or neon straps. |
| **Cap motion noise** | Dangling elements **limited**—they fight lip-read and FAB crop. |
| **Cap branding** | **No** designer logos, **no** FS wordmark on jewelry (embroidery on wardrobe is separate wardrobe bible). |

## Jewelry Hierarchy

Priority when framing, lighting, and retouching—**protect higher layers first**.

| Rank | Element | Rule |
| --- | --- | --- |
| **1** | Eyes / brows / lashes | Never obscured by eyewear or hair accessory |
| **2** | Mouth | Never blocked by mic jewelry or large pendant |
| **3** | Cheek / jaw silhouette | Earrings **inside** silhouette or **small** at lobe |
| **4** | Neckline / décolletage | Chains **sit in** collar opening—**not** over face |
| **5** | Hands (when visible) | Rings/bracelets **subordinate** to gesture readability |
| **6** | Props | **Temporary** in frame; jewelry **persistent** |

## Signature Jewelry Collection

The **default canon set** for all expression PNGs, FAB, Lounge TV host, and concierge stills unless a documented **variation tier** applies (events).

| Piece | Canonical specification | Recognition role |
| --- | --- | --- |
| **Earrings** | **Single small polished yellow-gold stud** per lobe (visible lobe: typically **viewer’s left** in 3/4 master) | Pinpoint luxury without swing |
| **Necklace stack** | **Three-layer yellow-gold chain** stack, **no pendants** | Signature secondary marker |
| **Rings** | **None** in master reference default | Keep hands clean for FAB |
| **Bracelets** | **None** in master reference default | Reduce wrist clutter |
| **Watch** | **None** in master reference default | Avoid tech/date noise |

### Necklace stack detail (locked)

| Layer | Position | Chain character | Finish |
| --- | --- | --- | --- |
| **L1 (top)** | High collarbone | **Fine delicate cable** / micro chain | High polish yellow gold |
| **L2 (middle)** | Mid chest | **Medium oval / paperclip links** | High polish yellow gold |
| **L3 (bottom)** | Lowest in V of open collar | **Substantial curb / Cuban link** — **weight anchor** | High polish yellow gold |

**Why three layers:** Reads **intentional styling** and **luxury weight** while staying **one metal story**—not influencer randomness.

**Interaction with wardrobe:** Stack lives **inside** open collar (typical **white or neutral shirt** or **black/charcoal stylist base** per wardrobe spec)—chains **never** ride over chin.

## Earrings

| Field | Standard |
| --- | --- |
| **Purpose** | Subtle light catch at face edge; **not** ear focus |
| **Emotional communication** | Refined, finished, professional |
| **Luxury positioning** | **Real gold stud** read—micro scale Cartier-class restraint |
| **Visual hierarchy** | **Smallest** jewelry element in frame |
| **Wardrobe** | Cleared by hair behind ear; **no** conflict with collar |
| **Lighting** | **One specular point** per stud—no disco sparkle |
| **Camera movement** | **Fixed** to ear—no lag unless physics sim for video |
| **Animation** | Dots or small spheres—**no** dangling loop |

**Approved:** Round / soft geometric **studs**; **yellow gold**; **4–7 mm** apparent diameter at bust scale.

**Prohibited:** Hoops (large), chandeliers, shoulder-grazing drops, mismatched singles, pearl drops (unless event tier), logos.

## Necklaces

| Field | Standard |
| --- | --- |
| **Purpose** | Anchor **luxury weight** at neckline without pendant story |
| **Emotional communication** | Confidence, heritage warmth |
| **Luxury positioning** | Layered **real chain** weights—quiet **Hermès/Cartier** grammar |
| **Visual hierarchy** | **Secondary** to face; **primary** among jewelry |
| **Wardrobe** | Nested in **open collar V**; compatible with **black, charcoal, white** bases |
| **Lighting** | Specular **along links**; rim light may edge-gold—**hue locked** |
| **Camera movement** | Chains **settle** on chest with slight delay when walking |
| **Animation** | Link loops simplified; **layer count = 3** always |

**Layering rules:** See *Layering Rules*. **No** fourth chain without Founder exception.

## Approved Metals

| Metal | Role | Finish |
| --- | --- | --- |
| **Yellow gold (primary)** | All canonical jewelry | **High polish** |
| **Muted gold / champagne** | Alternate hardware on props | Satin acceptable on **props only** |
| **Sterling / white gold** | **Not** in default stack | Event exception only |

## Stone Philosophy

Stones **whisper**; they **never** shout in canon host.

| Principle | Application |
| --- | --- |
| **Purpose** | Light catch, heritage—not color story |
| **Emotional communication** | Permanence, calm wealth |
| **Default canon** | **No stones** in signature stack |
| **If used (exception)** | **Single** stone type per piece |

## Diamond Standards

## Chrome Integration

Frontal Slayer digital language uses **glass, marble, chrome** (`visual-language`, `CORE.md`). Accessories **echo**, not **copy UI chrome onto skin**.

| Context | Rule |
| --- | --- |
| **Jewelry** | **Gold-dominant**—no chrome ear cuffs |
| **Props (tablet, portfolio clasp)** | **Thin chrome edge** OK |
| **Holographic rim** | **Lighting effect**—not metal jewelry |
| **Reflection** | Chrome **single** specular—no mirrored face |

## Reflection Standards

| Rule | Detail |
| --- | --- |
| **Specular count** | **Limited**—stud + link highlights, not **full frame sparkle** |
| **Key light** | Elongated soft specular on curb chain |
| **Rim light** | May **edge** chains; **must not** shift gold to white chrome |
| **Grade** | Exposure OK; **hue family locked** |

## Layering Rules

```
Neck (canonical):

   [Face]
     │
   L1 fine cable      ─── shortest
   L2 paperclip       ─── mid
   L3 curb/Cuban      ─── longest (weight anchor)

Rules:
  • 3 chains max (canon)
  • Same metal family
  • No pendants between layers
  • Layers nest flat on chest — no tangled AI knot
```

| Zone | Max items |
| --- | --- |
| **Ears** | 1 stud per lobe (2 total if both visible) |
| **Neck** | 3 chains |
| **Wrists** | 0 default; 1 event |
| **Fingers** | 0 default; 1 event |

---

## Proportion Standards

| Reference | Guideline |
| --- | --- |
| **Stud vs face** | Stud **≤ 1/40** face width at bust crop |
| **L3 curb width** | **Substantial** but **fits within collar V**—not shoulder-wide |
| **Chain drop** | Lowest link **above** garment logo embroidery zone when possible—**jewelry ≠ logo** |
| **Prop vs torso** | Portfolio **≤ 1/3** torso height in frame |

**Scale test:** Squint test—**face remains first read**.

---

## Continuity Standards

| Rule | Detail |
| --- | --- |
| **Set lock** | **Same** earrings + **same** 3-chain stack across expressions |
| **No drift** | **No** swap to silver, pearls, or pendants per slug |
| **No duplication** | **One** stack—AI **must not** double chains |
| **Clipping** | Chains **may** clip shirt slightly—**must not** clip **through** neck skin |
| **Physics** | Drape **downward** on chest; **follow** body turn with lag |
| **Wardrobe change** | If wardrobe bible approves new base, chains **remain** same stack |
| **Versioning** | New jewelry **only** via bible version + master reshoot |

### Continuity checklist

- [ ] Signature **3-layer gold stack** present (host canon)  
- [ ] **Small gold stud(s)** present  
- [ ] **No** pendants, logos, or fashion colors  
- [ ] **No** extra rings/bracelets/watch (default tier)  
- [ ] Metal **yellow gold polish**—not silver/chrome jewelry  
- [ ] **Face** remains primary focus  
- [ ] Matches [`identity.md`](./identity.md) expression discipline  
- [ ] **No** plastic or fast-fashion read  
- [ ] Reflections **controlled**—not strobing  
- [ ] Animation **same count** of layers

## Accessories Across Media

| Medium | Standard |
| --- | --- |
| **Photography** | Reference truth; **no** remove/replace stack in retouch |

## Quality Assurance Checklist

| # | Question |
| --- | --- |
| 1 | Do accessories **support** luxury without **competing** with PSA’s face? |
