## Introduction

PSA’s **hands are education tools** and **trust signals**. Members see them in chat avatar states (`waving`, `pointing`, `presenting`, `talking`), in tutorials, demos, and future video. Gestures must be **recognizable**, **restrained**, and **hospitality-forward**—never influencer theatrics or aggressive direction.

> **Identity lock:** **Five fingers**, natural knuckles, graceful stylist hands ([`identity.md`](./identity.md)). **Bad hands = instant reject.**

> **Luxury gesture grammar:** **Small, slow, open, intentional.**

## Gesture Philosophy

| Principle | WHAT | WHY | Brand recognition |
| --- | --- | --- | --- |
| **Open palms default** | Invitation, not command | Hospitality | Apple Retail calm |
| **Small amplitude** | Wrist-elbow range; not full windmill | Luxury restraint | Distinct from influencer |
| **Slow speed** | Readable on mobile & TV | Education | Host credibility |
| **Low frequency** | Gesture → return to rest | Calm authority | FAB readability |
| **Product respect** | Two-hand handling for units | Category authority | FS craft |
| **Member respect** | Never point **at** member face | Trust | Concierge ethics |

## Permanent Gesture Standards

| Dimension | Standard |
| --- | --- |
| **Hand openness** | Palms visible when directing; no hidden intent |
| **Gesture size** | **Small–medium**; fits bust/FAB frame |
| **Speed** | **Slow–moderate**; demo slowest |
| **Timing** | Start **after** verbal cue or simultaneous; complete before next line |
| **Frequency** | **1 active gesture per idea**; return to rest |
| **Finger positioning** | Relaxed extend; index only for soft point |
| **Palm orientation** | Up or neutral open—not downward dismiss |
| **Precision** | Fingertips aim at **feature**, not vague air |
| **Elegance** | Wrist lead, not elbow spike |
| **Restraint** | No double gesture stack |
| **Smoothness** | Ease-in/out; no snap |
| **Intentionality** | Every motion has job |

## Open Palm Communication

Default **luxury grammar**:

```
REST → OPEN (palm up/neutral) → HOLD 12–24 frames → REST
```

Used for: invite, present, reassure, transition.

## Gesture Playbooks (structural)

### Welcome someone into a room

Open torso + planted feet → optional one-hand wave → open palm invite inward → **rest**.

### Introduce products

Eye to product → present palm → one feature point → rest.

### Present hair (on mannequin/unit)

Two-hand support → slow rotate edge → open palm on lace/hairline.

### Demonstrate technology

One-hand touch, other relaxed; device chest-high; **no** face block.

### Guide through mansion (narrative space)

Walk lead → pause at junction → open palm direction → check member follows.

### Invite interaction

Palm up “your turn” toward UI/touchpoint; verbal invite per dialogue bible.

### Conclude consultations

Nod → hands clasp low → stillness; **no** handshake unless scripted human event.

### Transition topics

Small open palm “bridge” → rest → new present.

### Celebrate customer success

Micro open hands once → return rest ([`acting.md`](./acting.md) face `celebrating`).

### Respectfully redirect attention

Open palm redirect to correct topic/path; **no** finger wag.

## Prohibited Gestures

| Prohibited | Why |
| --- | --- |
| Aggressive pointing at member | Trust |
| Finger wagging | Scolding |
| Large theatrical arms | Influencer |
| Excessive waving | Childlike / noisy |
| Constant hand movement | Anxiety |
| Crossed arms / hidden hands | Defensive |
| Impatient chop | Rudeness |
| Fidgeting / hair touch loop | Unprofessional |
| Hands behind back during demo | Hides intent |
| Finger guns, peace signs | Trend |
| Grabbing member arm | Boundary |
| **Sixth finger / melted hands** | AI fail |
