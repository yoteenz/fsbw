## Introduction

PSA’s **nails are continuity equipment**. In education, concierge chat gestures, product demonstrations, and close-ups, hands enter frame often—and **hands are a primary AI failure surface** ([`identity.md`](./identity.md)). Nails must read **salon-maintained, luxury-neutral, and timeless**—never trend canvas, never distraction.

This document is **not** a nail tutorial, consumer beauty advice, prompt pack, or generation brief. It defines **shape, length, finish, color family, and continuity** for every medium.

> **Goal:** **Recognizable grooming**, not fashionable nails. If nails are remembered before PSA’s face or lesson, the standard **fails**.

> **Master reference authority:** Measured specs and reference stills lock to the approved master portrait set and secure vault (*Future Expansion*). Observable canon below is **production truth**.

## Nail Philosophy

| Principle | WHAT | WHY | HOW (identity) | WHEN vary | WHEN never vary |
| --- | --- | --- | --- | --- | --- |
| **Quiet luxury** | Manicure **finished but quiet** | Luxury = restraint | Supports educator credibility | Event +5% gloss only | No novelty art |
| **Timelessness** | No micro-trends | Host asset for years | Matches makeup/hair philosophy | — | No seasonal themes |
| **Education first** | Nails **never** steal gesture read | Hands teach lace, parting, density | Short-neutral shape | — | No long dramatic lengths |
| **Human realism** | Believable nail beds | Trust | Subtle imperfection OK | — | No plastic claws |
| **Stylist hands** | **Graceful, groomed** | Category authority | Parallel to hair bible quality | — | Five fingers, natural proportions |

## Luxury Through Grooming

Grooming signals **competence** the same way PSA’s hair signals **craft**.

| Signal | Standard |
| --- | --- |
| **Maintained** | Even lengths, clean cuticles, no chips at hero delivery |
| **Restrained color** | Neutral palette only (see below) |
| **Restrained length** | Functional for typing, gesturing, demonstrating |
| **Restrained art** | **None** in canon default |

**Comparison:**

| Luxury grooming | Not luxury |
| --- | --- |
| Even sheer nude gloss | Chipped polish |
| Soft filed shape | Broken/spike shapes |
| Clean cuticle line | Hangnail chaos |
| Consistent set shot-to-shot | Random length drift |

## Signature Nail Identity

**Canonical default (host, FAB, expressions, TV, tutorials):**

| Attribute | Specification |
| --- | --- |
| **Shape family** | **Soft square to soft almond** — balanced, feminine, **not** stiletto |
| **Length** | **Short to short-medium** — **past fingertip ≤ 2 mm** apparent extension |
| **Color** | **Sheer nude / soft pink beige** unified across all nails **or** classic **soft French** (see French standards) |
| **Finish** | **Natural high gloss** (default) |
| **Art** | **None** |
| **Accent nails** | **Forbidden** in canon |

**Recognition:** At hand close-up, nails read **“salon executive manicure”**, not **“content creator nail art.”**

---

## Shape Standards

| Shape | Status | WHY |
| --- | --- | --- |
| **Soft square** | **Approved primary** | Clean, timeless, camera-stable |
| **Soft almond** | **Approved alternate** | Slightly elegant; same length caps |
| **Round** | **Acceptable** if reference locked | Youthful—use only if master reference dictates |
| **Coffin / ballerina** | **Prohibited** | Trend + AI distortion |
| **Stiletto / extreme almond** | **Prohibited** | Distracting, impractical for demo |

**WHEN vary:** Founder-approved master reshoot only.  
**WHEN never vary:** Per-expression slug random shape changes.

---

## Length Standards

| Zone | WHAT | WHY |
| --- | --- | --- |
| **Free edge** | **Minimal** — nails **do not** extend dramatically past fingertip | Gesture clarity, realism |
| **Uniformity** | All five nails **even** within **≤ 0.5 mm** apparent tolerance | Continuity |
| **Thumb** | **Not longer** than index exception for gimmick | Balanced hand read |

**WHEN vary:** **Never** longer for events. **May** appear **slightly shorter** if reference updates—never longer without bible version.

**Prohibited:** Long dramatic nails, uneven lengths, one extra-long accent nail.

---

## Width & Proportion

| Standard | Detail |
| --- | --- |
| **Nail plate width** | Proportional to phalanx—**no** oversized paddle nails |
| **Side walls** | Parallel, **no** extreme taper to needle |
| **Finger length** | Identity lock—**no** elongated AI fingers ([`identity.md`](./identity.md)) |

**WHY:** Correct proportions prevent uncanny hands and keep **stylist hands** credible.

---

## Cuticle Standards

| WHAT | WHY | HOW |
| --- | --- | --- |
| **Neat, hydrated cuticle line** | Luxury maintenance signal | Soft pushback read; no ragged skin |
| **No bleeding or inflammation** | Health + trust | Reject hero frames |
| **No over-cut “micro wound” red** | Salon professional | Editorial cleanup only within retouch bounds |

**WHEN never vary:** Sloppy cuticles in close-up education content.

---

## Surface Finish

| Finish | Role |
| --- | --- |
| **Smooth plate** | Even reflection |
| **No ridges** | Avoid aged or damaged read unless scripted |
| **No bubbles / dimples** | AI artifact reject |

---

## Polish Philosophy

Polish **enhances grooming**; it **does not** express fashion cycles.

| Principle | Application |
| --- | --- |
| **One color story** | All ten nails match (or classic French two-zone) |
| **Sheer builds** | Skin shows through slightly—believable |
| **Opacity** | Medium-sheer nude default; full opaque nude OK |
| **Wear** | **No visible chips** at delivery |

**WHY:** PSA is **institutional host**, not nail influencer.

---

## Neutral Color Palette

Approved **hue families** (describe, not product SKUs):

| Family | Read | Status |
| --- | --- | --- |
| **Sheer pink beige** | Clean salon nude | **Default** |
| **Soft rose nude** | Warmth on deeper skin tones | **Approved** |
| **Translucent jelly nude** | Natural | **Approved** |
| **Classic soft French** | Pink bed + soft white free edge | **Approved alternate** |
| **Sheer beige/cream** | Neutral luxury | **Approved** |

**Prohibited:** Bright red, black, neon, chrome, glitter, dark fashion colors, **brand red `#EB1C24` on nails** (red stays wardrobe/UI accent).

---

## French Manicure Standards

| Element | Standard |
| --- | --- |
| **Smile line** | **Soft**, not harsh V; **thin** free edge |
| **White tip** | **Off-white / ivory**, not optic white stripe |
| **Bed color** | Sheer pink compatible with skin undertone |
| **Style** | **Classic**, not exaggerated long tip |

**WHY:** Timeless editorial; reads professional on camera.

**WHEN vary:** Alternate to sheer nude **one look per reference set**—not mixed within expression library.

---

## Gloss Standards

| WHAT | WHY | WHEN |
| --- | --- | --- |
| **High gloss default** | Healthy, salon-fresh | Host, FAB, TV |
| **Specularity** | **One soft highlight** per nail—not mirror blob | All photography |
| **Layer read** | Single cohesive coat | — |

**Event variation:** Slightly **brighter gloss in grade** only—no new product finish.

---

## Matte Standards

| WHAT | WHY | WHEN |
| --- | --- | --- |
| **Matte** | **Not default** | Can read dry or trendy |
| **Allowed** | **Rare** Founder exception for specific campaign stills | Non-canon or versioned shoot |

**Default canon:** **Gloss or natural satin sheen.**

---

## Seasonal Variations

| WHAT | WHY |
| --- | --- |
| **No seasonal nail art** | Identity stability |
| **No holiday palettes** | Avoid meme association |

**WHEN vary:** **Never** for seasons in canon PSA.

## Event Variations

| Tier | Allowed | Forbidden |
| --- | --- | --- |
| **Red carpet / formal** | **Same shape/length**; optional **micro-shimmer sheer** (not glitter) | Rhinestones, art, longer length |
| **Luxury event** | **French or nude gloss** only | Bright colors |

**Rule:** Events change **lighting**, not **nail story**.

---

## Camera Close-Up Standards

| Shot type | Requirement |
| --- | --- |
| **Macro hand** | Cuticle clean; polish even; **five fingers** |
| **4K scrutiny** | Micro texture OK; **no** AI smear on nail beds |
| **Color grade** | Hue family locked—grade exposure, not neon shift |
| **Focus** | Nails sharp when hands hero; **no** waxy merge with skin |

## Hand Modeling Standards

Aligned with [`identity.md`](./identity.md) gestures:

| Gesture | Nail visibility |
| --- | --- |
| **Presenting** | Palm angle shows **even nail line** |
| **Pointing** | **Single index**—nail **not** weapon-long |
| **Waving** | **Short edge**—not claw flash |
| **Talking** | Hands in frame **consistent** set |

**Jewelry:** Default **no rings** ([`jewelry-accessories.md`](./jewelry-accessories.md))—nails remain primary hand detail.

---

## Jewelry Interaction

| Rule | Detail |
| --- | --- |
| **Rings default** | **None**—nails unobstructed |
| **Event ring** | **Thin band** only—must **not** cover nail plate |
| **Bracelet** | Does not change nail spec |

**WHY:** Demo and education need **clean nail read**.

---

## Product Demonstration Standards

| Context | Standard |
| --- | --- |
| **Lace / hairline demo** | **Short nails**—no scratching visual |
| **Comb / clip handling** | Grips look **professional** |
| **Unit display** | Nails **neutral**—product color is hero |
| **On PSA’s head** | **Not** applicable—do not style PSA with product-as-nails |

**WHY:** Hands are **tools of teaching**, not secondary product ads.

---

## Gesture Visibility

```
Priority in hand frame:

  1. Gesture meaning (point, present, open palm)
  2. Finger count & anatomy
  3. Nail grooming read (neutral, even)
  4. Jewelry (minimal)
```

**Nails support (3); they must not overpower (1).**

## Realism Standards

| Standard | Reject |
| --- | --- |
| Anatomically correct nail beds | Floating nails |
| Polish follows plate curvature | Flat sticker nails |
| Specular moves with light | Static white squares |
| **Five fingers** | Extra/missing digits |

---

## Natural Imperfections

| Allowed | Not allowed |
| --- | --- |
| **Subtle** vertical micro-lines at macro | Dirty edges |
| **Tiny** asymmetry finger-to-finger | Broken index long, others short |
| Human skin texture at knuckle | Plastic glove hand |

**Luxury ≠ sterile 3D shader.**

## Continuity Standards

| MUST stay constant | MAY NOT change |
| --- | --- |
| Shape family | Coffin day, square next shot |
| Length band | Longer for “glam” expression |
| Color family | Red episode, art episode |
| Finish default (gloss) | Glitter slug |
| Even lengths | Broken set |
| No art (default) | Seasonal art |

### Continuity checklist

- [ ] **Short–short-medium** length band  
- [ ] **Soft square or soft almond** shape  
- [ ] **Neutral** sheer nude **or** approved French—**consistent across all visible nails**  
- [ ] **High gloss** (default)  
- [ ] **Clean cuticles**, no chips  
- [ ] **Five fingers**, natural proportions  
- [ ] **No** art, rhinestones, bright color  
- [ ] **No** rings default; jewelry bible compliant  
- [ ] Same as other expressions in library  
- [ ] Hands pass identity **AI failure** reject rules

## Quality Assurance Checklist

| # | Question |
| --- | --- |
| 1 | Do nails read **luxury groomed**, not trendy? |
| 2 | Are they **instantly subordinate** to face/gesture/education? |
| 3 | **Shape and length** within approved bands? |
| 4 | **Neutral palette** only (or approved French)? |
| 5 | **No art, gems, or bright color**? |
| 6 | **Even lengths**, no chips? |
| 7 | **Five fingers**, believable anatomy? |
| 8 | Consistent across **expression assets**? |
| 9 | Compatible with **jewelry** defaults? |
| 10 | **Timeless** five-year test? |
| 11 | Strengthens **Frontal Slayer** expert identity? |
| 12 | Realistic finish—not plastic? |

**Two or more NO → reject or fix.**
