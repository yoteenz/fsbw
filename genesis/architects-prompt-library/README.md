The Architect's Prompt Library™ is Studio OS's permanent institutional repository for architecture prompts, implementation prompts, validation prompts, research prompts, design prompts, and future AI workflows.

It is not a folder of prompts.

It is the internal operating manual for building Studio OS.

## Prime doctrine

```text
Prompts are architectural assets, not disposable instructions.
```

## Core objects

| Object | Purpose |
|--------|---------|
| Collection™ | Curated shelf of prompts serving an operating purpose |
| Category™ | Canonical prompt domain with review standards |
| Prompt Template™ | Reusable instruction artifact |
| Prompt Version™ | Versioned evolution record |
| Execution History™ | Record of model, context, output, artifacts, review |
| Generated Output™ | Artifact produced by a prompt |
| Validation Result™ | Evidence of output quality |
| Model Performance Record™ | Which model works best for which prompt/category |
| Lesson Learned™ | What prompt execution taught Studio OS |
| Genesis Reference™ | Canonical relationship to Genesis articles/proposals |

## Lifecycle

```text
Draft → Review → Execution → Output Review → Founder Approval
→ Genesis References Updated → Canonized → Archived
```

## Canon rule

No prompt becomes canonical without review, execution evidence, quality scoring, version history, and accurate Genesis relationships.
