# Build Order Registry

Canonical system records for the Studio OS Build Order Engine™.

**Runtime:** `src/studio-os-core/genesis/build-order/build-order/registry.ts`  
**Schema:** [`system.schema.json`](./system.schema.json)

Every system stores: system ID, official name, architectural phase, priority, dependencies, dependents, blocked-by, blocks, complexity, business/platform value, estimated build time, architectural/implementation readiness, rewrite/debt risks, and current status.
