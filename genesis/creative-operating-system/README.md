**Parent:** Studio Intelligence Layer™ · Creative Direction Studio™  
**Relationship:** Permanent executive creative organization above Studio Production System™

Creative Operating System™ turns Creative Direction Studio™ into a continuous
creative company, not a software surface and not a collection of individual AI
agents.

It owns the organizational layer that lets departments collaborate, knowledge
compound, and every production improve the next.

## Rule

Studio Production System™ executes governed productions.

Creative Operating System™ governs the creative company that decides, learns,
remembers, evolves, and reuses across productions.

Future runtime work should model durable organizational objects: Executive
Creative Board™, Creative Council Session™, Unified Creative Recommendation™,
Founder Creative Decision™, Creative Memory Record™, Production Memory Record™,
Creative Learning Event™, Evolution Proposal™, and Creative Economy Asset™.
