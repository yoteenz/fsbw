# Narrative Intelligence™

**Ontology:** [`../articles/NARRATIVE_INTELLIGENCE.md`](../articles/NARRATIVE_INTELLIGENCE.md)  
**Parent:** Studio Intelligence Layer™ · Experience Runtime™  
**Status:** canonical architecture draft  
**Compiled guide:** [`../../docs/studio-os/genesis/NARRATIVE_INTELLIGENCE.md`](../../docs/studio-os/genesis/NARRATIVE_INTELLIGENCE.md)

Narrative Intelligence™ is the experience-design layer that turns company truth,
brand meaning, audience desire, product promise, founder taste, and proof into a
resolved **Narrative Experience™** before any content, video, campaign, page,
package, or asset is produced.

Creative Direction Studio™ should not generate videos first.

Creative Direction Studio™ should generate experiences.

## Subsystems

| Folder | Role |
|--------|------|
| `narrative-intelligence/` | Narrative reasoning layer and source object model |
| `production-genome/` | Format-agnostic production DNA for reusable execution |
| `experience-arc/` | Arrival → Recognition → Tension → Desire → Proof → Transformation → Invitation → Memory |
| `storyworld-graph/` | Persistent graph of myths, symbols, proof, motifs, transformations, and anti-stories |
| `emotional-journey/` | Intended emotional progression and transformation model |
| `moment-map/` | Ordered graph of experiential moments before scenes or formats |
| `proof-system/` | Evidence and credibility architecture for narrative trust |
| `production-brief/` | Governed handoff from narrative to production systems |
| `experience-score/` | Narrative quality, proof quality, emotional clarity, and production readiness |

## Rule

Content is an output container.

Narrative Experience™ is the canonical source object.
