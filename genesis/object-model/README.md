# Genesis Canonical Object Model™

**Ontology:** [`../articles/CANONICAL_OBJECT_MODEL.md`](../articles/CANONICAL_OBJECT_MODEL.md)  
**Runtime:** `src/studio-os-core/genesis/object-model/`  
**Admin:** `/admin/studio/genesis` → Object Model tab

The Canonical Object Model is Studio World's first-class object framework. Registry starts **empty** — no Studio World feature content is seeded at runtime.

## Structure

| Path | Purpose |
|------|---------|
| `object-types/` | 56 canonical object type definitions |
| `object-registry/` | Canonical Object Registry™ |
| `object-factory/` | Object registration and updates |
| `object-relationships/` | Relationship Engine™, inheritance, composition, references |
| `object-validation/` | Validation Engine™ and graph traversal |
| `object-versioning/` | Object Versioning™ |
| `object-history/` | Object History™ archive |

## Rule

Model concepts as canonical objects plus relationships before implementing pages, routes, or components.
