# Genesis Live Validation System™

**Ontology:** [`../articles/LIVE_VALIDATION_SYSTEM.md`](../articles/LIVE_VALIDATION_SYSTEM.md)  
**Program:** Studio OS Launch Stack™  
**Parent:** Founder Acceptance Testing™  
**Runtime:** `src/studio-os-core/genesis/live-validation-system/`  
**Platform guide:** [`../../docs/studio-os/genesis/LIVE_VALIDATION_SYSTEM_PLATFORM.md`](../../docs/studio-os/genesis/LIVE_VALIDATION_SYSTEM_PLATFORM.md)  
**Experience:** `/admin/studio/live-validation-system`

Live Validation System™ makes Founder Acceptance Testing™ continuous and invisible.

The founder should never feel like they are testing software.

Studio OS should learn from natural business operation: what the founder uses, avoids, replaces, escapes, trusts, depends on, and finds delightful.

## Core systems

| System | Purpose |
|--------|---------|
| **Founder Diary™** | Adaptive daily reflection operated by Orb |
| **Escape Velocity™** | Signature metric for meaningful work completed outside Studio OS |
| **Daily Reflection™** | Lightweight reflection driven by actual founder activity |
| **Weekly Executive Review™** | Orb synthesis of validation trends and business operation |
| **Launch Stack Health™** | Milestone readiness and validation score |
| **Company Health™** | Company-level operating improvement from Studio OS |
| **Orb Self-Evaluation™** | Orb's own usefulness, interruption, recommendation, and learning score |
| **Mission Effectiveness™** | Whether Studio OS helps real missions move |
| **Knowledge Health™** | Retrieval confidence, source truth, missing knowledge, stale answers |
| **Automation Health™** | Safe completion, approval, reversal, recovery, and trust |

## Prime rule

```text
Founder behavior becomes validation evidence.
Validation evidence becomes Genesis learning.
Genesis learning becomes platform improvement.
```

## Relationship to FAT

Founder Acceptance Testing™ defines the gates.

Live Validation System™ continuously gathers the evidence that determines whether those gates are truly passed.
