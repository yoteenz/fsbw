# Studio Production System™

**Canonical article:** [`../articles/STUDIO_PRODUCTION_SYSTEM.md`](../articles/STUDIO_PRODUCTION_SYSTEM.md)  
**Status:** canonical architecture draft  
**Compiled guide:** [`../../docs/studio-os/genesis/STUDIO_PRODUCTION_SYSTEM.md`](../../docs/studio-os/genesis/STUDIO_PRODUCTION_SYSTEM.md)

Studio Production System™ is the permanent production division inside Studio
Intelligence™. It makes Creative Direction Studio™ operate like a Hollywood-style
AI production company: approved Narrative Blueprints™ become Production
Packages™, departments are assigned, assets are generated only after gates, and
distribution/performance learning closes the loop.

## Production flow

```text
Topic
  -> Brand DNA™
  -> Audience DNA™
  -> Narrative Intelligence™
  -> Approved Narrative Blueprint™
  -> Production Genome™
  -> Assign Production Departments™
  -> Generate Assets
  -> Quality Review™
  -> Distribution™
  -> Performance Analytics™
```

## Rule

No asset is created until an approved Narrative Blueprint™ and Production
Package™ authorize the production.
