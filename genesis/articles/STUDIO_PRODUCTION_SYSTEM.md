## 0. Prime directive

```text
Creative Direction Studio™ is not a content generator.
Creative Direction Studio™ is an AI production company.
```

Studio Production System™ is the permanent production division inside Studio
Intelligence™. It turns an approved Narrative Blueprint™ into an organized
production pipeline with departments, specialists, approvals, quality gates,
distribution packages, and performance learning.

It does not begin by asking:

```text
What should we generate?
```

It begins by asking:

```text
What production company must Studio OS assemble to execute this narrative safely,
beautifully, on-brand, and with founder-approved quality?
```

---

## 1. Why this system exists

Narrative Intelligence™ defines the experience.

Production Genome™ defines the reusable production DNA.

Studio Production System™ operates the company that executes the work.

Without this layer, Studio OS risks treating creative work as isolated prompts,
files, or media outputs. With this layer, every creative initiative moves through
a real production-company operating model:

```text
Topic
  -> Brand DNA™
  -> Audience DNA™
  -> Narrative Intelligence™
  -> Approved Narrative Blueprint™
  -> Production Genome™
  -> Production Team Assembly
  -> Department Execution
  -> Quality Review
  -> Distribution
  -> Performance Analytics
  -> Memory / Canon Learning
```

The system is format-agnostic. It can produce video, campaign, course, podcast,
newsletter, blog, community, commercial, headquarters scene, social package, or
launch sequence, but none of those are the core object.

The core object is the **Production Package™**.

---

## 2. Anti-patterns

Studio Production System™ must never become:

- a button that calls a generation model directly
- a prompt wrapper around a video generator
- a content calendar without production intelligence
- a template library pretending to be a studio
- an asset factory that bypasses narrative approval
- a distribution scheduler without quality gates
- a performance dashboard disconnected from creative decisions
- an automation that publishes without founder-approved gates

No model, tool, generator, department, or downstream system may create or publish
production assets without an approved Narrative Blueprint™ and a Production
Package™ plan.

- audience segment
- required production departments
- assigned AI specialists
- casting plan
- production design plan
- camera plan
- sound plan
- post-production plan
- distribution plan
- quality gates
- approval gates
- required source assets
- generated asset manifest
- dependencies
- schedule / stage status
- escalation log
- founder approvals
- performance metrics
- memory outcomes

Status lifecycle:

```text
intake
  -> team-assembly
  -> pre-production
  -> production-design
  -> asset-production
  -> editorial
  -> quality-control
  -> approval
  -> distribution-ready
  -> published
  -> performance-review
  -> archived / canon-candidate
```

## 5. Automatic production team assembly

When a creator clicks **CREATE CONTENT**, Studio Intelligence™ must not generate
content immediately.

It assembles the production company.

```text
CREATE CONTENT
  -> resolve topic / goal
  -> consult Company Operating Manual™
  -> consult Brand DNA™
  -> consult Audience DNA™
  -> consult Product DNA™
  -> consult Taste Genome™
  -> generate / load Narrative Blueprint™
  -> require blueprint approval
  -> load Production Genome™
  -> infer production type
  -> assign departments
  -> assign AI specialists
  -> open Production Control Room™
```

Department assignment depends on:

- narrative type
- production format targets
- audience risk
- brand complexity
- product complexity
- required proof
- required talent / characters
- distribution surfaces
- compliance / trust risk
- founder approval preferences
- historical performance

---

## 6. Department contract

Every Production Department™ must expose the same contract:

| Field | Requirement |
|-------|-------------|
| Responsibilities | What the department owns and does not own |
| Inputs | Required upstream intelligence, approvals, assets, and constraints |
| Outputs | Structured department deliverables |
| Approval Gates | Human or system gates before downstream handoff |
| AI Specialists | Specialist roles assigned to the department |
| Knowledge Sources | Canonical sources consulted before action |
| Success Metrics | How quality/performance is evaluated |
| Escalation Rules | When the department must stop and escalate |

This makes production explainable, auditable, and reusable.

## 8. Casting Intelligence™

Casting Intelligence™ decides who or what appears, when, and why.

### 8.1 Castable roles

- Founder
- Orb™
- AI Specialists
- Virtual Experts
- Customer Personas
- Voice Actors
- Narrators
- Hosts
- Guests
- Brand Characters
- Digital Humans
- Animated Characters

### 8.2 Appearance logic

| Role | Appears when |
|------|--------------|
| Founder | Founder trust, authority, legacy, personal POV, premium proof, personal welcome, or brand-defining stakes are required |
| Orb™ | Guidance, memory, evidence, recommendation, or headquarters continuity is required |
| AI Specialist | A department needs visible expertise: stylist, producer, analyst, editor, instructor, advisor |
| Virtual Expert | Professional trust, explanation, regulated caution, or expert teaching is needed |
| Customer Persona | Audience recognition, objection handling, or transformation mirroring is needed |
| Voice Actor | Emotional narration or platform-native voice is better than founder or Orb presence |
| Narrator | Story clarity, episode continuity, or documentary structure is required |
| Host | Series format, repeatable show structure, or audience relationship is required |
| Guest | External proof, testimonial, collaboration, or expert credibility is required |
| Brand Character | Brand mythology, recurring mascot, or playful/luxury memory device is required |
| Digital Human | Human presence needed without founder availability; requires likeness and trust review |
| Animated Character | Simplification, teaching, humor, fantasy, or youth/family accessibility is required |

### 8.3 Casting gates

- real identity / likeness gate
- testimonial / proof gate
- professional claim gate
- brand character canon gate
- voice rights gate
- audience sensitivity gate

## 21. Governance

Rules:

1. No asset may be generated without an approved Narrative Blueprint™.
2. No Production Package™ may advance without department assignment.
3. No department output may overwrite upstream canon.
4. No real-person likeness, testimonial, professional claim, or regulated advice
   may publish without explicit review.
5. No platform package may publish without QC pass and distribution approval.
6. Performance learning may propose genome/canon updates, but founder approval
   and Canon Engine™ review are required.
7. Rejected production plans are valuable memory and should be archived with
   reason codes.
