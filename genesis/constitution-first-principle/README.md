Constitution First Principle™ separates constitutional architecture from systems
engineering:

- **GPT-5.6 Terra** governs architecture.
- **Composer 2.5** implements approved architecture.
- **Genesis** is binding source of truth.
- **Architecture Review Request™** is mandatory when implementation discovers a
  material conflict, missing dependency, unclear owner, unsafe/impossible
  constraint, or required architectural change.

The principle extends Codex First Principle™ with an enforceable authority
boundary and implementation-to-architecture feedback loop.
