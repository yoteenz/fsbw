# Experience Engine™

**Ontology:** [`../articles/EXPERIENCE_ENGINE.md`](../articles/EXPERIENCE_ENGINE.md)  
**Program:** Studio OS World Experience™  
**Parent:** Genesis™ · Studio OS Design DNA™  
**Runtime:** canonical architecture draft — runtime implementation pending  
**Compiled guide:** [`../../docs/studio-os/genesis/EXPERIENCE_ENGINE.md`](../../docs/studio-os/genesis/EXPERIENCE_ENGINE.md)

Experience Engine™ is the platform-wide generator for branded operating environments.

It consumes layered Experience DNA™ files:

```text
Brand DNA™
  -> Department DNA™
    -> Division DNA™
      -> Scene DNA™
        -> Component DNA™
          -> Motion DNA™
            -> Interaction DNA™
              -> Experience™
```

## Relationship to Studio OS Design DNA™

Studio OS Design DNA™ is not redesigned or diluted.

It becomes the first official Brand DNA™ / Experience DNA™ profile consumed by
the Experience Engine™.

## Canon rule

Studio OS owns the engine. Companies own DNA. Experiences are generated from
layered DNA, not handcrafted redesign.
