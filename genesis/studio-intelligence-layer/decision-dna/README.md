# Decision DNA™

Founder decision model for recommendations.

Captures risk tolerance, speed vs quality, luxury vs affordability, innovation
vs convention, automation preferences, leadership style, approval patterns,
trade-off philosophy, long-term thinking, platform philosophy, decision
confidence, decision history, and decision outcomes.

Orb™ uses Decision DNA™ to make recommendations that feel like founder judgment
scaled through Studio OS.
