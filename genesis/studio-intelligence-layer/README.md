# Studio Intelligence Layer™

**Canonical article:** [`../articles/STUDIO_INTELLIGENCE_LAYER.md`](../articles/STUDIO_INTELLIGENCE_LAYER.md)  
**Status:** Architecture drafted; runtime implementation planned  
**Purpose:** Executive reasoning layer that lets Studio OS understand how companies operate, decide, create, sell, learn, and evolve.

---

## Systems

| System | Role |
|--------|------|
| **Company Operating Manual™** | Living operational doctrine every AI worker consults before acting |
| **Decision DNA™** | Founder decision model and recommendation preferences |
| **Taste Genome™** | Founder creative fingerprint and aesthetic learning |
| **Canon Engine™** | Canonization governance and approval pipeline |
| **Experience Compiler™** | Intelligence-aware experience assembly compiler |
| **Audience DNA™** | Permanent audience intelligence model |
| **Product DNA™** | Product identity, launch, lifecycle, and content intelligence |
| **Creative Genome™** | Creative knowledge graph across campaigns, assets, decisions, and approvals |

---

## Relationship to existing systems

```text
Company Genome™ + Brand DNA™ + Institute of Knowledge™
  + Experience Engine™ + Experience Runtime™ + Mission Engine™
    -> Studio Intelligence Layer™
      -> Executive recommendations
      -> Canon candidates
      -> Complete branded operating environments
```

Studio Intelligence Layer™ does not replace founder approval. It prepares
evidence, trade-offs, recommendations, and canon candidates.
