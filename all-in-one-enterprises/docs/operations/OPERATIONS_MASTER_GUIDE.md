# OPERATIONS MASTER GUIDE — All In One Enterprises Inc.

**Version:** 1.0 · **Effective:** 2026-08-16

## Operating model

All In One is the **business office behind the truck** — coordinating permitting, compliance, dispatch assistance, and partner-facilitated services. Software supports staff workflows; **regulated activities require verified business authorization**.

## Customer lifecycle

Public Site → Get Started / Road Ready → Account → Documents → Service Request → Staff Processing → Billing → Completion → Renewals

## Staff roles

OWNER · ADMIN · MANAGER · PERMITTING_SPECIALIST · DISPATCHER · CRM_SALES · CUSTOMER_SUPPORT · FINANCE · DOCUMENT_REVIEWER · SECURITY_ADMIN

## Daily operations

1. Review Office Command Center attention items
2. Process document review queue
3. Advance service workflows
4. Respond to customer messages
5. Check renewals/deadlines
6. Reconcile payments (when active)
