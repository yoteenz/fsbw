## Mission & Documentary Philosophy

### Mission

Social media should function like a **documentary crew** embedded inside a living technology company.

Every announcement, meeting, launch, employee introduction, keynote, award, celebration, lesson, and innovation **first occurs inside Studio World**. Only afterward is it distributed publicly.

### Core philosophy

```
STUDIO WORLD (events happen — always)
        ↓
STUDIO CHRONICLE (official record — truth)
        ↓
MEDIA & DOCUMENTARY DEPARTMENT (capture — evidence)
        ↓
HQX (broadcast staging — transmission)
        ↓
PUBLIC CHANNELS (windows — not origin)
```

**Laws:**

1. **Nothing is created for social media.** Social documents what already happened.
2. **Event before post.** No orphan public artifacts.
3. **Chronicle is truth.** Public content may simplify — never contradict canon.
4. **Cameras exist in-world.** Audience feels documentary coverage, not ad production.
5. **Careers unfold.** Story Arc Engine tracks employee evolution over years.
6. **World runs without audience.** Departments work when nobody is logged in; social reveals moments.

### What this sprint is NOT

| Not this | Because |
|----------|---------|
| Content strategy sprint | Philosophy — not editorial calendar |
| Social media planning | No post quotas · no engagement hacks |
| Marketing sprint | Documentary coverage — not campaigns |
| Content generation | No AI post factories in this phase |

## The Golden Rule & Event-First Law

### The golden rule

> Every public post must answer: **"What actually happened inside Studio World?"**

### Event-first gate

Before any public distribution:

| Gate | Question | Fail action |
|------|----------|-------------|
| **E1 — Event** | Did a real event occur at a named place? | **Stop** — no post |
| **E2 — Chronicle** | Is there a Chronicle entry or draft event ID? | **Stop** — record first |
| **E3 — Participants** | Are presenters in workforce registry (or guest canon)? | **Stop** — identity first |
| **E4 — Evidence** | Does Media Department have capture assets? | **Defer** — document when ready |
| **E5 — HQX** | Did transmission pass HQX pipeline (if public)? | **Stop** — no side-channel posts |

### Event types (canonical)

| Category | Examples | Typical location |
|----------|----------|------------------|
| **Organizational** | New hire · promotion · reorg | Directory · department office |
| **Ceremonial** | Award · graduation · anniversary | Arena · Institute · HQX stage |
| **Executive** | Council meeting · strategy review | Council chamber · boardroom |
| **Creative** | Concept presentation · golden build | Creative Studios · Works |
| **Educational** | Lesson ship · certification | Institute classroom |
| **Broadcast** | Genesis Briefing · keynote | HQX |
| **Innovation** | Prototype unveil · lab result | Labs · Forge |
| **Founder** | Founder's Address · decision | HQX · executive floor |

**If nothing happened:** silence is correct. Empty weeks are not filled with graphics.

## Studio Chronicle Architecture

### Chronicle thesis

The **Studio Chronicle™** is the chronological **official history** of Studio — every documented event receives a permanent record.

Aligns with [Civilization Bible § Studio Chronicles](../docs/studio-world/STUDIO_WORLD_CIVILIZATION_BIBLE.md#section-xi--the-studio-chronicles).

### Chronicle event schema

| Field | Requirement |
|-------|-------------|
| **Event ID** | `CHR-YYYY-NNNNNN` — immutable |
| **Date** | When event occurred in-world (not publish date) |
| **Location** | Atlas address · building · room · zone |
| **Participants** | Employee IDs · founder flag · guest IDs |
| **Department** | Primary originating division |
| **Event Type** | From event taxonomy |
| **Summary** | Neutral factual abstract (1–3 sentences) |
| **Media Assets** | Documentary captures · links to vault |
| **Transcript** | Meetings · keynotes · interviews (when applicable) |
| **Historical Importance** | `routine` · `notable` · `milestone` · `legendary` |
| **HQX Transmission Ref** | Optional `HQX-YYYY-NNNN` if publicly broadcast |
| **Story Arc Refs** | Links to employee arc milestones |
| **Pillar** | LEARN · CREATE · LEAD · DISCOVER (Civilization) |

### Chronicle vs. public post

| Chronicle | Public post |
|-----------|-------------|
| Complete truth | Window into truth |
| Permanent | Channel-formatted variant |
| Internal + external cite | Never contradicts Chronicle |
| Written at event time | Distributed after HQX staging |

### Chronicle write paths

```
Event occurs in Studio World
        ↓
Department or Council logs event (draft)
        ↓
Media Department attaches evidence
        ↓
Chronicle Liaison assigns Event ID + importance
        ↓
Chronicle sealed (amendments only via successor entry)
        ↓
(Optional) HQX transmission references CHR-ID
```

**Law:** Chronicles are **never deleted** — deprecation adds lineage note.

### Proposed module

```
src/studio-os-core/living-timeline/
├── chronicle-registry.ts      # Single writer — event truth
├── event-taxonomy.ts
├── story-arc-engine.ts
├── calendar-registry.ts
├── documentary-refs.ts
└── bridges/
    ├── workforce-registry-bridge.ts
    ├── hqx-bridge.ts
    ├── atlas-timeline-bridge.ts   # Atlas replay pins
    └── world-graph-bridge.ts
```

## Story Arc Engine

### Purpose

Employees **evolve over time**. The audience watches careers unfold — not static personas.

### Arc milestone types

| Milestone | Chronicle trigger | Public documentary |
|-----------|-------------------|----------------------|
| **Promotion** | `promoted-to` edge + ceremony | HQX stage · press photo |
| **Mentorship** | `mentors` edge activated | Interview segment |
| **New responsibility** | Project lead assignment | Behind the Build |
| **Cross-department project** | `collaborated-on` | Department documentary |
| **Conference presentation** | External speak event | Clip from HQX |
| **Institute teaching** | Faculty flag + course | Institute Session |
| **Leadership change** | Manager edge update | Executive Memo coverage |
| **Award** | Employee Awards tradition | Ceremony footage |

### Arc record (proposed)

```typescript
interface StoryArcMilestone {
  milestoneId: string;
  employeeId: string;
  chronicleEventId: string;      // CHR-...
  arcType: StoryArcType;
  narrativeSummary: string;      // documentary voice — factual
  occurredAt: string;
  publicCoverageRefs: string[];  // HQX · social variant IDs
}
```

### Arc rules

1. Arcs derive from **Chronicle + Relationship Engine** — not invented per campaign.
2. Multi-year arcs encouraged — promotion is one chapter, not the whole story.
3. Founder arcs parallel employee arcs (Founder Journey™ integration).
4. Guest experts have bounded arcs with expiry.

## Documentary Production Standards

### Media principle

> Never create "marketing graphics." Create **coverage of a real company.**

### Approved media forms

| Form | Use |
|------|-----|
| **Press photography** | Employee portraits · executive stills · event photos |
| **Behind-the-scenes footage** | Departments at work · launch prep |
| **Conference photography** | Summit · HQX Conference · Expo |
| **Documentary interviews** | Employee Spotlight · leadership |
| **Press releases** | Factual Chronicle abstract — not hype copy |
| **Employee portraits** | Registry headshots · annual refresh |
| **Award ceremonies** | Stage · audience · recipient |
| **Executive broadcasts** | HQX transmissions |

### Forbidden forms

| Form | Why |
|------|-----|
| Feature bullet graphics | Marketing — not documentary |
| Stock photography | Breaks immersion |
| Anonymous quote cards | No event · no person |
| Engagement bait templates | Not history |
| UI screenshot posts (primary) | Product demo ≠ world event unless staged in HQX |

### Production quality bar

1. **Establishing place** — viewer knows where they are in Studio World
2. **Named people** — registry IDs for every on-camera employee
3. **Event ID visible** — subtle Chronicle or HQX reference in metadata
4. **Factual voice** — documentary narrator · not sales copy
5. **Archive-ready** — every asset lands in vault with CHR linkage
